# 分类基线

## 已经用户逐类确认的展示

“数量”指预览头部的精确数量；调用方可以传数量标签。未列出的冗余字段不自动补入。

| 类型 | 名称与头部顺序 | 正文与描述 | 禁止回退 |
| --- | --- | --- | --- |
| 装备 | 装备原名；类型＝槽位（法兵显示 `法兵 · 器形`，旧武器缺省器形按剑）→ 要求＝境界阶段（如 `炼气初期`）→ 五行（有则显示）→ 可选铸造者 → 可选已穿戴；无持有数量 | 器胚属性、附灵属性；器蕴／器诀按名称独立展开，默认收起；器诀展开后只显示直接战意消耗；有实际比较对象时折叠展示比较；存在 desc 时在底部独立展示，最多60字；铸造者来自打造时的名称快照 | “可御使”、双加合计、归元后消耗；无事实时编造描述、五行或铸造者 |
| 图纸 | `境界＋期＋槽位`，如 `炼气期法兵`；类型＝道装图纸 → 产物境界＝炼气期 → 数量 | 无重复资料组；完整保留 `记载法兵铸造之法的图纸，铸造时消耗1张。` 这类描述 | 名称“图纸”后缀；重复部位／铸造境界；把炼制门槛当成产物境界；截短描述 |
| 传承灵印 | 所携技能名，如 `噬血`、`高级连击`；类型＝普通／上品 · 传承灵印 → 数量 | 所载传承下面直接显示技能信息；底部保留灵印描述 | 泛称作标题；重复技能名称；第三层缩进 |
| 归元灵露 | 原名；功能＝灵兽洗炼 → 要求＝不高于金丹（普通）／不限境界（上品）→ 数量；不显示类型 | 洗炼效果集中展示重置等级、重孕资质／成长／天生技能、寿命恢复原上限；底部描述去除重复效果和境界枚举 | 名称与类型重复；冗长境界要求；效果与描述重复 |
| 功法玉简 | 功法名，如 `轻风诀`；类型＝功法玉简 → 传承境界 → 数量 | 所载功法下面直接显示功法效果；保留底部玉简描述 | 名称“玉简”后缀；传承境界埋在正文；重复功法名／第三层缩进 |
| 丹药 | 原名；类型＝品质 · 丹药 → 丹相（有则显示）→ 功能 → 数量 | 效果、实际代价／服用规则、默认收起的炼制信息；保留原描述 | 道具资料、丹评、要求；丹相放在功能下方；无丹毒、不占服用额度 |
| 灵果 | 原名；类型＝品质 · 灵果 → 功能 → 数量 | 效果与实际适用限制；有查看者上下文时展示有用的预计效果；保留原描述，空规则组省略 | 要求、泛化造化来源、无丹毒、不占服用额度、无上下文时的占位说明 |

### 语义边界

- 装备比较的箭头表达与比较装备的属性差异，不冒充穿戴后的角色最终面板变化。装备颜色来自原始 equipmentLevel 对应境界，器蕴不改变分级颜色。
- 图纸“产物境界”来自产物等级对应的境界；炼制最低境界由炼器玩法提示，不搬进预览。示例境界文案以项目正式配置为准，不进行全局改字。
- 灵印普通／上品对应实际技能层级；已失效的技能保留实际失效状态，不伪造正常效果。
- 灵露要求来自 allowedRealms。当前普通范围可概括为“不高于金丹”；未来若范围不连续，不能只取最大值概括。
- 当前灵露普通描述为 `涤去后天积累。`，上品为 `元婴及以上物种须用此露；不额外提高资质、成长或多技能概率。`。后一句区分上品真实作用，不属于泛化“无副作用”占位。
- 丹药真实丹毒、额度占用及灵果实际境界过强／过弱限制仍需保留。隐藏“无丹毒”不改变或隐藏有丹毒的事实。当前丹药代价组名为“代价”。

## 未逐类重新设计的现有类型

以下记录现状以便保持一致，不把现有每个字段推广为新类型的必填模板；未经本次需求涉及，不顺手重设计。

| 类型 | 当前头部 | 当前正文 |
| --- | --- | --- |
| 材料 | 品质 · 材料类别 → 数量 | 有五行时展示资料组；描述在底部，不另套“材料特性”重复描述 |
| 灵种 | 品质 · 灵种 → 功能＝灵田培育 → 要求＝最低境界及以上 → 数量 | 五行、存在时的培育线索，底部原始种子描述；事实来自 SeedFactsSchema 的 seedSpec.plant |
| 符箓 | 品质 · 符箓 → 数量 | 用途、符箓效用、底部描述；用结构化行，不为对齐丹药而补要求、丹相等字段 |

## 旧宝库边界

- 功法典籍 `gongfa_manual`、神通秘术 `skill_manual` 是继续保留的材料，取出统一转换为 `material.v1`，保留原类型、名称、品质、五行和描述；取出本身不映射为功法玉简或传承灵印。功法典籍可在悟道室通过独立参悟流程消耗并获得新版功法玉简；神通秘术不参与该玩法，不恢复旧抽取。
- 旧法宝不再用于新版。未鉴定材料及缺少有效生长数据的历史灵种硬弃用，不能鉴定、补齐事实或迁移。
- 旧宝库使用文字列表，不为了复用物品格新增历史数据展示兼容。桌面左侧旧藏取出、右侧公共物品栏；移动端物品栏使用抽屉，取出后可立即查看。

## 新道具接入时的判定

先选已有事实类型与适配器。同类新增内容沿用该类顺序，不因单个道具名称、描述长度或 ID 添加特判。新类型只列真实且帮助识别／决策的头部字段；效果按语义分组，描述独立，默认非限制不写。新规则若不能准确映射现有契约，说明具体缺口并做最小扩展，不能仅为了“可扩展”放开递归布局或任意正文组件。
