# 解谜场景插画

## 用途与边界

一张底图对应一类地貌，由多个秘境共用。画这一类地方的典型空间与气象，避免某个节点独有的地标、人物或事件。类别以 [`DUNGEON_SCENE_KIND_VALUES`](../../../packages/game-domain/src/world/map.ts) 为准。

- 节点到类别的对应以 `packages/game-content/src/world/data/map.json` 中各节点 `dungeon_config.scenario.scene` 为准；为某类出图前读取属于该类的节点设定（`setting`、`places`、`objects`），提取它们共有的空间与器物，不取某一节点独有的地标。
- 不画人物、妖兽、文字、题签、印章、边框或界面元素；不画能被误读为线索的具体物件（尸骸、钥匙、信件、机关部件）。

## 笔墨语言

继承写意墨像与水墨地图的同一套笔墨：暖灰宽笔墨面、少量浓墨支点、中淡墨、飞白与留白。场景插画比地图更近、比立绘更远，是“一眼的气象”而非细节图。

| 维度 | 原则 |
| --- | --- |
| 构形 | 以几块有方向的墨面建立空间骨架：洞口、殿檐、塔身、林带、岸线、冰壁等主结构用实笔，其余散入留白。不铺满画面，不做远中近三层都精描的风景画。 |
| 浓淡 | 画面大部分为中淡墨与留白。浓墨只留一两处靠边的结构支点，避开贴底取景后的题签文字区。 |
| 彩墨 | 可按地貌身份加极少量低饱和彩墨（如冰窟的淡青、魔域的淡赭紫、药园的淡石绿），用于辨识而非渲染；不加光效、发光、雾气特效。 |
| 气氛 | 来自空间开合与虚实（幽深、空旷、压抑、苍茫），不靠题字、飘带、粒子或电影光照。 |
| 纸感 | 由笔墨本身承担，不叠加噪点、裂纹、做旧纸张贴图。 |

## 构图与叠放

- 横向构图，主结构放在两侧或下缘，中央偏上约半幅尽量留白。现有界面统一贴底取景并渐隐上缘。开局与调查页题签使用 2:1 并叠标题，调查段落另排。案情板“地点”页将图独立显示为 2:1，秘境介绍窄屏用 2:1、宽屏用 3:1。
- 题签文字在裁切后的画幅内居中。以页面纸色和素材正常不透明度检查这片区域，墨色不深于极淡灰。贴底裁切和上缘渐隐后，关键结构仍须完整可辨。
- 交付真实透明素材，留白与墨迹外完全透明，淡墨和飞白保留半透明。纸色生成稿可按画面本身纸色做去纸色（color to alpha），分离墨色与透明度。界面上缘渐隐用于柔化裁切边缘，去纸色在素材交付前完成。

## 设计与制作

根据同类节点的共有空间确定骨架、留白与彩墨。按 imagegen 流程制作，可用[写意墨像的固定基准](../daoyou-ink-portraits/SKILL.md#生成前先看固定参考)参考笔墨。

## 交付

- 正式素材：`apps/web/public/assets/mystery/scenes/{scene}.webp`（带透明通道），键名与 `DUNGEON_SCENE_KIND_VALUES` 一致；在 `apps/web/src/routes/game/dungeon/components/mysteryArt.ts` 登记后才会显示，未登记的类别不显示底图。
- 按实际显示宽度与设备倍率选择分辨率与压缩，检查压缩后飞白与淡墨是否糊掉。
- 项目内只保留生产素材；母稿、提示词与中间版本不入库，交付后清理临时文件。

## 验收

对照独立图、2:1 题签叠字和 3:1 秘境介绍，核验纸色背景上的实际效果。

1. **辨识**：遮去名称，能否从空间与器物认出是哪一类地方？能否和其他类别区分？
2. **从属**：题签标题是否清楚可读？浓墨是否避开了叠字区域？
3. **笔墨**：是否仍是暖灰宽笔、飞白、留白的同一体系，而不是写实风景或做旧滤镜？
4. **干净**：没有人物、文字、印章、边框、可被当成线索的物件；在深色背景上检查透明通道，没有残留纸色、灰边或矩形边。
5. **裁切**：两种取景下地貌的关键轮廓都清楚，墨迹边缘自然渐隐。
