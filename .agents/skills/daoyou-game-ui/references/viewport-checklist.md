# 主流程场景验收清单

- 对照 [场景结构](../SKILL.md#场景结构)，在桌面和窄屏打开受影响场景，检查首屏、正文操作与离开入口。只改局部组件时，检查实际使用该组件的场景。
- 改动共享壳或全局入口时，抽查入口型、流程型和列表或服务型场景。检查顶部 HUD、底部导航及安全区，确认世界聊天与正文按实际底栏高度避让，键盘和弹层不会挡住当前操作。
- 改动路由时，从相关导航入口进入并返回，再直接打开受影响的地址，核对场景标题、导航状态与滚动归属。
- 执行 [仓库验证规则](../../../../AGENTS.md#verification-checklist)，并按 [测试规范](../../../../docs/testing.md) 做受影响场景的本地浏览器检查。
