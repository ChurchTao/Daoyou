# 灵田灵植设计

先读 [百草志目录](../../../docs/spirit-garden-catalog.md) 和 [现行配置](../../../packages/game-content/src/spirit-field/data/garden.json)。目录提供物种与品阶的设计基准，配置和运行规则决定实际成长与收成。只做设定或美术时，按任务范围交付候选方案。

## 物种与品阶

- 每株先定一个玩家能复述的特征，再写出**成株名、品阶理由、株形与习性、采收部位、基础产物和特化用途**。将候选与同阶及相邻阶物种并排比较，至少有一处能从株形、习性或采收上直接认出。色相、元素、数值与修饰词用于强化这个区别。
- 名称顺口、易读、能联想到形态或用途。优先用玩家熟悉的字词和修仙意象，如玉髓芝、紫猴花、金雷竹、霓裳草。采用《凡人修仙传》《遮天》等已有意象时，保留真正有辨识度的特征，区分可核对的原设与万界道友的改编。游戏内药效、成长条件和获取方式以实际规则为准。
- 用品阶解释灵性从何而来。凡品是山野常药，灵品有可观察的灵性，玄品有明确的炼丹用途，真品以通灵习性立身，地品依赖特殊生境，天品承受天地之气，仙品有独到造化，神品应有镇册的传说和形象。低阶也要有记忆点，高阶的份量靠特征与设定支撑。
- 让习性、采收部位与收益互相印证。基础药材和特化产物各有出处。描述涉及丹方、采收条件、战斗或复生时，先核对当前实现，再决定哪些属于传说、哪些能写成玩家可用效果。

## 固定笔墨基准

制作或评审立绘前，用图片查看工具打开 [毕方](../../../apps/web/public/assets/icons/beast-bifang.webp)、[麒麟](../../../apps/web/public/assets/icons/beast-qilin.webp)、[白泽](../../../apps/web/public/assets/icons/beast-baize.webp)，并对照 [凡品图谱](../../../apps/web/public/assets/spirit-garden/botanical-garden-fan.webp) 的甘草和 [天品图谱](../../../apps/web/public/assets/spirit-garden/botanical-garden-tian.webp) 的金雷竹。前三张是笔墨与配色参考，后两张展示笔墨在植物剪影和阶段图格里的落位。新稿始终回对这些基准，基准更新以用户确认的新样张为准。

- 使用写意国画水墨。宽笔墨面先组织枝干和叶丛，少量浓墨压住识别支点，淡墨、飞白和留白分开层次。彩墨落在能辨认的器官上，如花瓣、竹节、根须或果实。色相随物种特征选取，墨色承担主要构形。
- 保留主体剪影与真实透明的负形。背景和图格间隙留空，浅色花瓣、淡墨和半透明笔触边缘保留层次。写实细描、满幅纹理、发光轮廓和纸底会削弱小尺寸下的株形，发现这些特征时回到笔墨与素材修正。
- 使用内置 ImageGen 制作栅格立绘。给工具注明固定基准提供笔墨与配色，本株成株图可提供构形参考。批量制作前先看一株完整阶段样张，最终提示词、参考与采用稿记录在 [立绘生成记录](../../../docs/art/spirit-garden-atlas-prompts.json)。

## 生长形态

先定成株的骨架、根部落点与识别器官。成株图可以作为同株其他阶段的构形参考，成图仅用于成株行。每个可达阶段都交付独立画面，用分杈、展叶、开花、结果或根系展开改变剪影，缩放与色相只作辅助。

| 图谱行 | 阶段 | 画面要点 |
| --- | --- | --- |
| 0 | 幼苗 `seedling` | 保留最初的叶、芽或菌体，显出初生轮廓。 |
| 1 | 成株 `mature` | 完整呈现最容易辨认的株形，作为百草志标本。 |
| 2 | 蕴灵 `nurtured` | 加入符合物种的结构变化。投入灵气完成定向后才显示，画面共用于繁茂与特化方向。 |
| 3 | 蜕变 `evolved` | 成功完成蜕变才显示。沿用同一物种的骨架与原种品质，以新结构体现变化。蜕变提升之后的产物品质，生产周期随产物品质调整。神品以蕴灵为终态，末行透明。 |

田块、详情和保种阁按 [共享规则](../../../packages/game-rules/src/spirit-field/garden.ts) 的实际阶段取图，百草志取成株行。

## 接入与验收

- 当前目录八阶各四株，每阶一张 `1152×1536` 透明 WebP，按四列四行排列，每格 `288×384`。同株根部约落在格高的 88%，留足透明间隙。交付到 `apps/web/public/assets/spirit-garden/`，以 `portrait.atlas/index` 指定文件和列。取图沿用 [BotanicalArt](../../../apps/web/src/routes/game/spirit-field/components/BotanicalArt.tsx) 与 `GameImage`。生成草图的画布尺寸和排版可按需要调整，交付以实际切图为准。
- 接入前确认本次是物种设计、已授权替换还是扩容。四列已经排满，增加名额涉及 [运行时校验](../../../packages/game-content/src/spirit-field/garden-schema.ts)、[编辑器 schema](../../../packages/game-content/src/spirit-field/data/garden.schema.json)、图谱寻址与百草志展示。扩容可先评估追加同规格图谱，保留已有格位、物种 ID 和已存事实。核对物种顺序、元素对旧种匹配的影响，并检查种子生成、在田株、保种、图录和待领收成。
- 按 [配置指南](../../../docs/spirit-garden-content.md) 核对品阶、成长时间和产物。灵种名由「成株名的种子」派生。复合灵果的有效药性共享一份同品预算，灵兽修为保持独立。改内容和规则时遵循 [领域技能](../daoyou-game-core-domain/SKILL.md)，改场景布局或预览时使用相应的 [游戏 UI](../daoyou-game-ui/SKILL.md) 和 [物品预览](../daoyou-item-preview/SKILL.md) 规范。
- 美术验收同时查 alpha 和纸色、深色底合成。检查外缘、格间隙与内部留白，确保没有白底、脏边或串格。以手机田块约 85px、桌面约 139px 和百草志册签的实际尺寸查看。遮住标签仍应认出物种和阶段，去色后主要剪影仍有区别。通过后在 360px 与桌面实际页面确认切图、阶段和产物展示。按改动范围执行仓库规定的验证。
