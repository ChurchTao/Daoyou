# 首版灵兽设计确认基准

确认日期：2026-09-12。来源：用户在本项目任务中确认的第二版物种设计、资质成长表、随后确认的出生技能表与配套规则。

这是设计基准，不是代码上线清单或平衡验证报告。旧稿的固定定位、每种四项成套技能、雷羽鹰、逐风豹、镇岳龟等不属于本版。具体执行约束见 [SKILL.md](../SKILL.md)。

| 元婴 | 银翅螳螂 | 银灰甲壳、弯刃状前肢，贴背薄翅近乎透明；长时间静伏，出击时连续挥斩 |

| 化神 | 雷鹏 | 苍青巨翼、银色颈羽、深紫翼尖，在云海雷区积蓄雷息；属于高阶雷禽，不等同鲲鹏 |
| 化神 | 六目灵猿 | 灰白长毛，双目之外眉侧各有两枚小灵目，攀行古林，遇敌灵目逐次睁开观察动作 |

炼气是山野开灵；筑基为天赋稳定的禽虫走兽；结丹是能长期占据灵地的成熟异种；元婴引入成熟蛟类、凶虫、地脉妖兽；化神体现深厚血脉与特殊生命形态。此分层不分配战斗角色。

## 4. 不应在“优化”时丢失的取舍

- 狼不自带必杀、吸血；螳螂可能获得普通必杀，但没有偷袭、吸血成套附赠；雷鹏不自带法连、法暴、灵法精通。兽决培养仍有明确作用。
- 墨蛟的高级毒只通过普攻触发，水漫金山不附毒；保留毒牙和御水的共同身份，不修成隐藏的法术中毒机制。
- 玄甲龟的迟钝可保留也可覆盖。候选不是对每种最终培养方向都有用，不以“不能组成最佳搭配”为由自动替换。
- 冥灯蝶可能没有攻击法术，可选自带水攻的个体或通过兽决调整。普通与高级鬼魂术在确认时效果相同，核心使用普通鬼魂术；不为了化神标签机械换成高级版。
- 出生数量与资质、成长独立；不设关联保底或惩罚。二至四格是首版规则，不因扩展境界就自动增加五格或更多高级天赋。
- 各大境界初期开放三种并进入对应野外捕捉池，首版不另分稀有概率层级。免费伙伴采用所属物种的同一出生表。
- 旧捕捉额外技能抽签被本表替代；存量个体不重抽、不重置。设计确认不等于这些生成与捕捉改造已经完成。
