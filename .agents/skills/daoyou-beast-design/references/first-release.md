# 灵兽设计确认基准

初版确认日期：2026-09-12。最新定稿日期：2026-09-18。来源：用户确认的首版数值与出生规则，以及本轮命名、形态、物种替换和新增设计。当前共十六种：炼气、筑基、金丹、化神各三种，元婴四种。本文统一使用当前配置的“金丹”称呼。

这是设计基准，不是代码上线清单或平衡验证报告。物种配置（内容修订7）、野外捕捉池（内容修订5）和相关地图文案已按本轮定稿同步。现有头像素材沿用，狰与三足金蟾暂用豹、蛙 emoji，专用头像尚未制作。旧稿的固定定位、每种四项成套技能、雷羽鹰、逐风豹、镇岳龟等不属于本版。具体执行约束见 [SKILL.md](../SKILL.md)。

| 元婴 | 狰 | 沿用传统异兽赤毛、独角、五尾的轮廓，生态和天赋解释为本项目设计；如健壮山豹，赤褐短毛，额生后弯黑角，五尾分展如扇；独居灵脉石岭，伏卧时垂尾感知气流与震动，交锋转身卸力后回爪反击；正式名称仅“狰” |
| 元婴 | 三足金蟾 | 浑圆三足，暗金皮肤，金色背疣间透朱红细纹；腹内天生火囊，蹲伏地火泉眼吞吐热息；施法喉腹鼓起，红纹亮如炭火，张口吐大片烈焰；法力资质突出，擅长火系法术 |

炼气是山野开灵；筑基为天赋稳定的禽虫走兽；金丹是能长期占据灵地的成熟异种；元婴引入成熟蛟类、凶虫、地脉妖兽；化神体现深厚血脉与特殊生命形态。此分层不分配战斗角色。

## 4. 不应在“优化”时丢失的取舍

- 精灵狼以隐身、偷袭替换原连击、偷袭，不自带凶猛、噬血；螳螂可能获得普通凶猛，但没有偷袭、噬血成套附赠；雷鹏不自带灵力相续、灵涌、灵性。传承灵印培养仍有明确作用。
- 墨蛟的高级毒性只通过普攻触发，洪流不附毒；保留毒牙和御水的共同身份，不修成隐藏的法术中毒机制。
- 蛇颈玄龟的迟钝可保留也可覆盖。候选不是对每种最终培养方向都有用，不以“不能组成最佳搭配”为由自动替换。
- 冥灯蝶可能没有攻击法术，可选自带激流的个体或通过传承灵印调整。普通与高级魂生在确认时效果相同，核心使用普通魂生；不为了化神标签机械换成高级版。
- 出生数量与资质、成长独立；不设关联保底或惩罚。二至四格是首版规则，不因扩展境界就自动增加五格或更多高级天赋。
- 各大境界初期开放本表对应物种并进入对应野外捕捉池；元婴四种，其余境界各三种，不另分稀有概率层级。免费伙伴采用所属物种的同一出生表。
- 旧捕捉额外技能抽签被本表替代；存量个体不重抽、不重置。设计确认不等于这些生成与捕捉改造已经完成。
