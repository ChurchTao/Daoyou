# 水墨技能图腾提示词

先核对技能机制并选择主体，再填写下列内容。固定风格段用于保持画种和构形关系；不要为了“高级感”追加写实材质、光效和细纹。数字与形状数量只在当前技能需要时指定，不成为整个系列模板。

## 共用风格段

```text
Use case: stylized-concept.
Asset type: ONE original transparent skill icon for 万界道友, shown at 24–40px.
为中国修仙游戏制作一枚水墨技能图腾。先有可辨认、可命名的形象／器官／纹样，再让辅助形与主体咬合成紧凑完整的印记。用短勾、块面、重复节奏和大块透明负形组织结构，避免任意笔刷符号。暖炭墨与暖灰墨为主，粗厚宽笔承担结构，少量方向明确的飞白和局部灰洗表现干湿。局部沉稳矿物彩墨落在识别支点，与墨色自然衔接。平面的象征性构形，保留手绘笔墨变化，不做均匀矢量细描边、写实材质、浮雕高光或全图裂纹噪点。
参照本 skill 冻结的三枚最终稿，保持主体层级、墨笔尺度、浓淡和负形关系；不复制它们的眼、爪、云形来套用新技能。
正方形画布，单枚完整图腾居中，留适当安全空间，不截断主结构；外底及设计留白孔隙都是真透明。24px 仍能识别主体与必要关系。无纸张、棋盘底、文字、印章、水印、徽章底盘、统一外框、发光、粒子或背景景物。
```

## 技能与构形段

```text
技能名称／机制事实：[实际效果；重点说明易混淆机制]。
第一识别主体：[眼、爪、盾、焰、咒纹等；为什么支持这个技能]。
必要行为线索：[接续、包裹、爆发、反向、阻挡等；不画完整战斗场景]。
整体结构：[主辅大小、连接／对扣／咬合／重复关系、方向和外轮廓]。
关键负形：[哪些开口、孔隙或间隔在24px仍须分开]。
墨彩组织：[深墨结构支点、灰洗／飞白位置、局部彩墨的身份与落点]。
同组区别：[与容易混淆的已有图标在主体或轮廓上如何不同]。

```

## 三个采用方案示例

这些是特定技能的构形，不是全系列默认造型。

- **观照万象**：一只大横眼是焦点，左右对扣角勾组成紧凑神目纹，赭金墨瞳；眼眶与瞳之间大块留白。不增加第二只眼、虹膜细环或独立攻击场景。
- **嗜血追击**：清楚的三趾兽爪，有掌部与弯曲爪尖；前大后小的两枚同向爪以短根接续，前爪局部朱砂。读到“击倒后续攻”，不画吸血嘴或血滴；这些避免项只针对当前机制。
- **出奇制胜**：两块对扣粗云勾藏住法势，一枚深灰紫四尖法芒从缺口骤出；云内孔隙大，法芒有足够分量。不要回到多层碎云和浅白发光芯，不增加雷电属性的暗示。

## 定向修改

编辑时明确给出目标、只改的主要偏差和必须保留的结构；示例：

```text
保留单枚藏云法芒图腾、暖墨／灰紫配色和真实透明底。只减少云勾层次并增强法芒识别：多层云瓣收成两块粗云勾，保留大孔隙；法芒改为有分量的深灰紫墨面，去掉浅白芯和材质高光。四芒从云口突出，与主体咬合，保持完整框内构图。不要添加闪光线、拖尾、符文或背景。
```

修改后重新看小尺寸与固定基准。提示词要求不等于输出已经满足，最终采用图以视觉验收为准。
