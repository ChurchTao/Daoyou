# 写意墨像

## 风格定义

古籍中的修士墨像，介于人物剪影与国画人物之间。**墨迹构成形体，少量浓墨、宽笔淡墨、飞白与留白共同完成角色。** 先服务游戏界面的识别与层级，再考虑独立欣赏；不把写实白衣立绘降低饱和度或透明度当作水墨画。

## 生成前先看固定参考

用图片查看工具打开与当前任务相关的参考；男女成套、跨角色或首次建立系列时同时查看两张：

- [男修基准](references/male-baseline.webp)
- [女修基准](references/female-baseline.webp)

两图是 2026-09-10 当前页面成稿的冻结副本，用于固定宽笔肌理、暖灰墨色与浓淡关系。它们仍有简化眉眼及连贯衣袍轮廓，不把这些细节当作必须复制的身份模板，也不声称已经完全达到纯减笔画。发生冲突时以用户最新要求和下列规范为准。

生成工具支持参考图时，把它们明确标为**笔墨参考**，不是必须保留脸、衣服或姿势的编辑对象。不要把最新生成的未验收图接续作为唯一风格参考，避免逐轮漂移。仅在用户明确接受更新基准时更换这两张参考；普通生成不改 skill 基准。

## 不随角色变化的规范

| 维度 | 必须保持的关系 |
| --- | --- |
| 形体 | 用宽笔墨面与少量长线概括；允许轮廓局部断开，留白补全形体，不依靠均匀描边封闭每个部位。 |
| 墨色 | 暖灰墨色为主体，少量深墨建立发式、肩背、衣侧或主体结构；中淡墨连接形体，不额外加入青色、金色或彩色光效。 |
| 飞白 | 体现毛笔行进中断续露底与干湿变化，服务结构方向；不是全图叠加噪点、裂纹或纸张贴图。 |
| 衣袍／躯体 | 几块墨面形成组织关系，不逐条刻画衣褶、鳞片、肌肉；避免材质渲染、层叠白衣和写实体积光。 |
| 头面 | 允许少量眉眼鼻墨点提示朝向与神态，不精修成具体演员般的面孔。留白须与笔墨自然相接，不能先画完整脸框再抹去五官。 |
| 边缘 | 局部实、局部虚，下摆或肢体末端可散入留白；主体重心仍明确，不能糊成一团或像残缺肢体。 |
| 气韵 | 来自疏朗、稳定、轻重与虚实关系，不依赖飘带堆叠、风吹长发、光环、粒子或发光轮廓。 |
| 系列一致性 | 性别、年龄、阵营与强弱不改变笔墨语言；不能男版厚重写实、女版华丽唯美、BOSS 改成高精度概念海报。 |

用户明确要求的标志性色彩、特殊姿态或装备可作为该角色的局部例外，不自动升级成整套风格规则。

## 角色与使用位置的差异

| 场景 | 可变化的内容 | 收敛边界 |
| --- | --- | --- |
| 装备栏玩家 | 以肩形、发式与衣袍轮廓区分男女。近正面、头身同向，清瘦修长，重心稳定；双臂自然收在袍内。 | 形象不强调具体身份，不抱拳行礼；主体收在两列装备槽之间，袖摆不铺到格子后；彩色物品 emoji 是第一视觉焦点。 |
| NPC | 年龄、胖瘦、职业姿态与少量神态；按设定选择一件主要识别物，如药杵、书卷、拂尘。 | 身份来自轮廓与关键墨笔，不靠服装细节清单；不擅自让所有人清瘦、站直或双手藏袖。 |
| 人形 BOSS | 更强的肩背结构、重心、姿态和少量深墨，可用设定中的兵器或冠形建立威胁感。 | 强度来自形与墨，不靠更花的配色、光效、满幅黑墨或繁密铠甲；保留内部留白。 |
| 异形 BOSS | 遵循物种解剖与设定，以角、背脊、翼或肢体等关键结构组织墨面。 | 不强套人形长袍；皮毛鳞甲仍以笔墨概括，不能变成写实怪兽再套水墨滤镜。 |

## 提示词组织

先确定角色职责和实际显示范围，再使用 [提示词模板](references/prompts.md)。固定风格段保持稳定，只替换角色设定与构图段。不要每次重新堆叠“仙气、唯美、电影级、极致细节”等容易互相冲突的词。

复杂角色先让一个样本通过笔墨验收，再拓展同批角色。修正时一次针对主要偏差，不通过不断增加负面词掩盖错误造型。记录最后采用的提示词与参考图，方便复现；不要把工具生成结果反向解释为已经满足需求。

## 素材与页面接入

- 使用当前可用的图像生成工具制作栅格美术；需要工具流程时遵循 imagegen skill，不用代码图形冒充生成立绘。
- 独立立绘使用真实透明底，不含纸张矩形、棋盘纹、地面、背景光晕、题字、印章或水印，除非本次明确要求这些内容。
- 核验 alpha 通道，并在页面纸色背景上查看。存在 alpha 不代表画面里没有烘焙底纹；同时检查外缘、衣内留白和半透明区域。发现伪透明时重新生成或用图像工具修正，不以 CSS 混合模式掩盖。
- 浓淡由素材本身承担，页面默认正常 opacity；不要统一降至半透明来“融入背景”。按实际显示尺寸控制存在感，不添加循环动画。
- 人物与可操作格子划定各自范围，完整展示关键轮廓；不要靠裁断头、手、武器解决空间冲突。若素材形状不适配，先修构图。
- 项目资源保存到明确的生产素材目录，按现有格式做保留透明度的尺寸／压缩处理。仅在已授权替换时覆盖现有素材；候选稿不要被当作正式图自动接入或批量删除。
- 本 skill 不要求所有角色共用固定像素尺寸；按页面实际显示大小、设备倍率与包体取舍。960px 高只是当前装备栏导出的尺寸，不是 NPC／BOSS 的通用规则。

## 验收与防漂移

同时看独立图、与固定基准并排的效果、实际页面缩小后的效果。逐项判断：

1. **构形**：是否首先读到有方向的墨笔与墨面，而不是白衣人物、实体剪影或写实材质？
2. **浓淡**：少量深墨是否起到支点作用，中淡墨与留白是否仍有空间？既不全图苍白，也不铺满黑色。
3. **面部**：有朝向和神韵，是否避免清晰脸框中的空白面具？NPC 的识别性是否没有挤掉笔墨概括？
4. **轮廓**：头身关系、重心和解剖是否合理？局部断笔是否没有误读为缺损？
5. **一致性**：与固定参考相比，笔触疏密、墨色冷暖、材质概括是否属于同一系列？BOSS 不能因身份变强而换画种。
6. **落位**：目标尺寸下头身仍能读清，衣摆与道具不压住交互区；装备栏中 emoji 仍优先被看见。
7. **技术**：真实透明、边缘无脏底、完整框内构图；实际主题与桌面／窄屏未产生明显裁切或失衡。

典型不合格情况：褪色白衣立绘、无脸纸人、过多飘带、过密衣褶、大片浓墨堵住形体、棋盘底图、男女画风分裂、写实 BOSS 加水墨滤镜。未满足时明确指出差距，修正该项；不要用“已经符合写意墨像”替代验收证据。
