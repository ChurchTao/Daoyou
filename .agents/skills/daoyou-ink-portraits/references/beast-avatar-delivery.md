# 灵兽头像素材交付

仅在导出、替换或检查游戏中的灵兽头像时读取。美术设计与通用验收沿用 [写意墨像](../SKILL.md)，本页只补充项目接入约定。

- 默认导出 **256×256、真实透明的 WebP**，高分辨率原图等比缩小并保留 alpha。质量 90 为起点，按边缘和缩小效果调整。保留用户选稿的构图、姿态与笔墨，不在导出时擅自重新设计。
- 按 [统一图标规范](../../../../docs/game-icons.md)，素材放在 `public/assets/icons/`，由 `src/react-app/components/ui/icons/registry.ts` 注册稳定的 `icon:名称`，`BeastIcon` 取值后交给 `GameIcon` 渲染。不新增页面分支或图标协议。
- 检查独立导出图、列表、移动详情和桌面详情，显示尺寸以当前组件为准。缩小后主要轮廓和身份特征仍可辨认，正常 opacity 下与其他头像大小协调、无意外裁切或挤压。
- 检查 alpha、纸色与深底上的透明边缘，以及注册路径、图片加载、WebP 尺寸和体积。原稿与未选候选不进入生产目录；记录采用的提示词、参考和最终素材。
- 涉及接入代码时运行 lint/build 和针对性浏览器检查；纯素材或文档变更检查相关文件与显示效果，不机械运行全量游戏测试。只做头像时不修改物种、数值、技能或玩法能力，不自动启动全物种重绘。
