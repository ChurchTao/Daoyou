# 幽都基础技能还原记录

本轮以《梦幻西游》电脑版阴曹地府的基础技能职责和施放规则为参照。官方入口：[阴曹地府门派介绍](https://xyq.163.com/mp009.html)。官方页面未给出的完整公式不能视为已经核实；下表明确区分已知机制与本项目暂定数值。

## 已确认的适配边界

- 不引入昼夜规则；所有技能均可正常施放。
- 不引入敏捷对固伤的加成。
- 两流派共有被动「神魂自守」：先计算并限制正常封印命中率，再乘 `0.7`。例如正常命中率 50% → 35%，20% → 14%，不是降低 30 个百分点，也不再套一次原始命中下限。
- 未核实系数先用适配值完成可运行模组，后续校准。下述“待校准”包括数值及明确列出的机制差异，不能作为原版数据引用。
- 本轮不整体重做经脉，也不加入门派克制技能（寡欲令、冤魂不散）及非战斗技能。

## 命名与描述语义

幽都主修神魂，擅长无视防御的灵魂攻击。固定伤害以“直击神魂”解释；伤势以“魂伤、降低气血恢复上限”解释，不描述为永久降低最大气血或无视所有防护。技能描述保留战斗作用，不将伤害与治疗写成等量吸取转换。

本轮采用：裂魂咒、灭魂杀、销魂蚀骨、滞魂咒、拘灵术、洞幽法眼、还魂决、涤魂诀、幽影遁，以及被动神魂自守。“还魂决”按已确认写法保留。同步状态栏和经脉中的引用文案，技能 ID、数值及结算规则不变。

## 基础技能

`N` 为所属心法等级。伤害、治疗还会经过 V6 对应的增减伤、治疗能力和经脉结算；表中的数值是基础值。

| 原版 / 幽都技能 | 已接入机制与消耗 | 待校准数值或适配规则 |
| --- | --- | --- |
| 阎罗令 / 裂魂咒 | 群体固伤与伤势；对 NPC 伤害增加 100%；每目标 20 法力 | 基础伤害 `40+floor(1.35N)`；伤势 `N`；目标数 `min(7,floor(N/25)+1)`。NPC 翻倍当前只作用于伤害，伤势独立结算 |
| 判官令 / 灭魂杀 | 单体固伤并削减法力；20 法力 | 伤害 `35+floor(1.05N)`；削蓝 `N` |
| 尸腐毒 / 销魂蚀骨 | 首击侵蚀、持续毒伤及削蓝、己方站立人物群疗；40 法力 | 首击 `min(目标当前HP×10%,8N)`；3 回合毒，每回合扣 `min(最大HP×4%,8N)`、`min(最大MP×2%,N)`；群疗基础 `2N` 加施术者治疗能力，不按队友血量比例恢复、不治疗灵兽。完整电脑版毒与治疗公式仍待核实 |
| 黄泉之息 / 滞魂咒 | 固伤并减速；50 法力；移除原本附带的伤势 | 伤害 `35+floor(1.05N)`；3 回合降低 `floor(0.2N)` 速度 |
| 锢魂术 / 拘灵术 | 5 回合禁止复活，倒地保留；50 法力 | 沿用基础封印参数 50，经正常封印公式计算；可选站立或倒地的敌方人物，命中及目标限制待继续对照 |
| 幽冥鬼眼 / 洞幽法眼 | 看破隐身及抗封；20 法力；移除旧版普通命中加成 | 最多 `min(6,floor(N/30)+1)` 目标、5 回合；原版“抗封提高10%”暂译为受封概率再乘 0.9，与门派特色叠乘为正常概率的 63% |
| 还阳术 / 还魂决 | 复活倒地人物并增攻降防；禁复活目标不可选；150 法力 | 恢复 30% 最大气血；5 回合物攻 +20%、物防 −20%，按施加时目标属性快照生成修正 |
| 魂飞魄散 / 涤魂诀 | 驱散敌方宗门法术的可驱散增益；40 法力 | 一次清除所有符合条件的增益，不移除法宝、灵兽等其他来源状态；`dispellable:false` 的状态保留。后续新增变身状态必须显式标记不可驱散，当前没有另建变身系统 |
| 修罗隐身 / 幽影遁 | 自身或队友隐身、期间不能施法；150 法力；后续施术者为自己支付 15、为队友支付 10 法力/回合 | 暂定 4 回合；不检查昼夜。隐身可被群攻与看破隐身攻击。施加当回合不收维持费，后续回合末收费；施术者倒地或付不起时解除。多个隐身分别收费 |

毒的首击、施毒、群疗目前按独立效果依次结算：施毒受免疫阻止或首击击倒敌人时，群疗仍可发生；不宣称这是已核实的电脑版成功施毒联动规则。毒按本项目回合末结算，施加当回合即跳毒并消耗一次持续次数，毒可致倒地；毒的等级上限保存于状态快照，恢复战局不重新取施术者技能等级。上述时序、免疫联动与致死规则是后续机制对照重点。

## 解锁与流派兼容

| 技能 | 心法等级要求 |
| --- | --- |
| 神魂自守 | 加入幽都即获得 |
| 灭魂杀、销魂蚀骨、幽影遁 | 20 |
| 裂魂咒 | 25 |
| 洞幽法眼 | 30 |
| 涤魂诀 | 50 |
| 拘灵术 | 75 |
| 滞魂咒、还魂决 | 120 |

心法等级映射到本项目既有成长系统；原版飞升条件暂以心法 120 级解锁映射，没有另加飞升系统。幽影遁的解锁等级为适配值。

「六道断狱」从公共基础技能移至六道魍魉流派自动授予，保留原物理效果，暂定 30 法力。两流派原来的固伤/物伤根基仍保留，和共同抗封特色分别生效。新增灭魂杀接入现有固伤经脉白名单。

仅同步必要的旧经脉衔接：伤势强化从滞魂咒移至裂魂咒；群疗强化改为新基础治疗的倍率；裂魂咒额外目标沿用 +1；拘灵术延长节点为 6 回合。蚀骨魂毒保留 4 回合、6% 最大气血，追加 `12N` 上限；削蓝仍为 2% 最大法力、上限 `N`。不代表两条经脉已按原版逐项复刻。

## 实现及验证

内容入口：`src/shared/engine/combat-v6/content/data/youdu-combat.json`、`youdu-paths.json`、`skill-learning.json`。引擎增加通用的受封乘法因子、宗门状态来源过滤、状态维持费和持续伤害上限，不在 core 内写幽都 ID 分支。

已验证抗封概率乘法、5/6 回合锢魂、隐身/看破与禁施法、维持费、复活及增攻降防、宗门增益驱散、毒上限与战局快照恢复。投影输入夹具不变，更新内容改动造成的哈希期望。

验证记录：`bun run test --testTimeout=15000` 全量 201 个文件、1845 项通过；补强不同最大气血队友的群疗一致性断言后，定向 3 个文件、18 项通过。`bun run lint`、`bun run build`、`git diff --check` 通过。构建存在既有分包/混合导入提示。使用本地幽都测试账号检查技能目录，新增技能、抗封被动和解锁等级可见，浏览器无错误日志；未改动角色养成数据。没有另做完整战斗浏览器对局，战斗规则由纯引擎测试验证。
