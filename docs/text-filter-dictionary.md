# 初始敏感词库整理说明

整理日期：2026-09-17。目标文件：`apps/api/src/config/text-filter.dictionary.json`。

这是万界道友对社区词库的筛选修改版，不是上游完整词库。初始版本共 **522 条屏蔽词**，例外词暂为空。词条按原有底量、来源类别的顺序排列；运行时仍只有一个全局屏蔽列表，不增加分类配置或外部依赖。

## 筛选边界

1. 涉政人物列表优先保留较明确的完整姓名及表达，剔除两字简称、纯英文缩写和部分泛称；这意味着某些两字全名也未纳入。本版不是人物名单全覆盖。
2. 明确保留一批涉政事件、组织名、口号及变体。人物和事件被提及就可能打码，不区分赞同、反对、引用或讨论历史的语境。
3. 不把普通地名、民族或宗教身份本身作为屏蔽依据，例如“西藏”“拉萨”“回族”“穆斯林”。也不导入“政府”“维权”“网络”“客服”“招聘”等泛词。
4. 色情类剔除服饰、普通身体部位、模糊动作和容易进入正常游戏语境的词，例如“丝袜”“美腿”“乳房”“后庭”“调教”“淫威”“欲火”。保留较明确的露骨性表达和辱骂词。
5. 广告文件仅选取部分明确的违规招揽或交易表达；不整体导入广告词、停止词、网址、药名、枪械或化学品名单。
6. 不导入“盘古”“毒龙”等修仙语境常见名称。英文不具备全词边界，因此没有导入主来源中的短英文脏话或纯英文政治缩写；补充来源仅保留少数明确的完整转写或缩写，详见清单。
7. 去首尾空白，按当前引擎的大小写与全半角规范化去重，保持每个词一行。没有用模糊规则生成更多拼音、谐音或繁体词。

这是一份可维护的初始化基线，不保证覆盖全部最新涉政、辱骂、广告或规避表达。后续根据实际误伤和漏词增删，避免以词条数量作为唯一指标。

## 2026-11-10 世界聊天辱骂词增补

本次仅以只读事务查询 `prd` 配置指向数据库的世界频道，不读取私聊、认证凭据或其他频道，也没有修改生产聊天、禁言或账号数据。固定分析窗口为北京时间 **2026-11-10 17:53:56–19:53:56**（数据库 UTC 09:53:56–11:53:56）。窗口内共有 **138 条消息、27 个发送账号**：121 条文字、7 条组队招募、2 条物品展示、8 条红包。聊天表使用无时区时间戳，窗口和发送时间已以数据库原始文本核实，避免客户端时区解析造成八小时偏移。

结合前后文，人工复核发现至少 **38 条针对性辱骂、人身或家属攻击**，集中于三个账号；其中包含已打码的辱骂和持续使用比喻攻击的发言。这是人工语境判断，不将所有争论、粗口或围观发言自动归为同等违规，也不凭聊天中的“小号”指称认定账号关联。玩家身份、原始聊天和逐条判断不写入仓库；具体处罚应由管理员查看原始上下文后决定。

本次手工增加 **59 条**明确的辱骂表达及常见繁体、拼音写法，并补充样本中出现的完整外语诅咒表达；屏蔽词由 522 条增至 **581 条**。同时为普通运气表达添加“狗屎运”“狗屎運”两个例外。词条来自本轮人工维护，不新增外部词库依赖；仍使用原有匹配、大小写与全半角规范化、有限分隔符和零宽字符处理机制。

增补继续控制误伤范围：

- 不屏蔽单个“狗”“屎”“死”等字，也不屏蔽亲属称谓本身。
- 不加入裸 `tm`、`jb`、`sb` 等短英文片段；仅对样本中明确的中文附着粗口及较完整的拼音表达补词。“几把”会误伤“几把剑”，不作为独立词条。
- 不把“畜生”“狗叫”整体加入词库；前者已出现在游戏内山狸精相关 NPC 叙事，后者可描述正常场景声音。对较明确的人身辱骂组合单独补词。
- 外语只补明确的完整攻击表达及对应写法，不封语言、文字种类、国籍或普通文化用语。

验证记录：

- 实际 JSON 可构造服务端同款 matcher；581 条屏蔽词均能命中自身，没有规范化重复、空词、非法字符或黑白名单直接冲突。
- 用新旧词库重新扫描这 138 条**已落库文本**，旧词库没有进一步命中，新词库可再命中 22 条，其中 20 条位于上述人工识别的针对性攻击中，另 2 条为粗口。部分历史文本早已打码，因此该结果只衡量本轮补词在现存文本上的增量，不能作为原始过滤拦截率或辱骂识别准确率。
- 18 个正常示例保持原文，涵盖宗门招募、双修功法、炉鼎炼丹、治疗组队用语、引妖香、NPC 山狸精叙事、场景狗叫、普通运气表达、数量“几把剑”和技术英文。
- 递归扫描 `packages/game-content/src` JSON 中 28,011 个字符串，新词库相对旧词库没有新增命中；不代表所有动态文案或所有语言变体都已覆盖。
- `pnpm exec vitest run packages/game-domain/src/social/text-filter.test.ts`：44 个现有纯逻辑用例通过。未修改 matcher 或新增测试脚本；完整应用检查和后台禁言流程由本次功能改动统一验收。

词库只处理明确字面表达，无法独立阻止绕词、隐喻、拆成多条消息或针对上下文的攻击。后台的聊天上下文查看和账号禁言用于处理这些情况。本次词库变更随 API 发版生效，不回写或删除历史聊天。

## 2026-11-10 常见人身攻击覆盖补充

在本日生产聊天样本增补之后，根据常见网络攻击表达再手工增加 **597 条**，屏蔽词从 581 条增至 **1,178 条**，保留原有两个正常用语例外。本轮不依赖新增生产查询或外部词库，没有修改匹配算法、消息处理及数据库。

新增覆盖智力和人格羞辱、针对性的废物/垃圾指称、非人化辱骂、亲属侮辱和家属诅咒、性羞辱、针对外貌/经济状况/疾病的侮辱、煽动死亡及自伤、线下暴力与人肉威胁，并包含常见谐音、数字混写、完整拼音、中文附着缩写、繁体写法和英文攻击短句。现有大小写、全半角、单个分隔符及零宽字符处理继续生效，无须逐条重复收录这些格式。

按误伤风险收紧词条：

- 不将疾病、残障、孤儿等身份或状况本身设为屏蔽词，优先收录明确针对人的辱骂组合。
- 不独立屏蔽“垃圾”“废物”“出生”“初生”“野种”“杂交种”“破鞋”“公共厕所”“千人骑”等多义片段，保留灵植、装备、坐骑、角色出生和普通设施讨论；其中部分只在明确辱人的组合中匹配。
- 不独立屏蔽 `sb`、`nt`、`2b`、`ass`、`kys` 等短片段，避免误伤普通英文、编号及游戏术语；也不屏蔽“司马”这类正常姓氏。
- 不把“杀你”“弄死你”“自杀”等动作本身加入词库。死亡相关家属表达使用完整诅咒，避免截断前缀误伤“死里逃生”“死而复生”；英文自伤攻击收录较完整的攻击祈使，保留常见的劝阻自伤表达。
- 词库不将普通玩法批评、轻度调侃或某个身份等同于违规，也无法理解所有引用、否定和反讽语境；持续隐喻攻击及拆分发言仍需管理员结合上下文处置。
