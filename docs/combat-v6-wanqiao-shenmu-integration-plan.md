## 1. 宗门定位与接入范围

### 1.1 万窍山

> 山谷有洞，风才会鸣；竹管中空，才可以成笛。万窍山门人从石隙、竹窍与人的呼吸中听取天地之声，以听入道，以息成音。一声止处，正是另一声将起之处。

宗门修行围绕**听、留、空、应**展开。风是穿过空处而产生的变化；音是这种变化被听见后的形迹。门人既可使众窍共鸣，也可将细微之声留入敌手气机，待其反复回响。

入门特色词：**听风观窍／虚而能应／余音入微**。武器和演出可采用洞箫、尺八、埙、无弦琴与山石空腔；不增加乐器装备类别或专用装备门槛。原型技能的伤害、持续和消耗仍按规则展示，意象不额外授予沉默、击退、闪避、飞行或速度收益。

“风属性”在首版体现为宗门题材、技能表现和已有装备元素关联。当前战斗伤害通道是物理、法术、固定，首版使用法术通道，不新增风抗、音抗或元素克制主管道。

## 4. 宗门根基、资源与行动语义

### 4.1 空谷应声：重光的音修表达

原版重光的**2%概率、追加40%伤害**保留，命名为**复响**。首版只允许列入白名单的本宗直接攻击法术触发；治疗系以后另列治疗白名单。一次根行动最多一次复响，追加不再触发自身，不重复支付MP／HP，不重复休息代价，不再次产生根行动完成收益。

复响是宗门专属追加，不直接借用灵兽法连或把法宝月影整套搬来。现有`innate.spellRepeat`仅支持主`effects`全为无独立选敌的`SpellHit`的直接法术；叩隙、截声、潜籁含伤势、控制和挂咒，首选第10.1节的**同一行动内显式概率分支**配方。普通`InvokeSkill`会创建独立行动并正常收费，不能拿它直接假充免费复响。

暂定复响沿用原根行动的目标集合，剔除已倒地／离场目标，不另外补满一批敌人；伤害与暴击重新判定。附属效果是否重复见技能表；没有明确白名单的强化、资源、复活和护盾不因复响重做。此为**改**，不是已核实的原作全部连击细节。

### 4.2 窍息：先给可运行初值，不伪称现服原值

| 项目 | 本作首版暂定 | 证据状态 |
| --- | --- | --- |
| 权威形态 | 战内资源`wanqiao.resource.breath`，0～6整数 | **改**；不持久化成角色资源 |
| 开场 | `min(6,floor(L调/60))` | **旧／暂**，180级为3，不一律给低级人物3层 |
| 基础恢复 | 存活者在偶数回合末+1，最高6 | **旧／暂**；不采用“每轮+1”或“群法每命中就获取”的混合版 |
| 每层基础效果 | 战内法攻+10 | **旧／暂**；确证不足，后续核实只改集中参数 |
| 倒地／复活 | 倒地清零；复活不重新给开场资源 | **改**；切换战斗、重连不得再发一次 |
| 驱散 | 资源本身不作为普通增益驱散；由技能消耗 | **改**；若要恢复原作可驱散语义，须另立状态／资源一致性方案 |
| 鞭挞 | 裂帛耗最多3层，每层伤害结果+15%；劲草改为20% | 3层／15%为**旧／暂**，劲草20%为**原** |

不凭空增加主动“充满窍息”按钮，也不把灵宝风舞心经的4／9／16层超限补充免费内置。低层或耗尽仍能施展基础技能，只失去相应资源强化。

消耗快照：行动确认合法、目标与费用确定后，保存`n＝本次消耗数`，再一次性扣除。基础每层法攻按**扣除后的资源**参与伤害；风魂护盾、绞藤和终极增伤按保存的`n`计算。这是**改／暂**的结算约定，避免先减后读导致倍率归零，或重复法术再次扣层。

### 4.3 留音：原雾杀的咒印

留音表现为某个窍隙中持续回荡的细音，战斗分类是本宗专属DOT，不附带控制。必须同时保留**施法者、目标、层数、年龄、剩余轮数、强化档数**。

原型确证了雾杀、一次附3层、催化及多处联动，但O1/O2未公开完整持续、上限及每轮公式。为让方案能实装评审，暂定：每个施法者对每个目标最多3层、持续4次轮末结算；基础每层`floor(0.5×L隙)`，年龄倍率为`min(已结算次数+1,3)`；重施增加层数并刷新剩余结算次数、年龄重置。以上全为**暂**，不是原版雾杀公式。

留音DOT不暴击、不触发复响、不触发本宗普通直接法术命中回调。受现有DOT／异常免疫约束。专属`kind`可使只免疫`beast.poison`／`youdu.poison`的能力不自动免疫它；鬼魂对整个DOT类的免疫仍有效。不能用`dispellable:false`绕过所有异常免疫。

现有同`kind`重施会合并并改写来源，不能直接满足双万窍山的“来自本人”条件。严格实现需第10节所列来源隔离；不允许用“后施法者取得对方全部层数”的默认行为蒙混过关。

### 4.4 空窍：天气节点的本宗触发条件

只替换依赖天气的两个节点，不增加共享天气、舞台区域或额外行动：

- **啸风→虚而应**：一次正常根行动把正数窍息消耗到0，记一次“空窍”；之后众窍鸣复响伤害增加20%，本场按触发次数累积。每个根行动最多记一次，追加法术、回合恢复、倒地清零不计。倍率暂定`0.4×(1+0.2×次数)`，保留原20%的幅度，改变触发条件，属于**改**。
- **灵归→虚生息**：轮末在基础恢复前，若本人存活且窍息为0，额外得1层；再结算偶数轮基础恢复。因此偶数轮空息可恢复2层、奇数轮恢复1层。法身只取消基础偶数轮恢复，本节点提供的额外恢复仍生效，属于**改**。

两节点保留在同一层的不同列，不能同时点出。空窍只是可由资源变化判定的本宗事实，不增加一个需要玩家维护的新资源条。

## 10. 当前V6实现边界与最小扩展

### 10.1 内容层可以直接组合的部分

现有资源、状态、`BeforeAction/AfterAction/AfterStrike/OnRoundEnd`、概率分支、伤害结果修正、技能补丁、伤势及驱散可承载绝大多数内容。六心法、两道途、经脉连通、技能学习与自动策略沿用当前结构。

**复响的首选配方**：在本次技能的`effects`中先完成根攻击与仅执行一次的附属效果，再声明一个**不带效果级targeting**的`RandomBranch`；它对原目标数组整体只抽一次概率，成功分支对仍合法的同一批目标声明40%攻击以及该技能允许追加的附属效果。分支前后用本宗fact区分基础／复响阶段，追击的额外耗息及风魂只结算一次；潜籁的返息、流韵Buff放在整段结束后的`successEffects`／根技能`AfterAction`。所有本宗命中钩子按技能白名单与阶段fact过滤，避免再触发一份附属效果；终极技不编译该分支，也不同时启用`innate.spellRepeat`。

该配方保持一个行动、原目标集合、一次成本和一次回合代价，不依赖`AfterAction`重新取得全体目标。当前`RandomBranch`和子效果可传递原目标数组，但仍须先用纯规则用例证明死亡中断、命中钩子、概率／暴伤及失败清理均符合本稿。`rootActionOnly`目前只排除器诀调用的攻击子技能，**不会自动排除普通InvokeSkill**；若上述配方不能成立，才提交有明确用例的通用追加阶段／因果上下文扩展，不能用宗门ID分支解决。

**法攻快照配方**：每息+10用0～6档有限隐藏自身状态表达，每档固定`magicAtk=10×档数`，同kind互斥；开场、支付基础资源、追击额外扣息、潜籁返息、轮末恢复和倒地清零之后同步刷新。当前`attrMods`是施加时快照，不会自动跟资源变化。空鸣的+100使用仅包围本次众窍鸣及复响的临时状态，根行动结束移除，失败／倒地同样清理，不能泄漏到后续其他技能。

**DOT配方**：天然DOT走`OnDotCalc→applyDamage`，不经过直接法术的source结果加成。留音使用新增的通用`onTick.hpPower`实时表达式，不以目标最大气血封顶；旧比例DOT保持原行为。层数／年龄／个人档／目标强化按留音事实计算，流韵20%在`OnDotCalc`按本人对应咒印另加一次；直接法术管线不再重复加这一份DOT修正。

**下回合控制配方**：截声冻结及血雨自禁法均以“本回合等待态→轮末转换为下一回合限制态”实现，只限制指定回合，限制态在次回合末清除；若现有`onExpire`组合受应用轮数影响，应先补可验证配方再配置，不把`duration=1`当成已等价。截声不吃施放轮目标尚未执行的窗口，血雨不拦截本轮余下的同行动附属效果。

`docs/sect-authoring-guide.md`仍有`packages/shared`、battle-v5、Factory和bun旧说明；本次不顺带重写它。实际依据为当前`game-domain/combat/content.ts`、`game-content/sects`、`game-rules/sects`、`game-rules/sect-organization/README.md`。

### 10.2 三项必须先做的能力核查／扩展

**A. 通用法力抵伤。** 现有`OnHitCalc`发生在部分最终倍率之前，钩子模拟无法保证“抵消的名义伤害＝扣MP”，特别是暴击、法连、盾和MP不足。为含虚增加不识别宗门ID的可配置MP抵伤能力；默认不存在时保持所有旧内容原行为。

本稿冻结语义：沿现有分流规则确定各实际承受者，完成结果／承伤修正与普通护盾吸收；对每位承受者的剩余**名义伤害**`D`，含虚抵消`A=min(floor(0.5D),当前MP)`、扣`A`MP，余下`D−A`进入现有HP扣除／不可致死限制／致命挽救流程。`D`不以当前HP截断：HP10、盾后伤害100、MP100时抵消50并扣50MP，剩余50仍可致命；不能以实际只掉10HP否认已经抵消50点名义伤害。不处理伤势、自付HP、资源扣除或非伤害型生命设置；本作暂定DOT也经过此层。

MP为0后效果不再抵伤，持续仍正常计时。分流伤害在各接收者上只执行一次各自的护盾／抵伤，不能把同一部分同时归入两人的减伤。战报分别记录名义抵消量、耗蓝量与实际HP损失；吸血、伤势和受击效果仍按最终实际HP伤害读取。顺序、分流和DOT范围是**改**，50%和1:1为**旧官方原值**。

**B. 来源隔离的咒印。** 沿用`StatusDef.sourceBound`，已补齐按来源叠层与逐实例移除事件。原`maxStacks`分支未按来源找实例，以及移除多来源同ID时事件丢失的问题已修复；施加／叠层、查询／年龄、自然到期、驱散、复制、替换和倒地清理均沿来源规则处理。留音、催化、迷缚、随机分配与驱散使用同一语义，默认非sourceBound内容保持原行为；core没有宗门ID分支。

**C. 通用状态移除上下文。** 内和需读取被驱散状态的剩余轮数，但现有`OnStatusRemoved`在移除后触发、没有移除前剩余时间。增加通用移除上下文，携带准确实例／来源、移除前剩余轮数、技能等级快照与移除原因；双来源同ID的移除逐实例发事件。驱散回血读取该快照，不能删除后再查`statusRounds`、不能用当前人物心法等级替代原施放快照。

这三项和10.1的配方验证是严格方案的前置，不能把首版描述成“只加JSON”。若决定不扩展，必须退回修改本稿的含虚、双施法者与驱散恢复语义，不能在实现时静默近似。

### 10.3 必须增加的投影事实

- 武器／衣甲的真实元素计数；沿已有`project-character-equipment.ts`输出，不从装备显示文字解析，不改旧无元素装备。
- **长生阵纹独立HP贡献**：按已装备实例实际阵纹等级累计，不使用`beltMaxHp`代替，不包含基础词条、精炼或其他来源。经脉编译输入显式传事实，不能让content反向依赖equipment规则。
- 本次耗息数、正常根行动身份、本人留音与强化档、复响是否已执行、状态移除原因及移除前剩余轮数。已有事实可复用；新增表达式逐项进入白名单，不在core写宗门语义。
