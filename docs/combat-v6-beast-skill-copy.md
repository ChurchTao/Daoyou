# 灵兽技能天赋文案定稿

本轮将67个技能及对应兽诀的名称、天赋文案迁移为灵兽自身的本领、体质与异能。普通／高级沿用同一词根；神佑复生最终定名为涅槃重生，法术连击定名为灵力相续。

技能ID、兽诀ID、技能族、数值、效果、出生技能池和学习规则均不变。天赋文案存于skills.json的flavorText，数值与限制继续从effect生成；不添加血脉、物种或元素限制。魂生两档现有效果相同，文案不虚构高级收益。

高级清灵天赋文案：灵息澄澈，常规异常难以附身。普通为回合末解除，高级为免疫，效果说明明确区分。

兽诀说明采用“蕴有天赋感悟，可助灵兽领悟「技能名」”，高级增加“更深的”。随后展示技能描述及学习替换规则。历史迁移文档保留旧称以追溯来源，本文件为当前定稿对照。

## 全项目文案复查

已同步项目灵兽设计SKILL、首版确认基准、物种生成文档、配置README、相关测试标题及致命判定注释。两份十五物种出生表的核心与候选技能名称逐项核对配置通过。

经典迁移文档的累计索引“游戏名称”已更新；原作参考列与历史实施记录保留当时名称，并在文首明确现行文案入口。法术暴击率、法术波动区间、通用吸血机制、人物功法冥思和原作物种吸血鬼不是当前灵兽旧技能名，不作批量替换。稳定技能ID与效果枚举保持不变。

验证：全量162个测试文件、1237项通过，lint与git diff --check通过。本次仅补文档、技能规范、测试文字和注释，未重复构建与浏览器验收。技能标准校验脚本因系统Python缺少PyYAML未运行成功；改用Bun解析frontmatter并校验相对链接，通过。
