# 洞府灵田：长期灵植首版

灵田以长期存在的灵植为经营对象。播种后自动成长、持续生产；收获只领取积蓄，不清空植株。玩家低频决定培养方向、完成蜕变，并根据修行需要调整六块田的配置。

场景与交互的独立重设计见 [灵田 UI](spirit-field-ui.md)，包括植物主景、单株生长历程、保种放置与百草志。

百草志为八个品阶各四种，共 32 种。名称、形态、产物、成长时间与灵果药性份额均由 [JSON 配置](../packages/game-content/src/spirit-field/data/garden.json) 维护，编辑方式见 [策划配置指南](spirit-garden-content.md)，完整设定见 [物种清单](spirit-garden-catalog.md)。

## 首版规则

- 每个角色有六块田，全部开放；不增加土地等级、灵植师等级或每日照料任务。
- 播种消耗一份合法 `seed.v1`，角色境界必须满足种子品质门槛。初始领取为甘草、野菊各两份，山枣一份，均为凡品；已经领取过旧版奖励的角色不会重复领取。
- 凡品在田生长四分钟后首次成熟，发放一份基础材料。之后按周期自动生产，不要求玩家在线或逐阶段确认。
- 凡品在田生长一天后可永久选择一次培养方向，三天后可完成一次蜕变。成熟、分支和蜕变所需时间按 `1 + 品质序号 × 0.25` 放大，凡品序号为零。
- 基础材料周期四小时，繁茂路线每周期两份；结实路线每十二小时一份灵果，凝珍路线每二十四小时一份天材地宝。生产周期使用同一品质倍率。
- 每株最多积蓄七天生产时间。满额后暂停新增产物，成长仍继续；领取后恢复生产。多次查看或提交操作不会绕过总容量上限。
- 成熟后的首次产出只发一次；培养节点不阻断基础生产，也没有枯死或腐烂惩罚。

分支选择前先结算旧路线，未完成的生产时间继续保留；已积蓄产物保留原类别与品质。首版所有分支的周期均不短于基础周期。蜕变同样保留生产时间与旧产物，只提高未来产物一个品质，不改变原种品质，不允许再次蜕变。神品不能继续升品。

蜕变需要角色达到下一品质的境界门槛，消耗一份不低于原种品质的药材，以及 `300 × (品质序号 + 1)²` 灵石。条件满足后确定成功。选中的药材、数量与库存版本、费用和全部状态在同一事务里校验；失败不消耗物品或灵石。

## 物种与长期记录

新谱从凡品常药、玄品筑基三药一路记录到仙品悟道古茶树和神品麒麟神药。八阶完整设定与实际收成见 [新谱目录](spirit-garden-catalog.md)。

百草志永久记录每种灵植的首次成熟、培养分支和蜕变。坊市及后台生成从同一目录选种，后台可按实际品阶与元素组合筛选。

新灵种统一命名为“成株名称的种子”。同一物种拥有固定的原种品质；一次蜕变只提高未来产物品质，不改变物种身份。灵果可以按设定组合 1–3 种药性，共享一份原灵果药效预算；每个效果按份额缩放，仍沿用弱于同品丹药的数值基线。灵兽修为果不与人物药性混用。

物种定义、产物用途和效果均为确定规则。新种子使用稳定的物种／品质身份，同种同品质跨批次堆叠；实际种下的每株灵植另有独立身份。日常生产、收获与灵种生成均不调用模型。

## 迁栽与收藏

保种收藏最多二十四株。移入收藏前结算已产生的收益，保留培养方向、蜕变、成长、未完成生产时间和待领产物；收藏期间暂停成长与生产。迁回需要一块空田与相应境界，收藏时间不补算成生产时间。

一键收获同时领取在田株和收藏株的全部待领产物，通过统一库存入包，背包不足时沿用储藏室交付。收藏株可以在领取全部产物后选择结束培育；确认后永久移除该株，不返还投入，图录保留。此入口避免收藏与田块都满后无法继续尝试新物种。

迁移 `0075_perennial_spirit_garden` 只向业务灵田表新增可空 `garden` JSONB 列。旧 `plots` 保留为迁移源，首次读取旧田地时在玩家锁和事务内迁移一次。之后读取只投影时间进度，正式写操作才提交状态，不需要逐株定时任务。

已发布的短期作物灵种保持库存事实与指纹，按名称或元素匹配当前目录的同品阶物种。找不到匹配时使用该品阶首项。旧在田作物折算已完成的生长进度；旧成熟作物按原田地身份、播种时间与灵种身份确定的结算，保留其类别、数量、品质与灵果用途，不补发多年离线产量，不额外重复首次收成。损坏资产拒绝迁移，不静默变为空田。

所有正式写请求都携带 `requestId` 与 `expectedVersion`；库存消耗另带物品版本。原请求重试回放结果，同键改参数、陈旧版本、资源不足和阶段不符均拒绝。前端在网络结果不明时保存原请求并提供原样重试。
