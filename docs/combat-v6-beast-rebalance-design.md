# 灵兽再设计：青鸾、后期数值与出生技能

日期：2026-10-05。状态：用户已确认实施，六目灵猿与幽冥虎的必带技能沿用原配置。实施与验收结果见第 7 节。

用户已明确：替换琥珀蝉；收紧化神及之后的数值；渡劫普通出生／洗炼成长最高 1.380、攻击资质最高 1900；融合仍可突破出生范围；增加无必带技能的物种。用户随后确认其他内容按本稿调整，并明确六目灵猿保留高级灵觉，幽冥虎保留高级镇魂、灵火。

调整前基线为物种内容修订 12；本轮已实施修订 13，见[首批基准](../.agents/skills/daoyou-beast-design/references/first-release.md)及[后续境界基准](../.agents/skills/daoyou-beast-design/references/later-realms.md)。旧版功能验收与本轮验证分别记录。

## 1. 本轮设计边界

- 数值调整覆盖化神至渡劫共 20 个物种；炼气至元婴的 14 种资质与成长保留。
- 出生技能重新审查全部 34 种，不只调整后期；多数物种收敛为 0–1 个必带；幽冥虎按用户要求保留两个。
- 普通野生、宝宝、假宝宝的自然生成与普通个体洗炼采用同一物种区间；捕捉仍保存遭遇事实，不在结算时重新掷资质或技能。
- 变异在普通抽取结果上增加 5%（2026-10-05按用户要求由10%下调），不受普通出生上沿裁剪；渡劫新生成／洗炼最高成长因此为 1.449，最高攻资 1995，按当前整数舍入规则计算；已生成个体数值不回填。
- 融合继续使用现有公式，成长 1.500 兜底、资质各 100000 的结构边界保持。1.380／1900 不加入个体存储合法性校验，不用来裁剪融合结果。
- 合体及以上稀有、逐只 0.8%、稀有与变异独立、成年等级随栖息地等规则保持。
- 不增加元素克制、治疗队友、净化全队、复活次数保底等新机制。

## 2. 琥珀蝉替换为青鸾

采用玩家较熟悉的青鸾，保留炼虚初期开放、携带等级 105。它是可在灵地繁衍的凤鸟旁支，具体生态属于项目改编，不将普通捕获个体描写为唯一的上古神祇。

**形态：** 青灰长羽，细长颈项，额后羽冠自然后拢；身躯紧实，双翼宽展，数根长尾羽向后垂落。主要轮廓是羽冠、弯颈和拖尾，足部为正常双足。以宽阔羽面表现墨色，少量石青集中在颈胸和尾端，不做火焰鸟或发光宝石鸟。

**生态：** 栖居古木覆盖的山涧高处，沿林冠与泉瀑往返，饮灵泉、啄食灵果。日常收翼立枝，受扰时借林风滑翔，再从高处掠回。水击来自含纳泉水与水息的本领；自愈与复生表现少数个体旺盛的生命力，不通过树脂封存、蜕壳或死物复活解释。

**与已有禽类的区别：** 雷鹏强调猛禽的胸肩和雷翼；琉璃鹤强调长喙、长腿与临水步态；毕方是独足直立，金乌是三足紧凑乌身；青鸾强调长冠、弯颈与垂尾，不依赖变色区分。

| 项目 | 确认设计 |
| --- | --- |
| 五项资质 | 攻击 840–1120；防御 1000–1300；体力 3300–4500；法力 2700–3370；速度 1350–1720 |
| 成长 | 1.205–1.275 |
| 必带 | 无 |
| 候选 | 高级涅槃重生、水击、自愈、迅捷 |
| 出生技能／格数 | 0–4；各候选独立 50%，全有与全无均为 6.25% |
| 取舍 | 成长较好，法力与速度有空间；体力和防御偏低，攻击资质明显较低。无强制加点方案 |

高级涅槃重生是候选，出生携带概率 50%；获得后受到致命伤有 30% 概率复生并恢复全部气血。两次概率分别发生在出生和战斗中，不是必定复活。自愈可正常作用于活体青鸾；没有灵魂体，技能池中也没有完整的法术增伤套装。保留原本高级涅槃重生的培养机会，但不承袭琥珀蝉的形态与生态。

**栖息地衔接：** 凝脂古林改为“听泉古林”，描述改为“古木根系攀住涧壁，泉声穿林，青鸾沿树冠掠过，银翅螳螂静伏枝叶间。”保持炼虚区域及 105–115 级；现有雾灯林、玉泉旧苑中的琥珀蝉位置也换为青鸾，普通池仍为原数量，不改变稀有概率。新物种使用独立 ID `combat.wild.species.qingluan`，头像另制；不沿用蝉的头像、描述或个体身份。

## 4. 必带从默认待遇改为少数天赋

调整前 34 种为：5 种无必带、18 种一个、11 种两个。本轮调整为 **16 种无必带、17 种一个、1 种两个**；化神及之后 20 种中有 9 种无必带。比例是逐物种取舍的结果，不新增全局配额规则。

保留必带主要有两类理由：直接定义形态的灵魂体／隐身／毒性／感知，或为具有法术增益的出生池保留基础攻击法术。连击、必杀、噬血、迅捷、反击及大多数高级增益无需因境界而保底。高级技能移入候选后同样各自 50%，不降级、不另建稀有抽签；以下表格逐种列明，不能自动推导为所有高级技能都应候选化。

### 4.3 概率与培养影响

每个候选独立一半概率，必带全部获得。因此 `E[技能数] = 必带数 + 候选数 / 2`；把一个必带移入候选，平均出生技能减少 0.5，满技能率也下降。这是本次设计的实际强度调整，不能当作只改标签。

| 例子 | 原版 | 本稿 |
| --- | --- | --- |
| 麒麟 | 2 必带＋2 候选；平均 3 技能，满 4 技能 25% | 0 必带＋4 候选；平均 2 技能，满 4 技能 6.25%，零技能 6.25% |
| 九尾狐 | 2 必带＋2 候选；平均 3 技能，满 4 技能 25% | 1 必带＋3 候选；平均 2.5 技能，满 4 技能 12.5% |
| 毕方 | 2 必带＋1 候选；平均 2.5 技能，满 3 技能 50% | 1 必带＋2 候选；平均 2 技能，满 3 技能 25% |
| 幽冥虎 | 2 必带＋2 候选；平均 3 技能，满 4 技能 25% | 按用户要求保持不变 |

融合结果会读取结果物种的必带表。本次候选化也会减少融合自动补入的必带技能；移出的技能只有亲本实际持有时，才会进入非必带继承集合并按现有概率抽取，候选池不会直接给融合补技能。数值公式和 1.500 兜底不改，但不能宣称技能产出成本不变。实施时应补验融合继承与零格培养。

## 5. 实施与验收要求

1. 将此稿的 20 种数值、34 种出生表同步到配置并递增物种内容修订；保留现有候选抽签、变异加成、面板系数和融合公式，不另加一套上限系统。
2. 青鸾使用新物种 ID，同步野外池、图鉴、地图描述、设计基准和头像注册。实施前盘点未发布环境中的琥珀蝉测试个体、未结束遭遇及相关引用，再确定清理范围；不把旧蝉个体静默改造成鸟。本地旧测试样本的处理见第 7 节；历史快照不随配置改写。
3. 数值及出生表只影响新生成和主动洗炼的个体。现有其他物种不自动降资质、删除技能或重掷；旧数据也不能被新版出生上沿判非法。验收应使用新生成样本，避免将存量高数值当作配置未生效。
4. 用当前共用面板公式在相同等级、相同加点、隔离技能增益的条件下比较旧／新范围。此项用于确认调整量与短板，不等同于实战伤害或胜率平衡；技能分布变化需另外验收。
5. 共享测试覆盖各境界上沿、19 个保留物种区间不增加、出生表全集与候选概率、变异边界、融合仍可突破 1.380／1900。随后运行必要的 lint、typecheck、build，并实测青鸾遭遇／捕捉／洗炼与融合继承。
