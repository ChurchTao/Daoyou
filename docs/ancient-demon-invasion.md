# 古魔入侵设计施工文档

## 赛程与集结

按北京时间自然周开放，每周一 00:00 换期，周内随时可结队开阵。系统传闻指向天南·坠魔谷外围的「镇魔营地」，炼气至渡劫角色均可进入。2–4 个不同账号使用[通用队伍](party-system.md)，全员准备后由队长开战，第一波从队长个人待挑战的下一波开始。挑战境界取实际参战名单中的最高境界。新场次冻结名单、难度和构筑，本期在下周一 00:00 收阵。

个人进度以期次和账号为单位，绑定本期首次出战用的角色。打赢个人下一波才推进一级。重打已过的波次或随队打到个人尚未解锁的波次均为助战。队伍改员、移交队长或解散时，已经开战的一波按原名单结算，波间结束旧场次并回营地重新集结。队长也可在休憩时结束当前连战。队伍变动和退队均保留个人已通关波次。

## 连战

首波参考对应境界普通云游·除祟第一战的整场气血和有效输出。两、三、四人队的起始气血预算分别为单人除祟首战的 1.65、3.5、5.8 倍。四人配四只出战灵兽时，以单人配一只出战灵兽的首战节奏和气血损耗定标。每波固定八个敌人，由一头目、两护法、两精英和三喽啰组成，单体气血占比分别为 25%、15%、9%、9%。每波气血与有效输出复利增长 5%，第 5、10、15……波全阵当波额外乘 1.2。首领波头目具备护法联动、延迟大招、低血量招式三类行为，技能和敌名提示对应。同期队伍共用波次编排与增益卡掉落序列。

每波读取人物和灵兽的常驻气血、法力及当前灵兽编组。胜败都结算本场损耗，技术中止保留开战前的状态。波间可用储物袋内的回复品，也可付费休养袋中灵兽。失败后可重新组队或原队再战，已使用的回复品和增益卡照常消耗。波间休憩最长 30 秒，全员就绪可提前迎战。收阵前由服务端确认的胜利计入本期，即使归档稍晚。未结束的战斗到收阵时终止。刷新和断线可回到正在进行的战局。

普通波胜后有一半概率掉卡，首领波胜后必掉。本期同一波的卡名一致，只有完成个人首次通关的参战者获得一张。下一战创建成功时消耗，战斗完毕后临时效果清除。

| 卡   | 下一战效果                               |
| ---- | ---------------------------------------- |
| 破军 | 自身物理、法术伤害 +12%                  |
| 镇岳 | 自身受到的物理、法术伤害 −12%            |
| 回春 | 自身施放治疗 +20%                        |
| 凝神 | 自身技能法力消耗 −20%                    |
| 护心 | 开场获得气血上限 18% 的护盾，持续 3 回合 |

## 奖励与除魔榜

每 5 波按本期首次出战时的个人境界发放一局同境界普通除祟 S 级的基础资源，包含四场战斗胜利和 S 级结算。修为、灵石和感悟分成五份，按组内累计进度取整后逐波入账。每次个人首通首领波时，按一局同境界普通除祟的对应评级计算道具掉落。第 5 波为 B，第 10、15 波为 A，第 20 波起每逢 5 波为 S。抽中的道具合在同一封传音领取。

除魔榜以个人最近一次有效通关的场次、波次和实际挑战境界记名。同一场同一波推进的玩家合并展示，详情展示有效通关波次与该波实际参战名单。新队内有效通关后，个人从旧成绩转入新成绩。各挑战境界内按波数降序，同波并列。有效成绩提交后更新实时榜。换期后可查看上周榜，待上周战局收尾后封榜。

封榜时向各挑战境界前 100 名的有效通关队员发放排名声望传音。第 1 名 300，第 2–10 名 200，第 11–50 名 100，第 51–100 名 50。并列同奖，每账号每期最多收到一封排名奖励传音，领取附件后声望入账。

## 实施边界

- 规则包负责北京时间窗口、关卡与预算、波间状态和奖项计算。内容包承载古魔技能与波次特色，V6 核心保持通用。
- 候场复用通用队伍，招募和准备按队伍名单版本保存。挑战场次保存冻结队员、难度及当前波，本期个人进度保存最高通关、当前场次占用、最新成绩和已发奖励波次。终局按场次和战斗身份推进个人成绩，奖励按已发波次补齐差额，发放与已发波次在同一事务提交。活跃单波沿用 Redis 多人战斗与重连。
- Phaser 活动视图呈现营地集结、休憩与结算，控件遵循共享主题和可访问性。战斗跳转现有 V6 多人战斗路由，战后返回营地。系统传闻、天南地图节点和万界金榜分别接入对应现有入口。
- 迁移 `0082_ancient_demon_invasion_and_parties` 直接创建通用队伍、古魔期次、招募、挑战场次和个人进度的最终表结构。

## 界面与素材

- [周常活动界面](weekly-activity-ui.md)统一活动入口、规则抽屉和榜单。古魔集结时展示队伍名册和准备，出战后显示波次、开阵倒计时、队员气血和法力、丹药格与增益卡。休憩时在倒计时下显示上一波战果、实际到账的资源，以及通过通用道具格预览的传音奖励。补结多波时显示最后一波的收益。
- 队伍传音沿用世界传音的消息行和输入组件。通用玩家布局提供可拖动的吸边入口，只有当前角色在队时显示，收起后可见新消息提示，普通战斗页和活动页共用。
- 镇魔营地在坠魔谷外围与空间断层带相邻。Phaser 背景为 `apps/web/public/assets/weekly/invasion-rift-camp.webp`，1536×1024。增益卡使用 `apps/web/public/assets/icons/invasion-{assault,guard,healing,focus,shield}.webp`，256×256，带透明通道。
- 素材由内置 ImageGen 生成。背景以留白、飞白和低饱和彩墨绘制断层、悬石与守阵营地。卡面分别使用破锋长矛、山石、药芽、凝液和护符的写意构形，图中文字由界面渲染。

## 个人进度版联机验收

- 三个独立本地浏览器会话验证混境开战、并发开战、原队解散后换队续打、战中移交队长、重打旧波和跳波助战。助战没有修改个人波次、榜单归属、奖励或手牌。
- 北京时间 16:00 截止时仍在进行的战局正常终止，个人成绩保留。除魔榜验证了同波并列、换队后仅保留新的有效成绩、助战者出现在参战详情以及参战者能查看战报。战斗和榜单详情在 360px 视口内无横向溢出。
- 跑完第 5 波，验证波间增益卡扣减、首领掉卡及每名首通玩家一封奖励邮件。重启本地 API 后，个人进度、奖励和上一期榜单仍可读取。

## 首波强度校准

旧四人队整阵气血为同境界普通除祟首战的 2.95 倍。多人的额外行动与群攻让这档敌阵很快失去火力。定标提高了整阵气血预算，让护法和精英能多打几个回合。双人样本原本已有较明显的气血损耗，三人队和四人队采用更高的气血档位。

定标用现有中期参考构筑、普通道装、每人一只出战灵兽，在 V6 引擎内执行实际自动指令。每境界有八宗门 × 五类除祟首战 × 三个种子的 120 场单人样本，以及四种队伍构成 × 三套古魔阵容 × 三个种子的 36 场四人样本。两、三人队也各跑了 324 场复测。气血损耗以结算时人物和灵兽合计气血占各自上限的净损耗为准。

| --- | --: | --: | --: | --: | --: |
