# 数字排版规范

数字按阅读用途分类，由 `src/react-app/index.css` 的 Tailwind v4 `@theme inline` 字体令牌与 `@utility` 管理。组件不得直接写 Georgia、系统等宽字体栈或内联 fontFamily 来表现数值。

| 类名 | 用途 | 默认规则 |
| --- | --- | --- |
| `num-body` | 正文、技能描述、提示中的数字 | 文楷；普通数字排版，通常直接继承正文，不必给每个数字加 span |
| `num-stat` | 属性、资质、气血/法力、贡献、概率、表格及独立统计数值 | Arial / Helvetica Neue，中文回退文楷；齐线、等宽数字，刷新和纵向比较更稳定 |
| `num-stack` | 物品格中的 ×数量 | 系统等宽字体，中文回退文楷；齐线、等宽数字，600 字重、轻微收紧字距 |

字体令牌分别为 `--font-numeric-body`、`--font-numeric-stat`、`--font-numeric-stack`。需要更换字体只修改这些入口，不引入新的远程字体请求。等宽数字指同一字体的数字使用相同字宽，不要求属性文字全部采用等宽字体。

## 使用边界

- 三个类只管理字体及数字排版。字号、颜色、截断、位置、阴影由所在组件管理；`num-stat` 的强调字重按需添加。
- 将 `num-stat` 放在数值元素上，不放在整个页面、包含标签的 dl 或段落上。数值中的 `+`、`%`、斜线和小数点一起保留。
- 文本混排以正文优先，必要时用 `num-body` 从数值父层恢复文楷。不要通过正则拆分所有正文数字。
- `font-mono` 不是数字语义类。现有房间码、角色 ID、兑换码、配置输入等是标识符或代码，不属于这次数字迁移；保留其现有行为，不把它们机械替换为 `num-stat`。
- 日期、等级说明、经验说明等正文数字默认继承文楷；专门的统计或数值表格使用 `num-stat`。

```tsx
<p>消耗 25 灵石，恢复 250 寿命。</p>
<dd className="num-stat text-sm">1,280</dd>
<span className="num-stack absolute top-1 left-1">×99</span>
```

本轮收敛物品堆叠、灵兽属性/加点、角色属性表、HUD、道装预览、战斗详情、宗门贡献/心法数值、闭关概率、资源日志及既有显式数字排版。正文保持默认字体，不增加数字渲染组件或格式化机制。
