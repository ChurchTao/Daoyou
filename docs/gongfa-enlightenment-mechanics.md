# 功法参悟机制说明

> 本文按 2026-08-20 当前代码整理，说明悟道室中“功法参悟”的实际计算规则。数值以 `creation-v2` 引擎为准，不以生成文案为准。

## 一句话结论

功法参悟遵循以下分工：

- 材料品质、投入数量和材料组合决定能量、成品品质与词缀上限。
- 材料元素和语义标签决定有哪些词缀可以进入候选池。
- 候选词缀经过槽位、稀有度、能量和互斥规则过滤后，再进行加权随机抽取。
- LLM 负责补充受限的材料语义标签，以及生成名称和描述；不会直接决定品质和战斗数值。

因此，“真品”不等于必定拥有很多词缀，“开放四个词缀槽”也不等于一定能抽满四条。

## 1. 参悟输入与消耗

### 材料限制

- 每次最少选择 1 种、最多选择 6 种材料。
- 每种材料可投入 1～3 件。
- 可用材料：灵药、妖兽材料、天材地宝、辅材、功法秘籍。
- 不可用材料：矿石、神通秘籍。
- 火焰与冰寒语义冲突的材料不能同时参与同一次参悟。

### 固定消耗

- 每次消耗 8 点天地灵气。
- 投入的材料会被实际扣除。
- 感悟消耗由本次投入材料中的最高品质决定，而不是由最终成品品质决定。

| 最高材料品质 | 基础感悟消耗 |
| --- | ---: |
| 凡品 | 5 |
| 灵品 | 10 |
| 玄品 | 15 |
| 真品 | 25 |
| 地品 | 40 |
| 天品 | 60 |
| 仙品 | 80 |
| 神品 | 100 |

命格可以修正最终感悟消耗，页面显示的预计消耗是应用命格后的结果。

## 2. 材料能量计算

每一种材料的基础品质权重如下：

| 材料品质 | 品质权重 |
| --- | ---: |
| 凡品 | 3 |
| 灵品 | 5 |
| 玄品 | 8 |
| 真品 | 13 |
| 地品 | 21 |
| 天品 | 34 |
| 仙品 | 55 |
| 神品 | 89 |

单种材料能量近似为：

```text
单种材料能量 = 四舍五入（品质权重 × √投入数量 + 秘籍奖励）
```

- 普通材料的秘籍奖励为 0。
- 功法秘籍额外增加 3 点能量。
- 数量采用平方根增长，所以投入 3 件会比 1 件强，但不会达到 3 倍能量。

总能量还会应用以下修正：

```text
有效总能量
= 所有材料能量之和
+ 材料类型多样奖励
+ 语义一致性奖励
- 缺少功法秘籍惩罚
```

### 材料类型多样奖励

- 第一种材料类型不奖励。
- 每增加一种不同材料类型，增加 2 点能量。
- 最多增加 8 点。

### 语义一致性奖励

- 多种材料共享同一个语义标签时获得奖励。
- 每增加一层共享关系，增加 2 点。
- 最多增加 6 点。

例如多种材料都具有“生机”“护体”或“爆发”语义，可以获得一致性奖励。

### 缺少功法秘籍

- 没有功法秘籍仍可参悟。
- 但有效总能量会减少 3 点。
- 功法秘籍本身还额外提供 3 点材料能量，因此同档方案中加入秘籍通常明显更稳定。

## 3. 成品品质

最终品质只看有效总能量，不看材料平均品质，也不直接等于最高材料品质。

| 有效总能量 | 成品品质 |
| --- | --- |
| ＜18 | 凡品 |
| 18～29 | 灵品 |
| 30～44 | 玄品 |
| 45～64 | 真品 |
| 65～89 | 地品 |
| 90～124 | 天品 |
| 125～169 | 仙品 |
| ≥170 | 神品 |

这意味着只使用玄品材料，也可以通过数量、多样性和一致性奖励生成真品、地品甚至天品功法。

## 4. 多词缀机制

功法会先保留 2 点能量用于功法本体，其余部分才可用于词缀：

```text
可支配词缀能量 = 有效总能量 - 2
```

### 词缀数量上限

| 可支配词缀能量 | 最多词缀数 |
| --- | ---: |
| ＜25 | 2 |
| 25～49 | 3 |
| 50～89 | 4 |
| ≥90 | 5 |

功法的词缀槽位依次为：

1. 核心词缀，必选，例如基础属性、控制命中或控制抗性。
2. 流派词缀，可选，例如【青木真解】【火行真解】。
3. 共鸣或修饰词缀，可选。
4. 修饰词缀，可选。
5. 修饰词缀，可选。

表中的数量只是理论上限。每次抽取还会受到以下限制：

- 当前槽位是否存在匹配材料语义的候选词缀。
- 剩余词缀能量是否足够支付该词缀的能耗。
- 词缀稀有度是否已经解锁。
- 是否与已经抽到的词缀处于同一互斥组。
- 主元素、共鸣元素和功法流派是否兼容。
- 同一个词缀不能重复抽取。

如果某个可选槽没有合格候选，系统会跳过该槽。因此可能出现能量还有剩余，但成品只有两条词缀的情况。

### 词缀稀有度解锁

| 有效总能量 | 新开放等级 | 累计已开放稀有度 |
| --- | --- | --- |
| 0～24 | `common` | 普通（`common`） |
| 25～79 | `uncommon` | 普通、优秀（`common + uncommon`） |
| 80～119 | `rare` | 普通、优秀、稀有（`common + uncommon + rare`） |
| ≥120 | `legendary` | 普通、优秀、稀有、传奇（全部开放） |

代码中的关键解锁点为：

- 有效总能量达到 25：开放 `uncommon`。
- 有效总能量达到 80：开放 `rare`。
- 有效总能量达到 120：开放 `legendary`。

稀有度解锁采用累计方式。达到 80 后不会只抽 `rare`，而是 `common`、`uncommon` 和 `rare` 都会进入候选范围，最终仍按材料语义、槽位、能耗与权重进行筛选和随机抽取。

达到真品只代表有效总能量达到 45，并不会自动开放稀有词缀。稀有词缀仍需要至少 80 点有效总能量。

### 随机抽取与数值浮动

- 合格候选根据基础权重、标签命中数量和语义覆盖率进行加权随机抽取。
- 词缀数值还有约 0.7～1.2 的随机倍率。
- 有效总能量越高，随机效率的平均值越高。
- 随机效率达到 0.95 以上会标记为极品词缀。

因此，同一套材料重复参悟，可能得到不同词缀组合和不同数值。

## 5. 玄品为上限的材料配法

### 灵品功法秘籍生成真品

功法秘籍不必达到玄品。使用 1 本灵品功法秘籍，搭配四类玄品材料即可稳定跨过真品门槛：

- 灵品功法秘籍 ×1
- 玄品灵药 ×1
- 玄品妖兽材料 ×1
- 玄品天材地宝 ×1
- 玄品辅材 ×1

基础计算：

```text
灵品功法秘籍 8
+ 四件普通玄品材料 8 × 4
+ 五种材料类型奖励 8
= 48 有效总能量
```

48 已达到真品门槛 45，但可支配词缀能量为 46，所以最多只有 3 条词缀。

如果想开放第 4 个词缀槽，目标应为至少 52 点有效总能量：

- 有 3 种材料共享同一个语义标签：`48 + 4 = 52`。
- 或任意 2 种玄品材料各投入 2 件：`48 + 6 = 54`。
- 如果只把 1 种玄品材料投入 2 件：`48 + 3 = 51`，仍然最多只有 3 条词缀。

这里的“共享语义”不要求材料相同。例如秘籍、灵药和妖兽材料都具有“爆发”语义，就视为 3 种材料共享同一语义并获得 4 点一致性奖励。多个共享标签不会重复累加，只按共享材料数最多的那一个标签计算奖励。

该方案只开放词缀数量上限。要实际抽满 4 条，材料还必须为共鸣或修饰槽提供足够的合格候选；共享“爆发＋灵识/灵气”通常比只共享“丹道”更容易进入功法修饰词缀池。

### 生成真品的稳定方案

全部使用玄品，每种投入 1 件：

- 功法秘籍 ×1
- 灵药 ×1
- 妖兽材料 ×1
- 天材地宝 ×1
- 辅材 ×1

基础计算：

```text
功法秘籍 11
+ 四件普通玄品材料 8 × 4
+ 五种材料类型奖励 8
= 51 有效总能量
```

结果为真品，但可支配词缀能量是 49，所以最多只有 3 条词缀。

### 开放第四词缀槽

在上述方案中，任意一种材料改为投入 2 件：

```text
有效总能量约 54
可支配词缀能量约 52
```

此时开放最多 4 条词缀。材料语义仍需匹配后续词缀，否则依然可能只有 2～3 条。

如果至少两种材料共享同一个有效语义标签，原方案也可能因一致性奖励从 51 提升至 53，从而开放第四槽。

### 开放第五词缀槽

使用 6 种玄品材料且每种投入 3 件，并至少包含一本功法秘籍：

```text
有效总能量通常可达到约 95
可支配词缀能量约 93
```

此时开放最多 5 条词缀，并能解锁稀有词缀池。玄品材料的理论极限有效总能量约为 101，无法达到 120，所以不能解锁传奇词缀。

## 6. 玄品功法与真品功法的区别

| 项目 | 玄品功法 | 真品功法 |
| --- | --- | --- |
| 有效总能量 | 30～44 | 45～64 |
| 最多词缀 | 3 | 3～4 |
| 稀有度池 | 普通、优秀 | 普通、优秀 |
| 战力评分品质系数 | 1.24 | 1.36 |

真品的每个可缩放词缀会比玄品多成长一个品质阶梯，但不同词缀使用不同的成长系数，并不存在统一的“真品全部提高固定百分比”。

以常见的基础属性词缀为例，在应用随机倍率前：

```text
玄品：1.5% + 2 × 1.2% = 3.9%
真品：1.5% + 3 × 1.2% = 5.1%
```

由于词缀还有随机倍率，极品玄品的单条数值可能超过低随机值真品。但在相同词缀、相同随机效率下，真品数值更高。

真品不会自动赋予特殊机制。特殊机制来自实际抽到的词缀。

## 7. LLM 在参悟中的职责

当前参悟流程会使用 LLM 完成两类辅助任务：

1. 根据材料名称和描述补充白名单内的语义标签。
2. 根据最终品质、元素、词缀、材料和玩家意念生成名称与描述。

限制如下：

- LLM 补充的标签必须经过白名单过滤。
- 品质、能量、资源消耗和战斗数值由确定性代码计算。
- “玩家意念”只影响名称和风格描述，不会直接修改核心数值。
- LLM 调用失败时会回退到规则分析或规则命名。

所以 Qwen 等模型可能间接影响候选词缀的语义丰富度，但不能随意决定成品是真品、增加词缀数量或填写战斗倍率。

## 8. 实例：【青木锁魂诀】为什么真品只有两条词缀

### 成品

- 名称：【青木锁魂诀】
- 品质：真品
- 元素：木
- 词缀：【锁魂】、【青木真解】

### 实际生成账本

| 项目 | 数值 |
| --- | ---: |
| 材料基础总能量 | 51 |
| 有效总能量 | 63 |
| 功法保留能量 | 2 |
| 可支配词缀能量 | 61 |
| 已消耗词缀能量 | 26 |
| 剩余词缀能量 | 35 |
| 理论词缀上限 | 4 |
| 实际词缀数 | 2 |

已抽词缀：

| 词缀 | 槽位 | 稀有度 | 能耗 | 随机倍率 |
| --- | --- | --- | ---: | ---: |
| 锁魂 | 核心 | 优秀 | 10 | 约 1.0772 |
| 青木真解 | 流派 | 优秀 | 16 | 约 0.9922 |

显示数值的来源：

- 【锁魂】实际控制命中约为 2.69%，界面取整显示为 3%。
- 【青木真解】实际木系伤害提升约为 5.06%，界面显示为 5%。

### 只有两条的根本原因

这次不是能量不足：抽完两条后仍剩余 35 点词缀能量。

真正原因是第三、第四槽需要共鸣或修饰词缀，而当次材料主要形成木、生机、丹道和灵气方向；在当前已解锁的普通、优秀词缀池中，没有同时通过语义匹配、槽位和流派兼容校验的后续候选，所以两个可选槽被跳过。

当前木水共鸣【水木生息】属于稀有词缀，需要有效总能量达到 80；本次有效总能量为 63，因此即使补充水属性，也无法在本次稀有度门槛下抽到它。

### 如何提高同类配方的词缀数量

在保留木系主材和功法秘籍的前提下，可以加入更明确的修饰语义：

- 爆发＋灵气/灵识/秘籍：进入【破釜】【涌潮】等优秀修饰词缀候选池。
- 锋刃＋血煞/爆发/妖兽：进入【死战】候选池。
- 防护＋爆发/金铁/锋刃：进入护盾强化方向候选池。
- 若要继续强化控制方向：把有效总能量提高到至少 80，并加入幻术、雷霆或冰寒语义，才可能进入【摧心】等稀有控制联动词缀池。

“玩家意念”中写控制或护体不会直接增加这些标签，必须由材料本身的名称、描述、类型和元素提供。

## 9. 持有、启用与替换

- 最多持有 10 部自创功法。
- 最多同时启用 5 部功法。
- 只有启用中的功法会被纳入玩家战斗配置，其运行时重建出的被动投影才会实际生效。
- 启用未满 5 部时，新功法通常自动启用。
- 持有达到 10 部后，新功法进入待取舍状态，需要替换旧功法或放弃新功法。
- 生成待取舍功法时，天地灵气、感悟和材料已经结算；之后放弃新功法不会返还这些消耗。

数据库保存的是可重建的功法产物模型，不直接持久化 `battleProjection`；读取功法时会通过现有词缀注册表重新构建运行时战斗投影。

## 10. 当前体验问题

当前结果页只显示最终词缀，没有展示以下关键信息：

- 有效总能量和可支配词缀能量。
- 理论开放了几个词缀槽。
- 某个槽是因为能量不足、稀有度未解锁，还是候选池为空而跳过。
- 哪些材料语义实际进入了候选计算。

因此，像【青木锁魂诀】这种“能量足够但候选不足”的结果，看起来容易被误认为系统少给了词缀。后续可考虑在结果页增加一段可展开的“参悟账本”。
