# combat-v6 Phase 5A 功法内容与数值基线

> 状态：已实现（2026-09-03）
> 上位设计：[`combat-v6 功法系统设计`](./combat-v6-manual-system-design.md)

Phase 5A 将功法实现为人物跨宗门被动。首版只有一套构筑，不提供主动技能、自动连击、法连、隐匿、AI 内容或旧功法转换。

## 槽位与状态

炼气至渡劫的道印位依次为 `2、3、4、5、6、6、6、6、6`。状态使用 `CultivatorManualStateV1`，所有参悟、改修和散功操作显式指定槽位并校验 revision；本篇可在原槽升级为真解，其他冲突必须先散功。

## 首批十个谱系

| 谱系 | 本篇 | 真解 |
| --- | ---: | ---: |
| 断岳 | 主动直接物理暴击 +5 个百分点 | +10 个百分点 |
| 凝光 | 主动直接法术暴击 +5 个百分点 | +10 个百分点 |
| 破军 | 主动直接物理伤害 +5% | +10% |
| 焚灵 | 主动直接法术伤害 +5% | +10% |
| 饮血 | 物理实际伤害吸血 10%，单行动恢复上限为最大气血 15% | 15%，上限 25% |
| 护元 | 气血低于 50% 时打击承伤降低 8% | 降低 15% |
| 回生 | 每场首次致命事件 20% 概率复起，恢复最大气血 20% | 30% 概率，恢复 30% |
| 定魂 | 封禁抵抗 +10 | +20 |
| 冥思 | 回合末恢复最大法力 2% | 4% |
| 生息 | 回合末恢复最大气血 1% | 2% |

暴击、增伤与饮血只作用于普攻、宗门主动技能和攻击型器诀产生的直接伤害。DOT、主动耗血、伤势和 Hook 派生伤害不受益。饮血、回生、冥思和生息是独立资源恢复，不读取治疗强度或施疗/受疗倍率。

回生的唯一机会在判定时消耗，失败后本场不再判定；成功会清除普通战斗状态，保留 `persistWhenDowned` 状态。状态 tick 先于冥思和生息，只有 tick 后仍站立且未逃跑的人物能够恢复。

