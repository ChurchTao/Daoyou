# 红尘剑宗 V6 技能与流派审查

> 日期：2026-09-21。范围：当前 V6 的 10 个主动技能、双流派 42 个节点，以及相关编译、伤害、状态和剑意结算逻辑。
> 本文为审查与设计建议，不是已批准的改版方案；不修改当前配置、机制或存档。机制结论来自代码路径检查，数值比较为限定条件下的公式分析，不代表跨宗门实战胜率。

## 1. 结论

大唐式的「集中点杀—休息」「后发抢先」「养意再爆发」骨架可以保留。当前优先级应是先修机制与配点陷阱，再调整终式和节点预算，最后统一命名。

主要问题：

1. **组合有效性不足**：「连破＋四象归锋」丢失第四剑；「剑意不绝」主动养意后反复停在 10 点；「血勇」完全覆盖「神凝」。
2. **高层奖励缺少足够回报**：两种终式的常规单体伤害均低于基础三连，却仍需休息；万锋归一还清空全部剑意。
3. **同层选择预算失衡**：新主动技能、永久增加一段攻击，与一次性追击、下一段小幅增伤放在相近甚至相同的竞争位置。
4. **部分收益容易溢出或重复**：命中堆叠很快触顶；高频刷新惊鸿时，延长持续时间的价值有限。
5. **名称有意象，却没有稳定地传达动作**：「凝罡」实际只加命中，「开天门」实际缺少终式独有机制；「斩尘证道」也与宗门“不求无尘，但求无愧”的背景存在张力。

## 2. 优先修复的机制与配置问题

### P1：连破会使四象归锋的第四剑失效

涉及万剑归一 `6.1`、`7.1`。

编译器按层依次应用补丁。六层连破先在技能末尾追加扣除 3 点剑意；七层四象归锋随后追加「当前剑意至少 11 点」才生效的第四剑。执行器逐个执行效果，条件读取的是即时资源，而不是出手时的资源。

因此满 11 点出手时：前三剑 → 取消休息 → 剑意降到 8 → 第四剑条件不满足 → 行动结束再获得剑意。资源上限只有 11，正常执行这一组合时第四剑无法触发。

建议明确「满剑意强化」按出手时判定，并让额外伤害在本次消费之前结算；选择最小的内容/补丁调整即可，不必为宗门在 core 中加特判。修复后还必须复查连续三连与满剑意第四剑的总输出，不能只把失效节点恢复后视为平衡完成。

### P1：剑意不绝的收益与扣费时机脱节

涉及万剑归一 `7.3`。

增伤在每段伤害计算时要求当前剑意为 11；扣费却在行动后、基础养意等获得剑意的钩子之后检查当前资源。

仅靠主动技能养意且没有行动外获意时，会出现：

- 10 点使用裂阵沉舟：伤害阶段没有 10% 增伤 → 养意到 11 → 扣回 10。
- 10 点使用惊鸿掠影：伤害阶段没有 10% 增伤 → 技能效果加意并夹到 11 → 扣回 10。
- 后续重复以上过程，始终无法把 11 点留到下一次攻击。

受锋等行动外获意可以让它获得收益，因此不能笼统称为“任何情况下都无效”；但节点暗中依赖另一个节点和敌人的攻击，普通主动循环无法兑现顶层奖励。非伤害技能也可能触发扣费。

建议把支付绑定到确实获得该增伤的一次攻击，并明确整次技能共消费一次；或者重做成可以维持的高剑意档位。不要先给所有产意技能加点数，这不会解决时序问题。

### P2：血勇完全覆盖神凝，形成零边际收益配点

涉及斩尘证道 `4.1`、`6.2`。

神凝把三连门槛降到 40%；血勇同时降低耗血，并把门槛降到 35%。两者都通过 `capRequireHpRatio` 取较小值，共选之后，移除神凝不改变任何最终战斗效果。

建议血勇保留耗血减免，门槛职责留给神凝；或者把神凝改为独立作用。不要仅把 40% 改成更低数字，否则会继续挤压三连的血线约束。

### P2：砺锋、裂军的“伤害提高”文案不等于实现

砺锋写“总伤害提高 5%”，实际只将系数乘 1.05；每段附加的技能等级伤害不受影响。裂军也只乘系数，并非整段伤害乘 1.1。

此外，砺锋在一层修改已有三段；四绝在七层追加的第四段仍为 0.95，也没有乘到砺锋。

建议先决定这两个节点究竟是“系数强化”还是“最终伤害强化”。若保留现实现，应准确改文案；若兑现原文案，应覆盖附加伤害和后续增加的段数，并重新计入节点预算。

## 3. 主动技能的强度与定位

### 3.1 两个终式缺少与成本匹配的收益

令 `B` 为物理公式中的基础伤害，心法同级为 `L`。先忽略命中、暴击、浮动、逐段取整、修炼差、护盾和其他节点，且目标能承受完整连击：

| 技能 | 单次总伤害近似 | 成本与节奏 |
| --- | --- | --- |
| 断尘三叠 | `2.55B + 1.5L` | 10% 最大气血，至少 50% 血线，随后休息 |
| 血锋连斩 | `1.50B + 0.8L` | 8% 最大气血，无休息、无额外血线门槛 |
| 一剑开天门 | `1.65B + 0.6L` | 15% 最大气血，随后休息 |
| 万锋归一 | `1.80B + 0.6L` | 要求 11 点并清空剑意，随后休息，无耗血 |

以 `B=650、L=120` 为演算示例，四者约为 1837.5、1071、1144.5、1242。此示例不是实际角色标定值。

单段本身在当前公式下不天然更擅长破高防：技能系数乘在物理基础伤害上，并没有在扣防前放大攻击。多段还会重复获得等级附伤。两个终式也没有配置专属忽防、必中、斩杀或破盾机制。

一剑开天门存在低于三连门槛仍能施放的用途；万锋归一存在不耗血、减少多次受击反应的用途。因此不是所有场景严格劣于三连，但不足以自然支撑“七层终式”的定位，尤其同层还有四绝。

建议先选定终式职责，再定倍率：

- 一剑开天门：作为破坚重剑，与三连的稳定点杀区分；让重甲/护盾或其他明确目标条件下的收益足以覆盖代价。
- 万锋归一：作为主动兑现养意成果的爆发。若保留清空 11 点和休息，兑现后的收益必须高于继续保留高剑意攻击的机会成本；若输出只接近基础点杀，就应显著降低资源或休息代价。

不建议在未确定职责前直接填一个“大倍率”。

### 3.2 血锋连斩有价值，但会挤压同层其他选项

两回合连续血锋为 `3B + 1.6L`，两回合三连＋休息为 `2.55B + 1.5L`。血锋消耗 16% 最大气血，三连消耗 10%，所以有“持续输出换更多血量”的合理交换；它不是无代价超模。

问题在于同层杀意和蓄锐只强化下一段伤害。对三连而言，一次首段提高 10%，整次技能通常只增加约 3%；一次首段提高 12%，约增加 3%～4%。还分别要求击倒或主动防御并受击。与获得一个无休息、低血线可用的主动技能相比，竞争力明显不足。

建议优先重做杀意、蓄锐的收益单位和使用场景，而不是先削弱血锋。

### 3.3 命中收益必须按实际命中率评估

当前公式为 `clamp(0.2, 1, 0.5 + (命中 - 闪避) / 200)`。

- 明锋的 +30 命中最多提供 15 个百分点，不是 30% 增伤。
- 剑煞凝罡在 120 级提供 +120 命中，最多对应 60 个百分点，但超过上限的部分没有收益。
- 万剑归一的 2 点剑意根基是命中概率 +0.1；旧纵切文档写“+20 命中”，边界行为不能完全等同。

裸身面板中，命中为 `80 + 永久速度属性`，闪避为 `永久速度属性`。双方永久速度相同、没有其他修正时，基础已有 90% 命中；剑煞心法达到 40 级再加 20 命中，已经触顶。

因此“增加命中”可能在高速/高闪避对手面前有用，在常规同速对手面前完全无收益。应把低闪避、同速、高闪避三个目标档位纳入比较；不宜让主动增益和多个节点同时依赖这一容易溢出的属性。

### 3.4 后发、群攻、控制各有用途，但不能只比较纸面伤害

- 伏锋待机是当前行动蓄势、下回合强制抢先普攻，并非本回合反击。它的价值包含物防、命中和抢先收人头；候锋的两回合仅 1 点剑意不足以独立支撑选择。
- 裂阵沉舟 1～59 级只有一个目标，60 级两个，120 级三个；命名和预览应说明成长，避免初学时期待群攻。拓阵/开阵是实质性的目标数档位奖励。
- 澄神守一增加法防与封抗，不是净化。摄心剑印是概率混乱，不是硬性跳过敌人行动。二者先保留战术职责，不因物理输出宗门就直接删除。

### 3.5 未点经脉时，两流派的根基不对等

相同六心法、没有节点时，斩尘没有流派根基被动、额外主动或资源；归一保留同样六个基础技能，额外拥有惊鸿、剑意和 2/5 点奖励，没有相应负面交换。因此这一阶段归一的可用能力是斩尘的超集，斩尘的独特收益完全依赖后续节点。

这不能直接推出满经脉归一更强，但说明入门流派选择缺少对等理由。建议先明确是否允许这种成长差异；若两条流派应从入门就有特色，应给斩尘一个与即时点杀/收剑节奏有关的小型根基，并从后续节点总预算中统筹，而非简单白送一层增伤。

万剑归一的启动成本也影响整体流派价值：不受击、无鸿意、未选剑意不绝、仅用惊鸿养意时，达到 11 点需要六次惊鸿，随后才能以满剑意发动其他攻击；鸿意将其缩为四次。短战中高层节点可能根本没有兑现机会。应分别检查短战、中战和首领长战，而不是给流派一个统一“强/弱”标签。

## 5. 命名建议

原则：招式名称先表达动作或用途，再承载少量剑宗意象；精确段数、目标数、门槛、休息放在短说明里。保留已有辨识度好的名称，不必全部重命名。

| 当前名 | 问题 | 建议名 | 配套的一句用途说明 |
| --- | --- | --- | --- |
| 断尘三叠 | “三叠”有连击感，但动作略隐；“断尘”与宗门母题有张力，四段后段数也不直观 | 叠锋连斩 | 单体连续斩击，出剑后调息。 |
| 伏锋待机 | “待机”像系统状态，缺乏剑招感 | 藏锋后发 | 本回合蓄势，下回合抢先出剑。 |
| 裂阵沉舟 | 前半能表达破阵，后半像额外绝境/搏命机制 | 横剑破阵 | 横剑扫敌，目标数随修为增长。 |
| 剑煞凝罡 | 容易被理解为伤害或护盾，实际只加命中 | 照隙剑诀 | 洞察破绽，提高一名友方的命中。 |
| 澄神守一 | 大体成立，但防护职责还能更明确 | 澄心护神 | 提高自身法防与封禁抵抗。 |
| 摄心剑印 | 控心意象与混乱契合 | 保留 | 概率扰乱敌人心神，使其随机普攻。 |
| 血锋连斩 | 耗血、攻击、连击都已有暗示 | 保留 | 耗血连斩两剑，无需调息。 |
| 一剑开天门 | 气势过大，无法识别用途；现效果也不支撑承诺 | 一剑断岳（机制定稿后确认） | 单剑重击；若改为破坚，说明应明确破坚条件。 |
| 惊鸿掠影 | 速度意象成立，但像纯身法 | 掠影追锋 | 攻敌、加速并积累剑意。 |
| 万锋归一 | 汇聚为一剑的动作与资源兑现契合 | 保留 | 汇尽剑意发动终式，随后调息。 |

流派名建议保留「万剑归一」；「斩尘证道」可考虑「纵剑决胜」，以出剑决断、击倒追击区别于养意爆发。名称是候选，不在本轮锁定。

节点只需优先改少数语义薄弱或重复者：

- 神凝 → 血战：前提是继续承担低血施放。
- 明锋 → 照隙：明确命中方向，与命中剑诀统一词根。
- 杀意 → 乘胜：与现有状态名一致，表示击倒后获益。
- 长虹 → 留影：表达延长惊鸿状态。
- 四绝 → 四叠连锋：表达第四剑。
- 斩尘连破 → 乘胜连斩；归一连破 → 剑意连斩：让取消休息的两种条件可辨。

“破甲”若保留，要在说明中写清是本次攻击忽防，没有给敌方挂持续减防状态。“澄心护神”同样不能暗示净化。

## 6. 下一轮打磨顺序与验收标准

1. **先修组合与说明**：连破＋四象、剑意不绝、神凝＋血勇、系数与总伤害不一致。验收应有实际战斗事件和资源变化断言，不能仅检查编译结果变化。
2. **再重定价关键选择**：两终式、斩尘三层与七层、后发养意、长虹。先明确每层至少两个不同场景下成立的选择，再做精确数值。
3. **最后落定命名**：稳定 ID 保留，仅改显示文案与对应引用；机制确定前不要用更强烈的名称掩盖定位问题。

建议下一轮在已有纯共享引擎测试体系中增加以下验证，不新增独立脚本框架：

- 满 11 点、连破＋四象，目标存活：四次打击、一次消费、无休息；另测不足 11 点和中途击倒。
- 剑意不绝：10→11 的获得过程不应为未享受的增伤付费；享受增伤的一次多段攻击只消费一次；辅助/休息是否扣费须有明确设计。
- 神凝＋血勇：两者共同选择时各自应有可观察收益，或配置明确禁止冗余选择。
- 砺锋＋四绝、裂军：逐段和整次伤害应与最终文案一致。
- 养意的 0/2/5/8/11 档位，分别覆盖不受击、每回合受击、护盾完全吸收，以及连续三连的耗血约束。
- 相同装备/心法/修炼下，比较 3、6、12 回合的输出、兑现回合、耗血、休息和控制机会成本；覆盖单体与多目标、不同防御及闪避档位。固定种子的确定性验证与多种种子的平衡统计应分开解释。
