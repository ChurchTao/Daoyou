# MMORPG 战死、爆装与安全存储设计

> - 状态：讨论整理稿
> - 适用范围：开放世界遭遇战、野外 PvP、高危地图和多人秘境
> - 核心目标：让战死具有风险和刺激感，但不清空核心成长，也不迫使玩家重头开始。

## 1. 问题背景

如果玩家在普通遭遇战失败后被掠夺整个储物袋，会产生以下问题：

- 长期积累可能被一次失败全部清空。
- 新玩家和弱势玩家容易被反复掠夺，无法恢复。
- 玩家为了避免损失会拒绝携带物资，进而回避开放世界玩法。
- 强者通过掠夺继续扩大优势，形成不可逆的滚雪球。
- 玩家失去的不是一次战斗收益，而是数天甚至数周的成长成果。

因此不采用“普通死亡清空全部储物袋”的默认规则。基础成长应保持安全，风险主要作用于玩家主动携带的部分资产。

## 2. 核心原则

### 2.1 战败不等于删号

角色死亡后可以复活，以下内容不应因一次死亡归零：

- 境界和修为阶段。
- 已学功法和技能。
- 洞府、宗门身份和已解锁玩法。
- 主线任务进度和长期剧情记忆。
- 绑定物品、任务物品和付费物品。
- 安全箱中的所有资产。

### 2.2 损失必须提前可知

进入危险区域前明确显示：

- 是否可能战死。
- 是否允许 PvP。
- 可能爆落的物品范围。
- 最大爆落件数和价值。
- 当前装备受到哪些保护。

### 2.3 风险必须由玩家控制

玩家可以通过存放物品、减少携带、保护装备、购买保险或离开危险区域来降低风险。普通挂机和普通云游不能在玩家不知情时进入全掉落状态。

### 2.4 损失必须能够恢复

死亡可以带来短期挫折，但应提供以下恢复路径：

- 返回死亡地点寻回遗物。
- 修复损坏装备。
- 使用宗门援助、保险或护命道具。
- 通过追凶、复仇或悬赏任务取回部分损失。
- 连续失败时获得损失保护。

## 3. 战败与战死分级

| 结果 | 常见场景 | 推荐后果 |
| --- | --- | --- |
| 战败 | 普通副本、切磋、低风险云游 | 返回安全点，轻伤或耐久损失，不爆装备 |
| 重伤濒死 | 普通野外遭遇、团队战斗 | 短时间倒地，可被队友、NPC 或丹药救援 |
| 战死 | 明确标注的高危地图或 PvP | 宗门复活，产生有限爆落与神魂伤势 |
| 轮回 | 玩家主动选择的硬核模式 | 保留传承后转世，不作为默认死亡规则 |

普通区域应以“战败”为主。只有提前标明风险的区域和行为才进入“战死”判定。

## 4. 安全存储系统

### 4.1 洞府安全箱

洞府安全箱是玩家最主要的资产保护设施：

- 箱内物品永不参与死亡爆落。
- 只能在洞府、宗门或指定城镇存取。
- 初始容量有限，可通过洞府建设、宗门贡献或灵石扩容。
- 不能在野外实时取用，避免完全消除出行风险。
- 角色复活后仍可正常访问。

### 4.2 随身保护格

玩家可拥有少量不会爆落的随身格，适合存放本次行动必需的关键物品：

- 初始提供一至两个保护格。
- 可通过纳灵匣、锁魂印等道具扩充。
- 保护格数量应严格限制，不能代替洞府安全箱。
- 任务物品和明确绑定物品不占普通保护格。

### 4.3 商会托管库

可选的跨地区安全存储服务：

- 在主要城镇存取。
- 跨城取出需要手续费或等待时间。
- 适合作为灵石回收机制。
- 不允许在战斗中或高危区域直接远程存取。

### 4.4 出行决策

安全存储应形成明确的风险选择：

```text
珍贵资产存入洞府安全箱
  → 选择本次行动所需装备和补给
  → 将少量关键物品放入随身保护格
  → 其余随身物资承担对应区域的爆落风险
```

## 5. 爆落方案

### 5.1 不采用全储物袋掠夺

普通玩家战死后，不能把整个储物袋原样转移给击杀者。建议由服务端根据可掠夺范围和价值上限生成战利品包。

这样可以保证：

- 不会抽中安全箱、绑定和任务物品。
- 不会因一个超大材料堆叠超过损失上限。
- 可以为新玩家、连续失败者和正常玩家应用保护规则。
- 服务端可以记录每件爆落物的来源，便于申诉和异常追查。

### 5.2 《传奇》式装备爆落

“死亡后概率爆出少量身上装备，随后复活”是可行方案，优点是规则直观、战斗刺激强、战利品有展示价值。

但极品装备的完整丢失可能导致玩家直接弃游，因此需要分层处理：

- 普通区域不爆装备，只损失耐久或少量随身物资。
- 普通野外 PvP 只允许低概率爆落一件未保护装备。
- 高危区域最多爆落一至两件，并在进入前明确提示。
- 正常玩家的高价值装备优先进入“破损掉落”，而不是直接转移所有权。
- 红名玩家和主动进入极端红区的玩家可以完整爆装。

### 5.3 破损掉落

高价值装备可以采用残器机制：

- 原主人保留损坏装备，需要材料和灵石修复。
- 获胜者得到装备残片、器魂或部分打造材料。
- 双方都能感受到战斗结果，但失败者不会永久失去唯一核心装备。
- 极端高危模式可以关闭该保护，使完整装备成为可拾取战利品。

### 5.4 推荐初始参数

| 场景 | 随身物资损失 | 装备风险 |
| --- | --- | --- |
| 安全区、切磋 | 0 | 0 |
| 普通 PvE 战败 | 0～5%，以耐久和伤势为主 | 不爆落 |
| 普通野外 PvP | 最多10%～20%未绑定随身物资 | 低概率一件破损掉落 |
| 高危区域 | 最多20%～30%，设置总价值上限 | 最多一件完整或破损装备 |
| 极端红区 | 进入前主动确认 | 最多两件完整装备 |
| 红名玩家 | 在所在区域基础上提高 | 至少一件，最多两件 |

百分比和价值上限需要根据真实经济数据调整，不能只根据物品数量计算。

## 6. 装备与物品保护

### 6.1 永久保护

以下物品不参与爆落：

- 主线和宗门任务物品。
- 已绑定的核心成长物品。
- 付费物品及法规要求保护的资产。
- 安全箱和托管库中的物品。
- 系统明确标记为不可交易的物品。

### 6.2 主动保护

玩家可以配置有限的保护手段：

- `锁魂印`：保护指定的一件装备。
- `护命符`：本次死亡降低爆率或代替装备损坏。
- `战利品保险`：返还部分打造材料，不直接复制完整装备。
- `随身纳灵匣`：提供少量不爆落格子。

保护手段应主要消耗游戏内资源，避免形成单纯付费免除风险的体验。

## 7. 复活与恢复体验

### 7.1 倒地救援

进入战死结算前提供短暂倒地阶段：

- 队友可以施救。
- 敌人不能无限延长倒地时间羞辱玩家。
- 超时或被处决后才进入战死结算。
- 普通怪物不会持续守尸。

### 7.2 宗门命灯复活

战死后通过宗门命灯或元神回归复活：

- 在宗门、洞府或最近安全城镇重生。
- 保留角色等级、境界、功法和剧情状态。
- 获得有明确结束时间的“神魂受损”。
- 可以通过休养、丹药、宗门设施或短任务提前恢复。

### 7.3 遗物寻回

死亡地点可以生成限时遗物或尸身储物匣：

- 一部分未被其他玩家拾取的物品留在原地。
- 玩家可以独自返回，也可以邀请队友协助。
- 遗物过期后可由邮件返还不可掠夺部分。
- 重要剧情死亡可以产生托梦、追凶、复仇或故人来信。

死亡由此成为后续玩法入口，而不是单纯的惩罚页面。

## 8. 红名、因果与反恶意机制

### 8.1 主动袭击的代价

主动击杀非敌对玩家会积累血煞、罪业或通缉值：

- 红名玩家死亡爆率更高。
- 无法使用部分安全城镇和商会服务。
- 位置更容易被追踪。
- 其他玩家可以领取悬赏任务。
- 连续攻击低境界玩家会快速提高惩罚等级。

### 8.2 被害者保护

- 新玩家和低境界玩家具有保护期。
- 复活后获得短期不可攻击状态。
- 连续被同一玩家或队伍击杀时，后续损失递减至零。
- 大境界差距过大时，击杀者收益下降而罪业上升。
- 注销、断线和地图切换不能规避已经确认的战斗结算。

### 8.3 防止滚雪球

- 战利品价值有单场和每日上限。
- 击杀同一玩家的重复收益快速衰减。
- 高价值战利品公开来源并进入追踪记录。
- 极端高风险收益必须对应同等级的暴露和被追杀风险。

## 9. 推荐默认规则

第一版建议采用以下组合：

1. 普通区域只有战败，不完整爆装。
2. 玩家拥有洞府安全箱和少量随身保护格。
3. 普通野外战死最多损失随身未绑定资源价值的20%。
4. 普通玩家最多出现一件装备破损掉落，不直接清空整套装备。
5. 高危区域允许一件完整装备爆落，进入前必须二次确认。
6. 红名玩家最多爆落两件装备，并承担追踪和悬赏风险。
7. 战死后通过宗门命灯复活，境界、功法和长期成长全部保留。
8. 连续被击杀、新手期和刚复活状态提供额外保护。

核心体验可以概括为：

> 基础成长永远安全，随身收益承担有限风险；高额爆装只属于玩家明确选择的高危玩法。

## 10. 第一版验收标准

1. 普通 PvE 失败不会导致装备、功法、境界或安全箱资产丢失。
2. 任何死亡结算都不会选择绑定、任务和受保护物品。
3. 爆落价值不会超过当前区域配置的比例与总价值上限。
4. 高危区域在进入前明确展示规则，并记录玩家确认。
5. 红名与普通玩家应用不同的爆落上限。
6. 玩家复活后可以立即进行基础活动，不会因死亡完全失去行动能力。
7. 连续被同一攻击者击杀时，不会持续产生同等损失。
8. 服务端能够追踪死亡、爆落、拾取、保险、返还和修复的完整链路。

## 11. 开工前必须确定的事项

不需要在编码前确定每一个最终数值，但以下规则会改变数据模型、战斗流程或网络架构，必须先拍板。

### 11.1 遭遇战形态

这是最优先的架构决策，需要在以下方案中选择第一版：

| 方案 | 说明 | 主要影响 |
| --- | --- | --- |
| 实时开放地图 | 玩家在同一地图移动、追逐并直接开战 | 需要位置同步、视野、AOI、断线处理和更高频服务器状态 |
| 地图匹配后进入战斗实例 | 地图只表达玩家存在，遭遇后进入权威战斗房间 | 能复用现有战斗引擎，第一版成本较低 |
| 离线异步袭击 | 使用玩家保存的阵容或快照自动结算 | 不需要实时联机，但公平性和离线保护规则更复杂 |

推荐第一版采用“地图匹配后进入战斗实例”。先验证 PvP、死亡、爆落和经济闭环，再决定是否升级为实时开放地图。

### 11.2 PvP 触发规则

需要确定：

- 哪些地图允许主动攻击。
- 是否需要双方同意，或者高危区默认同意。
- 是否允许攻击正在挂机、断线或加载中的玩家。
- 大境界差距是否禁止开战。
- 组队、偷袭、援助和第三方加入如何处理。
- 玩家退出、断线和超时时按照撤退、战败还是战死结算。

### 11.3 区域风险表

每类区域必须配置明确的死亡规则：

```text
是否可能战死
随身物资损失比例
损失价值上限
装备最大爆落件数
完整爆落还是破损掉落
是否允许使用护命道具
复活地点和神魂伤势
```

所有客户端提示读取同一份服务端配置，不能在页面中另写一套规则。

### 11.4 装备所有权变化

需要确定装备爆落后的法律状态和生命周期：

- 完整装备是否立刻转移所有权。
- 原主人、队友和击杀者分别拥有多长时间的拾取优先权。
- 未拾取物品多久消失或通过邮件返还。
- 破损装备由谁持有，胜者获得什么残片。
- 已强化、镶嵌或带有唯一 ID 的装备如何保存属性。
- 交易锁、保险和申诉期间是否允许再次出售。

### 11.5 安全箱规则

需要确定：

- 初始容量和扩容方式。
- 哪些地点可以存取。
- 是否按角色、账号或洞府共享。
- 是否允许存入正在交易、任务锁定或来源异常的物品。
- 死亡、转服、角色删除和宗门退出时如何处理。

推荐按角色拥有洞府安全箱，后续再增加账号共享仓库；第一版不支持野外远程存取。

### 11.6 复活与伤势

需要确定：

- 倒地持续时间和队友救援方式。
- 复活地点的选择规则。
- 神魂伤势持续多久、影响哪些属性。
- 是否能用游戏资源立即恢复。
- 复活保护持续时间和取消条件。
- 连续死亡保护如何叠加和重置。

伤势不能严重到让玩家复活后仍无法参与任何玩法，否则复活只是延迟后的软封号。

### 11.7 红名与反滥用

需要确定：

- 什么行为增加罪业，什么行为属于合法反击。
- 红名阈值、消除方式和死亡惩罚。
- 击杀同一玩家的收益衰减。
- 小号互刷、工作室转移装备和故意送死如何识别。
- 大境界压制、新手保护和复活保护规则。
- 是否开放悬赏、追踪和宗门战争等合法 PvP 身份。

### 11.8 经济验证

在确定正式爆率前，需要用当前物品和市场数据回答：

- 玩家平均随身资产价值。
- 各品质装备的平均制作时间和交易价格。
- 一次死亡损失相当于多少小时正常收益。
- 每日 PvP 产生和销毁多少物品、材料和灵石。
- 保险、修理和安全箱扩容是否会造成过强付费优势。

推荐把普通玩家一次战死的预期恢复时间控制在30分钟至2小时，高危区由玩家主动承担更长恢复时间。

### 11.9 技术权威边界

以下结果必须由服务端在事务内裁决：

- 战斗参与者、区域规则和死亡类型。
- 可爆落物品集合、随机结果和价值上限。
- 所有权转移、耐久变化、保险赔付和邮件返还。
- 红名、罪业、悬赏和连续击杀保护。
- 复活状态、伤势和保护期。

每次死亡需要一个稳定 `death_event_id`，爆落、拾取、修复、保险和返还都引用该 ID，保证幂等并形成审计链。

## 12. 推荐第一版垂直切片

如果接受以下默认值，就可以开始制作，不必等待完整 MMORPG 设计全部完成：

1. 只在一个新建高危地图开放 PvP，普通地图保持现状。
2. 玩家在地图上发起遭遇后进入独立权威战斗实例，不制作实时自由移动和追逐。
3. 高危地图进入前二次确认，离线和加载中的玩家不可被攻击。
4. 玩家战死后在宗门复活，境界、功法、绑定物品和安全箱资产不变。
5. 初始洞府安全箱固定容量，只能在洞府存取。
6. 战死最多损失20%未绑定随身物资，设置单场价值上限。
7. 普通白名最多一件装备进入破损状态，不完整转移所有权。
8. 主动袭击者积累罪业；连续击杀同一玩家不再产生战利品。
9. 复活后获得短期保护和可通过休养解除的轻度神魂伤势。
10. 第一版暂不实现完整爆装、悬赏追踪、保险、商会跨城仓库和永久轮回。

### 12.1 第一版开发顺序

```text
区域风险配置
  → 洞府安全箱与物品保护标记
  → 遭遇战实例及断线规则
  → 战败/战死服务端裁决
  → 战利品包与破损装备
  → 宗门复活、伤势和保护期
```
