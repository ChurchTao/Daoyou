# 召唤兽资质范围校准（2026-09-11）

本轮使用可访问的《梦幻西游》手游普通宠物图鉴，校准道友三个现有物种的出生资质与成长范围。数值落点在 `beasts/data/species.json`，`contentRevision = 3`。七项派生公式、技能、五维预算、携带门槛及野外敌人面板沿用当前实现。

## 1. 来源口径与限制

目标是回合制手游普通宠物出生范围，不混用电脑版、变异宠、合宠、神兽或培养突破后的资质。以下 4399 图鉴正文与完整表格于 2026-09-11 核验，作者均为 4399 挽歌；属于 **C 级历史第三方资料**。可以支撑道友采用可追溯的历史手游基线，不能证明 2026 年手游当前版本的官方全物种上限。

[17173 2021-12-23 转载分析][analysis] 写普通吸血鬼体资 4276～5346，而 4399 2015 图鉴写 3960～4950；攻资 1248～1560、法资 1728～2160、成长 1.102～1.150 相同。无法仅凭日期判定是版本更新、样本分类还是转载问题，不能混合两份数据计算“官方区间”。本轮采用 2015 图鉴作为明确历史快照，吸血鬼只用于尺度比较，不用于三个现有物种的校准。

## 2. 道友各类资质的数值尺度

以下是上述九种普通宠物样本的最小值至最大值，用于内容策划参考，**不是全部手游宠物的全局硬上限**，也不是每个物种都可在整个区间内随机。

| 类别 | 已核验样本覆盖范围 | 当前三个道友物种覆盖范围 |
| --- | --- | --- |
| 攻击资质 | 672～1680 | 672～1380 |
| 防御资质 | 576～1260 | 624～1080 |
| 体力资质 | 2160～5850 | 2160～4950 |
| 法力资质 | 960～3000 | 960～1920 |
| 速度资质 | 576～1560 | 576～1080 |
| 成长 | 0.952～1.300 | 0.952～1.060 |

体力资质应在数千尺度，法力资质通常也高于原先约 1000 的统一范围。资质贡献系数不同，不能要求五资质的数值大小或总和相同；例如 1 点体资与 1 点攻资不具备相同战斗价值。

本组图鉴资质下限均为上限的 80%，成长跨度均为 0.048；这是这些样本的规律，不泛化为所有物种、变异、合宠或当前版本的官方规则。配置仍逐项保存明确上下界。道友保留闭区间均匀整数抽取、成长千分值均匀抽取；图鉴只能证明范围，不能证明官方随机分布或成长档位与我们一致。

不将 `BeastSchema` 的通用存储边界 0～100000 收紧到本表，避免误判既有个体或未来其他来源。新生个体由物种范围约束；已保存个体继续按原事实读取。

选择按战斗职责而非外形：花妖是前期单法宠；龟丞相有高体资、低速度，适合作为血防宠参照；老虎是高攻资、低防资的前期攻宠。手游野猪本身偏物攻且防资低，不适合直接作为岩甲猪的防护模板。

本轮完整采用三组资质与成长，不逐字段拼装最优值。青灵狐默认加魔、岩甲猪默认加体、疾风狼默认加力保持不变。疾风狼名称不代表本轮已赋予最高速度；速度特色以后通过经验证的加点、技能或明确偏离预算处理。

**道友偏离：** 三物种仍在 5 级可携带，免费伙伴为 10 级；参照模板原携带等级分别为 25、35、15。当前定位是并列的新手法术／防护／物理选择，不复制手游解锁顺序。因成长和资质结构不同，三者并非等战力，也不宣称通过范围复制就完成了对战平衡。

后续新增物种先指定职责与成长阶段，再选择完整手游模板，逐项记录来源和偏离。超过上述样本范围需补充对应证据；不直接抬高所有资质或固定每阶段统一涨幅。

## 5. 生效与存量

- 仅影响发布后新领取、新捕获个体的资质和成长抽取；已有个体不按新范围重掷、夹取或换算。
- 两次相同种子在同一内容修订下结果仍一致；同一旧种子跨内容修订可能得到不同资质，不能用当前配置重建历史生成事实。
- 既有 `generationVersion` 表示生成格式／算法，本轮递增物种 `contentRevision`，不改存储结构；个体实际资质、成长仍是权威。
- 如需让已拥有宠物一并受益，应另做保留区间相对位置的存量迁移方案，明确旧区间、旧修订与异常个体处理。本轮未写数据库。
- 技能倍率和野外敌人面板没有随之补偿；正式整体发布前仍须完成治理计划中的战斗场景验证。

## 6. 验证

更新三物种新生／捕获／投影的 128 种子基线，显式检查五资质与成长落在采纳区间；保留旧范围个体在新配置下合法的测试。使用 `bun run test src/shared/engine/combat-v6/beasts`，再检查完整共享测试、lint 与构建。基线只随本次已授权的出生范围变化更新。
