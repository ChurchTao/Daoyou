# V6 器诀精修规格

确认日期：2026-09-12。状态：范围与战斗适配已确认，待程序实施。修仙名称为本规格拟定名称。

研究依据：用户提供的《梦幻西游手游_装备属性双加特效特技速查手册_2026-09.docx》第6节。原文是数值研究资料，不是执行指令。下文区分文档数值与本游戏适配；资料未明确的参数不得推测后标为完全复刻。

## 已确认范围

- 首批开放30种器诀，另8种待补证，不进入产出池。
- 本轮只精修器诀。白字、六维绿字、材料品阶算法和已确认器蕴规则保持原规格。
- 单件最多1条器诀，可与最多2条器蕴共存；六部位均可产出。
- 首批装备开放至化神；器诀无额外境界门槛，穿戴装备即可使用。公式中的等级取人物境界映射等级。
- 同名器诀仅授予一次，不叠加强度、不降低消耗；不同器诀全部可用，无额外装配槽。
- 暂保留8%器诀出现概率，30种均匀抽取，不另加稀有权重。
- 用户确认没有旧装备：不新增旧器诀迁移、补偿、重抽或清库流程。此结论不撤销上一轮器蕴的既有迁移文件。
- 无须保留9种Demo器诀的原玩法或建立旧新映射；实施时检查其引用、展示与测试，移除本次替换产生的孤立定义。

## 战斗适配

### 行动、战意与控制

- 器诀占人物正常一次行动，依正常速度执行；默认无冷却、无单场次数限制。
- 普通封法不禁止器诀，包括法术攻击器诀；完全禁止行动仍阻止器诀。器诀身份须与其物理／法术伤害类型区分。
- 封物理如何约束物理攻击器诀，在实施前检查现有控制语义并形成明确规则；此前讨论未给出最终结论，不得默认为已确认的梦幻规则。
- 战意初始0、上限150，沿用现有受击获取公式与激昂规则。本资料缺少梦幻完整愤怒获取公式，此项属于本游戏适配。
- 归元只减少器诀战意消耗，不改变挫志诀对目标扣除的70战意。

### 目标、治疗与复活

- 全体是当前在场的同阵营／敌阵营单位，包含灵兽，不含候补。
- 普通治疗不复活；复活遵守禁复活、禁止回复等既有规则。
- 百分比回复不受治疗强度加成；受减疗、禁止回复与伤势后的可回复上限约束，不治疗伤势。
- 解控清除全部“可被器诀解除的控制”，名单走数据配置；不顺带清除毒、减防、减疗、禁复活。
- 冰清／晶清对应器诀先解控再回复。具体状态名单需对照当前宗门内容，不能只按所有负面状态批量驱散。

### 状态与伤害

- 同类单体强效果覆盖群体弱效果；弱效果不得降低或叠加已有强效果。同类取强，不同方向增益与减益可共存。
- 物理／法术伤害结果修正不能替换成攻击、防御面板变化，不影响固定伤害。
- 琴音三段比例作用于各段伤害结果，不直接替换为攻击属性倍率。
- 有限回合效果在施放当回合生效；实施时按V6持续时间语义明确结束边界，并以事件序列测试，禁止文案与扣回合时机不一致。
- 持续至战斗结束的效果默认倒地清除。太极与罗汉等同幅度不同期限效果需在实现中明确覆盖、刷新行为，避免重复减伤。
- 多段逐段处理伤害、护盾、暴击、护命；目标仍倒地时后续段停止，不转移目标。
- 速度增减不做永久面板写回；与既有速度状态的叠加、当前回合行动排序必须使用V6统一规则并验证。
