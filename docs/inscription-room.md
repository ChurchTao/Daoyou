# 阵纹室

2026-09-23。路由 `/game/inscriptions`，场景名「阵纹室」，在洞府与展开导航进入。页面提供绘制、合成、烙印，首版不提供拆卸、转移、自动合成目标或失败概率。

## 道具与材料

九种阵纹沿用 combat-v6 装备内容包中的类型 ID，每种有1—11级。固定物品定义为 `inscription.<patternId>.<level>`，同种同级堆叠99枚，无个体随机属性。背包、仓库、寄售沿用统一物品协议；属性与适用部位只读已有阵纹定义，不另存加成。

绘制仅消耗 `material.v1` 的矿石、妖兽材料、辅助材料、天材地宝。四格各放一个库存堆叠，可设置1—99数量；同一堆叠再次选中增加该格数量，不重复占格。不同库存堆叠可分别投入。

## 绘制

- N级阵纹需要 `4 × 2^(N−1)` 份。总投入先产出尽可能多的11级阵纹，再依次向下分配，最多保留三个有产出的等级组，同级数量不限。
- 不足4份不能提交；成纹后未分配的余料全部消散，包括超过三个等级组的部分；确认层提示余料消耗，不回显份数。
- 九种类型等概率、逐枚独立随机，允许重复。材料类型不改变抽取概率。
- 成功率100%。天地灵气为 `min(100, max(1, ceil(总份数 / 512)))`，单次最多100点；灵石为 `ceil(总份数)`，不封顶。两项费用均按全部投入计算，包括消散的余料。单件神品天材地宝50,000份，消耗98点天地灵气、50,000灵石；四件200,000份，消耗100点天地灵气、200,000灵石。
- 949份只产出8级、7级、6级各一枚，余下53份消散，消耗2点灵气。
- 112份固定产出5级、4级、3级各一枚，类型随机；132份产出6级和1级各一枚，消耗1点灵气。
- 抽取前，按消耗材料后的背包，计算所有类型分配中最大的新增占格数。无法容纳时拒绝整笔操作，不能按某次随机结果是否恰好可堆叠选择性成功。不溢出仓库。

## 合成与烙印

- 背包合成消耗两枚同种同级阵纹，生成同种高一级的一枚，最高11级。
- 升至N级支付 `10 × 2^(N−2)` 灵石，不消耗材料或天地灵气，必定成功。
- 空孔烙印免费消耗一枚阵纹。支持背包与已穿戴道装；仓库物品须先取出。
- 已占用孔位支持覆盖，确认时展示原孔位阵纹及投入阵纹；旧阵纹直接消失，不返还。
- 孔内合成把该孔视为一枚材料，另消耗背包中的同种同级一枚，费用与背包合成一致，不改另一孔。
- 所有烙印／孔内合成均遵守部位及每孔等级上限：装备10／30／50／70／90对应3／5／7／9／11级。炼气不额外限制。

## 写入与界面

规则位于 `src/shared/inscriptions/rules.ts`，协议位于 `src/shared/contracts/inscriptions.ts`。服务端经活动角色认证、角色锁与 `playerCommandExecutor` 事务；材料／阵纹／装备均按所属角色、位置、数量和版本校验，费用重新计算。随机结果、库存、资源扣减及幂等结果在同一事务中提交。客户端持久化未确认请求，刷新或网络失败复用原请求ID核对结果。

已穿戴装备变更发布 `player.profile`，由已有资源提交器刷新投影、气血法力上限与关联缓存，不自动补满气血。

桌面左操作台右背包；手机使用抽屉。三种操作共用绘阵台，上方原生单选按钮组切换为四个材料格、两个阵纹格、一个装备格加两个孔位格。格子角标显示投入数量，数量在物品浮层内编辑，格子下方不再重复显示；点击孔位放入阵纹，已有孔位的物品浮层提供孔内合成。正文与确认层均不展示材料合计份数和预期产物，确认层仅展示投入、费用与余料／覆盖损失提醒；结果按等级降序，合并同种同级数量。物品详情沿用共享浮层。

使用内置imagegen生成后，保留alpha缩放压缩为WebP；页面正常不透明度展示，不使用混合模式伪装透明。
