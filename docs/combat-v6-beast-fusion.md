# 灵兽宝宝体系与融合设计

定稿日期：2026-09-19；实施日期：2026-09-20。状态：宝宝体系、融合规则、持久化与界面已实现；尚未完成战斗与经济平衡验收。

本文以用户提供的初始属性表和本轮明确决定为依据。梦幻西游端游提供炼妖结构参考；未获权威验证的后台概率不视为原作事实。本文区分用户确认规则与授权策划选定的首版参数，后者是道友规则，不宣称为梦幻官方数据。

## 1. 已确认范围

- 引入宝宝、假宝宝、纯野生的培养身份；变异宝宝有更高基础属性。
- 普通宝宝：0级五项基础各10，另有50点自由属性，总计100点。
- 假宝宝：0级五项基础各10，无初始自由属性，总计50点。
- 变异宝宝：0级五项基础各20，另有50点自由属性，总计150点。
- 初始自由属性由玩家分配，不随机预分配，不把宝宝生成为五项各20。
- 纯野生捕获前存在点数亏损，初始等级越高，亏损越大；捕获后正常升级。
- 变异不能参与融合，普通融合不产生变异。不引入五行或隐藏五行加成。
- 首版结果物种只来自两只材料，不加入大海龟、泡泡对应的异种结果。
- 保留双材料消耗、物种随机、必带恢复、技能继承、双亲资质成长遗传与重复回炉。无保底变强、技能锁定、择优保留或代数惩罚。
- 灵兽玩法尚未发布，不设计历史身份推断、旧个体兼容层或存量迁移方案。采用新个体模型，不回填旧数据；新增融合记录表。

## 2. 身份、属性与点数守恒

培养身份与当前年龄、当前等级分开：宝宝升到30级仍是宝宝；假宝宝和野生不会靠升级变成宝宝。变异为个体特征，首版只与宝宝身份组合，不存在变异假宝宝或变异纯野生。

五项属性为体质、力量、魔力、耐力、敏捷，与攻击／防御／体力／法力／速度五项资质分开。

设当前等级为 `L`，个体生成时等级为 `L0`。每次正常升级仍使五项属性各增加1，并获得5点自由属性。

| 身份 | 每项0级基础 | 初始自由点 | 当前可支配点总预算 P | 五项属性与未分配点合计 |
| --- | ---: | ---: | --- | --- |
| 普通宝宝 | 10 | 50 | `50 + 5L` | `100 + 10L` |
| 假宝宝 | 10 | 0 | `5L` | `50 + 10L` |
| 变异宝宝 | 20 | 50 | `50 + 5L` | `150 + 10L` |
| 纯野生 | 10 | 0 | `5L - 2L0` | `50 + 10L - 2L0` |

共同投影与守恒式：

```text
某项实际属性 = 该身份的0级基础值 + L + 该项已分配点
sum(已分配点) + 未分配点 = P
```

基础值只计一次；宝宝的50点进入可分配预算，不能同时加到五项基础上。资质成长面板公式沿用当前灵兽投影，只替换属性输入，不改修士永久六维属性。

### 2.1 纯野生的首版具体化

用户确定了亏损方向，以下每级亏损2点是授权策划选定的道友参数，不冒称梦幻精确公式。

- 生成时 `L0 >= 1`。基础采用五项各10，获得前每级只形成3点可支配属性，由系统沿用现有无物种偏好的野生加点算法分配，未分配点为0。
- 五项自然随等级增加的部分仍各为 `L0`，所以生成时总点数为 `50 + 8L0`。
- 捕获后每次升级正常获得5点自由属性，固定亏损 `2L0` 不再扩大，也不补回。
- 加点、转手、交易、换编组不改变 `L0`。洗炼重新生成宝宝后才清除此亏损。
- 同等级下，纯野生比假宝宝少 `2L0` 点，比普通宝宝少 `50 + 2L0` 点。

例如30级捕获的野生合计290点，同级假宝宝350点，普通宝宝400点，变异宝宝450点。该野生养到60级后合计590点，比同级普通宝宝700点仍少110点。

这里的点数预算不承诺每种身份在任何加点下的各项面板都逐项领先；初始分配自由度也是价值的一部分。

## 3. 来源、洗炼与变异

| 来源 | 生成结果与属性处理 |
| --- | --- |
| 初始伙伴 | 普通宝宝，沿用10级领取；50初始自由点加50升级自由点，共100点待分配 |
| 野外普通幼崽 | 0级普通宝宝，50点待分配 |
| 野外普通成年 | 纯野生，按实际生成等级记录 L0，生成阶段3L0点已分配 |
| 野外变异 | 0级变异宝宝，五项基础各20，50点待分配 |
| 普通个体洗炼 | 0级普通宝宝，已分配点归零，待分配点为50 |
| 变异洗炼 | 0级变异宝宝，保留变异，已分配点归零，待分配点为50 |
| 融合 | 按第4节生成普通宝宝、假宝宝或纯野生 |

为形成一致的变异宝宝定义，首版方案将现有“成年也可变异”改为：每只野外个体先独立按0.8%决定变异；变异结果统一0级宝宝，非变异再按原幼崽／成年规则生成。0.8%是每只遭遇个体的概率，不变成“仅幼崽内再乘0.8%”。普通幼崽条件概率、物种选择与数量规则不另调。当前遭遇生成已将变异结果统一为0级。

变异五项资质和成长在普通物种抽取结果上提高10%的既有规则保留，只应用一次；新增加的基础属性优势另行进入投影，不能仍将最终面板优势概括为约10%。变异的出生技能池、数量概率不变，不能融合，依靠洗炼与传承培养。

洗炼还会重抽资质、成长和出生技能，实际格数回到本物种出生结果。融合获得的超出生区间资质、多技能与传承投入全部失去，不返还；保留名字、个体ID、物种及既有寿命恢复方式。洗炼不保留双亲遗传事实作为当前数值来源。

## 4. 融合资格与结果身份

### 4.1 资格与消耗

- 两只不同、同属当前角色、非变异的灵兽，等级均不低于30。
- 主人达到双方物种携带要求，双方等级不高于主人当前承载等级。
- 无战斗／结算占用，材料不在首发或携带编组、拍卖托管、邮件待领状态。
- 宝宝、假宝宝、纯野生均可作材料，无需先洗炼；身份影响结果身份。
- 首版不另收灵石或专用融合道具。材料、垫书和培养到30级构成成本，不增加幸运值、保护符、冷却或每日次数机制。
- 两只材料永久消耗，生成一个新ID个体，初始名字采用结果物种名，修为为0，寿命及上限均按当前生成配置1000，不继承编组。
- 结果再次达到条件后可回炉。无融合代数带来的强度、概率或费用变化。

### 4.2 结果分布

以下概率、野生结果等级为授权策划选定的首版参数；端游参考确定分支结构，不提供这些具体概率的证明。

| 材料身份组合（顺序无关） | 普通宝宝 | 假宝宝 | 纯野生 |
| --- | ---: | ---: | ---: |
| 宝宝＋宝宝 | 95% | 5% | 0% |
| 宝宝＋假宝宝 | 0% | 25% | 75% |
| 宝宝＋纯野生 | 0% | 25% | 75% |
| 假宝宝＋假宝宝 | 0% | 25% | 75% |
| 假宝宝＋纯野生 | 0% | 25% | 75% |
| 纯野生＋纯野生 | 0% | 25% | 75% |

- 两种材料物种各50%，同种材料则100%为该物种。左右位置无影响。
- 物种抽签与身份抽签独立。身份不改变技能、资质、成长抽签权重，不叠加隐藏品质惩罚。
- 宝宝和假宝宝结果均为0级；宝宝待分配50点，假宝宝0点。
- 纯野生结果等级为 `floor((材料A等级 + 材料B等级) / 2)`，以此作为新个体的 L0；属性按第2.1节重新生成，不复制材料加点或累计材料的点数亏损。
- 结果物种决定携带要求，不取双方要求最大值；低携带要求物种可能通过高阶材料得到更高资质，需要纳入同境界战斗验收。
- 不存在异种分支，也不暗中用无效个体、道具或“无结果”替代异种失败。每次成功提交都产出一只有效灵兽。

## 5. 技能继承

记双方当前实际技能集合为 `SA`、`SB`，结果物种的出生必带集合为 `C`：

```text
U = unique(SA ∪ SB)
R = U − C
最终技能 = C ∪ {R 中每项独立以50%概率继承的技能}
理论技能上限 = |U ∪ C|
实际技能格数 = 最终技能数量
```

- 同ID只抽一次，共有技能不提高继承概率；候选按稳定ID排序，不能由材料排列或界面位置影响抽签。
- 只补回结果物种必带；双方已被传承覆盖掉的其他技能不复原。
- 不另外抽取普通出生候选；使用技能总数而不是战斗实际生效技能数构造材料池。
- 普通／高级同族是不同ID，可以同时占格；战斗仍只生效高级。已有互斥规则继续由投影处理，不自动优化出有效技能组合。
- 零必带物种可能出零技能，延续首次传承开启第一格的规则；已有技能的传承仍只覆盖。
- 解除现有8技能硬限制，不另加8／12／16格玩法上限。集合去重和已注册技能校验形成自然边界；当前共有67个技能ID，不将67硬编码为永久玩法上限。
- 出生3—6技能、必带0—2的物种配置保持原样。出生上限不用于裁剪融合个体。

四技能＋四技能，候选八项互不重复且不含结果的两项必带时：结果为 `2 + Binomial(8, 0.5)`，条件均值6技能，十技能概率1/256。若只接受其中一种物种且要求宝宝，完整十技能宝宝概率为 `0.5 × 0.95 / 256 = 0.185546875%`，该例不能外推到所有材料。

## 6. 资质与成长

普通出生和洗炼仍按物种区间生成；融合以双亲当前保存的最终数值为原料，不按结果物种重新洗一次，不继承材料初始属性分配。

设某项资质均值为 `A=(A1+A2)/2`，成长千分整数均值为 `G=(G1+G2)/2`。均值阶段不提前取整：

```text
结果资质 = clamp(round(A × 资质系数), 1, 该项融合上限)
结果成长千分值 = clamp(round(G × 成长系数), 100, 1300)
```

正数四舍五入，成长按千分整数计算后再除1000保存，避免链式浮点误差。五项资质各自独立抽取系数，成长另抽；与技能、身份、初始点数分开。

## 7. 数据与事务落点

个体新增必要事实：培养身份 `originKind: baby | pseudo_baby | wild`、本次个体生成等级 `initialLevel`；保留变异标记。由身份与变异推导固定基础值和初始50点预算，不重复存储可推导的总属性。不使用当前等级推断身份，不从资质或技能猜测变异。

- 校验 `level >= initialLevel`；纯野生 `initialLevel >= 1`，变异只允许宝宝身份。初领宝宝initialLevel为10，野外宝宝与洗炼宝宝为0。
- 点数守恒改为第2节的 P。首发、捕捉、洗炼、升级、加点、交易、邮件、聊天及战斗构建均使用同一权威个体结构。
- 修改归元时，initialLevel归零；失去野生亏损并得到宝宝50点预算，不能沿用当前“待分配点归零”的代码。
- 为融合设置独立生成规则版本与配置修订，不冒用普通出生的生成版本。服务端生成随机种子并调用共享纯函数，不接受客户端种子或结果。
- 物种、身份、技能、五项资质、成长和野生加点使用稳定独立随机流；双方按ID规范化，交换材料位置不应改变固定种子的结果。
- 新增纯领域融合模块与配置，不能把融合规则放进战斗核心或调用LLM生成结果。

服务端在现有角色锁及一个数据库事务内重读双方并校验归属／revision／占用，消费双方、生成结果、维护编组和记录一次融合操作。记录请求标识、双亲必要快照、结果快照、算法与配置版本；双亲删除后记录仍可追溯，不做级联删除。

同请求标识同负载返回原结果，不因网络重试再抽签；同请求标识不同材料应拒绝。失败整体回滚。提交后返回最新灵兽名册，由现有页面刷新路径更新；恢复接口同时返回当前名册与原结果快照。持有容量按最终净减少一只计算，满袋仍可融合。拍卖／邮件托管的个体先回到角色持有状态才可用，不跨容器直接消耗。

不添加旧模型字段缺失时自动认定为宝宝的回退，不编写数据回填脚本。新模型启用前的本地测试数据准备在实施验收中单独处理，不执行全库清理。

## 8. 界面与验收

灵兽详情、交易和融合选择清楚显示培养身份。变异仍保留异色；现有战斗界面只用异色、不增加变异标签的约定不变。宝宝不称为永远不会长大的幼崽，五项基础与待分配点不能混在“资质”中。

融合流程：选择双方 → 展示双方身份／等级／数值／技能 → 分别展示两种结果物种的必带与理论上限、身份概率 → 确认永久消耗 → 展示实际结果。理论技能上限不得写成预计技能数；预览不抽取或泄露未来随机结果。

确认明确结果可能为假宝宝或纯野生、可能掉技能和资质、两只材料无法恢复。洗炼确认明确会丢失融合技能和超出生范围数值。结果不自动首发，也不一键连融。

实施验收分三步：

1. 纯共享领域测试：四类属性预算、初领100待分配点、升级守恒、捕获阶段亏损不继续扩大、洗炼50点恢复、变异禁止融合、六种身份组合、必带补回、同ID只抽一次、高低级共存、零技能与超过8／16技能、资质成长档位／边界、材料顺序对称性和固定种子可复现。
2. 代码检查、lint/build及本地浏览器模拟：双材料事务、重复请求、交易互斥、断线后查询结果、满袋净容量、展示与真实属性一致；不新增服务端／数据库／前端单元测试或临时验收脚本。
3. 通过允许的共享领域测试分析固定种子样本分布及多代选优；检查同等级多技能融合兽、普通宝宝、变异宝宝的面板与实际技能组合，以及低携带要求物种获得高资质后的影响。不得把数学期望当作实战结论。

经济基准：当前0→30级为15,970修为，两只0级材料合计31,940；野外暂不发灵兽修为。观察材料、灵印、丹药／灵果供给以及可用成品的投入，不在尚未验收时承诺固定获得周期。
