# 周常活动界面

炼丹大会、百晓盛会与古魔入侵共用 `WeeklyActivityHeader`、`WeeklyActivityLobby` 和周榜页头。活动入口组织活动身份、地图返回、规则、开放状态和入场操作。活动底画随玩法更新，界面使用全局纸墨主题。入场后的炼制、答题和连战按各自当前操作设计工作区。

## 活动入口

- 顶部用固定位置返回地图、识别活动和查看规则。活动内容区依次给出当前位置或开放状态、到场后的下一步和行动前需要知道的时间与条件。规则与奖励用共享详情抽屉。
- 每个阶段设置一个主要操作。候场强调入场或准备，游玩中把实时进度和操作摆在一起，完成后展示个人战果。活动日期与时刻按北京时间呈现。
- 场景底图遵循留白与安全区，窄屏可向下滚动。正文和按钮采用游戏主题色，数值沿用数字排版规范。

## 周榜

- 页头展示榜名、期次、地点、公布状态及返回活动入口。首位或并列首位优先呈现，随后展示第二、第三席及余下名次。我的成绩和筛选条件与席位列表分开。
- 个人席位突出头像、姓名、名号和本玩法成绩。队伍席位按名次独占一行，按当场阵容排列队员。每位队员的头像、姓名与名号放在一起，窄屏每行两人。点击席位以同一详情抽屉查看成绩明细。
- 除魔榜按挑战境界筛选。详情显示排名、有效通关波次及该波实际参战名单。该名单与榜单记名成员可能不同，详情标记本条成绩记名人。
- 桌面和 360px 视口覆盖状态提示、打开和关闭详情、键盘与滚动。参见 [玩法 UI 原则](../.agents/skills/daoyou-game-ui-principles/SKILL.md)。
