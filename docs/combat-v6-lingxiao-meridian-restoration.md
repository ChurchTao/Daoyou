# 红尘剑宗经脉还原方案

> 2026-09-22：两条流派、基础被动、装备联动及经脉界面已实施。下文区分用户确认的原版效果与本项目适配口径；以当前配置和共享领域测试为运行时依据。

## 数据依据和适配原则

- 节点以[叶子猪奇经八脉模拟器](http://xyq.yzz.cn/special/qjbmmn/)为准；原流派名为浴血豪侠、无双战神。
- 浴血豪侠对应斩尘证道，无双战神对应万剑归一。节点保留原版名称，技能使用红尘剑宗主题名称。
- 横扫千军→断尘；后发制人→惊雷；破釜沉舟→临渊；杀气诀状态→破极剑意；安神诀→剑心通明；翩鸿一击→惊鸿掠影；破血狂攻→器诀双剑合璧；愤怒→战意。
- 优先保留倍率、概率、代价、持续时间、PVP/PVE限制和同层竞争。不得把伤害力、伤害结果、暴击概率、暴击倍率混为同一项。
- 破极剑意、剑心通明仍固定5回合，剑龙吟固定2回合。

### 装备八行

- 复用现有 `ELEMENT_VALUES`，每件新锻造装备等概率生成一种属性，固定写入装备实例的 `element` 字段。
- 使用独立的有种子随机序列，不改变白字、双加、器蕴和器诀的生成结果；材料择优不改变元素抽取。
- 新锻造标记生成器 v4；v4 必须具备合法元素。旧 v1/v2/v3 实例允许没有元素，不随机回填、不因读取或穿戴而生成元素。
- 无元素的旧装备不满足金／火／风条件。当前没有新增元素洗炼或相生相克功能。
- 沿用 `inventory_items.instance_data` 保存完整事实，不添加独立元素表或派生战斗属性存储。
- 预览头部在御使要求后展示实际五行，没有该事实的旧装备不显示占位信息。

## 基础技能与流派被动

以用户补充的2026年4月正式服口径为准，不混用旧攻略、测试服与畅玩服数值。

- **连破**：切换万剑归一后自动拥有；成功施放断尘后有1%概率不休息，不需要点经脉。勇进、熟练与亢强在此基础上生效；亢强记录最近一次器诀的原价战意，不累加多次器诀，下一次成功断尘后消耗。
- **剑意**：万剑归一自动拥有；每次成功施放断尘加1层，不按段数增加，临渊与惊鸿掠影不增加。无固定层数上限，倒地保留，复活继承，新战斗重置。杀伐是另一来源，每回合最多成功一次，自身倒地时不能触发。
- **剑意基础收益**：≥2层，攻击被保护时，被保护者所受伤害提高5%；≥5层，自身造成伤害提高5%，两档累计。无需破军。连斩每层1.5%与5层基础5%按同类增伤相加，例如10层合计20%。
- **破军**：11／17／23层分别对应禁保护与3目标溅射、4目标溅射、免疫禁复活；23不是上限，也不提供自动复活。
- **惊鸿掠影**：基础神通，主心法45级解锁；100%普攻伤害、50法力、冷却6回合，仅下一回合速度+15%。第1回合施放则第7回合可再次使用。翩鸿的增伤、驱散和击倒不冷却是节点效果。
- **长驱直入**：第二层经脉选择后替换惊鸿掠影，不作为基础技能同时保留。沿用本项目逐层成长门槛（第二层人物60级），不额外引入梦幻人物89级／乾元丹系统。
- **乘胜追击（改编）**：不引入奇袭系统，改为主动准备神通，主心法45级解锁，消耗50法力、占一次行动、冷却6回合。状态保留至下次断尘：主目标是人物时，逐段对其在场召唤灵造成等量派生伤害；击倒主目标则保留状态，否则消耗。50法力、6回合冷却和解锁等级是本项目参数，不声称为原版参数。乘势进一步取消此状态下断尘的血线与气血代价。

[2026年4月同站调整说明](http://xyq.yzz.cn/focus/202604/1764531.shtml)及其[大唐调整图](http://i1.cdn.yzz.cn/pub/imgx2026/04/16/503_085049_91819.png)作为背景资料。该测试阶段文章中的剑破150%不采用，当前按用户确认的正式服200%实现；历史连破18%不能用作基础概率。

## 结算与适配口径

- 保护采用保护者70%、原目标30%的伤害分摊；破空和剑意2层只放大原目标所受部分。该比例是本项目规则，不是对梦幻底层公式的推断。
- 溅射以主攻击完成攻防、暴击、增减伤后的伤害结果为基数，在护盾吸收和目标剩余气血截断之前取值；派生伤害不再次计算攻防、暴击和增伤，不递归触发溅射。同一次多段技能固定一组溅射目标。
- 突进按直接物理攻击实际扣血次数累计；纯护盾吸收、落空和派生溅射不累计。突刺读取扣血代价前血线。
- 翩鸿驱散、长驱重创、勇武易伤按成功命中触发，不额外要求实际扣血；护盾全部吸收仍可触发，落空不触发。通过通用 `afterStrike` 钩子实现，原 `afterHit` 实际扣血语义保持不变。
- 勇武、长驱的易伤按施法者绑定；多个施法者可各自保留，同类降低受疗效果不叠加，其他受疗增益仍正常参与计算。
- 扶阵沿用本轮用户接受的简化实现，未额外扩展到持续伤害结算。同名扶阵不叠加，来源须存活；普通与强化破极剑意取较强效果，持续时间仍固定5回合。
- 第七层左右奖励自动生效，不占中央无敌／破军的选择。原来选择第七层左／右位置的旧方案在读取时映射到中央节点，正式保存时写回标准选择；未执行数据库批量迁移。
- 两条流派删除旧版自创终式、消耗剑意免休息与击杀必定免休息机制，避免新旧效果并存。

## 经脉连通与交互

- 本轮仅对红尘剑宗两条流派启用：每层至多选一个节点，后层必须连接前层同列或相邻列节点，不允许跳层或从最左跨至最右。第七层自动奖励不参与连线选择。
- 页面使用紧凑方形节点，仅画出已选路径和下一层可选分支，以节点边缘之间的直角折线连接；已选路径朱红高亮，可延伸分支次级高亮，不连通节点淡化且选择按钮禁用。末端自动奖励为圆形节点；不新增机制说明文字。
- 改选前层时保留仍连通的后续节点，断开部分连带取消；保存使用同一共享规则验证，绕过页面提交非法组合会被拒绝。
- 旧方案在读取与战斗投影时只保留连通前缀，不代选前置节点；正式保存写回新选择，无数据库批量迁移。第七层左右旧 ID 仍兼容映射至中央节点，但中央节点须与第六层连通。
- 扶阵简化方式、末端奖励自动发放时点和乘胜追击改编均保持用户已接受的方案。

## 运行时实现与后置范围

- 核心新增通用条件、技能修正、冷却、按结果溅射、施法者绑定状态和条件禁复活免疫，不包含宗门ID分支；宗门规则在内容包声明。
- 战斗快照保存剑意、技能使用次数、装备事实及冷却。无上限资源以空上限表示，界面显示实际层数，不显示错误的“/11”或“/23”。规则版本提升为v9。
- 装备八行经库存及投影入口校验后，提供金／火／风装备数量、武器与衣服均符合三行条件的标记、武器玄锋等级和物攻贡献，接入杀意、杀伐、不惊与剑破。
- 不新增数据库表或回填旧装备；装备字段仍存于统一背包JSON事实。两条流派的位置ID沿用现有方案。
- 组队阵法、本命法宝、灵宝和独立角色称谓系统后置；当前扶阵、干将、剑破使用已确认替代效果，历战只实施PVP血线部分。
