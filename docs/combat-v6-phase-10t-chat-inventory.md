# Phase 10T：世界／宗门聊天道具展示接入新版物品栏

2026-09-10 用户确认范围，主体实施与重点本地验收完成。

## 开发边界

- 世界与宗门频道共用新版背包选物与服务端快照；支持新版材料、种子、丹药／灵果、符箓、道装、图纸、玉简、兽诀。
- 每条消息展示一个物品或堆叠；只从 bag 选择，storage 须先取出。已装备道装允许展示，不扣物、不改变装备。
- 保留频道权限、冷却、100字附言和现有消息存储／推送机制。不新增私聊、交易、召唤兽展示、战报分享或聊天框架。
- 旧晒物保留记录与附言，统一显示“旧版道具展示已停用”，不再解析旧物品详情。不清空聊天、不迁移历史消息、不增加旧表兼容分支。
- 角色查看与秘境叙事旧装配读取另行处理；前序未验收事项继续保留。

## 实现

- 新请求只接受 itemId、revision、textContent 和消息类型；拒绝旧 itemType、客户端 snapshot 等多余字段。
- 服务端复用公开 readInventory 背包视图，核对本人持有与 revision。种子沿用公开视图的精简事实，不把完整种植配置写入消息。
- 消息 payload.version=1，snapshot 白名单为 name、definitionId、quantity、instanceData。消息不保留库存格位、stackKey、revision、equipped 或库存持有者字段；道装实例自身 ID 保留。消息信封沿用现有发言人信息。
- 快照深复制，之后的物品移动、消耗不改变已发送内容。固定物品继续按版本化定义 ID 展示；不引入另一套物品规则。
- 桌面左表单、右五列40格公共物品栏，窄屏抽屉。选物后预览、附言、确认发送；发送期间阻止重复操作。
- 消息中的紧凑名称链接打开只读详情，复用公共 itemPresentation、EquipmentDetails、ConsumableDetails，并标注发送时状态；没有使用、装备或交易操作。
- 移除旧分类列表、旧物品快照类型及旧详情解析。没有改表、执行维护清理、提交 Git 或部署。
- 全部文件变更使用内置 apply_patch，保留原有 eslint.config.js 改动。
