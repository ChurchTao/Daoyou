## 1. 纵切定位

无相禅宗是 combat-v6 第三个完整宗门，用于验证治疗、防护、疗伤、净化、复活和纯法术输出。v6 不读取旧宗门进度，也不采用 battle-v5 的“佛相 A／魔相 A+B／无相 A+B+C”动态技能结构。

- `慈航渡厄`：治疗、护盾、疗伤、净化和复活。
- `明王镇狱`：纯法术群攻、法术忽防、法术吸血和耗血爆发。
- 两流派共享六门基础技能。
- 两流派均以单场资源“念”驱动主动技能“无相诀”。
- 无相只是一段短期强化窗口，不存在战外形态选择。

## 2. 通用规则增量

### 2.1 护盾

护盾随单位、快照与录像保存。伤害在公式、暴击、波动、承伤倍率和保护/分流后，先消耗护盾，再进入 HP。

- 吸收物理、法术以及主动或派生固定伤害。
- DOT、伤势、MP 伤害和主动耗血绕过护盾。
- 同 `kind` 取较高剩余盾量并刷新持续；不同 `kind` 共存。
- 按 `appliedRound → id` 稳定吸收。
- 普通驱散不移除护盾，倒地清除全部护盾。
- 全额吸收时不产生 Damage、伤害 Hook、战意、吸血或致命判定。

### 2.2 疗伤与净化

`RemoveWound` 只降低伤势、提高 `recoverableHp`，不自动恢复当前 HP。同一技能中按声明顺序先疗伤、后治疗。

净化支持最大数量，并按 `Control → Debuff → Dot`、施加回合、状态 ID 稳定选择。基础六根清净排除 `blocksRevive`，因此不能清除锢魂；破妄拔魂解除该排除。`dispellable: false` 的无相不能被普通净化。

### 2.3 成功结算与法术公式

技能主效果没有产生 `ActionFailed` 时才执行 `successEffects`。合法 no-op 仍算成功；资源不足、目标丢失和复活受阻不执行成功段。

rules v3 法术公式为：

```text
effectiveMagicDef = floor(magicDef × (1 - defenseIgnore))
(magicAtk - effectiveMagicDef + schoolTerm + power)
× coeff × splashFactor
→ 法术修炼差 → 暴击 → 波动 → 承伤倍率
```

忽防最终夹取到 0～100%。固定伤害继续沿用 rules v2 行为。

## 3. 六心法

| 槽位 | 心法 | 面板贡献 |
|---:|---|---|
| 1 | 《无相菩提总经》 | 最大气血 `floor(N×2)`，主心法 |
| 2 | 《慈航渡厄经》 | 治疗能力 `floor(N×0.5)` |
| 3 | 《金刚护生篇》 | 物防 `floor(N×0.4)` |
| 4 | 《明王镇狱录》 | 法攻 `floor(N×0.5)` |
| 5 | 《六根清净诀》 | 抗封 `floor(N×0.25)` |
| 6 | 《一苇凌虚章》 | 速度 `floor(N×0.15)` |

心法上限为 `min(180, 人物等级+10)`，分支不高于主心法，技能等级严格等于所属心法等级。

## 5. 念与无相诀

念为 0～6 的单场资源，初始0，不持久化。基础技能合法成功即使数值 no-op 也按表获得念；明确失败、普攻兜底或无相期间不获得念。

念满后可主动施放无相诀：消耗 MP `40+0.3N` 和全部6念，占用行动，为自身施加2回合不可驱散的无相状态。施加当回合不扣持续；倒地清除。慈航无相提高宗门治疗、盾和疗伤20%，复活恢复提高到30%；明王无相提高宗门直接法伤20%并忽略10%法防。

## 8. 投影、兼容与边界

V2 宗门注册表包含红尘剑宗、幽都和无相禅宗；`projectCultivatorMultiSectV3ToCombatV6` 是本阶段完整入口。V1 注册表与 Phase 1～6A 的旧入口、版本和黄金结果保持不变，并显式拒绝无相内容。

本阶段不包含旧无相数据迁移、数据库、Repository、API、页面、进度事务、Battle Host、AI 选招、战斗记录、战后永久伤势、其他宗门、召唤兽、药品、阵法、法宝、道装经济外围或无限护盾/复活体系。
