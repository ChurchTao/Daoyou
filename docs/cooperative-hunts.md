## 分域部署连接修复（2026-09-30）

- 原因：多人战斗直接用当前页面域名拼接 WebSocket，绕过 `VITE_API_BASE_URL`。前后端分域时，HTTP 战况读取成功，但战斗连接落到静态站点，页面持续显示「连接恢复中」并禁用指令。服务端超时推进仍在运行，因此玩家最终会看到战斗结束。同域开发代理会掩盖此错误；擂台参战和观战共用此连接入口，也受影响。

## 玩法规则

- 地图出现限时讨伐目标，覆盖金丹、元婴、化神、炼虚、合体、大乘、渡劫。系统频道发布传闻，点击「前往查看」进入对应地图与组队抽屉；地图头像也可打开组队。
- 创建队伍时指定最低与最高境界，范围必须包含队长。支持队伍列表加入、快速匹配已有队伍；快速匹配优先补齐人数较多的合适队伍。
- 每队 2～4 名不同账号的玩家，不要求满员。全员准备后队长开战；成员变化会清除准备，队长离开后自动由剩余成员接任。
- 出现期间各队分别挑战，战斗实例、血量互相独立。失败可重试，队伍在结算后保留并清除准备。
- 每个角色每次出现仅首次胜利发奖。已领奖角色可作为队长或队员助战、计入开战人数，不重复获得奖励，也不影响其他角色的领奖资格。
- 到期停止招募和新开战，旧链接展示「此处异动已平息」。到期前已开始的战斗继续完成并正常结算。

- 复用已注册头像，尚未新增专属 BOSS 立绘。
- 地图每 15 秒更新事件、组队页每 5 秒更新队伍；服务端严格检查到期时间，客户端显示可能有轮询延迟。

## 讨伐材料概率调整（2026-10-05）

保留各境界原有可掉品质范围与两件材料保底，在范围内按等比递减权重归一化：从最低品质开始，第 `i` 档权重为 `r^i`，单件概率为 `r^i / Σr^j`。金丹至渡劫的 `r` 依次为0.6、0.625、0.65、0.675、0.7、0.725、0.75；品质越高概率越低，境界越高曲线越平缓，高品质累计概率不倒挂。衰减参数位于 `packages/game-content/src/rewards/hunt-material-quality.ts`。

旧公式将两件奖励的各上位品质累计概率定为云游单次通关奖励的1.1倍，再由最低品质承接剩余概率，导致最低档占比约69%～73%。本轮不再维持该比例。渡劫单件真品／地品／天品／仙品／神品约为32.78%／24.58%／18.44%／13.83%／10.37%。

以下综合概率以一次个人获奖的两件材料中「至少一件达到该品质或更高」为口径，计算为 `1 - (1 - 单件累计概率)^2`：

| BOSS 境界 | 至少一件天品以上 | 至少一件仙品以上 | 至少一件神品 |
| --- | ---: | ---: | ---: |
| 金丹 | 0% | 0% | 0% |
| 元婴 | 12.25% | 0% | 0% |
| 化神 | 21.06% | 8.59% | 0% |
| 炼虚 | 41.51% | 23.41% | 9.81% |
| 合体 | 44.56% | 25.83% | 11.10% |
| 大乘 | 64.81% | 40.10% | 18.10% |
| 渡劫 | 67.10% | 42.54% | 19.67% |

讨伐服务和材料预览共用 `hunt-material-quality.ts`。只有讨伐启用严格品质选材；云游和挂机原来的选材逻辑不变。奖励池 version 从2升至3，新开战使用新曲线；旧战局沿用已生成的奖励事实。升版会更新新开战的灵印、灵露固定随机样本，二者掉率不变。
