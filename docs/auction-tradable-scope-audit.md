# V6 收尾：拍卖行交易范围梳理

核对日期：2026-09-19。以当前工作区代码为准，包括已有未提交修改；不代表生产部署状态或实际在售库存。拍卖交易规则保持不变；后续按用户要求退役四种固定铸造材料，幻境改为通用材料库产出，不迁移旧库存。

## 1. 当前交易范围

拍卖行实际为按件一口价寄售，支持部分购买，没有竞价或求购。新上架唯一来源是 `inventory_items` 中的随身背包 `bag`，不直接读取旧材料、消耗品、造物表，也不读取灵兽个体或已学习功法状态。

| 分类 | 当前可寄售对象 | 准入条件 | 单件价格上限（灵石） |
| --- | --- | --- | --- |
| 材料 `material` | 草药、矿石、天材地宝、辅助材料、妖兽材料，以及材料形态的功法典籍、神通秘术 | 玄品及以上 | 按品质限价 |
| 种子 `seed` | `seed.v1` 完整种子实例 | 种植物品质为玄品及以上 | 按品质限价 |
| 丹药／灵果 `consumable` | `consumable.v1`，且 `spec.kind` 为 `pill` 或 `spirit_fruit` | 玄品及以上 | 按品质限价 |
| 道装 `equipment` | `equipment.v6`，法兵、法冠、法衣、灵佩、腰封、云履 | 已卸下并放入随身背包；不额外限制器阶、词条、特技等 | 9,999,999 |
| 图纸 `blueprint` | 六部位 × 九个等级的已注册图纸，共 54 种定义 | 不设旧品质门槛，也不以当前开放产出等级限制寄售 | 9,999,999 |
| 玉简 `manual_jade` | 当前功法内容包对应的未使用玉简，共 24 种定义 | 不设旧品质门槛 | 9,999,999 |
| 传承灵印 `beast_book` | 灵兽技能内容包中标记 `book` 的技能对应物品，共 67 种定义 | 不设旧品质门槛；不是所有灵兽技能都自动对应可售物品 | 9,999,999 |
| 灵露 `beast_refinement` | 归元灵露、上品归元灵露，共 2 种定义 | 两种均可寄售；适用灵兽境界是使用条件，不是交易门槛 | 9,999,999 |

以上数量是当前注册定义数，不是市场货单数，也不证明这些定义全部已有正常产出。通用材料、种子、丹药、道装可承载不同实例，不能用定义数表示实际物品种数。

品质限价：玄品 100,000；真品 200,000；地品 400,000；天品 800,000；仙品 1,600,000；神品使用默认上限 9,999,999。凡品、灵品虽有价格配置，但在准入阶段就被拒绝。

核心依据：`src/shared/contracts/auction.ts`、`src/shared/config/auctionConfig.ts`、`src/shared/items/registry.ts`、`src/server/lib/services/AuctionService.ts`。

## 2. 明确不在交易范围内的资产

| 对象 | 当前边界 |
| --- | --- |
| 凡品、灵品材料／种子／丹药／灵果 | 品质门槛拒绝；好友专属寄售同样不能绕过 |
| 符箓 | 所有符箓均被消耗品白名单拒绝，包括拍卖行贵宾符；贵宾符只是专属寄售的消耗成本 |
| 已穿戴道装 | 不能直接寄售；先卸下进入随身背包 |
| 储藏室、旧洞府宝库、未领取邮件中的物品 | 不能直接上架；须经现有取出／领取流程成为有效随身物品，再重新判断准入 |
| 灵兽本体 | 不支持；灵兽个体、等级、资质、成长、技能、寿命等归属于独立灵兽资产，拍卖协议没有灵兽转移链路 |
| 已学习功法与修炼进度 | 不支持；可售的是玉简物品，不能出售角色已学习的功法或其等级、经验 |
| 宗门功法、经脉与宗门进度 | 不属于拍卖物品，不能寄售 |
| 灵石及其他角色资源 | 灵石用于支付，不是可上架的物品；不存在资源直接挂单接口 |
| 旧法宝、旧造物及未注册物品 | 不属于新上架协议；不能因旧表仍存在就视为可交易 |

道装没有“装备过即绑定”的检查；已卸下的有效 V6 道装仍按普通背包道装处理。目前物品定义、库存模型和寄售准入没有通用绑定、不可交易或交易冷却字段。

## 3. 交易方式与共同限制

- 公开寄售面向可访问拍卖行的角色；专属寄售上架时须指定好友并消耗一张随身拍卖行贵宾符。专属货单仅卖家与指定买家可见，购买时校验指定买家身份。
- 专属寄售沿用相同物品范围、价格上限和税费，不扩大可交易范围。购买阶段不重新校验好友关系。
- 同一账号下的角色之间禁止购买，包括卖家本人。没有按买家境界或物品使用等级限制购买；能买不等于能装备或使用。
- 每角色最多 5 个 `active` 货单，期限 48 小时。计数查询没有排除已过期但尚未被过期任务处理的 `active` 记录，因此此类记录仍可能暂占寄售位。
- 单次上架 1～99 件，且不超过所选一叠物品的剩余数量；道装不可堆叠，实际每单一件。没有跨格合并上架或批量多物品上架。
- 最低单价 1 灵石；单次成交总额最多 1,000,000,000 灵石。当前新货单最多 99 件，按最高单价计算为 989,999,901 灵石，低于总额上限。
- 上架校验物品归属、版本、数量与装备状态，并要求结束相关战斗／结算占用。购买、下架与上架不是同一组库存占用校验，不能笼统推断所有操作均被战斗状态禁止。
- 税费按单件价格分段累进，再乘本次成交件数向下取整：前 10,000 为 3%，10,000～100,000 部分为 5%，100,000～500,000 部分为 8%，500,000～2,000,000 部分为 12%，超过部分为 15%。分次成交按每次单独计税。
- 上架从背包扣物并保存可信快照；成交物品、卖家税后灵石、下架或到期剩余物品通过邮件领取。专属上架消耗的贵宾符不在返还附件中。
- 种子完整事实保留在服务端快照与交付链路中，对外列表仅显示公开名称、品质和描述。

依据：`AuctionService.ts`、`AuctionApplicationService.ts`、`auctionRepository.ts`、`InventoryService.ts`、`MailInventory.ts`。

## 4. V6 收尾需要决策或修整的项目

### 4.1 基础材料市场是否开放

当前规则允许低阶图纸、玉简、灵印和灵露，却拒绝所有凡品、灵品的有品质物品。四种旧固定铸造材料已正式退役，幻境改用通用材料库产出，新材料仍按实际品质判断寄售准入。是否保留玄品起售、仅开放铸造材料，或调整整个品质门槛，需要按经济设计决定，不能当作迁移遗漏直接放开。

### 4.2 灵兽本体交易是独立增量

灵兽培养道具已经能交易，本体尚不能。若要开放，本体需要单独定义转移快照、出战／锁定限制、购买容量、培养事实保留以及退回机制，不能只给现有分类数组加一个类型。

### 4.3 两类旧材料与 V6 玉简应明确区分

`gongfa_manual`、`skill_manual` 仍是合法材料分类；成为新版随身材料且达到玄品即可寄售。它们不是 `manual_jade`，现有炼丹分组明确跳过这两类，铸造规则也不接受。交易开放不证明它们具备 V6 功法学习用途。应决定继续保留其流通，还是等明确用途后再调整。

### 4.4 无品质资产统一限价尚未细分

道装、54 种图纸、24 种玉简、67 种灵印、两种灵露统一使用 9,999,999 上限；没有按器阶、功法档次、技能或灵露种类区分。图纸注册覆盖 10、30、50、70、90、110、130、150、170 九档，当前装备正常产出只开放前五档；寄售规则本身不检查这个产出开放表。

### 4.5 筛选仍沿用旧品质模型

浏览页八类标签齐全，前后端共用准入函数；但品级筛选对所有分类始终显示，且包含不可寄售的凡品、灵品。无品质货单保存 `itemQuality = ''`，选择任一品质会把它们全部排除。切换分类只清空子类、不清空品质，容易出现“切到道装后没有商品”的误解。

当前子类只细分材料类型、道装／图纸部位、丹药／灵果；没有器阶、功法档次、灵印技能档次等筛选。物品名和卖家名为精确匹配搜索。

### 4.6 新物品没有独立的交易授权配置

准入函数检查物品是否注册，然后执行位置、装备、消耗品子类和品质限制，没有逐定义的可交易开关。新增属于现有类别的物品会自然继承对应交易规则。后续若引入绑定物品、任务物品或限定奖励，应显式设计准入；目前不能假设其默认禁售。

### 4.7 拍卖禁售与禁止流通不是同一政策

好友邮件附件准入与拍卖行不是完全相同：材料、种子、丹药／灵果赠送不检查玄品门槛，但符箓同样不能作为普通消耗品附件。因此，如果目标是限制低品质物品在玩家间流通，仅调整拍卖规则不够；如果目标只是控制市场货单数量，则两者不同可以保留。

建议先确认基础材料、灵兽本体和旧典籍材料这三个产品边界，再决定限价与筛选的调整范围。以上均为待决策项，本次未修改规则。
