# 九劫天宫对齐天宫：来源、设计与实现

日期：2026-09-23。状态：**已实施基础技能及霹雳真君／踏雷天尊双流派重做**。

第1～8节保留调研时的来源与方案边界；实际采用的参数和适配口径以第10节为准。仍标记待核的项目，不代表已取得原版系数。

目标：以电脑版天宫的霹雳真君、踏雷天尊为原型，保留各自的出手节奏、收益与代价，替换当前封印／法术两系及三层电芒引爆方案。沿用本项目伤害公式，不把复刻技能机制表述为复刻梦幻完整伤害公式。

## 3. 宗门语义与流派骨架

宗门描述建议：

> 九劫天宫以劫雷淬体，以雷律御法。修士可将雷力纳入筋骨法兵，近身摧岳；亦可敕令九霄雷霆，借雷印牵引天罚。雷威愈盛，驾驭之险亦愈深。

| 流派 | 玩法与语义 |
| --- | --- |
| 霹雳真君 | 以身承雷、以兵行劫。单体重击与群攻各三档，主动选择本次输出强度，承担对应休息风险。强化重数是本次技能效果，不是整场永久等级。 |
| 踏雷天尊 | 以神驭雷、以印引劫。三目标法术铺印，依靠普通／赤色雷印增伤，选择群攻灌注或单体摄雷。 |

门派特色存在来源范围差异：当前天宫官网门派页仍写「具有15%的几率避免受到负面法术影响。当有其它同类效果并存时，几率可叠加，但最终的抵抗几率不超过25%」。2025年4月抢鲜看文章则在「踏雷天尊流派」下明确写出改为造成暴击伤害+2%、受到暴击伤害−2%。后者是流派调整资料，不能据此直接认定官网总览错误，也不足以单独证明两条流派当前正式服均应统一使用暴击特色。

撤回此前统一采用暴击特色的建议。本提案建议先以用户指出的官网门派特色作为九劫共同基准，命名「天罡辟邪」：15%概率抵御负面法术，同类抵御概率相加，合计最高25%。语义为劫雷淬炼真身，天罡正气辟除邪法。此为本游戏设计基准建议，不宣称已证实当前梦幻两流派均无特色替换。两系正式服是否覆盖此特色另行核实；不同时叠加两种特色。负面法术的具体范围与判定粒度仍待核，不能擅自等同于只抗封印、面板抗封+15点或15%概率免疫一切法术伤害。

保留流派基础被动与经脉解锁的边界：霹雳／飞霆、电芒并非需要额外点一丹才存在。返璞的物理收益、法术及封印代价需补核当前系数，不能用旧文案自行填数。电芒的封印命中率−15%也不能遗漏，更不能直接当作sealHit−15点。

### 4.1 必须保存的休息差异

采用2026年4月调整资料的设计方向，正式服最终细则待复核：

| 重数 | 休息规则 | 在本游戏中的表达 |
| --- | --- | --- |
| 一重 | 无基础休息 | 稳定输出档。 |
| 二重 | 50%概率休息1回合，不能使用法术 | 可以普攻、器诀；门派物理法术同样属于法术，不能趁机继续施展震岳。 |
| 三重 | 50%概率休息1回合，不能进行大部分行动 | 普攻、门派技能、器诀被禁。防御、保护、召回、召唤等剩余指令白名单待核，不直接当作旧版绝对跳过。 |

不能把二重休息做成普通可解「封法」：休息性质和可选指令是两件事。苏醒、定神雷音、器诀解封不能自动解除休息；自动战斗、指令预检与战斗UI必须共同遵守限制。

暂定本游戏实现口径：二／三重的额外升重不增加本次基础休息概率；强化到四／五重使用高阶休息限制。此项是待确认适配，不是已核原版规则。灌注层数也不能被误写成永久技能等级。

### 4.2 雷印与赤雷印

- 普通雷印：3回合，施加不叠层；后续自身法术伤害+12%。不要给物理、固伤、毒伤通用增伤。
- 赤雷印：点出赤殛且队伍只有一名九劫时，施加雷印有10%概率强化；法术增伤档位改为70%，不是12%再加70%。造成伤害后降为普通雷印。
- 不能额外要求实际扣到气血才算命中；护盾是否阻止赤印退化、多人九劫共享普通雷印的口径另核。
- 摄雷归一吸收普通／赤色印记时分别采用+75%／+200%伤害分支，吸收后清除印记并驱散1个增益。原资料未明确与12%／70%叠乘关系，建议消费分支替代该印记的常规增伤；须标作适配并校准，不堆成无依据的双重倍率。

补核模拟器当前前端后，连线规则已确认：接口没有独立edges／前置节点字段，前端使用`zindex`（层）与`xindex`（列）生成路径。`selectJm`拒绝跨层选择，并拒绝与上一层已选节点列差大于1的节点；`zIndexGuide`也按同一条件高亮。因此上一层左列可接下一层左／中，中列可接左／中／右，右列可接中／右。第一层三项均可选，第六层三项均能接第七层中列终极节点。修改较低层选择时清除更高层已选项；第8／9项为达到丹数后自动点亮的末端奖励，并非独立可选路径。此结论来自指定模拟器的实际代码，已足以作为本轮连线实现依据，不再列为待补查项。

## 7. 为什么这些适配合理，哪些不能简化

- **可直接平移的依赖**：特技→器诀，愤怒→战意，舍利子→灵曜阵纹，魔力→灵力属性点，召唤兽→归属明确的灵兽。保留施放条件、作用对象与代价；不因为有对应器诀便免费赠送。
- **缺少系统的适配**：霜雷常驻减半、劫后逢生改护体条件、驭雷挂主动灌注、罡威加强护体法攻。四项是明确的本游戏改编，不能标为原版复刻。
- **已有信息功能的裁剪**：删除知己知彼、定睛术及纯探查标记。踏雷洞察保留实际属性收益，建议改为节点授予的独立主动增益，保留行动与法力成本；霹雳同名洞察本就直接忽略物防，完全不依赖探查，保持原方案。
- **不能压平的机制**：重数直接选择、一重与二／三重休息差异、实际重数判定、灌注升重、赤印的一次性强收益、渡劫可以自损致死。省掉其中任一项都会改变流派手感。
- **不额外新增的限制**：不把“使用后”改为“造成气血伤害后”；不把“命中”与护盾后扣血混为一谈；不擅自加层数硬上限、PvP专属或额外冷却。
- **相对强度风险**：人物等级×2的六项洞察增益，在本项目面板比例下可能非常大；先保留来源公式提案，再做面板场景对照。不能只因数字来自梦幻就断言已平衡。50／60／80点固定面板奖励亦同。
