# 剧情秘境功能说明

## 1. 功能定位

剧情秘境是在普通五事件秘境外增加一层结构化剧情上下文。战斗、消耗、奖励和角色状态仍由服务端计算，LLM 只负责根据已经确认的剧情事实生成场景、抉择和结局，不能自行修改数值或推翻实际结果。

目前存在两种剧情秘境：

| 类型         | 来源               | 主要作用                             |
| ------------ | ------------------ | ------------------------------------ |
| 主线关联秘境 | 重要剧情信         | 推进个人主线章节                     |
| 异闻关联秘境 | 云游 ActivityStory | 完成一次独立动态异闻，不推进个人主线 |

普通地图秘境不会推进一条已经存在的个人主线。只有从重要剧情信开启、绑定到当前章节的主线关联秘境，才有资格推进该章节。

## 2. 个人主线完整流程

```text
普通经历留下记忆
→ 重要剧情信
→ 玩家选择介入方式
→ 主线云游前奏
→ 解锁关联秘境
→ 完成五个秘境事件
→ 余波回信
→ 延迟回响
→ 玩家回应
→ 章节归档并进入冷却
```

没有活跃个人主线且冷却结束时，一次普通秘境可以成为下一章的故事种子。它只负责触发新的重要剧情信，不会直接算作新章节的关联秘境。

## 3. 重要剧情信

重要剧情信负责建立章节前提、人物关系和核心疑问。玩家可以选择立即介入、调查后介入或暂缓处理。

玩家的选择会决定：

- 进入关联秘境的叙事方式。
- 初始优势或负面后果。
- 初始危险修正。
- 后续秘境蓝图的目标、线索和敌对关系。

选择一旦确认，后续云游和秘境只能延续该选择，不能让 LLM 替玩家改选或将未确认内容写成既成事实。

## 4. 主线云游前奏

剧情信选择确认后，玩家必须先在洞府首页处理“追查主线”事件，关联秘境才会真正开放。

两个前奏选择的固定影响为：

| 选择     | 秘境危险修正 | 叙事意义                     |
| -------- | -----------: | ---------------------------- |
| 谨慎接近 |           -5 | 排除伪痕，找到相对安全的入口 |
| 果断行动 |           +5 | 抢得先机，但使敌人提前警觉   |

云游结果会完整写入关联秘境上下文。秘境必须承认玩家已经完成该调查，不能遗忘结果或要求玩家再次处理同一线索。

## 5. 开启关联秘境

前奏完成后，玩家重新打开原重要剧情信，点击“前往关联秘境”。系统会将以下信息绑定到新秘境运行：

- 主线编号与剧情信编号。
- 玩家已经确认的选择。
- 剧情前提和核心疑问。
- 本次探索目标。
- 开场钩子与主要线索。
- 云游选择和实际结果。
- 初始危险修正。
- 根活动编号 `rootActivityId`。

剧情秘境目前不会动态创建一张全新地图，而是根据玩家境界，从可用秘境节点中稳定选择一个作为剧情载体。同一异闻意图重复尝试时会选择同一个节点。

## 6. 秘境内部流程

剧情秘境继续使用普通秘境的五事件框架：

1. 每个事件生成当前场景和三个行动方向。
2. 玩家完成一个方向后，系统记录行动、结果和所得。
3. 已发现但未完成的分支会保留，后续可以折返。
4. 如果当前路线仍有合理后续，可以继续前进。
5. 完成第五个事件后进入最终结算，不再生成第六个事件。

每次抉择必须产生具体结果，不能只写“完成查探，局势随之推进”等占位内容。行动所需的气血、法力、灵石、材料或战斗代价由服务端校验和扣除。

异闻关联秘境要求至少发生一次真实战斗。最迟进入高潮阶段时，系统会阻止 LLM 继续提供完全绕过战斗的路线。个人主线秘境是否强制战斗，则由该章节的目标和服务端配置决定。

## 7. 分支与历史记录

系统会记录每次探索的：

- 场景正文。
- 玩家所作抉择。
- 行动后的真实结果。
- 实际支付的代价。
- 当轮取得的物品。
- 已击败敌人。
- 尚未完成的探索方向。

结算页面按照真实探索顺序展示“此行旧事”。没有完成的支路可以写成留在身后的遗憾，但不能暗示结算后仍可继续折返。

## 8. 奖励与失败规则

LLM 只能提出符合剧情因果的奖励蓝图，最终奖励由服务端决定。

- 奖励名称必须在行动结果或结局中明确出现。
- 正文必须说明奖励来自何处，以及玩家已经取得、收起或带走。
- 妖兽材料必须对应实际击败的敌人，或来自场景中已经存在的遗骸。
- 战斗失败时，不发放该战斗事件尚未确认的奖励。
- 已在途中取得的物品不会在最终结算中重复生成。
- 禁止通过剧情虚构境界突破、属性强化或功法永久提升。

异闻选择产生的小额回响奖励与秘境正式奖励分开结算。二者都必须经过服务端预算、境界缩放、品阶上限和资源幂等校验。

## 9. 最终结算

结算按照真实状态区分：

- 完成探索。
- 战后撤退。
- 未战即放弃。

结局只能引用实际发生的抉择、战斗、敌人和奖励。不得虚构玩家已经突破境界、击败了另一种敌人、取得未出现的物品，或在五事件结束后仍能继续深入。

第五个事件完成后的界面只显示“完成探索”。系统整理所得并进入结算，不再显示“继续深入”或“见好就收”。重复点击和网络重试使用同一请求编号，不会重复发奖，也不会把已经成功的结算误报为秘境不存在。

## 10. 主线余波与延迟回响

主线关联秘境结算后，系统会：

1. 根据真实结算生成余波回信。
2. 更新相关人物的状态、生死和关系。
3. 将主线推进到 `aftermath` 阶段。
4. 创建一条延迟回响。
5. 等待玩家对回响作出最终回应。
6. 原子写入回响记忆和奖励，并将章节归档。
7. 开始下一章冷却。

开发环境的延迟回响默认立即可见，生产环境默认延迟十二小时。玩家回应前，章节不会提前归档，也不会生成下一章。

## 11. 异闻关联秘境

普通云游短篇可以在玩家选择后解锁一个异闻关联秘境。它使用相同的五事件框架、服务端消耗和奖励规则，但不属于个人主线章节。

异闻关联秘境完成后只会：

- 更新原异闻的关联秘境状态。
- 保存本次秘境的长期记忆。
- 收束原异闻及其剧情导演裁决。

它不会再把自己当作一个新的根活动，也不会额外触发个人主线异兆。

## 12. 根活动与剧情导演

每次活动都有稳定的 `rootActivityId`。由该活动派生的秘境结算、宗门任务完成和活动短篇必须沿用同一个根活动编号。

同一根活动只保留一个剧情裁决，优先级为：

```text
主线关联秘境结算
> 新主线异兆
> 宗门任务短篇
> 普通秘境短篇
> 普通云游短篇
```

例如，一次普通秘境同时完成宗门委托时，宗门任务短篇会替代尚未显示的普通秘境短篇。如果该秘境本身属于当前个人主线，则只生成主线余波；宗门奖励仍正常结算，但不再额外弹出一段冲突的短篇剧情。

新产生的秘境结算事件会携带继承后的根活动编号。旧版事件没有该字段时，系统仍会按秘境运行编号回退处理，避免历史消息无法消费。

## 13. 幂等与状态保护

剧情秘境通过多层状态防止重复推进：

- 剧情信选择只能确认一次。
- 云游前奏选择通过意图状态和玩家命令锁防重。
- 同一剧情线只能绑定一个运行中的关联秘境。
- 秘境行动、战斗和最终结算都有稳定请求编号。
- 同一根活动只能保留一个剧情导演结果。
- 已经完成的玩家选择不能被迟到事件静默覆盖。
- 奖励写入通过资源变更编号防止重复发放。

因此，刷新页面、重复点击或网络重试不会改变玩家已经确认的选择，也不会重复推进章节或重复发放奖励。

## 14. 与普通秘境的关系

普通秘境和剧情秘境共用同一套探索、战斗、消耗、奖励及结算引擎，差别只在于是否携带权威剧情上下文。

普通秘境可以：

- 生成长期记忆。
- 成为未来主线的故事种子。
- 触发普通秘境 ActivityStory 短篇。

普通秘境不能：

- 推进当前已有的个人主线阶段。
- 替代当前主线指定的关联秘境。
- 改写主线人物的生死或章节结局。

只有绑定当前剧情线、从重要剧情信正式开启的关联秘境，结算后才能推进该主线。
