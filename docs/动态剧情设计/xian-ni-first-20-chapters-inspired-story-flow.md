# 参考《仙逆》前二十章的原创剧情流程设计

> - 状态：剧情设计稿
> - 参考范围：用户提供文本的前二十章
> - 使用方式：提炼叙事结构、节奏和因果组织方法，转化为《万界道友》可运行的原创剧情流程。
> - 版权边界：不复刻原作正文，不沿用原作人物、门派、宝物名称和具体情节组合。

## 1. 参考文本采用的叙事方法

前二十章的核心并不是单纯的“主角得到宝物”，而是一条连续的压力链：

```text
平凡生活与亲情锚点
  → 外部机会突然出现
  → 家人与社会提前寄予厚望
  → 制度化测试连续失败
  → 公开失败带来身份坠落
  → 极端处境中得到隐秘变量
  → 以最低身份重新进入修行体系
  → 暗中积累并隐藏秘密
  → 秘密留下痕迹，引来权力人物
  → 表面晋升，实际进入利益交换
  → 利用信息差摆脱控制
  → 获得独立修炼的起点
```

### 1.1 五段节奏

| 参考章节 | 叙事作用 | 可借鉴的方法 |
| --- | --- | --- |
| 1～4 | 建立亲情、期待和测试失败 | 先让玩家真正在意成功，再让失败产生重量 |
| 5～7 | 公开羞辱和人情反转 | 用同一批人物前后态度对比，形成可长期记忆的关系变化 |
| 8～10 | 绝境、隐秘机缘、低位入门 | 机缘解决的是“存在机会”，不直接解决全部困难 |
| 11～16 | 底层生存、隐藏成长、秘密暴露 | 每次使用秘密都产生收益，同时积累暴露风险 |
| 17～20 | 正式修炼、师徒算计、脱离控制 | 晋升不是奖励终点，而是进入更高层利益冲突 |

### 1.2 值得用于游戏的结构

1. **情绪债先于力量奖励**：玩家先背负家人、引路人和自尊上的压力。
2. **失败必须成为事实**：不能每次失败都马上用更大奖励抵消，否则失败没有意义。
3. **机缘具有副作用**：秘密越有用，暴露、觊觎和利用风险越高。
4. **身份变化会重排关系**：同一个 NPC 会因玩家落魄、晋升再次改变嘴脸。
5. **角色靠观察而非全知取胜**：玩家从矛盾行为、错误功法、跟踪和利益交换中识别危险。
6. **阶段结尾只完成一次小突破**：前二十章结束时只是站稳脚跟，后续仍有大量空间。

## 2. 原创剧情概念

### 2.1 剧情名

《烬灯问途》

### 2.2 核心命题

> 当所有人都用资质、身份和利益衡量一个人时，玩家如何保存自己的判断，并找到一条不受他人定义的修行道路？

### 2.3 故事概要

玩家因偶然帮助宗门勘路使者，得到一次进入附属别院考核的机会。家乡众人提前把玩家当成未来仙师，但玩家在灵根与问心测试中接连落选，回乡后经历人情翻转。

为了证明自己不是因一场测试便走到尽头，玩家循着旧驿图寻找另一条入山道路，在坍塌的地下驿站中发现一盏能够照见残留意念和缺失文字的“照尘残灯”。玩家凭借从古驿带回的证据，以废卷库杂役身份进入宗门体系。

残灯帮助玩家修复废卷、理解残缺吐纳法，却也留下无法解释的痕迹，引来藏书执事祁守藏。祁守藏表面收徒，实际想控制玩家替他恢复禁卷。玩家通过朋友警告、旧卷矛盾和自身试验识破算计，在被逐出藏阁后拼出第一套真正属于自己的吐纳法。

二十节点结束时，玩家只完成第一次稳定引气，但已经形成三条可长期发展的剧情线：残灯来历、祁守藏的追索、同门竞争。

## 3. 背景适配

该剧情不强制玩家必须拥有父母或固定出身。创建剧情时从角色背景中解析一个“故乡牵挂者”：

| 玩家背景 | 故乡牵挂者 |
| --- | --- |
| 普通家庭 | 父母、祖父母或兄姐 |
| 孤儿 | 抚养者、村塾先生或救命恩人 |
| 世家旁支 | 失势长辈或支持玩家的族人 |
| 流民 | 同行伙伴或收留玩家的村落 |
| 宗门出身 | 外门教习或照顾玩家的杂役长辈 |

文档中的“家中长辈”是适配槽位，不是固定人物。

## 4. 主要实体

| 实体 | 类型 | 初始状态 | 叙事用途 |
| --- | --- | --- | --- |
| 玩家 | cultivator | 尚未正式入门 | 故事行动者 |
| 家中长辈 | personal_anchor | 对玩家寄予希望 | 情感锚点，不作为工具人死亡 |
| 韩渡川 | guide | 宗门勘路使者 | 提供试炼机会，后续可成为中立证人 |
| 陆承岳 | rival | 资质优异、出身较好 | 对照玩家的制度优势，可敌可友 |
| 柳砚 | companion | 废卷库杂役 | 底层盟友，后续提供关键警告 |
| 鲍简 | supervisor | 废卷库管事 | 欺软怕硬，展示身份变化 |
| 祁守藏 | mentor_antagonist | 藏书执事 | 表面收徒，实际觊觎残灯能力 |
| 照尘残灯 | relic | 第一重封印未解 | 显示残留意念和缺失文字，不直接赋予数值 |
| 旧驿守灯人 | echo | 只剩意念残响 | 提供残灯来历的远期伏笔 |

所有持久 NPC 由服务端分配稳定实体 ID。模型只能引用这些 ID，不能因名称相似创建另一个“同一人物”。

## 5. 核心状态

```ts
interface EmberLampStoryState {
  determination: number;       // 玩家面对失败时的行动倾向
  homeTrust: number;            // 与故乡牵挂者的真实信任
  publicReputation: number;     // 故乡和外围社会评价
  sectReputation: number;       // 宗门内部评价
  rivalRelation: number;        // 与陆承岳的关系
  companionTrust: number;       // 与柳砚的关系
  supervisorLeverage: number;   // 掌握鲍简问题的证据
  mentorSuspicion: number;      // 祁守藏对秘密的怀疑
  relicExposure: number;        // 照尘残灯暴露程度
  relicSealStage: 0 | 1;        // 第一篇只允许解开第一重
  truthfulToHome: boolean;      // 是否向故乡说明真实处境
  ownsFalseManualEvidence: boolean;
  protectedCompanion: boolean;
}
```

所有数值变化由服务端按选项配置执行，模型只能生成符合当前状态的叙事。

## 6. 剧情线

### 6.1 `thread_home_expectation`：故乡之望

```text
introduced：故乡对玩家入门寄予厚望
developing：玩家失败，关系和外部态度分裂
confrontation：玩家决定是否向故乡说出宗门真实处境
resolved：玩家与牵挂者建立不依赖“仙师身份”的关系
```

### 6.2 `thread_ember_lamp`：烬灯旧主

```text
introduced：地下古驿发现照尘残灯
developing：残灯显示缺失文字和旧日意念
confrontation：宗门开始追查残灯造成的异常
resolved：不在本篇解决，只解开第一重封印
```

### 6.3 `thread_archive_mentor`：藏阁师徒局

```text
introduced：祁守藏调查废卷异变
developing：以收徒为条件要求玩家修复禁卷
confrontation：玩家发现吐纳法被故意删改
resolved：玩家被逐出藏阁但保住证据和修行资格
```

### 6.4 `thread_rival`：同门对照

```text
introduced：陆承岳在入门试炼中取得高位
developing：两人的身份差距扩大
confrontation：陆承岳发现玩家已经真正引气
resolved：留到下一篇，根据旧选择进入敌对、竞争或复杂合作
```

## 7. 二十节点剧情流程

## 第一幕：机会与落选

### 节点 1：潮标来客

**叙事目的**：建立玩家的普通生活、能力和情感锚点。

宗门勘路使者韩渡川在故乡附近损坏了一枚测绘潮标。玩家凭读书、手艺或背景能力认出刻度问题，帮助他修正路线。韩渡川因此给玩家一枚附属别院的试炼凭证。

玩家选择：

1. 为让家中长辈安心而接受。
2. 因好奇修行世界而接受。
3. 把凭证视为偿还故乡恩情的机会。

服务端写入：

```text
memory: 玩家得到入门试炼凭证
memory.tag: motivation_family | motivation_curiosity | motivation_debt
thread_home_expectation: introduced
entity 韩渡川: relation +10
```

后续回收：节点 5、7、14 会按最初动机改变玩家内心叙事。

### 节点 2：悬舟入山

**叙事目的**：第一次展示修行体系，并建立竞争者。

玩家与其他候选者乘悬舟进入栖鹤别院。陆承岳熟悉礼制、装备齐全，对玩家的出身产生轻视；另一名候选者因恐高出现失态。

玩家选择：

1. 帮助失态候选者稳定心神。
2. 观察陆承岳与接引弟子的交流。
3. 当面回应陆承岳的轻视。

服务端写入：

```text
memory: 玩家在悬舟上的行为
rivalRelation: 观察 0；回应 -15；克制帮助他人 +5
sectReputation: 帮助他人 +5；公开争执 -5
thread_rival: introduced
```

后续回收：节点 4 的试炼旁观者态度、节点 20 的陆承岳回应。

### 节点 3：灵窍无声

**叙事目的**：让第一次失败成为不可撤销的事实。

灵窍测试确认玩家感应稀薄，无法取得正式弟子资格。这个结果不能被随机成功覆盖，因为后续全部剧情都建立在它之上。

玩家选择：

1. 接受结果，询问是否存在其他考核。
2. 质疑一次测试是否足以决定一生。
3. 沉默离开测试台。

服务端写入：

```text
canon: 玩家第一次灵窍测试未通过
determination: 询问 +10；质疑 +15；沉默 +5
sectReputation: 质疑 -5
```

限制：模型不得在这一节点偷偷补写“隐藏天灵根”或“测试石失效”。

### 节点 4：问心长廊

**叙事目的**：用接近成功但仍失败加深不甘，同时证明玩家拥有另一种品质。

低资质候选者可以进入问心长廊。玩家在规定时间内接近终点，却因帮助别人、判断岔路或体力不足错过最后钟声。别院记录玩家意志评级很高，但名额已经用完。

玩家选择：

1. 独自冲向终点。
2. 带上先前帮助过的候选者。
3. 停下记录廊中一幅异常旧驿图。

服务端写入：

```text
canon: 玩家问心试炼未取得名额
memory: 玩家在长廊中的最终选择
determination: +15
旧驿图线索: 选择 3 时完整；其他选择只记住残缺位置
```

后续回收：节点 7 前往古驿的路线难度不同。

## 第二幕：身份坠落与隐秘机缘

### 节点 5：先设的庆席

**叙事目的**：让失败进入社会关系，而不只是一条系统提示。

玩家回到故乡时，家中已经因外界误传准备庆席。陆承岳成功入门的消息同时抵达，宾客等待玩家宣布结果。

玩家选择：

1. 当众承认失败，并阻止众人责怪家中长辈。
2. 只对牵挂者说明，保持沉默。
3. 公开质疑别院只看资质与名额的规则。

服务端写入：

```text
canon: 故乡得知玩家落选
homeTrust: 选择 1 +20；选择 2 +5；选择 3 +10
publicReputation: 选择 1 -10；选择 2 -20；选择 3 -15
memory: 谁在玩家落选后仍然支持，谁转变态度
thread_home_expectation: developing
```

### 节点 6：礼簿翻页

**叙事目的**：建立可在后续反复回收的人情账。

部分宾客索回贺礼，部分人冷嘲热讽，引路人韩渡川或一名故乡旧识出面制止。玩家第一次决定如何处理外界的人情债。

玩家选择：

1. 尽可能退回全部礼物，从此不欠人情。
2. 记住态度变化，但暂不争辩。
3. 只保留真正帮助过家中的礼物。

服务端写入：

```text
memory.kind: relationship_turn
memory.importance: 70～90
publicReputation: 按选择变化
entity relationships: supporter | opportunist | hostile
```

后续回收：未来故乡事件必须根据名单生成不同 NPC 反应，不能全部恢复为友好。

### 节点 7：旧驿雨夜

**叙事目的**：让玩家主动寻找另一条道路，而不是被机缘随机砸中。

玩家回忆问心长廊中的旧驿图，决定验证那条已被宗门废弃的入山路线。暴雨导致古驿地窟坍塌，玩家被困在地下。

可用帮助取决于旧记忆：

- 节点 4 记录完整旧驿图：避开第一处塌方。
- 节点 5 保护家中长辈：获得一件家传工具，可打开石缝。
- 节点 6 保留支持者礼物：携带照明或干粮。

玩家选择：

1. 顺着风声寻找出口。
2. 追查墙上反复出现的灯形刻痕。
3. 先救出同样被困的采药人。

服务端写入：

```text
memory: 玩家主动寻找第二条入山之路
determination: +10
救人选择产生 witness 实体
```

### 节点 8：照尘残灯

**叙事目的**：引入秘密，但不直接给予无敌力量。

地窟深处留着一盏冷灰色铜灯。它不能照亮道路，却能在墙面和破纸上显出已经消散的文字与意念残响。玩家通过它看到旧驿守灯人留下的一段不完整警告。

玩家选择：

1. 承诺替守灯人查明古驿被废弃的原因。
2. 只把残灯当作逃生工具，不作承诺。
3. 先用残灯寻找其他被困者，再考虑带走。

服务端写入：

```text
entity 照尘残灯: acquired, relicSealStage=0
thread_ember_lamp: introduced
memory: 取得残灯的方式与是否立下承诺
relicExposure: 0～10
```

硬限制：残灯只提供信息和语义能力，不能直接增加属性、境界或战斗伤害。

## 第三幕：旁门入山与底层积累

### 节点 9：残图为证

**叙事目的**：让重新入门来自玩家行动和证据，而不是无条件破格。

玩家从古驿带回一份被残灯显出的旧路线记录，证明别院外围阵法存在长期未修复的缺口。为了收回记录并处理阵法问题，别院允许玩家以废卷库杂役身份留下。

变化条件：

- 节点 7 救过采药人：对方可作为证人，宗门态度稍好。
- 没有证人：玩家只能交出部分残图换取机会。
- 曾公开质疑别院：部分执事认为玩家借机要挟，初始宗门声望更低。

服务端写入：

```text
canon: 玩家以废卷库杂役身份进入栖鹤别院
sectReputation: -20～0
memory: 入门依赖的证据和交换条件
```

### 节点 10：百卷限期

**叙事目的**：建立底层劳动、制度压力和秘密使用规则。

废卷库管事鲍简要求玩家在不合理期限内清理、编号并修补大量残卷。完成量决定食宿和是否继续留任。

玩家选择：

1. 公开按正常速度工作，隐藏残灯。
2. 夜间使用残灯辨认残页，提高完成量。
3. 先梳理规则漏洞，要求鲍简留下书面任务数量。

服务端写入：

```text
relicExposure: 选择 2 +15
supervisorLeverage: 选择 3 +20
determination: +5
```

### 节点 11：同舍柳砚

**叙事目的**：建立不以力量为前提的盟友。

玩家与杂役柳砚同住。柳砚熟悉废卷库规则，但长期吃不饱，也不敢得罪鲍简。

玩家选择：

1. 分享食物和工作方法。
2. 交换信息，各取所需。
3. 保持距离，避免秘密暴露。

服务端写入：

```text
companionTrust: +25 | +10 | 0
memory: 玩家如何对待同处底层的柳砚
protectedCompanion: 选择 1
```

后续回收：节点 18 是否收到预警，节点 19 是否有人作证。

### 节点 12：无字残页

**叙事目的**：秘密第一次真正帮助修行，同时制造暴露痕迹。

玩家发现一批被判定为空白的残页。照尘残灯显出一段不完整吐纳法和旧驿阵图，但每次照读后纸面会留下浅灰灯痕。

玩家选择：

1. 只记住吐纳法，不移动残页。
2. 抄录一份给柳砚，共同验证。
3. 修复整批残页以换取宗门功劳。

服务端写入：

```text
memory: 玩家取得第一份残缺吐纳知识
relicExposure: +10 | +20 | +35
companionTrust: 选择 2 +20
sectReputation: 选择 3 +15
thread_ember_lamp: developing
```

限制：该吐纳法残缺，不能直接让玩家获得完整技能。

## 第四幕：秘密痕迹与利益收徒

### 节点 13：纸灰异动

**叙事目的**：让秘密使用留下因果，推动调查者登场。

藏书执事祁守藏发现废卷库中出现无法解释的灰色灯痕，且数卷残书恢复了部分文字。他开始调查最近接触过这些残页的人。

玩家选择：

1. 提前处理残灯使用痕迹。
2. 将异常解释为旧驿潮气和特殊纸料反应。
3. 主动提交一份普通修复成果，控制祁守藏看到的范围。

服务端写入：

```text
mentorSuspicion: +10 | +20 | +30
relicExposure: 按处理结果变化
thread_archive_mentor: introduced
```

### 节点 14：故乡来书

**叙事目的**：回收最早的情感锚点和身份变化。

玩家收到故乡来信。外界只知道玩家最终留在宗门，曾经冷落家中的人又开始登门示好。家中长辈询问玩家是否已经过上想象中的仙门生活。

玩家选择：

1. 说明自己只是废卷库杂役，但会继续寻找道路。
2. 隐去困境，让家中长辈安心。
3. 只写修行见闻，不回应身份问题。

服务端写入：

```text
truthfulToHome: 选择 1=true
homeTrust: 选择 1 +20；选择 2 -5；选择 3 0
thread_home_expectation: confrontation
```

后续发展：如选择坦白，剧情线可以提前解决；如持续隐瞒，未来回乡时会形成新的冲突。

### 节点 15：鲍简变脸

**叙事目的**：利用同一 NPC 的态度变化展示权力传导。

鲍简得知祁守藏正在调查玩家，误以为玩家即将被收入藏书阁，突然减少工作并赠送物品，希望玩家忘记此前刁难。

玩家选择：

1. 收下赠礼，但要求鲍简确认以前的任务记录。
2. 拒绝赠礼，维持距离。
3. 接受示好，并要求改善所有杂役待遇。

服务端写入：

```text
supervisorLeverage: +30 | +10 | +20
companionTrust: 选择 3 +15
memory.kind: relationship_turn
```

后续回收：节点 19 能否证明任务和残卷接触记录被人篡改。

### 节点 16：收徒有价

**叙事目的**：表面晋升，实际进入新的控制关系。

祁守藏提出收玩家为记名弟子，条件是玩家协助修复一册无法辨读的古目录。祁守藏不直接询问残灯，而是反复确认玩家是否还有其他修复手段。

玩家选择：

1. 接受，但要求所有修复任务留下记录。
2. 接受，并请求柳砚调入较轻岗位。
3. 先询问功法、住处和退出条件，再决定接受。

所有选择都进入藏书阁，但产生不同保障：

```text
选择 1: owns_task_records=true
选择 2: protectedCompanion=true, companionTrust +20
选择 3: mentorSuspicion +10, contract_clauses=true
thread_archive_mentor: developing
sectReputation: +20
```

## 第五幕：师徒局与自成一息

### 节点 17：缺了一句的诀

**叙事目的**：开始正式修炼，同时让玩家发现知识控制。

祁守藏传给玩家一套基础吐纳法。玩家将其与无字残页对照，发现关键经脉顺序少了一句；按现有版本修炼不会立刻受伤，但永远难以稳定引气。

玩家选择：

1. 暂停修炼，继续收集其他版本。
2. 小范围试验两种顺序，记录身体反应。
3. 直接询问祁守藏缺失内容。

服务端写入：

```text
ownsFalseManualEvidence: 选择 1 或 2
mentorSuspicion: 选择 3 +20
memory: 玩家发现传授功法存在人为缺失
thread_archive_mentor: confrontation
```

硬限制：危险试验不能由叙事直接造成永久属性变化，实际代价必须走服务端资源规则。

### 节点 18：灯下双影

**叙事目的**：将朋友信任、秘密暴露和师父监视汇合。

柳砚根据之前关系决定是否冒险警告玩家：祁守藏最近在暗中检查住处，并准备让玩家修复一份被封存的禁卷。照尘残灯则显出房间中残留的窥探术痕迹。

分支条件：

- `companionTrust >= 25`：柳砚主动预警。
- `companionTrust < 25`：玩家只能靠残灯发现监视，时间更晚。
- `relicExposure >= 60`：祁守藏已经接近确认残灯存在。

玩家选择：

1. 制作一份只能短期显字的假修复成果。
2. 向柳砚透露残灯的一部分真相，共同准备证据。
3. 直接停止使用残灯，观察祁守藏下一步行动。

服务端写入：

```text
memory: 玩家确认祁守藏正在监视
companionTrust: 选择 2 +25
mentorSuspicion: 选择 1 +5；选择 2 +15；选择 3 +10
```

### 节点 19：逐出藏阁

**叙事目的**：失去表面晋升，但保住自主权和关键证据。

祁守藏发现修复成果无法长期维持，判断玩家在隐藏手段。他以“损坏禁卷”或“私藏残页”为由将玩家逐出藏书阁，但因为此前任务记录、鲍简账目或柳砚证言，无法剥夺玩家全部入门资格。

玩家可使用的证据取决于旧选择：

- 节点 15 取得任务记录。
- 节点 16 要求书面条件。
- 节点 18 获得柳砚证言。
- 节点 17 保存错误功法对照。

玩家选择：

1. 公开部分证据，换取外院独立居所。
2. 暂不揭穿祁守藏，保留证据作为后手。
3. 以沉默换取柳砚不被牵连。

服务端写入：

```text
canon: 玩家被逐出藏书阁但保留弟子资格
sectReputation: 按公开程度变化
companionTrust: 选择 3 +20
thread_archive_mentor: resolved
new_memory: 祁守藏与玩家形成未公开敌意
```

祁守藏不死亡，也不立刻受到彻底惩罚；他作为后续中期对手继续存在。

### 节点 20：一息自成

**叙事目的**：完成第一篇的小突破，并同时开启后续冲突。

玩家搬入外院偏僻居所，将问心长廊记忆、无字残页、祁守藏的缺失功法和自身试验结果重新组合。照尘残灯第一重封印松动，显出旧驿守灯人留下的一段完整呼吸节律。

玩家第一次稳定感应并留住一缕天地气息。具体修为增益由修炼系统计算，剧情只确认“掌握正确入门方法”。

此时陆承岳因领取资源或执行任务经过外院，察觉玩家已经真正入门。

陆承岳的反应由节点 2 的记忆决定：

| 早期关系 | 节点 20 反应 |
| --- | --- |
| 玩家曾公开冲突 | 陆承岳怀疑玩家作弊，准备挑战 |
| 玩家保持观察 | 陆承岳开始调查玩家经历 |
| 玩家帮助过他人 | 陆承岳表面讥讽，实际承认玩家有韧性 |

服务端写入：

```text
canon: 玩家掌握第一套可用吐纳方法
relicSealStage: 1
thread_ember_lamp: developing
thread_rival: confrontation
thread_home_expectation: 若 truthfulToHome=true 则 resolved
next_arc: 外院试法与旧驿追索
```

结尾不直接给予超越境界的战力，只让玩家从“没有道路”进入“拥有自己的道路”。

## 9. 运行方式

这二十个节点不是二十段固定文本，而是二十个剧情目标。每个节点由模型结合玩家状态生成不同场景和对白。

推荐分成五个剧情包：

```text
剧情包 A：节点 1～4   机会与落选
剧情包 B：节点 5～8   身份坠落与残灯
剧情包 C：节点 9～12  底层入门与秘密使用
剧情包 D：节点 13～16 调查与利益收徒
剧情包 E：节点 17～20 师徒局与第一次引气
```

每个剧情包可以对应：

- 一次四至五事件秘境。
- 一组宗门任务。
- 一次秘境加若干非战斗剧情场景。

固定的是剧情目标、权威事实和状态变化；变化的是地点细节、遭遇对象、对白、战斗类型和玩家付出的资源。

## 11. 预生成建议

### 11.1 可提前生成

- 每个剧情包的总体蓝图。
- 当前节点的场景氛围、登场实体和冲突目标。
- 非战斗选项的一层后续草稿。
- NPC 对已确认旧记忆的不同回应模板。

### 11.2 必须运行时生成

- 玩家选择后的最终行动结果。
- 战斗胜负后的剧情。
- 根据当前实体状态决定的 NPC 反应。
- 因新记忆导致的剧情线推进。

### 11.3 不应提前生成

- 完整二十节点的全部正文。
- 所有选项的深层分支树。
- 假设玩家必胜或必败的后续场景。
- 具体奖励数值和资源变化。

## 12. 剧情质量约束

1. 玩家失败后至少间隔三个节点，才完成真正的修行突破。
2. 照尘残灯每次使用都必须在收益、痕迹或风险中至少产生两项。
3. 祁守藏不能在初次登场时直接承认恶意，必须通过行为矛盾逐步暴露。
4. 柳砚是否帮助玩家必须依赖既有信任，不能因为剧情需要突然忠诚。
5. 陆承岳的态度必须引用节点 2 的相处记忆。
6. 故乡人物不能在玩家进入宗门后集体无条件转为善意。
7. 玩家获得内门或记名身份不等于立即掌握修行能力。
8. 节点 20 只开放第一步修行，不解决残灯、导师和竞争者三条剧情线。
9. 所有战斗、奖励、修为和资源结果继续由游戏规则系统裁决。
10. 模型不得把原作人物、门派、石珠、云纹等标志性元素写入生成内容。

## 13. 第一篇结束后的三个方向

### 13.1 外院试法

陆承岳质疑玩家的入门方式，推动同门竞争。根据早期关系，可以是公开挑战、调查秘密或被迫合作。

### 13.2 旧驿追索

残灯第一重封印显出新的地名，玩家发现古驿被废弃与宗门过去的一次隐瞒有关。

### 13.3 藏阁余波

祁守藏发现玩家离开后仍能引气，开始通过鲍简、任务分配或其他弟子施压，但他同样担心错误功法证据暴露。

三条方向可以由叙事导演根据玩家记忆、地图位置和冷却时间选择，不需要固定顺序。

## 14. 验收标准

完成该剧情流程的实现后，应验证：

1. 相同角色重玩时场景正文可以不同，但二十节点的核心因果保持一致。
2. 节点 20 的陆承岳反应确实由节点 2 的选择决定。
3. 节点 18 的柳砚预警依赖节点 11、12 的信任记忆。
4. 节点 19 至少能够识别四类不同来源的证据。
5. 玩家未保存任何证据时仍可继续剧情，但付出更高代价。
6. 残灯暴露程度越高，祁守藏调查越早、准备越充分。
7. 玩家向故乡说谎不会立即受罚，但会保留一条未解决剧情线。
8. 模型无法让落选测试、已发生选择或实体状态被后续文本推翻。
9. 任一 LLM 生成失败时可以用模板完成当前节点。
10. 整条流程结束后至少留下两条可继续发展的剧情线，而不是彻底完结。
