# 变异灵兽

确认日期：2026-09-19。变异是同一物种的个体特征，沿用物种 ID、栖息地和培养规则。

## 规则

- 野外每只个体独立以 0.8% 概率变异，成年与 0 级幼崽一致。概率来自 `wild/data/wild.json` 的 `encounter.mutantChance`，当前格式版本 4、内容修订 8。
- 遭遇生成时确定变异，公开预览显示异色及“变异”。开战、重连、捕捉与结算使用同一份个体事实，不再抽签。初始领取只生成普通个体。
- 五项资质先按物种原范围抽取，再乘 1.10，四舍五入为整数。成长先按原千分位范围抽取，再乘 1.10，四舍五入到三位小数。数值提升仅应用一次。
- 技能池、必带技能、数量概率、技能格、寿命、加点、携带要求和捕捉公式沿用普通规则。变异不保底满技能；无必带物种仍可生成零技能个体。
- 洗炼保留变异身份，以物种基础范围重抽后再应用一次提升；普通个体不能洗成变异。药露种类及消耗不变。传承仍是零技能开启第一格，已有技能随机覆盖。
- 变异资质分布整体提高，但某项低资质变异仍可能低于优秀普通个体。不另设综合品质、隐藏保底或合宠规则。

## 数值与存量

面板的等级资质项与属性成长项相加，两者同时提高 10%，主要基础面板约提高 10%，并非叠乘成 21%。整数取整与成长精度造成少量误差；技能固定加值不强化，伤害和胜率不承诺同比变化。

`BeastSchema.isMutant` 为可选布尔值，缺失按普通处理，新普通个体保持旧数据形状。变异写入现有 `cultivator_beasts.individual` JSONB，无需数据表迁移，不重抽存量。保存最终资质与成长，投影不读取变异标记追加倍率。

生成链路为 `generateWildEncounter` → `generateWildIndividual` → `generateCapturedBeast` → `rollBeastTraits`。变异使用独立种子流，普通物种、数量、等级、资质与技能抽签不受影响。`WildIndividualSchema` 校验公开身份与内部个体一致。洗炼调用相同数值生成逻辑。

战斗和回放的 `unitAppearances` 保存 `isMutant`，共享回放严格校验接受此字段。旧战局、旧回放缺失时按普通显示，原有隐藏后备灵兽的可见性边界保留。捕捉结算复制原个体，仍经原事务、角色归属及容量校验入库。

## 展示

`BeastPortrait` 复用 `GameIcon` 的注册头像或 emoji，以 CSS 的 `sepia / saturate / hue-rotate` 组合生成紫色异色。滤镜只作用于头像，不改变血条、文字或技能；透明度与轮廓保留。野外发现与灵兽袋使用共用“变异”标签；战斗编组、单位详情、召唤选择及回放只通过头像变色区分，不显示“变异”文字或标记。

接入野外遭遇、灵兽列表与详情、战斗编组、单位详情、召唤选择与回放。洗炼确认层提示保留变异。CSS 是整体调色，不提供毛发、眼睛、火焰的分区着色。
