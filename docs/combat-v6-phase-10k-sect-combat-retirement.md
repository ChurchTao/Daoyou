- 不改 schema、不迁移或删除历史数据表；历史表删除仍按下一版本计划执行。

## 验收标准

1. 宗门生产源码不再依赖 battle-v5 或 creation-v2；旧编译与写入模块没有剩余消费者。
2. 五宗门历史心法槽位与现有 V6 迁移映射一致，静态定义仍支持历史状态校验。
3. 组织数据读取、任务链路和现有 V6 养成可用；旧入口返回明确的 410。
4. V6 宗门任务可开战、自动操作、结算、幂等奖励、归档及释放会话。
5. lint、共享测试、前后端构建通过；运行未覆盖场景单独记录。
