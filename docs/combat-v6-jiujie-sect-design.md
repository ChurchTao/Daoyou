# combat-v6 Phase 6D：九劫天宫天律镇妖与九霄驭雷纵切

> 状态：Phase 6D 实现基线  
> 稳定宗门 ID：`jiujie`  
> 适用版本：`daoyou_rules_v5` / `daoyou_character_build_content_v5` / `character_build_v5`

本文是九劫天宫在 combat-v6 中唯一有效的战斗设计。旧九劫稿只保留 battle-v5 历史与世界观参考价值；劫雷、劫债、劫数、行动后处罚、整技能免疫、劫眼临身和天谴加身均不进入 v6。

## 1. 构筑定位

九劫天宫以《梦幻西游》经典封天宫与魔天宫为原型，固定为两条共享基础技能的流派：

- 天律镇妖：速度、封禁命中、三封强化、净控与五雷裁定。
- 九霄驭雷：群体法伤、协同电芒、单体/群体引爆与法术吸血。

两流派共享六心法和六门基础技能，不拥有宗门专属战斗资源。电芒不归属施加者，任意九劫角色均可继续叠层或引爆，收益和击倒归当前触发者。

## 2. 六心法

| 槽位 | 心法 | 面板贡献 |
|---:|---|---|
| 1 | 《九劫天书》 | `maxMp += floor(2N)`，主心法 |
| 2 | 《乾坤镇妖录》 | `sealHit += floor(0.4N)` |
| 3 | 《混天雷法》 | `magicAtk += floor(0.5N)` |
| 4 | 《天罡护体经》 | `magicDef += floor(0.4N)` |
| 5 | 《傲世神诀》 | `sealResist += floor(0.25N)` |
| 6 | 《云霄步》 | `speed += floor(0.15N)` |

心法上限为 `min(180, 人物等级+10)`，分支不得高于主心法，技能等级严格等于所属心法等级。

## 3. 共享基础技能

| 技能 | 核心规则 |
|---|---|
| 雷霆万钧 | 群体0.85系数法伤；目标数`min(5,floor(N/45)+1)`；每目标分灵8%、下限60%；存活目标叠1层电芒 |
| 五雷轰顶 | 单体50%概率裁定；成功扣当前HP/MP 25%，HP封顶`50N`；失败扣5%，HP封顶`10N`；HP固定伤害非致命 |
| 天雷斩 | 单体1.0物理攻击；存活目标法防快照降低10%，2回合 |
| 镇妖 | `sealBase=45`，封行动1回合 |
| 错乱 | `sealBase=55`，封法并使普通攻击/直接物理技能随机首目标，2回合 |
| 百万神兵 | `sealBase=55`，封物2回合 |

三封均为可净化 `Control`，倒地清除且不阻止复活。封印判定失败支付成本并消耗行动，但不触发普攻兜底。天雷斩同时属于术法与物理，受封法和封物限制。

### 3.1 概率裁定与非致命伤害

五雷在目标、HP、MP和资源门槛通过后先支付成本，再使用 BattleSession RNG 判定一次。两个分支均为成功施法。HP部分使用 `Fixed/Judge + action-direct + cannotKill`：先经过护盾，最多把目标降到1HP，按真实 `hpDamage` 获得战意；MP损失绕过护盾。

## 4. 电芒与引爆

`jiujie.status.electric` 是普通可净化 Debuff，最多3层，持续3个完整回合。重复施加叠层并刷新持续，满层后只刷新；复制保留层数与剩余时间，净化或引爆一次移除整印，倒地清除。`sourceId` 只作最近施加事件归因，不参与使用资格。

引爆顺序固定为：

```text
读取目标当前电芒层数
→ 主法术伤害
→ MechanicTriggered
→ 每层 floor(0.25 × 施法者magicAtk) 固定派生伤害
→ 消费全部电芒
```

主伤击倒目标后不追伤。派生伤害经过护盾，但不产生战意、功法强化或吸血，也不触发二次引爆。

## 7. Core 与版本边界

Core只新增通用 `RandomBranch`、`ChanceResolved`、`cannotKill`、状态类别/层数条件和 `RandomAttackTarget`。Core、rules和通用投影均不得识别九劫技能、状态或节点ID。

五宗门入口为 `projectCultivatorMultiSectV5ToCombatV6`；V1～V3注册表和 Phase 1～6C 投影保持冻结并拒绝九劫。Phase 6D 不接数据库、旧进度迁移、Host、AI、PVE Boss抗性、战后回写或雷属性克制。
