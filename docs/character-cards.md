# 角色名片

聊天消息只显示姓名与现有角色名号，境界统一放在名片内。桌面悬停姓名 250ms、触屏点击或键盘聚焦均可打开名片；系统传闻不提供角色名片。原有好友收录入口保留在名片内。

名片显示姓名、朱色「名号」、当前宗门／散修、境界阶段、角色背景，以及最多 3 件道装和 3 只灵兽。赞助印戳复用 `MeritStamp`，读取已公开的最高赞助档位；已有“不公开功德簿”设置继续生效。名片中的道装与灵兽使用最大64px的紧凑格子和现有详情，未设置时不展示相应区域；查看详情后关闭只关闭当前层。姓名与名号左侧对齐，境界和宗门合在一行。赞助印戳以176px、12%不透明度置于名片内容右下角的背景。

## 配置与存储

- 入口：`/game/cultivator?tab=card`，角色页的「名片设置」页签。
- 名号沿用角色 `title`，2–8 字，可清除；不创建第二套名号。
- 设置页只显示已选对象；选择道装时通过抽屉复用 `CraftInventoryPanel`、`InventoryItems` 和公共背包／储藏室数据源，选择灵兽时复用 `BeastRosterEntry`、`useBeastPicker` 与已有分页。
- `cultivators.game_settings.profileCard` 只保存 `equipmentIds`、`beastIds`、`revision`，无需数据库迁移。
- 展示对象必须属于当前活跃角色；既可选择随身／穿戴道装，也可选择仓库里的道装和灵兽。读取时再次按当前归属查询，已消耗、转出或寄售离身的对象不继续展示。按玩家选择顺序展示。
- 保存通过既有玩家命令执行器、角色行锁和资源事件提交；请求携带名片版本，过期返回 409。名号变化更新 `player.profile`。
- 世界／宗门及队伍聊天历史批量读取发送者当前名号；新消息在写入通知前补全名号。旧消息不依赖新增数据库列。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/cultivator/card/settings` | 当前角色的设置和名片预览 |
| `PUT /api/cultivator/card/settings` | 原子保存名号与展示选择，要求 `title`、`equipmentIds`、`beastIds`、`revision` |
| `GET /api/cultivator/:id/card` | 查看活跃角色名片，只返回展示字段及选中对象，不返回账号、原始 prompt 或完整背包 |

三个接口都要求活跃角色身份；写入对象由服务端会话确定。每类最多 3 个不同 ID，拒绝额外字段。参数错误返回 400，未登录 401，目标角色已失效或不存在 404。

## 本地验证（2026-10-26）

使用既有 local1／local2 账号，在 `127.0.0.1:5174` 和本地 API 验证：3＋3 选择与数量禁用、完整客户端请求保存、数据库只读核对、刷新后恢复、过期版本、重复／超量／额外字段／无归属对象拒绝、未登录拒绝。第二账号能从聊天查看名号与名片，并打开原有好友收录窗口；不能展示第一账号的道装。

浏览器验证覆盖 1280px 桌面及 360px 手机：悬停／点击、边界避让、名片内道装与灵兽详情、分层 Esc 关闭、设置页物品格尺寸，无页面脚本错误。临时名号与展示选择在验证后恢复，名片版本继续递增。
