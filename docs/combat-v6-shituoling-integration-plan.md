# 新宗门接入方案：狮驼岭技能与双流派经脉

设计日期：2026-11-03。状态：**首版已接入，验收记录见第 11 节**。原型为《梦幻西游》电脑版狮驼岭；本作宗门为**啸岳岭**，ID `xiaoyue`。仅接入**嗜血狂魔**和**万兽之王**两条原型流派，分别为**血啸**（`xiaoyue.path.blood`）和**同契**（`xiaoyue.path.bond`）；不注册狂怒斗兽。

本文的“原”指列明的官方页面／接口直接给出的条件或数字；“改”指本作系统映射或强度调整；“暂”指可实施但尚未得到原作公式支持的首版参数；“待核”指不能宣称已复刻的原作细节。技能的最终伤害仍走本作 V6 公式，**原版费用或百分比相同，不意味着跨游戏最终伤害相同**。

## 1. 结论与范围

啸岳岭是一门有准备成本的物理宗门：主动变身后，以鹰击攻击多人、以连环击点杀；象形用输出机会换取控制。血啸强化本人群攻、吸血和变身续航；同契把原版“驯兽·幼狮”的玩法改为**本人已有的出战灵兽**与主人配合。灵兽保留自己的物种、资质、兽诀、HP、行动和编组；不生成幼狮、幻影、分身、额外行动单位或新的持久召唤资源。

当前 V6 已有七宗。宗门战斗模型固定六心法、两道途；每途前六层各三选一，第七层中列为唯一可选终极节点、两侧为自动奖励。首版因此是两途共 **38 个可选节点＋4 个自动奖励**。已有社会宗门定义、战斗定义和真实灵兽编组是不同层，不能只把一个 JSON 加进注册表就称为接入完成。

### 3.1 变身、休息与控制

变身是一个本人状态，不是换模型或第二单位。首版**暂**定施放后覆盖 4 个完整后续回合、物攻＋`L主`，消耗原版 20 MP。普通状态在施放当回合不扣时长，故建议配置 `duration=4`：第 1 回合施放，第 2～5 回合可借此施展攻击，第 5 回合末到期；入场赠予的“2 回合变身”应另按入场窗口核对，不能直接照抄 `duration=2`。原版只公开“临时提高伤害力”，未公开此处的持续和增量；因此不得把“4 个后续回合／＋L主”写成原作值。变身在原版要求的四个技能上做施放前提；被驱散、到期、象形或基础连环击取消后，应立即移除相应攻击资格。倒地时清除，复活不自动重获。

鹰击和连环击造成的“休息一回合”按本作**下一个完整本人行动窗口**处理：当前 V6 `skipNextAction` 会跳过人物这一次行动，灵兽仍按自己的指令行动；这与原作休息轮可能允许的防御操作是**改**。休息不得由速度先后或回合末状态衰减提前吃掉。鹰击本身也不得连续两回合使用。

象形命中后限制敌人下一个完整行动窗口；施者下一完整行动窗口禁止使用宗门法术，并取消变身。物理攻击命中与封印命中分别结算，目标免控、未命中或被解除时保留正确战报。控制底率 S1 未公开，首版**暂**用本作封印曲线与 55% 底率；原版没有明确保证必中。

## 4. 血啸：嗜血狂魔经脉完整映射

表中同层三项互斥，列号按 S2 原坐标保留。第 7 层只有中列可选。被动中“攻击”默认指本人的根行动直接物理伤害；需要按原文覆盖反击或器诀的项目会单列，避免多段、反击和灵兽连击无意重复触发。

| 层位／原节点 | 首版效果与原版差异 |
| --- | --- |
| 1-1 爪印 | **原**：本人攻击敌人或被其攻击后，给该敌人本人来源的爪印，最多 6 层、持续 5 回合／目标死亡止；每层使本人每回合第一次攻击该目标的伤害结果＋`P`。**改**：一次根行动对同目标最多叠 1 层，防止连环击一出手叠满；爪印不可被普通净化清除。 |
| 1-2 迅捷 | **原**：对 NPC 进场得 2 回合变身，但伤害力减少人物等级×1，外部变身套装不触发。**改**：伤害力映射为本作物攻－`P`；与主动变身互斥／刷新，不叠两层物攻。 |
| 1-3 驭兽 | **原**：本方所有召唤兽伤害＋3%、承伤－3%，相同效果不叠加。**改**：只数同队真实在场灵兽，不新造单位；多名本宗也只取一份。 |
| 2-1 化血 | **原**：本人攻击时 30% 概率回复其造成伤害的 16% HP。**改**：按实际气血伤害计算，护盾吸收和溢出伤害不算；每段独立判定，不能由治疗反向触发。 |
| 2-2 宁息 | **原**：变身持续＋1 回合；击倒目标时 15% 概率再延长 1 回合。**改**：一次根行动只抽一次，不按群攻击倒人数多抽。 |

| 3-2 鹰啸 | **原**：雪天鹰击 30% 概率额外造成 40% 伤害。**改／暂**：无天气，改为“每次主动兽形后的首次鹏击”才作同样 30% 判定；外部进场变身不满足。保留准备成本，不给常驻 40%。 |

## 5. 同契：万兽之王改为本人灵兽协同

### 5.1 统一改编语义

原版“驯兽”是额外的幼狮单位，具备自己的“幼狮之搏／驯兽重生／狮魂”。本作已经有一只可出战的个人灵兽，且人物与灵兽各自提交正常指令。**“驯兽”一律指本人当前在场、存活且 `ownerId` 匹配的灵兽；“幼狮之搏”一律映射为这只灵兽的一次正常直接物理行动**。没有灵兽或灵兽倒地时协同收益暂时失效，但本人仍能使用共通的兽形、狮搏、鹏击等技能。换宠只切换协同对象，不复制狮魂或重置每轮触发预算。

S2 未公开狮魂每层原始增幅、幼狮基础伤害和自动行动规则。本作先将“狮魂”定为战内**最多 1 层**：本人狮搏击倒非灵兽敌人后，当前本人灵兽得到 1 层；其下一次正常直接物理行动的**第一击**结果＋8% 后消耗。若此时无本人在场灵兽，不补发给未来换入者；灵兽收回时未使用的狮魂清除，再次换入不恢复。原版未证实的“每层伤害”不能冒充 8%；8% 是为了替换额外幼狮行动而设的**改／暂**。一次性协同节点各自记录消费预算；常驻数值节点对每次符合条件的直接打击生效。法连、物连、反击、反震和 DOT 不额外触发一次性协同。

正常协同需主人站立；“复仇／救主”是明示的倒地例外。原版针对幼狮的 10% 双防、12% 双倍、25% 同攻、30% 击倒强化以及额外幼狮攻击，不能原封不动叠到一只已有完整资质／兽诀／独立回合的灵兽上。下表的削减、上限和“仅下一次正常行动”均属本作平衡改编。

## 6. 外部机制与强度处理

| 原依赖 | 本作接法 |

| 法宝、灵宝、神器、变身套装 | 首版不接入相应物品、灵气或自动变身来源；依赖这些来源的节点改为明确的本人主动技能触发，不能无代价常驻。 |
| 天气“雪／风” | 鹰啸读“主动兽形后的首次鹏击”；展翅读“主动兽形后的首个完整回合”。这是触发条件替换，不宣称等于原天气出现率。 |

| 破血狂攻／破碎无双 | 怒火只绑定本作已有双剑合璧／摧灵斩，二者仍需真实装备器诀及 80 战意，不无偿授予。 |
| 五龙丹、九转回魂丹 | 战斗药品指令当前未实现。背水改读友方净化事件；救主以灵兽 HP 成本代替药品并限制一次。 |

| PvP 的“玩家／召唤兽／孩子” | 玩家对应 V6 角色，召唤兽对应有主人 ID 的灵兽；无孩子或独立召唤物时没有替代目标，不把普通 NPC 当成孩子。 |
| 门派克制、返宗、临时腰带符 | 不构建缺失的克制环、战外传送和临时装备经济；登记原型，不虚构免费战斗收益。 |

同契的增益按“本人＋本人一只正常灵兽”的**合计**评价。原版幼狮是额外、受专用数值限制的行动体，本作灵兽已能持有高成长、兽诀、连击和暴击；因此第 5 节保留原概率、条件或比例的同时，对常驻增伤、额外攻击、互疗和救主增加了明确上限。需要抽取／触发的一次性协同各自持有每轮预算，仅看 `action-direct`；常驻条件增益按节点表作用于每个合格直接打击。高级连击的 55% 追加攻击不再次抽取一次性协同。

## 7. 数值基线与验收预算

暂值集中在第 3、5 节，不混写入“原”。平衡比较必须使用本作同等级、同属性点、同普通道装、同修炼、同品质本人灵兽与同一组种子，计算**主人＋本人灵兽的实际 HP 伤害／每个完整回合**，同时记录首目标点杀、击倒回合、承伤和治疗。变身起手、休息、灵兽本来就有的正常行动都计入；不可只比鹰击单次系数。参考对手至少包括红尘的断尘／临渊和九劫的震岳／掠霆，覆盖 50／90／170 级、1／3／6 敌人、无宠／普通物攻宠／高级连击宠及 PvP 单宗／双宗阵容。

首轮评审预算：同契在**有本人普通灵兽**的六回合中位合计伤害应落在血啸同构筑的 **90%～110%**；前四回合点杀输出不超过血啸的 **115%**；高级连击宠的高分位场景不应因协同额外获得一次完整宠物行动。两流派可以在群攻、回复和控制上各有优势，预算是发现异常的复核阈值，不用全局削弱所有原版来源数值来机械卡线。无宠时同契仍可用共通攻击，但协同收益自然缺席；需在道途说明和自动战斗提示中写清。
