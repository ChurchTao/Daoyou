# Phase 10V：旧秘籍抽取退役与天骄宝阁新版入库

2026-09-10 用户确认旧抽取先下线，已有专属符箓和秘籍暂不转换、不补偿，后续独立设计抽取玩法。主体实施与重点本地验收完成。

## 边界与实现

- 删除旧抽取页面、导航、HTTP 路由、两层服务、专属 DTO、概率配置及其测试。不提供隐藏入口或旧接口兼容。
- 保留历史符箓、秘籍、道具库及邮件数据；历史符箓展示停用说明，移除跳转。没有删除或转换玩家资产。
- 道具库发布与新奖励生产禁止旧抽取专属符箓／秘籍；历史邮件领取仍走原历史通道，不在库存读取或历史领取入口加入禁用校验。后台符箓场景选项移除旧抽取。
- 天骄宝阁仅接受可生成新版库存事实的材料、种子、丹药／灵果及有效场景符箓。玩家列表隐藏不支持的存量商品，直接购买与后台上架同样拒绝。后台仍可查看、归档旧商品。
- 复用现有新奖励事实构建和 grantInventory，优先 bag，满包 storage。声望扣除、库存写入和周购买记录同一玩家事务；ResourceEngine 只处理声望，不整体改造历史发物能力。
- 请求必须携带 UUID requestId；复用玩家命令持久凭据，以商品 ID 为指纹。同键重试返回原结果，不再扣费或发奖；同键换商品返回 409。
- 页面保留原兑换结构，增加同步提交保护与按商品保留的失败重试凭据；成功后刷新声望、额度并提示入库位置。新版库存页进入时读取当前事实，不新增平行库存订阅协议。
- 保留价格、每份数量、周限购与历史附件规则。不增加道装／玉简／兽诀商品类型，不重新设计抽取、闭关或高阶产出，不执行迁移、补偿、删表、部署。

- 后续用户确认保留旧秘籍材料类型、现有生成能力与权重，供未来用途设计；不执行旧秘籍材料的全局退役或道具库批量下架。旧抽取仍停用，已有符箓与秘籍不转换、不补偿。
