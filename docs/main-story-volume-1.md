# 主线卷一细纲：入山（炼气）

状态：细纲草案第二版（2026-11-10），未实现。已按第 7 节的核对结果修订。总体设计与故事圣经见 `docs/main-story-design.md`。

## 1. 本卷要做到的事

- **明线**：你在别人的身体里醒来，被采药老人救起，拜入山门做记名弟子，受管事师兄刁难，结识两个同批的怪人，在入门考校中出头，筑基。
- **暗线**：只埋不问。卷末揭开第一层：同批的怪人都是和你一样从人间来的。
- **引导**：教完战斗、灵兽、宗门、铸器、炼丹、野外、宗门差事、闭关、秘境、坊市、破境，并把玩家送进日常循环。
- **情绪**：先孤身一人，后有了落脚处、有了朋友，最后发现自己并不孤单。

## 2. 人物

| 人物 | 小像 | 性情与说话方式 | 本卷作用 |
| --- | --- | --- | --- |
| 许伯 | `portrait-elder-m` | 话少，句子短，先做事后开口。从不问你打哪来 | 救你、送你上山、隔三差五捎东西 |
| 陈放 | `portrait-disciple-m` | 话多，爱起外号，管灵石叫钱。闯祸不断，讲义气 | 朋友；卷末的揭示由他完成 |
| 林晚 | `portrait-disciple-f` | 寡言，记性好，记账用一套别人看不懂的记号 | 朋友；揭示时的第二重印证 |
| 贺钧 | `portrait-noble-m` | 客气，从不高声，事事占着规矩 | 本卷对手。只属于明线，没有秘密 |
| 沈长老 | `portrait-elder-f` | 温和，记得每个弟子的名字 | 卷末才露面，赏识你，赠清心丹（为卷二、卷六铺垫） |
| 教习、丹房执事、器坊执事、接引弟子 | 各宗现有人物 | 沿用各宗现有称呼（现有填词） | 教本事 |

陈放、林晚的名字放在一群古风名字里显得平常得出奇。当时的解释是小户人家出身；这是本卷最早的一处埋线。

贺钧、陈放、林晚、沈长老在八宗通用，不随宗门改名，只在称谓上跟随各宗（待确认无相禅宗、幽都是否需要单独的称谓表）。

## 3. 节奏

炼气的设计周期是三天：四个小阶各需 500、600、800、1200 修为，每日预算约 1000。

| 段 | 章 | 目标时长 | 进度门槛 | 预计到达 |
| --- | --- | --- | --- | --- |
| 开场 | 序、一 | 10 分钟内 | 无 | 第一天 |
| 入门 | 二、三、四 | 约 30 分钟 | 无 | 第一天 |
| 日常 | 五、六 | 跨一到两天 | 炼气中期 | 第一、二天 |
| 考校 | 七、八 | 约 30 分钟 | 炼气后期 | 第二天 |
| 筑基 | 九、卷末 | 取决于修炼 | 炼气圆满且修为已满 | 第三天前后 |

第六章是有意放慢的一章：主线只给宽松的目标，让玩家自己过宗门日子。

剧情不写具体的年月。闭关以年计并消耗寿元，一次闭关可能就是几年，文字里只说「后来」「过了些时候」。

## 4. 分章细纲

幕的类型：演出、剧情战、练习（带教学）、目标（做到即可，不带教学）。带「新」字的类型现有引擎尚不支持。

### 序 最后一夜

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 序-1 | 演出 | 人间的最后一夜。三四句，只写夜深、灯还亮着、你累了。不写职业、家人、城市。最后一句：「睡着之前，你想了一件事。」 |
| 序-2 | 创建角色 | 现有创建流程。「以心念唤道」就是那件事 |

埋线：心念原文（卷九使用）。

### 一 溪边

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 1-1 | 演出 | 在青溪边醒来，浑身湿冷。衣服不是你的，手也不是你的。采药的老人放下药篓探你的鼻息 |
| 1-2 | 剧情战（新） | 下山路上，一头受惊的山兽冲出来。必胜。只教三件事：出手、用一次本事、看懂胜负 |
| 1-3 | 演出 | 许伯看了你一眼：「学过？」你答不上来。翻倒的药篓底下钻出许伯捡来的小灵猫咪咪，它不肯让许伯碰，却挨着你坐下；许伯把它送给你 |
| 1-4 | 练习 | 选一只带走（现有初始灵兽领取）。教携带与出战 |
| 1-5 | 演出 | 许伯指给你山上一座旧洞府：前头的人走了很久了，你先住着。他把药篓里的干粮留下一半 |
| 1-6 | 练习 | 认洞府：只指灵眼之泉和出门的路两处 |

- 奖励：干粮与几株草药（沿用 `first-herbs`）。
- 开放：洞府、道身、灵兽。
- 埋线：「这个时节水凉，怎么又有人躺在这儿。」；你打赢了；幼兽不怕你；洞府「前头的人」。
- 这具身体的来历（创建角色时生成的姓名、出身、背景）只从别人口中听到，你自己并不记得。见第 7 节第 5 项。
- 现有教学的去向：`cave-layout` 缩为两步；`cultivator-basics`、`inventory-basics` 改为首次进入对应页面时的一次性提示，不占主线。

### 二 山门

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 2-1 | 演出 | 几天后，许伯上山：再过两日诸宗开山收徒。没有师门的生面孔，在这山里活不长 |
| 2-2 | 练习 | 舆图：找到太岳山与诸宗山门（沿用 `map-qingxi`，改写文字） |
| 2-3 | 练习 | 看诸宗，选一处拜入（现有流程，`sect_joined`） |
| 2-4 | 演出 | 验根骨。接引弟子的手在你腕上多停了一息，低头在名册上添了一笔：「记名弟子。去吧。」 |
| 2-5 | 练习 | 选流派、加点（现有 `sect-first-path`、`first-attributes`，`sect_ready`） |
| 2-6 | 剧情战（新） | 教习试手。胜负都过关；输了教习说「还行，知道躲」 |

- 开放：宗门、舆图。
- 埋线：接引弟子多看了一眼，在名册上添了一笔。

### 三 记名

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 3-1 | 演出 | 管事师兄贺钧发放用具。给你的那把兵器崩了口。「记名弟子的份例就是这些，规矩如此。」顺手把清扫山门的差事牌递给你 |
| 3-2 | 目标（新） | 清扫山门一次（现有玩法） |
| 3-3 | 演出 | 器坊执事看见你那把刀，哼了一声：这也叫兵器。炉子空着，自己打一把 |
| 3-4 | 练习 | 铸第一件兵器并穿戴（现有 `forge-first-weapon`、`weapon-equip`） |
| 3-5 | 演出 | 夜里睡不着。你找了张纸，想把家里的事记下来。选项：三句里选一句写下（内容留白，例如「家门口那条街的名字」「常吃的那家店」「一个人的声音」） |

- 奖励：铸器材料（沿用 `first-weapon`）。
- 开放：炼器（个人入口）、储物袋、修仙日志。宗门器坊平时要内门弟子才能用，这一课是执事破例。
- 埋线：手记里的那一句（卷二使用，需要记住玩家选了哪句）。

### 四 丹房

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 4-1 | 演出 | 贺钧派你去丹房打杂。丹房里一个记名弟子正对着一炉焦炭发愁：陈放。他自我介绍完，问你月例几块钱。旁边记账的林晚头也不抬：「灵石。」 |
| 4-2 | 练习 | 丹房执事教第一炉（现有 `alchemy-first-furnace`） |
| 4-3 | 目标（新） | 把炼出的丹给灵兽或自己服下一枚 |
| 4-4 | 演出 | 陈放把你的丹和他的焦炭摆在一起比了比，决定以后跟着你混 |

- 奖励：药材（沿用 `first-furnace-lesson`）。
- 开放：炼丹（个人入口）。宗门丹房同样只是破例一课。
- 埋线：陈放说「钱」；林晚账本上的记号（陈放凑过去看，被她合上：「家里传下来的。」）。

### 五 青溪

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 5-1 | 演出 | 教习点了几个记名弟子去青溪坡清点雨后的兽情。陈放自告奋勇，被留下抄名册 |
| 5-2 | 目标 | 在青溪坡寻觅，遭遇一次生灵（现有 `qingxi_met`）。打、捉、退都算 |

| 5-4 | 演出 | 回山复命。教习记下，没有夸你，也没有再多问 |

- 开放：野外。
- 埋线：无。这一章只负责让玩家喜欢许伯。

### 六 攒本事

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 6-1 | 演出 | 事务堂贴出告示：记名弟子入门考校在即，过了的才发下山的腰牌。贺钧在告示前拦住你：「名额有限，别白费力气。」 |
| 6-2 | 目标（新） | 完成三次宗门日常（清扫山门、巡视矿场、灵矿采掘任选）；闭关一次；修习心法或打通一处经脉。三项不分先后 |
| 6-3 | 演出（随目标触发） | 你的差事牌被换成了灵矿采掘。林晚替你对了账：换牌的人是贺钧 |
| 6-4 | 演出（随目标触发） | 教习看你们三个练功，摇头：「这几年的新人，一届比一届怪。」 |
| 6-5 | 等待（新） | 修至炼气后期 |

- 开放：事务堂、静室。宗门修炼室要外门弟子才能用，留到卷二。
- 埋线：教习的那句话。
- 6-3 顺带引入灵矿采掘。

### 七 考校

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 7-1 | 演出 | 今年的考题：落日森林边上那座废弃药园，近月药草成片枯死，林中野兽也躁了。去查清缘由，回来禀报。三人各走各的 |
| 7-2 | 目标 | 完成一次云游探秘：落日森林·废弃药园（现有 `dungeon_settled`）。教学只讲三件事：看案情、问人、下结论 |
| 7-3 | 演出 | 出园时，贺钧的两个跟班堵在路口，要你把查到的东西交出来。陈放抄起锄头引走了一个 |
| 7-4 | 剧情战（新） | 对付剩下的那个。可败；败则林晚带着教习赶到 |
| 7-5 | 演出 | 放榜。三人都过了，各领一块下山的腰牌。贺钧站在人群外，客气地拱了拱手 |

- 奖励：一份考校赏赐（新奖励）。
- 开放：秘境。
- 考校是剧情事件，不改变宗门身份。晋外门留给卷二（原因见第 7 节第 2 项）。
- 药园现有的场景设定正好是「药草成片枯萎、野兽暴躁」，与卷一的气氛相合，不需要改。

### 卷末 同乡

| 幕 | 类型 | 内容 |
| --- | --- | --- |
| 末-1 | 演出 | 夜里守着陈放。他烧得迷糊，嘴里念了半句话。那是一句只有人间读过书的人才接得上的口诀。选项：接下半句／不作声 |
| 末-2 | 演出（回照，新） | 无论接不接，他都睁开眼笑了：我就知道你也是。此前的几句话重新浮在纸上：「月例几块钱」、林晚合上的账本、接引弟子添的那一笔、教习的那句话 |
| 末-3 | 演出 | 林晚把账本推过来。那套记号你从小就认得。她说名册上你们几个的名字旁都有一个小记号，同批里还有好几个 |
| 末-4 | 演出 | 第二天，世界频道的引导：这一批来的人，比你想的多 |

- 开放：世界频道的引导。
- 揭示之后不追问「宗门为什么要记这个记号」。那是卷二的事。
- 口诀建议用「奇变偶不变」与「符号看象限」。它不属于任何作品，玩家一眼就懂。

## 5. 样稿

完整台词见 `docs/main-story-volume-1-script.md`。下面两段是定调时的样稿，与完整台词不一致时以完整台词为准。

样稿用来定调，不是定稿。玩家的话尽量交给选项，旁白不替玩家下判断。

### 5.1 第一章开场（1-1）

> 冷。
>
> 你是被冻醒的。耳边有水声，身下是硌人的卵石。
>
> 身上的衣服不是你的。
>
> 有人在你旁边蹲下，放了件什么东西，草叶的气味。一只粗糙的手探到你鼻子底下。
>
> 许伯：「这个时节水凉，怎么又有人躺在这儿。」
>
> 许伯：「能走吗？能走就跟我回去，喝口热的。」
>
> · 这是哪儿？
> · 你是谁？
> · （试着站起来）
>
> 许伯：「太岳山，青溪坡。我姓许，在山弯里采药。」
>
> 他没有问你的名字，也没有问你打哪来，背起药篓就走。走出几步，停下来等你。

## 6. 本卷需要的引擎能力

| 能力 | 用在 | 说明 |
| --- | --- | --- |
| 创建角色之前播放演出 | 序 | 演出播放器本身不依赖服务端，可在创建页直接播放，不记进度 |
| 课堂破例 | 3-4、4-2 | 现在由前端按章节 `arrival` 与幕 `hearth`、`forge` 硬编码放行，换章节后要改为按幕上的声明放行 |
| 剧情战 | 1-2、2-6、7-5 | 指定对手；可配置必胜或胜负皆可 |
| 目标幕（多项、计数） | 3-2、4-3、6-2 | 取代只能认事实的练习幕 |
| 等待幕 | 6-5、9-1 | 显示门槛，不留空白 |
| 随目标触发的演出 | 6-3、6-4 | 完成某项目标时插播 |
| 选项写入标记 | 3-5、末-1 | 需保存所选内容 |
| 回照 | 末-2 | 把此前的原句重新摆出来 |
| 功能开放 | 各章 | 见各章「开放」 |
| 新条件 | 清扫山门、宗门日常次数、闭关、用丹、买入、境界小阶 | 现有事实只覆盖入宗、流派、灵兽、炼丹、铸器、穿戴、青溪遭遇、秘境结算 |
| 新奖励 | 考校赏赐 | 现有只有三份剧情奖励 |

### 6.1 实施时的调整（2026-11-10）

- 不做独立的剧情战，原因见 `docs/main-story-design.md` 第 8.1 节。1-2 用青溪坡的野外遭遇，战后的文字不分胜负；2-6 改为练功房教学；7-5 改为演出里的选择，台词稿录入时相应改写。
- 「服下一枚丹」按「用过一次消耗品」判定；「买一样筑基丹的材料」按「在坊市买过一样东西」判定，不校验买的是什么。
- 「修习心法或打通经脉」按宗门战斗页的修习与打通操作判定。

### 6.2 录入与台词稿的出入（2026-11-10）

数据在 `packages/game-content/src/performance/data/v1-*.json` 与 `packages/game-content/src/story/data/v1-*.json`。

- 去掉了「服下一枚丹」这一幕：不确定满状态下丹药能否服用，怕卡住进度。
- 8-3 改为门房转述许伯捎来的话（哪家铺子有那味药），不再送东西；8-4 沈长老改为许诺日后备些清心的丹药。原因是剧情不能写出没有真实发放的物品。
- 6-3、6-4 原想在做目标的途中插播，现合并为目标完成后的一场演出。
- 3-2 的目标是「完成 1 次宗门日常」，不限定清扫山门。
- 新增的坊市、云游、日志没有配界面高亮教学，只有目标提示。
- 入口开放顺序：系统类入口一开始就有；灵兽袋、舆图、宗门、宗门心法、修仙日志、每日占卜、云游与探险札记、坊市与回收、任务中心、世界传音依次随章节开放；卷末之后全部开放。

## 7. 核对结果

以下均对照当前代码确认，文件位置附后。

| # | 核对项 | 结论 | 对细纲的影响 |
| --- | --- | --- | --- |
| 1 | 炼气的成长速度 | 设计周期三天；四小阶 500、600、800、1200，每日预算 1000（`packages/game-content/src/cultivation/`） | 第 3 节的门槛已按此排定 |
| 2 | 记名晋外门 | 条件是累计贡献 100 加三次日常，没有试炼。记名弟子能接的日常只有清扫山门、巡视矿场、灵矿采掘，每次约 4 到 5 贡献；按每日各做一次估算，要一周左右（`StandardSectOrganizationModule.ts`、`taskRewards.ts`） | 炼气三天就结束，晋外门赶不上。「大考」改成不绑身份的入门考校，晋外门移到卷二开头 |
| 3 | 宗门设施的身份要求 | 修炼室要外门；丹房、器坊要内门。现行教程靠前端的课堂破例进入，判断写死了章节与幕的编号（`SectCraftBoundary.tsx`），服务端未见对应判断 | 第三、四章保留破例一课，课后玩家用个人的炼丹、炼器入口；第六章不开放修炼室 |
| 4 | 废弃药园能否进入 | 开局只校验所选节点自身的境界，该节点为炼气、难度为易（`DungeonApplicationService.ts`、`map.json`） | 可用 |
| 5 | 秘境的玩法形态 | 云游探秘是查案，不是取物。剧本库有手写保底与模型生成两种来源（`ScenarioLibrary.ts`） | 第七章改为「查清药园为何枯萎」；主线这一场可以指定一份手写案卷 |
| 6 | 秘境的消耗 | 消耗寿元，炼气基数 1，易难度再乘 0.75（`packages/game-content/src/dungeon/cost.ts`） | 负担很轻，不需要额外补偿 |
| 7 | 心念原文 | 已保存在角色表的 `prompt` 字段，2 到 200 字（`schema.ts`、`genesis.service.ts`） | 卷九可以直接引用，引用前仍需过文字过滤 |
| 8 | 创建角色生成的内容 | 模型会生成本地的姓名、出身、性格和背景故事（`prompts/character-generation.md`） | 开场必须是魂穿：你在别人的身体里醒来。见下方待确认第 1 项 |

| 10 | 闭关 | 以年计，上限 200 年，消耗寿元（`cultivationExpGain.ts`） | 剧情不写具体年月。许伯多年不见老，可以作为卷七的一处埋线 |

## 8. 待确认

1. （已定，2026-11-10）按魂穿处理：心念是你许的愿，创建角色时生成的姓名与身世是应愿给你的这具身体的来历。开场你不记得这些，只从别人口中听到。不改生成逻辑。
2. 考校那一场秘境用固定的手写案卷，还是接受每个玩家遇到的内容不同。建议固定，因为出园后的剧情要接得上。
3. 无相禅宗、幽都等宗门对「师兄」「管事」「长老」的称谓是否需要替换表（尚未核对各宗的称谓配置）。
4. 已完成现行章节的老角色：直接视为卷一已读，还是允许从卷末补看。
5. 药园等秘境的场景设定文字里出现了「黄枫谷」等名称，与舆图地名同属需要评估的范围。
