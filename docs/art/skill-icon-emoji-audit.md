# 技能图标替换进度与 emoji 待替换清单

盘点日期：2026-10-05。依据当前灵兽技能修订 **19**、物种修订 **15**，并核对技能编译、展示适配器和前端调用。第二批 16 枚图腾已接入，覆盖 28 条技能配置；此次只替换图标，技能机制和内容修订不变。

## 统计口径与结论

| 范围                     | 技能配置数 | 独立图标题材数 |
| ------------------------ | ---------: | -------------: |
| 已接入水墨图腾的灵兽技能 |         65 |             41 |
| 仍使用 emoji 的灵兽技能  |     **16** |         **11** |
| 灵兽技能合计             |         81 |             52 |

待替换的 16 项由 **5 组普通／高级家族（10 项）与 6 项独立技能**组成。普通／高级同家族共用图标符合现行约定，所以下一轮需要设计 **11 枚**，无需分别制作 16 枚。

剩余 **16 项均可通过传承灵印学习**。全部 14 个特殊技能均已接入图腾，第二批补齐 **摧山、善恶有报**。

当前剩余 emoji 没有跨家族共用同一字符的情况；重复均来自普通／高级配对。本轮待解决的是图标风格、技能语义与辨识度。设计时遵循 [水墨技能图腾 skill](../../.agents/skills/daoyou-skill-totems/SKILL.md)，沿用已验收的固定参考。

依据：

- [技能配置与家族关系](../../packages/game-content/src/beasts/data/skills.json)：计数读取 `icon`；配对读取 `families`，不靠名称推断。
- [当前物种出生池](../../packages/game-content/src/beasts/data/species.json)：下表物种数为同一家族在 `birthSkills.core` 或 `candidates` 中出现的去重物种数，涵盖普通及高级版；不代表掉落率或玩家持有率。
- [技能编译器](../../packages/game-content/src/beasts/skill-compiler.ts)及[效果说明](../../packages/game-rules/src/combat/skill-details.ts)：核对主动／被动行为与容易误读的效果。
