# Phase 9F：功法玉简与人物道印养成闭环

> 2026-09-07：实现完成，核心本地链路已验收。未验证项单独列于文末。

## 确认范围

- 沿用 Phase 5A 十谱系、本篇／真解二十定义及境界派生的 2～6 道印位，单构筑。
- 玉简进入唯一库存；固定定义堆叠键，每格 99。只消费储物袋中的玉简，储藏室需先取出。
- 参悟、指定改修各消耗一本，无额外资源、冷却或失败概率。真解可直接参悟，同源本篇只能原位升级；重复与降级拒绝。
- 替换目标本身的冲突可移除，其他位置冲突须先散功。免费散功，无返还。
- 野外按胜利场次独立 3% 产出一本，十谱系等权，本篇总权重 95%、真解 5%；概率不对外显示。不赠送初始玉简。
- 悟道功法页面硬切新版；旧创建及确认写入关闭，保留旧数据及放弃待确认结果的清理能力。
- 无 AI、随机属性、升级经验、多构筑、残页、交易、药品、旧数据转换或全仓 v5 删除。

## 实施方案

1. 玉简定义分类注册，引用现有功法 ID；业务掉落池升版接入，通用底座不变。
2. 复用现有功法状态和槽位表；角色 Redis 锁、SQL 角色锁、revision 与同一事务完成消费和构筑更新，不新增凭据表。
3. 新页面主展示道印位，统一抽屉选择与确认、tooltip 说明；库存参悟链接进入同一流程。
4. 活动战斗及结算期间禁止修改。开战冻结构筑、下一场更新、既有回放不变。
5. 纯共享规则测试、lint/build、触及文件 Prettier 和本地真实页面验证；历史暂缓项不代替本轮通过记录。

## 发布

无需新增数据库迁移。前后端同步发布并刷新旧页面。青溪掉落池版本由 1 升至 2，已开始的战斗沿用冻结配置；新战斗采用新版。正式概率尚不代表经济平衡已验证。
