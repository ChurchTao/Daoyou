## 确认边界及补充决定

- 排行榜角色查探、本人角色总览统一显示 V6 面板、六部位道装、已装配功法、宗门流派与当前构筑可用技能。
- 移除现役角色读取中的旧装配字段、player.loadout 订阅／协议／事件及其读取器。历史宝库、旧物品详情、旧法宝回收继续保留。
- 闭关、客栈、消耗品操作移除旧装配查询，保留现有 V6 现实资源权威及战斗占用规则。
- 实施中确认旧功法品质仍实际参与闭关修为倍率。用户明确补充决定：“闭关取消功法倍率收益，后续在重新设计”。因此本阶段删除旧品质倍率表及计算，不映射新版功法，不作补偿或历史修为重算。原倍率含0.8～1.15，移除后该因子为1；其他收益因子保持。
- 秘境实际入口已使用 V6 技能投影，旧 loadCultivatorDungeonPromptFacts 无调用方，本轮删除废弃读取，不重写秘境。
- 不改战斗公式、宗门养成、客栈价格／损失规则、抽取概率、回收价格、高阶掉落，不迁移历史物品、不删表。

## 实现

- publicCombatV6Build 生成专用公开构筑：同一组 V6 事实产生面板、装备、装配功法和可用技能；技能说明沿用公共描述器并应用投影的技能覆盖。
- 查探默认使用只读 repeatable-read 事务，读取身份、condition 与构筑；只返回白名单，不返回构筑档案ID、修订号、经脉方案、宗门账户、背包或储藏室。原身份、命格与炼体展示保留。
- 构筑未就绪返回 build=null、combatPanel=null，界面明确提示未初始化，不回退旧装配。
- 本人总览复用现有 combat-v6-build 资源订阅来触发只读查探刷新，和他人查探共用构筑展示组件；HUD 不再等待旧 loadout。
- 道装固定六位，窄屏三列、桌面六列；公共物品预览不提供操作。功法显示已装配槽位，技能只读展开说明。
- 历史宝库法宝分栏不再等待旧装备状态。旧法宝回收仍发布历史列表删除及货币变更，不再重读当前旧装配；材料抽取删除与实际产物无关的旧 loadout 事件。
- 闭关倍率删除后，突破／寿尽叙事不再从旧功法读取名称，也不新增新版叙事映射。
- 没有新增迁移脚本或运行时旧装配兼容层。既有资源事件协议已能对不兼容历史事件要求重新读取权威快照，本轮未新增专属兼容逻辑。
