# combat-v6 首版功法改造计划

> 2026-09-16：根据用户确认的 24 本设计编制。状态：首版代码已实施、本地迁移已执行；表中数值是首轮验证基线，不代表已通过战斗平衡验收。
> 现行规则见 [境界功法系统](combat-v6-manual-system-design.md)。下文保留实施分解，第 8、9 节记录最终决定和本次证据。

## 1. 目标与范围

将现有 16 本纯六维功法替换为 24 本有明确意象与构筑取舍的功法。每本由一项随层数增加的六维贡献，以及一个随层数增强的简单机制组成。

确认保留：

- 炼气、筑基、金丹、元婴各一个激活位，更高境界不新增位置；同位只激活一本。
- 九层培养；三、六层使用同名玉简解锁后续层数；每本独立培养，战外免费切换，受既有战斗与结算占用保护。
- 学习一本玉简，三层突破两本、六层突破三本（合计六本）；修炼成本采用本文末尾已确认的升级消耗修订，不引入品质倍率。
- 六维只加入战斗/展示投影，不写入永久属性。升层与切换不得免费补满气血、法力。
- 取消功法 common/rare 稀有度。供给由产出概率、权重、渠道等配置决定，不增加战斗预算。

本轮不做：连续行动、连招计数、目标记忆、失败补偿、解封反应、治疗转盾、DOT 跳数强化、内部冷却、额外行动、功法主动技能、五行伤害体系、灵根门槛、战外修为倍率、化神以上新功法位、多套构筑存档。

按用户“按照推荐，开始实施”的授权，每槽最多收藏六本，仍只激活一本，无遗忘或退款功能。

## 2. 内容与成长基线

### 2.1 来源与命名

灵感资料为用户提供的《凡人修仙传_功法境界表.xlsx》，工作表「功法表」A2:C54；其中包含五行基础功法泛称及同一功法的分段条目。只取名称、描述和意象，以下数值与效果均为本项目游戏改编，不宣称原著存在这些机制。

- 炼气取长春功，另自拟金、木、水、火、土五本入门功法。
- 筑基来源重点为 A4:C11；金丹来源重点为 A20:C30；元婴来源重点为 A32:C38。
- 使用项目正式六维名：体魄 vitality、力道 strength、灵力 spirit、根骨 endurance、身法 speed、神识 willpower。
- 游戏境界统一使用「金丹」，不引入资料中的「结丹」作为第二个境界键。

### 2.2 成长公式

| 归属境界 | 一层加成 | 后续每层增加 | 九层加成 |
| --- | ---: | ---: | ---: |
| 炼气 | 12 | 2 | 28 |
| 筑基 | 18 | 2 | 34 |
| 金丹 | 24 | 4 | 56 |
| 元婴 | 36 | 4 | 68 |

四槽九层合计 186 点六维。每本仅一项属性，不为难获取功法增加第二项完整属性。

机制一层即开放，每层线性成长：`value(L) = valueAt1 + (valueAt9 - valueAt1) × (L - 1) / 8`。条件阈值固定，突破仅解锁升级上限，不新增第二个机制。

配置存数值，比例以 0～1 表示；概率修正与伤害倍率使用不同 effect 类型，避免把「降低 3 个百分点」误写成「乘以 0.97」。展示不反向参与计算。金额/气血/法力只在既有最终结算处取整，不在每层插值时提前截断。概率与面板尺度转换保留所需精度，不能沿用整数面板处理使部分等级升级无效。

## 3. 战斗结算合同

这些口径需先写成共享领域测试，再接入全部内容。

### 3.1 适用对象与效果来源

- 功法只装配到人物，不给灵兽继承属性或被动。
- 输出增幅作用于人物普攻、宗门主动技能的主目标；按物理、法术、普通固定伤害分别编译。通用伤害钩子默认跳过 Fixed，不能遗漏对普通固伤的显式分支。
- 不强化器诀、物品、反击、连击式派生追击、HookDerived 伤害、DOT 或宗门派生追伤。宗门原技能明确声明的多段直接攻击属于原行动，不因段数新增触发计数。
- 普通固定伤害可以强化；按目标气血比例扣血、资源扣除等特殊效果不得强化。实施前盘点效果级来源，不通过解析公式字符串、技能中文名或在 core 中硬编码宗门/功法 ID 判断。
- 仅 skillId 白名单可能无法区分同一混合技能的不同效果。优先利用已有类型与 origin；不足时由内容编译层声明最小的通用效果分类，并由伤害路径透传，避免误伤其他系统原有修正。
- 治疗与护盾增幅只作用于宗门主动技能的主目标。排除器诀、物品、被动恢复和功法回合恢复，不因群体目标数量获得多倍功法增益。
- 受击减伤/闪避是佩戴者的防御能力，可应对敌方人物、灵兽、NPC 的相应直接攻击，包括敌方直接攻击器诀；与己方输出不强化器诀的规则分开。

### 3.2 条件与时机

- 「低于」「高于」严格使用 `<` 与 `>`，恰好 35%、50%、70% 均不满足对应严格条件。
- 比例气血以当前气血 / 最大气血判断，不以伤势后的可恢复上限替换分母；法力同理。条件在每一段打击或治疗/护盾计算前读取当前事实。
- 多段攻击跨阈值后，后续段按新血量判断；不添加行动开始快照。
- 有效护盾指当前尚有正数吸收量的护盾。归元与太白在吸收前判断，最后一层盾被打破后后续段不再获得护盾条件收益。
- 玄阴读取目标当前的 Dot 类状态，任意施加者均可；不追踪归属、不延长持续、不改 DOT 本身。同一行动先伤害后挂 DOT 的首段不能倒用新状态。
- 浩然仅读取 Debuff 类；Dot、Control 不混为一类。
- 明王读取可解除的封印控制。复用并核对既有解控类别口径，排除宗门休息/反噬、不可驱散状态和禁复活状态；不能简单等同于「所有 Control」。
- 大衍使用现有封印公式尺度和上下限，不绕过免疫，不给必中状态额外掷骰。幻灵/千浪沿用命中钩子和下限，不把必中攻击改成可以闪避。
- 保护发生后，防守功法读取实际承伤者；输出仍服从既有主目标身份语义，增加保护重定向专项测试。

### 3.3 恢复、叠加与显示

- 长春/清泉只在回合末对在场存活人物生效，沿用现有回合结束、DOT、战斗结束顺序，不为回血改变胜负裁定。
- 恢复基数为相应最大资源，最终恢复受当前缺口约束。长春遵守既有禁止恢复、减疗和伤势上限，不复活，不清伤势；恢复不进入主动治疗强化链。
- 恢复向下取整，允许低等级小基数时为 0，不私自增加保底 1。展示应准确说明比例；验证时检查低境界实际体感。
- 伤害、治疗等倍率沿用既有计算链，不新增「功法统一加算并封顶」系统。概率差额按现有公式聚合。
- 四槽机制输出最大倍率粗估为 `1.03 × 1.04 × 1.06 × 1.06 = 1.20360032`。这不是最终战力上限：六维、命中、抗封、恢复、护盾和其他系统交互必须另计。
- 不增加功法专属通用触发平台。利用现有战报表达回血/回蓝及最终伤害；条件与本层效果在功法详情可见。额外逐击触发提示不作为首版必做项。

完整模块路径以 `src/shared/engine/combat-v6` 为基准；服务/仓储位于 `src/server/lib/services/combat-v6`、`src/server/lib/repositories`。

### 4.1 功法内容格式

建议数据包格式升为下一版，结构仅包含稳定身份、境界、意象描述、培养规则引用、单属性成长、单机制定义。机制用有限的 discriminated union 表达：伤害增幅、承伤减免、治疗增幅、护盾增幅、物理命中抵抗、封印抵抗、回合气血恢复、回合法力恢复。

各类型只开放需要的条件、类型范围、valueAt1/valueAt9。由编译器落实主目标/来源限制，避免策划漏填后把加成扩散到全场。阈值与效果文字由同一数据生成，意象描述单独保存。数据包不接受任意 JS、自由公式、嵌套条件树或 hook 脚本。

没有新增状态的机制不人为生成 StatusDef。若实现证明需要临时状态，才补投影状态表合并及 ID 冲突检查，不能预先搭建新框架。

静态内容包格式、战斗内容版本与角色 learned 状态 version 是不同概念，不能为了内容变更一并升级所有持久版本。

### 4.2 展示范围

- `ManualRoom.tsx`、`ManualRealmSlot.tsx`、`ManualJadePicker.tsx`：已学显示实际层数；修炼显示本层→下层的两部分变化；瓶颈明确仅解锁上限。
- `presentation/basic.ts` 的 manualAdapter：继续「功法名 / 类型→传承境界→数量 / 所载功法效果 / 玉简描述」，不加重复功法名或第三层标题。
- 未学习玉简显示一层效果和九层成长终点，不假装玩家已具有满层收益。已学上下文不得把玉简本身当成带层数的实例。
- 共享描述器放在纯 shared 层，复用于页面、物品、公开构筑及查探。概率文案明确为加减百分点，UI 可采用规范允许的简洁符号表达，不能与相对比例混淆。
- 不新增 rarity 徽章、品质筛选或难获取配色。不影响其他物品自己的品质体系。
- 公开构筑只暴露激活功法和层数，不暴露收藏；保持现有布局、操作入口、响应式结构和 GameIcon 规范。

## 5. 分阶段实施与完成标准

阶段顺序为 A → B → C → D → E → F。B/C 可在纯领域数据夹具中先验证，E 的投放及旧资产切换在第 8 节决策落实前不执行。

### A. 冻结合同与引用清单

- 固化第 2、3 节内容；整理 24 本新 manualId/玉简 ID 清单。长春可评估保留原 ID，名称相近但境界不同的功法不能复用身份（例如原筑基厚土功与新炼气厚土诀）。
- 盘点普通固伤、按目标血量比例效果、混合技能、主目标治疗/护盾、可解除封印的现行分类。
