## 验收

- 独立母版及同批图与固定基准并排检查，在纸色 `#f8f3e6` 上查看24、32、40px。24px可分辨横扫爪、法核、莲相、乘风龙首、招手猫及日冠乌形，32／40px能进一步读出内孔、扫势与三足关系；不要求24px数清十日。
- 六枚alpha范围均为0–255，四角均为0；外底及主孔隙真实透明。保留笔刷边缘的低alpha飞白，未见可见脏底、烘焙纸纹、棋盘、文字、印章、发光或裁断主体。强alpha主轮廓均在画布内；个别近透明笔刷点接近画布边缘。逐图数据见 `alpha-verification.json` 与技能子目录验收记录。
- 实际本地灵兽袋检查1280×900桌面、390×844手机；六枚图片均加载为256×256，无❔回退或水平溢出，emoji三家族正常，普通／高级依既有名称与红色级别样式区分。招财简述与具体效果切换正常。截图与 `browser-checks.json` 保存于 `verification/`。
- 使用本地道友1和正式本地发放／阵容接口创建两只临时展示样本；已放生样本并核对原24只保留、携带顺序及首发恢复。本轮未开战或修改玩法事实。
- `pnpm run lint`、`pnpm run build`、两份第三轮技能测试（37项）、最终 `pnpm run build:client` 与 `git diff --check`通过。最终构建产物包含六枚素材，逐枚SHA-256与生产源一致，证据在 `verification/`。构建只有已有超过500kB分块提示。本轮没有新写测试，未重复全量2730项测试；玩法实现的全量结果见[技能接入记录](combat-v6-beast-next-skills-plan.md)。
