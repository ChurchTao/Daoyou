# combat-v6 Phase 7D：野生灵兽暗雷遭遇与人物资源结算

## 内容与入口

开放地图卫星节点 `SAT_TN_08`（太岳山·青溪灵草坡），以 `wild_encounter_id` 引用独立野外内容，原有副本入口保留。人物炼气起可探索，须完成当前宗门v6构筑初始化。没有持久地图位置或旅行耗时。

青灵狐偏法术、岩甲猪偏防御、疾风狼偏速度物攻。等级固定在5～15级（启灵境），三个物种分别保存11档显式面板，不随玩家境界缩放。每次必遇敌，人数1～3等概率，每个位置独立等概率抽取物种与等级，允许重复。同seed生成同阵容；战斗继续使用rules v5。

物种身份与每个敌方单位ID、等级写入可信来源元信息。没有资质、成长、出生技能格、寿命或宠物个体生成，不将野外战斗模板作为捕捉后成长公式。

## 探索额度与接口

每角色所有野外区域共享每日20次，北京时间00:00重置、不累计。成功创建才扣次；创建后所有终止方式均不退次数，包括技术中止。成功创建间隔至少3秒。训练房不计数。

`POST /api/combat-v6/wild/explorations` 仅接受 `{nodeId, requestId}`。服务端生成seed与来源幂等键；请求ID用于去重。Redis Lua原子检查活动会话、结算锁、次数和间隔，并提交运行态、结算摘要、索引、扣次与去重记录。额度/去重记录保留至创建日结束后48小时。同请求不重新抽取或扣次，已结束且不可恢复的旧请求返回稳定错误。

`GET /wild/regions/:nodeId` 返回区域与今日额度。`GET /wild/sessions/current`、`GET /wild/sessions/:sessionId`、`PUT /wild/sessions/:sessionId/commands/:unitId`、`POST /wild/sessions/:sessionId/resolve`、`DELETE /wild/sessions/:sessionId` 使用同一认证边界和revision语义。上述路径均以 `/api/combat-v6` 为前缀。

指令与单位视图复用v6公共契约，野外视图使用nodeId，不伪造训练tier。Host抽取中立NPC选招/回合编排，共享训练和野外行为，训练入口与黄金结果保持不变。

## 资源权威与结算

入场先按v6真实最大值完成正常自然恢复，再以当前HP/MP投影。角色状态事务与野外创建共用角色互斥边界。战斗和待结算期间阻止丹药、构筑变化和其他战斗操作；自然恢复暂停。宗门转移先完成旧战斗结算。资源读模型附加v6上限与暂停标记，该标记不写入condition。

正常胜负、平局、逃跑、放弃、超时和membership失效，均结算最后成功CAS提交的资源。HP/MP可以高于入场值，只按锁定构筑的真实最大值夹取；最终HP为0时置1。技术中止保留入场资源，不退次数。伤势、护盾、状态与宗门资源不回写。

运行态从创建起最多2小时，正常结束仍保留至显式关闭或截止时间。独立最小结算摘要记录归属、来源、版本、revision、入场/最终HP与MP及最大值；不包含指令、RNG或回合checkpoint。创建和每次CAS同时更新摘要，因此运行态已删除时仍能处理超时。

终局仅发布 `combat.v6.battle.finished {battleId}`，Condition消费者从Redis读取事实。复用 `wanjiedaoyou_message_consumptions` 和 `claimMessageForConsumer`，在更新condition的同一PG事务中记录消费凭据，同时提交资源失效事件；成功后释放Redis结算锁。该消费者以 `battleId` UUID作为稳定逻辑消息键（不是NATS信封ID），使MQ与后台重试共享 `(consumerName,messageId)` 去重。重复消息、PG提交后进程中断、Redis释放失败通过凭据重试，不重复覆盖资源。该消费者凭据暂不参与通用定期清理，以保护无限期待解锁结算；其他消费者保留原清理策略。

未处理的终局、摘要和锁持续保留，后台协调器重试并对超过24小时的未完成结算告警。处理后删除摘要，终局事实至少再保留24小时。MQ发布确认不作为业务结算确认。回放归档独立，不阻塞角色结算锁；沿用7C正常终局归档范围。

## 页面

节点详情展示物种、境界及今日次数，入口进入 `/game/wild?nodeId=SAT_TN_08`。页面展示区域介绍与探索操作；战斗中使用共享v6状态面板、指令和分回合中文事件流。刷新恢复会话，关闭页面不放弃。主动放弃确认保存资源损耗、不退次数。结果展示结算状态，结算完成后可关闭并继续探索。

## 边界与验证

不实现捕捉、宠物持久化、奖励、掉落、经验、任务进度、自动探索或移动系统。PG复用现有消费凭据表，本阶段不新增表或migration，不修改Better Auth和旧回放表。

共享测试覆盖独立面板、三种物种/等级/人数、五宗门低等级战斗、恢复对拍、北京时间跨日、净回血回蓝、1HP规则和严格请求契约。基础设施通过实际Redis临时键验证Lua扣次、CAS、超时摘要与终局保留；不得新增服务端/前端单元测试或基础设施mock。

上线前应用业务迁移，并验证认证玩家的初始化、地图入口、探索、刷新、结算、放弃及移动端布局；验证JetStream重投、PG幂等归档/结算及进程中断恢复。回放播放器、奖励与捕捉属于后续阶段。
