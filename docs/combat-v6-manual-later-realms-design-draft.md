## 1. 范围与沿用规则

| 人物境界 | 已开放位置数 | 本轮新增内容 |

| 炼气／筑基／金丹／元婴 | 1／2／3／4 | 现有24本不改 |
| 化神 | 5 | 化神功法6本 |

- 每境界位最多学习六本，同时激活一本；功法只归属自己的境界位。
- 每本九层，三／六层遇瓶颈；学习消耗一本玉简，瓶颈分别消耗两／三本同名玉简，突破只解锁后续层数。
- 修为与道心感悟用于升层；各书独立保存进度，未激活书可培养，战外免费改修，继续使用既有战斗／结算占用保护。
- 每本仍是一项六维贡献与一个主被动，一层同时生效；允许有限新增被动触发、作用范围与短期记忆，不给一本书同时塞入多套独立能力。六维只进入投影，不写入永久属性，不因上限变化免费恢复气血／法力。
- 九层内线性提升主被动的强度、额度或触发概率；门槛、触发次数与持续窗口不随层数另外解锁。保留普通固伤／比例伤害区分及封印概率尺度；新作用范围与既有过滤的差别逐本明示。
- 不引入高阶共用位、继承、精研、道意、新货币、功法主动按钮、额外行动、分身或复活。培养流程保持；本次变化集中在附加被动本身。
- 玉简与获取渠道沿用现有体系。本轮不重新设计悟道室概率、产出渠道或经济玩法。

当前代码事实以 `packages/game-domain/src/manuals/pack.ts`、`packages/game-rules/src/manuals/mechanism.ts`、`packages/game-rules/src/manuals/compiler.ts` 为准。旧文档中的“四位封顶”由本次八位决定替代；现有24本与培养规则不因此重做。新增被动需要扩充功法内容模型，不能继续声称只往旧机制枚举填数据即可。

## 2. 出处与改编边界

选取《凡人修仙传》《遮天》《完美世界》《仙逆》中已有名称，不自拟新功法名，不从同人小说、手游攻略或自动生成的小说百科反推原著。

下表“原著依据”仅说明名称、类别和可核查意象；“游戏属性／机制”全部是本项目改编。化神至大乘的归属是本游戏的装配安排，不代表原著修炼门槛，不建立跨小说战力排名。九层、玉简瓶颈与数值也不宣称来自原著。

现有内容已经包含剑诀、神光等不同原著类别，故本轮可收录有持续修炼法门性质的秘术／变化法；资料中保留其原著类别，不把它们都宣称为原著的主修吐纳功法。

来源等级：优先采用正版平台的原著章页；部分作品采用可定位的原著章节转载，明确不称官方正文。章节编号会因平台计数不同而错位，因此同时记录书名、章题和链接。

## 3. 四境24本建议名单

本稿以“它会改变玩家哪一个选择”为设计检验：普攻或施法、聚焦或换招、防御或抢攻、破盾或破守、持续施压或制造修复空窗。低阶功法继续提供稳定基础，高阶被动为这些基础建立新的使用场景；不要求每个后续境界都引入一套新系统。

表中均为游戏改编，名称、原著依据和六维属性与第一稿一致。具体一／九层数值尚未冻结；次数、触发先后、目标范围与反制先按下述合同评审。

## 5. 触发、成长与反制合同

### 5.1 行动与目标

- 本人的普通攻击、本人直接选用的宗门主动技能是本稿“合格出手”的基础范围。器诀本体与其调用的子技能、法术连击复制、追击、反击、被动伤害和灵兽行为，不额外建立／消费这些新被动的行动序列；原有低阶被动的过滤规则不变。
- 一次多段、群体行动只更新一次出手记忆；不能把第二段当第二次行动。恒宇、梵圣和原始真解对整次合格出手的主目标／本人承伤使用冻结判定；不因第一段改写记忆而让后段自行触发。
- 恒宇与梵圣记录正常实际发动的伤害出手，未命中或被护盾全挡仍会更新／消费本次序列；因控制、目标失效等原因未能实际发动则中断序列。不能靠打空保留准备，也不能把未执行指令当成已经铺垫。
- 九转仅计算同次宗门主动、同一主目标的原生法术段序；群攻的不同目标不拼段，复制施法和派生追击不接续序号。上限是整次出手额外收益，不只是每段一个上限。
- “实际掉血”只计算真正扣除气血的数量，不计护盾吸收或超过剩余气血的击杀溢出。“成功施放”与“实际命中／实际受益”分开，不能用没有 ActionFailed 代替这些事实。
- 太皇只处理防御指令的基础减伤部分；厚土等附加被动照常存在。太阳只增加耗盾，不能把剩余的额外耗盾变成气血伤害。
- 六道要求前一次技能仍至少剩两回合冷却，才有可缩减对象；无此对象不尝试、不消费间隔。成功／失败都消费本次尝试间隔，防止多段重抽。普攻、防御、道具、无效技能和控制跳过中断其主动轮换序列，不能用空放技能刷触发。
- 梵圣只记录一次出手的主要伤害类型；混合技能按固定内容标记归类，不能一招同时建立物理与法术记录。低阶功法或DOT的附加伤害不改变分类。

### 5.2 护盾、治疗与恢复

- 西皇短盾只由本人宗门主动治疗主目标产生；回合回血、吸血、功法恢复、物品与灵兽治疗都不参与。仅“正常气血上限已满造成的有效过量”可转盾；被重伤／禁疗吞掉的治疗不算。
- 西皇盾按施法者与受术者最大气血分别限额、取较小上限；百脉与杀戮盾按本人最大气血限额。三者同源只补至较高额度，不把新盾直接累加到旧盾；持续到下一回合结束，替换／刷新仍受各自频次限制。
- 不同来源护盾继续沿用现行共存规则，分别有预算；本稿不增加全局护盾互斥。由这些被动派生的盾不再触发主动施盾增幅或九天的救援净化，避免二次增幅与循环。
- 百脉必须在防御指令实际执行后才生盾；被封印而未执行不能提前生盾。需特别验证慢速人物的盾能跨到下一回合，不在刚出现的回合末立即消失。
- 不灭经在本轮所有回合末伤害结算完毕后再判断；任何已经发生的气血损失都留下本轮受损事实，后续被治疗补回也不能伪装“无损”。倒地／离场不修复，自损与支付气血费用同样会中断；恢复不能越过现行重伤可恢复上限。
- 不灭经有每场累计恢复预算，避免通过留弱敌无限拖回合补满；与长春的“低血时仍能恢复”保留差异。其精确恢复不吃主动治疗加成，不产溢疗盾，也不结转到下场。
- 护盾仍不能阻挡当前内核中绕盾的DOT，不因新增功法修改这条底层规则。

### 5.3 状态与短期记忆

- 炼神仅认敌方可解除封印的正常到期／友方驱散；倒地清除、状态替换、宗门休息、自身代价结束不触发。记住一次短期抗再次封印，下一次判定成功或失败都消耗，不成为免控期。
- 惊蛰只取上回合最后一次合格承伤类型；本轮受伤仅影响下轮，没有上轮合格记录便无适应。护盾完全挡住、持续伤害、固伤、自损不更新该类型。
- 原始真解最多记一名敌人及其最近一招；新的合格敌方攻击会替换记录。首次不减伤，同一出手的多段不自行完成识破；未命中不建立新的识破记录。
- 金刚的防御准备只留至下一回合末。折锋只影响敌人下一次直接物理／法术行动，整次原生段共用效果；该次行动结束后消耗，未行动则最迟再下一回合末过期；驱散、低代价攻击消耗、持续伤害均可反制。
- 九天只记上一次真正产生治疗／有效新增主动护盾的人物主目标；首次有效救援只建立记录，换目标才尝试净化。溢疗派生盾不能把本来无实际受益的主动治疗变成合格救援。每两回合一次尝试，成功或失败均消耗；单人连续救自己不触发。
- 吞天每两回合最多尝试一次，成功／失败均消费本次间隔；无合格增益不尝试。净化／吞噬的普通数值减益与临时增益须由内容明确分类，不可直接等同全部 Buff／Debuff。吞天按最早施加的合格增益选择，平局用稳定ID排序。
- 不灭天功在本人行动窗口检查前尝试一次，即使随后被封印跳过行动也使用相同检查点；须有两种不同的敌方普通减益／DOT，不能用同一种多层凑数。优先移除最早施加的一项，平局用稳定ID排序；每三回合一次尝试，失败也消费间隔。
- 九天与不灭天功均不解封印；原始真解不移除状态；炼神不主动解控。宗门的专门解封职责仍有价值。
- 无始的结束点是本人行动窗口结算，不是“成功攻击后”；受控跳过、逃跑或其他结束窗口的情况也必须关闭，不能通过不行动维持整回合。
- 所有短期记忆、间隔和恢复预算均为当场事实，退出战斗清空，不增加战外培养资源或计量条；有决策意义的准备、适应、识破、折锋应在战况中可见。

### 5.4 九层成长与数值定稿

- 名称、归属境界和六维属性保留本表；本轮不重定基础属性成长或费用。
- 多数被动随层数线性提升伤害修正、防御穿透、护盾／恢复额度、持续伤害专精或节蓝强度。门槛、次数与持续窗口固定，不到三／六／九层另塞第二个被动。
- 九天、六道、吞天、不灭天功的主要成长量采用触发概率；净除一项或缩减一回合的离散结果保持固定。概率未定，不写成必然发生，不能同一触发失败后多段反复尝试。
- 五藏折扣不得单独把原正费用变为零；与既有费用修正共同结算时维持最低正费用，并同步预检、扣费、自动战斗判断和展示。原本零耗的技能保持零耗。
- 古神削峰按扣盾后的预期掉血判断，既有减伤先结算，再对超出阈值部分应用折减和本回合剩余预算；不是将整段伤害硬压成固定上限，不抵御比例伤害或保留必死角色的一点气血。
- 必须把八本同时生效的总收益，以及“人物防御、灵兽仍可输出”的真实战斗情况一并测算，不能仅因人物放弃攻击就认为防御生盾没有平衡压力。

## 7. 实现边界与待验项

本轮只改设计文档，不修改代码。此前“只扩八位、不扩机制编译器”的实现判断由本稿替代：

1. **先扩功法接入层。** 内容模型使用有边界的被动类型，显式描述触发、次数、目标与预算；不开放任意脚本。已有钩子、修正、有限事实和状态可复用，短期状态定义须由功法投影合并并做ID冲突检查。
2. **少量通用事实需补齐或验证。** 西皇需要治疗完成后的有效过量事实；任意可解除封印的移除响应需要类别／可解除性元数据；完整出手与器诀子调用需能区分，行动窗口在控制跳过时也要可靠结算；古神需要扣盾后、扣血前的受损修正位置。不得将已有战报误认为可订阅钩子，也不得为了单本书把ID分支写进内核。
   不灭经还须记录支付气血费用、自损等所有气血减少，不能只用当前伤害累计量推定“无损”；持续伤害需能区分常规／比例来源；五藏的最低正费用、六道的冷却下限及失败尝试间隔须在共享规则中显式落实，不能当作现有功能已自动覆盖。
3. **专项验证穿透与持续伤害。** 太皇只折减防御指令的基础部分；万毒与太阴仅调整目标持续伤害路径，不让DOT开始走护盾；太阳额外耗盾不转为额外掉血。所有规则继续保留有种子的确定性和回放一致性。
4. **先定规则合同，再定强度。** 重点检查多段／群体重复触发、器诀子调用、法术连击、派生盾增幅、重伤／禁疗伪溢出、被控跳过窗口、冷却缩减白名单与下限、净化类别，以及单人／组队中各自有效的选择。
