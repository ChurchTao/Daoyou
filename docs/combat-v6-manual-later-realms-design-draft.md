# combat-v6 后续境界功法内容草案

> 2026-10-24。状态：来源研究与内容初稿，尚未实施，也未完成数值平衡验收。
> 本轮采用用户最新约束：逐境开放功法位，化神、炼虚、合体、大乘各新增一位，最终八位；渡劫不新增位置或专属功法。既有功法玩法与机制规则保持。

## 1. 范围与沿用规则

| 人物境界 | 已开放位置数 | 本轮新增内容 |
| --- | ---: | --- |
| 炼气／筑基／金丹／元婴 | 1／2／3／4 | 现有24本不改 |
| 化神 | 5 | 化神功法6本 |
| 炼虚 | 6 | 炼虚功法6本 |
| 合体 | 7 | 合体功法6本 |
| 大乘 | 8 | 大乘功法6本 |
| 渡劫 | 8 | 无新增，继续使用前八境功法 |

- 每境界位最多学习六本，同时激活一本；功法只归属自己的境界位。
- 每本九层，三／六层遇瓶颈；学习消耗一本玉简，瓶颈分别消耗两／三本同名玉简，突破只解锁后续层数。
- 修为与道心感悟用于升层；各书独立保存进度，未激活书可培养，战外免费改修，继续使用既有战斗／结算占用保护。
- 每本仅一项六维贡献与一个已有简单机制；一层同时生效，随层数成长。六维贡献只进入投影，不写入永久属性，不因上限变化免费恢复气血／法力。
- 既有线性成长、固定条件阈值、主目标／伤害来源过滤、普通固伤与比例伤害区分、封印概率尺度均沿用。
- 本草案不沿用上一轮的高阶共用位、首次伤害触发、行动后恢复、蓄势、虚实转换、资源互换、周天循环等建议；不增加继承、精研、道意、功法主动技能或新货币。
- 玉简与获取渠道沿用现有体系。本轮不重新设计悟道室概率、产出渠道或经济玩法。

当前代码事实以 `packages/game-domain/src/manuals/pack.ts`、`packages/game-rules/src/manuals/mechanism.ts`、`packages/game-rules/src/manuals/compiler.ts` 为准。旧文档中的“四位封顶”由本次八位决定替代；其余既有规则不因此重做。

## 2. 出处与改编边界

选取《凡人修仙传》《遮天》《完美世界》《仙逆》中已有名称，不自拟新功法名，不从同人小说、手游攻略或自动生成的小说百科反推原著。

下表“原著依据”仅说明名称、类别和可核查意象；“游戏属性／机制”全部是本项目改编。化神至大乘的归属是本游戏的装配安排，不代表原著修炼门槛，不建立跨小说战力排名。九层、玉简瓶颈与数值也不宣称来自原著。

现有内容已经包含剑诀、神光等不同原著类别，故本轮可收录有持续修炼法门性质的秘术／变化法；资料中保留其原著类别，不把它们都宣称为原著的主修吐纳功法。

来源等级：优先采用正版平台的原著章页；部分作品采用可定位的原著章节转载，明确不称官方正文。章节编号会因平台计数不同而错位，因此同时记录书名、章题和链接。

## 5. 数值与后续工作边界

- 本轮先形成有出处的24本初稿及既有机制映射，不冻结一／九层数值、逐层费用或获取概率；这些仍是内容定稿项，不标作已完成。
- 后续按既有公式填写一层属性、逐层增量、一／九层机制值及逐层培养费用；保持同境界同档基础属性预算与相同培养结构，不引入稀有度倍率。
- 八位会使更多既有被动同时生效，因此定数值时检查总属性、同条件增伤、抗封、恢复与防护叠加；沿用现行叠加规则，不额外增加互斥组或衰减公式。
- 正式实施需将功法境界／槽位类型、校验、数据库范围和页面展示从四位扩至八位，并确保渡劫仍为八位。这是已确认的开放范围扩展，不扩充机制编译器或战斗内核。
- 旧功法数据与培养进度保留。本轮不实施任何迁移、重置、部署或代码变更。
