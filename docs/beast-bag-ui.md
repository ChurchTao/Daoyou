# 灵兽袋页面

`/game/beasts` 的灵兽袋就是携带出战编组，上限 8 只，首发最多 1 只。不再另设「全部／携带出战」筛选。暂不出行的灵兽放在 `/game/beasts/warehouse`，上限 50 只，可查看与袋子相同的详情。捕捉后进入灵兽袋；袋满时不能继续开打。已经开打的结算仍会完成，袋子装不下的捕捉寄入仓库。

- 桌面左侧名册、右侧选中灵兽详情；移动端名册两列排列于详情上方。袋子与仓库共用等高条目，只显示头像、单行名字、等级及锁定／首发状态；不重复显示物种名。长名字截断，完整名称在详情展示。
- 灵兽袋保留 8 个位置；点击空位提示从仓库取出或野外捕捉。仓库保留分页与列表内部滚动。
- 直接展示战斗面板上限、资质、成长、寿命、经验及基础属性。经验与面板取现有领域计算，无设计稿示例数值。
- 技能格复用 InkTooltip 的定位、触摸点击、键盘与关闭行为；只展示实际技能，被高级技能抑制时降低视觉强调并解释原因。
- 详情主操作区保留「设为首发／取消首发」或「取出到灵兽袋」、「培养」、「管理」三个主要入口。培养抽屉收纳喂养、休养、领悟传承、洗炼和洗点；管理抽屉收纳锁定／解锁、改名、存入仓库、融合和放生，按所在位置显示。每项操作均有图标、标题、简短说明，受限时说明原因。
- 属性点与加点区直接展示在详情页，支持加号长按连加、重置及战斗属性前后预览，InkModal 二次确认后提交，返回调整保留页面内草稿。传承灵印抽屉复用通用储物袋格位与物品预览，只允许选择传承灵印；休养与放生使用 InkModal 确认，锁定／解锁直接生效。请求反馈使用 toast；提交中阻止重复提交及关闭操作确认层。
- Tailwind v4 和现有纸色、墨色、teal、crimson 色标；常规操作使用 InkButton，不增加 CSS modules 或新状态库。
