# 灵兽袋页面

`/game/beasts` 延续现有接口与规则：最多拥有 24 只灵兽，出战编组最多 6 只，首发最多 1 只。未加入编组的灵兽仍计入灵兽袋容量。未新增仓库、扩容、改名或洗练机制。

- 桌面左侧名册、右侧选中灵兽详情；移动端名册三列排列于详情上方。全部／出战编组筛选保留可见选中项，否则展示当前筛选的第一只。
- 编组筛选显示六个位置；点击空位返回全部灵兽，优先选中未编组灵兽，由玩家点击加入编组。
- 直接展示战斗面板上限、资质、成长、寿命、经验及基础属性。经验与面板取现有领域计算，无设计稿示例数值。
- 技能格复用 InkTooltip 的定位、触摸点击、键盘与关闭行为；只展示实际技能，被高级技能抑制时降低视觉强调并解释原因。
- 加点使用原属性分配抽屉；兽诀学习使用原专属抽屉；休养与放生使用 InkModal 确认，含取消按钮。请求反馈使用 toast；提交中阻止重复提交及关闭操作确认层。
- Tailwind v4 和现有纸色、墨色、teal、crimson 色标；常规操作使用 InkButton，不增加 CSS modules 或新状态库。
