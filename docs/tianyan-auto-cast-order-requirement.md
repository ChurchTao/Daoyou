# 天衍自动战斗主动栏顺序修复需求

## 背景

天衍自动战斗在多个落印术都能触发反应时，会在候选技能之间继续比较法力消耗。该规则可能让低耗蓝技能长期压过后续槽位，使某些技能即使法力充足也始终无法释放。

典型配置如下：

1. 《青萝生脉》
2. 《离火流照》
3. 《玄水回澜》
4. 《坤岳镇形》

旧规则在水印阶段会因为《青萝生脉》耗蓝更低而跳过《坤岳镇形》，最终反复形成木、火、水三元素循环，无法按主动栏配置进入土印和触发后续崩根。

## 目标

- 自动战斗不再把法力消耗作为落印术之间的选择优先级。
- 法力充足时尊重玩家配置的主动栏顺序。
- 当前顺序位置的技能法力不足或不可用时，继续向后查找可用技能。
- 到达主动栏末尾后从第一槽继续查找，形成环形选择顺序。
- 保留现有的法印反应合法性、本轮未使用元素、治疗与回蓝阈值以及兜底技能规则。

## 选择规则

### 无法印

按主动栏顺序选择第一个可用的落印术，不再比较技能法力消耗。前置技能法力不足时顺延到后续可用技能。

### 存在法印

1. 只保留能与当前法印触发化生或冲克反应的技能。
2. 优先选择本轮尚未参与反应的元素。
3. 同优先级候选从当前法印对应的主动栏槽位之后开始查找。
4. 查找到主动栏末尾后绕回第一槽。
5. 法力不足或其他原因无法施放的技能不进入候选池。

### 小周天

小周天不会重新排列主动栏，但会优先补齐本轮尚未参与反应的元素；存在多个同优先级候选时，继续使用主动栏环形顺序决定。小周天只改变自动选择决策，不修改技能本身的伤害、法力消耗或反应效果。

## 对小周天的影响

### 不会修改主动栏配置

选择小周天后，技能所在槽位和玩家配置的主动栏顺序保持不变。本次修改只影响自动战斗运行时的选技优先级，不会自动交换、覆盖或保存新的主动栏配置。

### 补齐元素优先于槽位顺序

小周天原有的核心规则仍然保留：优先选择本轮尚未参与反应的元素。因此，小周天不是严格逐槽释放；当靠前的合法技能元素已经使用、后续合法技能元素尚未使用时，会跳过靠前技能，先施放后续技能。

例如水印下，木术可以触发滋荣、土术可以触发泥沼：

- 本轮木元素已经使用、土元素尚未使用时，优先选择土术，即使木术的槽位更靠前。
- 木、土元素都尚未使用时，按当前法印槽位之后的环形主动栏顺序选择。
- 木、土元素都已经使用时，同样按环形主动栏顺序选择。

因此，小周天的实际优先级为：

```text
可用且能触发反应 → 本轮未使用元素 → 主动栏环形顺序
```

### 环形顺序成为同优先级决胜规则

修改前，小周天在多个候选之间使用候选池的原始顺序。修改后，会从当前法印对应槽位的下一槽开始查找，并在主动栏末尾绕回第一槽。这使玩家仍可通过主动栏顺序控制同优先级技能的施放方向，同时支持稳定的四元素循环。

### 与基础策略的重叠增加

本次修改后，基础策略和小周天在血蓝充足、只装配常规落印术时，都能按主动栏环形顺序维持反应，因此两者在常规战斗中的表现会更接近。

小周天仍保留以下区别：

- 小周天持续反应的优先级更高，不会像基础策略一样在低气血或低法力时主动切换治疗、护盾或回蓝技能。
- 小周天会优先补齐本轮尚未使用的反应元素，从而提高完成三次不同元素反应的稳定性。
- 小周天没有独立的伤害或回复加成；三次反应后的数值收益来自河图道途的“河图周天”机制，而不是自动战术本身。

如果后续需要进一步强化小周天的战术辨识度，可以将“本轮未使用元素优先”仅保留给小周天，基础策略只负责按主动栏环形顺序选择合法技能。本次修复不包含该项规则调整。

## 预期示例

主动栏按以下顺序配置：

1. 《青萝生脉》
2. 《离火流照》
3. 《玄水回澜》
4. 《坤岳镇形》

在技能均可用且能正常命中的情况下，应形成：

```text
木印 → 火术（燎原）
火印 → 水术（蒸发）
水印 → 土术（泥沼）
土印 → 木术（崩根）
```

随后继续按木、火、水、土的环形顺序循环。

## 验收标准

- 无印时选择主动栏靠前的落印术，而不是耗蓝最低的落印术。
- 多个合法反应候选不再使用法力消耗排序。
- 木、火、水、土法印能按主动栏环形顺序选择下一项合法技能。
- 环形下一项法力不足时能顺延到后续合法技能。
- 小周天能从当前法印对应槽位之后环形选择反应。
- 不改变技能数值、反应矩阵、法印持续时间和衍数结算规则。
