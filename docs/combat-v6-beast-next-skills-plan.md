# 灵兽第三轮技能迁移方案

2026-10-12。状态：全部名称、机制、数值及物种安排已获确认，三批已连续接入；长期实战平衡尚未验收。

本轮修订：飞行、幸运及高级名称保留；合纵改为号令；风起龙游保留原名；招财进宝专属爆发概率定为8%，取消元宝特效；金乌保留红莲业火必带，新增八凶原型候选。其余按首稿推荐执行。已接受的本游戏适配参数仍与原作证据分开记录。

本轮新增12项技能：飞行、幸运、合纵及各自高级版，共6项常规被动；剑荡四方、灵能激发、灵山禅语、风起龙游、招财进宝、八凶法阵，共6项特殊技能。前6项开放传承灵印，后6项暂不开放，沿用特殊技能出生与融合继承的接入方式。剑荡四方和灵山禅语暂不指定出生来源，注册完整机制但不进入自然获取池。

用户本轮明确要求接入八凶法阵，覆盖此前“原始神兽技能暂不接入”的范围限制；不据此扩大到其他神兽技能。物种决定出生来源，获得技能后均不设置物种生效门槛；风起龙游明确去掉原作龙族限制。

## 1. 接入前代码事实

- `beasts/data/skills.json`：内容修订19，81项技能，其中67项开放传承灵印，14项特殊技能关闭灵印。早期经典迁移记录中的67项是历史阶段数量。
- `beasts/data/species.json`：内容修订15。咪咪无必带，实际候选为迅捷、必杀、灵觉、招架、自愈，共5项；首批基准的旧三技能表尚未反映目前配置，本方案以代码为准。
- 毕方必带红莲业火，候选高级灵法精通、迅捷；应龙必带翻江倒海，候选高级灵法会心、御法、自愈；金乌必带红莲业火，候选高级涅槃重生、灵觉、迅捷。
- 稀有集合目前由合体及以上境界推导，不能直接表达炼气稀有咪咪。咪咪目前也是免费初始伙伴之一，在青溪坡普通池中等概率出现。
- 现有物理命中由命中、躲避数值计算，法术基础命中为1；灵兽基础躲避为0。不能把“躲避能力增加20%”直接解释成20%闪避，也不能仅乘0就宣称完成飞行。
- 现有群法按等级增加目标数，最多3个；没有配置分灵，红莲业火系数0.8、附加威力10＋技能等级、耗法力20。因此八凶“不分灵”不能单独作为本游戏的强度优势。
- 暴击基础倍率为2；已有最终伤害倍率、当前气血消耗、主次目标条件、随机分支、状态属性快照、封印承受倍率与有效速度表达式。普通与高级同族由投影统一过滤，保留两个技能格事实。

全部名称已确认：灵山禅语为宝相庄严，八凶法阵为十日横空。保持兽类天赋、灵息和血脉语义，不要求灵兽持剑、修习佛门功法或具有特定五行。

宝相庄严以自成护身宝相的意象承接高阶属性转化天赋，与瑞气盈身并列；名称不表示无敌、免疫或获得独立金身状态。

十日横空取金乌与十日并出的太阳传说意象：参照[《山海经广注·海外东经》所载扶桑、十日及阳乌传说](https://zh.wikisource.org/zh-hans/山海經廣注_(四庫全書本)/卷09)，以横空烈阳呈现霸道威势，涤荡浊息呈现净化意象；这里的净化属于本项目改编表现，实际机制仍为群体伤害与随机属性削弱，不新增驱散、灼烧、元素克制或十个攻击目标。

招财进宝保留民俗名称，取消元宝、金元灵光等具象特效；只使用正常物理打击与伤害反馈，不新增专属特效或货币产出。

## 4. 具体适配规则

### 飞行：区分能力数值与概率

- 普通／高级均使灵兽面板命中×1.2；面板躲避分别×1.2／1.3，合并已有躲避加成后向下取整。与现有灵觉、定神躲避加成按明确顺序计算，展示和战斗共用投影。
- 被普通物理命中判定攻击时，再使攻击方最终命中概率×0.95／0.90；用已有命中概率钩子合并，不多抽一次随机数。独立物理闪避使基础躲避为0的灵兽仍有收益。
- 主动物理、普攻和派生物理攻击均受对应命中规则影响；法术、固定伤害不受影响。显式必中攻击继续必中，属于本游戏接入边界。
- 不附赠速度。暗器代价记录为未适配；本轮不新增暗器伤害体系。

### 幸运：只削弱暴击额外部分

设攻击方最终暴击倍率为C：普通为`1＋(C－1)×0.75`，高级为`1＋(C－1)×0.5`。基础2倍变1.75／1.5倍；不会把整次暴击伤害直接乘0.75／0.5，否则高级会将2倍降成1倍。

不降低暴击触发概率，不清除暴击事件，也不增加5%法术闪避。覆盖物理和法术暴击，固定伤害不生效；攻击方额外暴击倍率和特殊物理技能显式暴击倍率也在同一入口处理。派生连击、反击仍可被减免，不能因派生钩子抑制漏掉防守能力。善报治疗不属于所受伤害，不由幸运削弱。

### 号令：按在场异种去重

- N＝己方当前存活、未离场、非后备的其他灵兽中，与自身不同的物种数。幼崽、成年、变异、改名均不拆成新物种；同种多只只计1。
- 普通增加`floor(自身等级×N/5.5)`，高级增加`floor(自身等级×N/4)`的物理伤害结果。算总量后取整；不加面板物攻。换宠、死亡、复生之后实时重算。
- 同时使所受封印命中概率×1.1，遵守现有上限与免疫。不是降低所有负面状态抗性，N为0时仍保留封印代价。
- 结果加成适用于物理攻击，也应被横扫四方的主次倍率缩放；法术、固定伤害不增幅。派生物理沿用同一规则。
- 单人一人一兽战斗N为0，这项技能的价值主要在多人队伍；不把主人或后备灵兽计入来伪造单人收益。暂只开放灵印，不随意塞进出生池。

### 横扫四方：端游主次倍率与气血费用

- 一次主动物理行动；指定首目标，另从可攻击的敌人中随机选至多2个不同目标。目标不足就少打，不重复攻击同一目标；随机选择遵循种子和隐身规则。
- 先扣`floor(施放前当前气血×0.1)`，不消耗法力；沿用现有气血费用的至少保留1点规则。低气血取整为0时不擅自增加原资料没有的最低费用。
- 使用已有物理公式与最终结果系数0.65／0.35／0.35，采用端游测试的必中边界。每个目标独立暴击、护盾、保护、反震／反击、神佑；攻击者被反伤击杀时停止后续目标。
- 不触发普攻连击、普攻毒或嗜血追击；连击的全局物伤代价仍在。噬血按各目标实际扣血结算，派生不递归，沿用现有规则。
- 属于主动攻击，可被观照万象调用，每次正常支付气血。后续按用户要求，在物种修订17中安排给六目灵猿，替换反击候选；不开放灵印。

### 灵息激发：主动蓄势，保留魔力属性依赖

- 用一次行动给自身施加增益，不同时攻击。建议采用玩家推定公式`floor(魔力属性点/2.2)`增加法攻；魔力包含自然与已分配点数，不能用剩余MP、最大MP或法力资质替代。
- 5回合增益采用施放时快照；不叠层，重施刷新，不重复累加法攻。建议施放回合计入持续期，与现有主动灵罡计时一致，正常后续行动有4个输出回合。该计时解释没有原作专项实测确认。
- 原耗蓝尚未查实。本游戏已确认用`floor(等级/2)＋50`，取现有灵罡护体的费用模板；这是已接受的适配参数，不是已查实原值。
- 定义为普通可驱散Buff，沿用灵效绵长的时长规则及绝灵拒绝增益；隐身期间不能施放。法术连击不重复施加自身增益。
- 不进入观照攻击列表。自动战斗需识别这项辅助行动：法力充足、未持有同类增益且有可用法术攻击时才可先激发；已有增益优先攻击，避免反复蓄势。
- 毕方新增该候选，保留现有必带与候选；不改资质、成长或强制加点。

### 宝相庄严：改贡献项，不砍整张面板

设M为完整魔力属性点、G为成长，按当前投影建议实现：

- 法攻的魔力贡献`M×G×1.3`变0，等级与法力资质贡献保留。
- 法力上限的魔力贡献`M×G×5`变`M×G×2.5`，等级与资质贡献保留；不是将总MP减半。
- 法防保留当前全部基础项，额外加`M×max(0,G－0.3)`；额外项与基础项合并后向下取整。G低于0.3时不增加负法防，是本游戏边界。
- 不写回永久属性、资质、成长。灵慧天成等独立被动加成继续保留，不凭原文自行增加互斥；宝相庄严取消的是魔力的基础法攻贡献。
- 面板、战斗、喂养／升级预览共用相同投影；资源上限变化沿用现有重基准规则，不暗中补满MP。
- 仅注册，不安排物种、不开放灵印；可以在纯规则夹具中测试，不增加新获取渠道。

### 风起龙游：去种族限制，逐目标比有效速度

- 每次直接打击比较双方包含状态增减的有效速度，自身严格大于目标时伤害结果×1.1；相等不触发。群体攻击逐个目标判断。
- 普攻、主动物理、法术、主动固定伤害及观照子技能均适用。建议连击、反击等派生打击也适用，速度即时判定；反震以已受伤害派生，排除再次增幅；周期状态伤害不额外乘算。这些来源边界是本游戏适配，不声称复刻原作所有外围情况。
- 不以“已经先行动”代替速度比较，抢先行动状态不等于更快；当前内核没有随机乱敏，不另增随机速度系统。
- 不附赠速度，不要求龙身、羽翼或血脉标签。应龙新增该候选，速度资质仍保留原值。

### 招财进宝：稀有爆发，与必杀互斥

- 每次成功命中的普攻或直接主动物理打击，先独立判定8%专属爆发；成功使本击伤害结果为普通非暴击的4倍，并跳过必杀；失败再正常判必杀。用户本轮所称“暴击率8%”落实为本技能专属4倍爆发概率，不写入普通critRate。8%为用户指定的适配值，4倍有玩家实测支持，均不是已披露官方精确公式。
- 只提高这一击，不额外产生一次攻击或再次做攻防计算；避免“额外造成伤害”被实现成可重复触发吸血、反震或追击的第二击。
- 普攻连击的追加可独立判定一次；反击、嗜血追击、反震与周期伤害不触发，是明确的非递归边界。横扫每个直接命中独立判定。善恶的善报治疗分支排除，恶报物理伤害可以触发。
- 本技能是独立非暴击爆发，幸运不削弱它；不能同时标为普通必杀。取消元宝特效，使用正常物理打击与伤害反馈；不消耗或奖励灵石，不增加掉落率。

### 十日横空：三目标群法与随机削弱

- 固定至多3个可攻击目标，0级即可攻击3个；指定目标优先补满，走现有群法可见性与目标规则。
- 系数确认为1.0，高于红莲业火的0.8（系数高25%，不代表每个目标的最终伤害恒高25%）；附加威力`10＋技能等级`、耗法力30。无分灵，不把原作约1.39倍群法测试比值硬套在本游戏已有公式上。
- 建议每个直接命中后独立40%抽取一种削弱，4类等概率：物攻－10%；物防－10%；速度－10%；法攻与法防均－10%（承接原作灵力）。持续3回合。40%仅来自早期小样本估计；10%、3回合、费用及基础伤害模板均为本游戏建议初值。
- 每次只中一种，4类共享一个状态kind，再中刷新并替换类型，不叠多种或多来源层数；按施加前有效属性快照，刷新时排除自身旧削弱，防止越刷越低。
- 为可驱散Debuff，沿用解厄、高级避厄、灵魂体、绝灵等免疫／驱散规则，不绕过抗性；命中完全被护盾吸收也可施加，目标倒地则不施加。
- 可法术暴击、波动、法术连击。法连追加仍造成伤害，建议不再次抽取削弱，沿用追加攻击抑制状态触发的边界；观照调用则是新的直接子行动，可以抽取。
- 无手游引燃、结束爆炸、治疗抑制，不附加额外持续伤害。金乌保留必带红莲业火，在现有3项候选之后新增十日横空候选，各项仍独立50%。
