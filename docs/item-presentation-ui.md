# 新版物品展示

## 组件职责

- `components/feature/items/ItemSlot.tsx`：统一方格、底部单行省略名称、emoji、堆叠数量、已装备／已投入标记，以及浮层预览。`InventoryGrid` 只负责布局，容量和格位来自业务数据。
- `components/feature/items/itemPresentation.ts`：按物品类型维护图标、名称颜色、分级文字、说明。配色复用 `inkBadgeTiers`，不在场景页另写配色判断。
- 道装预览复用 `EquipmentDetails`；业务页面通过预览操作区接入已有操作，共用组件不发起业务请求。

## 分级与交互

道装按原始 `requiredLevel` 换算境界颜色；轻灵等器蕴不改变颜色。材料按品质，图纸按等级对应境界，兽诀按普通／高级。名称底部单行省略，数量为 1 不显示角标，浮层始终展示完整名称与精确数量。

PC 悬停延迟 200ms 展示，允许移入预览操作；触屏点击展示同一个浮层。采用原生 `popover=auto` 顶层展示，自动关闭其他物品预览，避让视口边缘，长内容内部滚动；不使用详情抽屉承载预览。仅打开的预览挂载正文和业务操作。

储物袋保留装备、转存、移动／合并、拆分；道具使用仅承载无需复杂选择的直接消耗品，不在此实现功法参悟、兽诀打书等玩法。功法参悟由参悟页面承载，兽诀选择与学习由灵兽详情承载。操作成功、失败、移动指引统一使用 toast，不在物品栏固定位置展示消息。炼器选材反馈同样使用 toast；物品用途、不可投入原因等决策信息仍保留在预览内。

炼器 PC 点击直接投入／移出，触屏先预览后确认；空材料位直接打开选材入口。开炉消耗由 InkModal 确认。成器动效结束后通过成功 toast 提示，成品保留在炉心；悬停或点击直接使用 ItemSlot 的统一道装浮层，不自动打开详情，也不提供再次打开详情弹窗的按钮。

## 物品格视觉收敛（2026-09-08）

图标扩大为主要视觉中心；堆叠数字采用左上角等宽半粗字体与乘号，状态标记移至右上角。名称改为底部单行省略，空格标记独立居中，不再被空名称占位挤偏。炉心成品宽度由炉阵的 25.2% 缩为 18%，略小于外围 19% 的材料格。

使用已有材料检查桌面与 360px：窄屏格子为 70×70px，空格标记容器与格子中心重合，页面无横向溢出。本次仅修改视觉布局，未重复消耗物资开炉。
