# 灵兽天生技能机制与全物种审查

2026-09-19，species内容修订10。根据用户要求，天生全集限制为3—6项、必带限制为0—2项；所有物种允许满天生技能，用户确认无必带物种可以出现0技能。用于全游戏的初领、野外生成／捕捉和洗炼。

## 机制

- 天生全集 = 必带 + 普通候选，去重后3—6项。多数物种3—4项，少数5—6项，不按境界保送格位。
- 先抽额外数量，再从候选等权、不放回抽取。必带保底，候选可全部抽中。资质／成长随机流与技能独立。
- 实际技能数就是个体格数，无额外空格。每种物种至少75%的个体至多两技能；满技能概率3%—5%。概率是本轮设计值，不是梦幻西游官方概率或长期平衡结论。
- 无必带物种20%为零技能，仍可普攻、培养属性及洗炼。传承允许零技能个体消耗1枚灵印，学会所载技能并开启第一格；后续仍随机覆盖已有技能，不继续扩格。
- 野外遭遇时确定技能，捕获完整保留；洗炼重新抽技能与格数，可增可减。初领也采用同一规则，不给免费伙伴额外保底。
- 满天生技能只是该物种的全部原生能力，仍可通过传承替换构筑；除零技能首次开格外，不提前实现合宠、额外扩格或相关概率机制。
- 个体存储上限8格维持，出生上限6不限制已有个体；旧资质、成长、技能、格数及已冻结遭遇不重抽。主动洗炼采用修订10，无数据库迁移。

## 概率与培养空间

同一必带数／天生总数组合采用同一数量分布，避免用境界提高保底。以下为总技能数概率，不是额外数量。

满技能按天生总数分档：3项为5%，4项为4%，5—6项为3%。增加的概率从额外1项的档位调出，无必带物种的零技能率仍为20%。

## 零技能首次传承

2026-09-19按用户要求补充：以目标当前是否0技能为准，不增加终身次数记录；洗炼回零后也能再次开启第一格。

- 0技能／0格：消耗1枚所选传承灵印，获得该技能，变为1技能／1格。
- 至少1技能：仍随机覆盖一个已有技能，格数不变；同技能拒绝、等级限制与技能冲突规则保持。
- 服务端沿用角色锁、物品／灵兽修订校验和同一事务，技能与格数同存，成功后才扣1枚；0格不调用零上界随机函数。
- 前端允许零格选择灵印，详情与确认层显示“开启第一个技能格”；已有技能显示“随机覆盖一个已有技能”。

- `bun run test src/shared/inventory src/shared/engine/combat-v6/beasts src/shared/engine/combat-v6/wild`：22文件、312项通过。新增测试先复现旧拦截，随后验证0→1、第二次仅覆盖、旧对象不变、重复技能／越界格位／等级限制。
- `bun run lint`、`bun run build`、skill-creator校验、`git diff --check`通过。本轮未重复全量测试。
