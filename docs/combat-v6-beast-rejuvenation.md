# 化生果

化生果是御灵集出售的固定灵果，仅最高层货架每批上架1颗，售价在170万至190万灵石之间。它在灵兽详情的「洗点」入口使用，每次消耗1颗。物品可在储物袋或储藏室，确认时说明等级与修为保持不变，已分配属性点会退回待分配。

物品格与预览名称使用天品颜色。

服用后，灵兽等级和修为不变，五项已分配属性点清零，并按当前等级的点数预算全部转为待分配。宝宝含初始50点；变异同样是宝宝，确认文案不与「宝宝」并写。个体ID、主人、名称、物种、身份、原始等级、变异、资质、成长、技能与格数、寿命、生成记录、携带编组和首发保持不变；只递增个体版本。尚未分配属性点的灵兽不能消耗。

捕获时已有等级的野生保留原始等级 `L0`。当前等级为 `L` 时，可分配总预算仍是 `5L - 2min(L,L0)`。例如原始30级、现为30级的野生洗点后仍是30级、90点待分配，不获得宝宝的50点，也不会额外亏损。养到60级后预算为240点。没有捕获等级的野生，以及宝宝，沿用各自原点数预算。

服务端沿用背包物品操作的角色锁、战斗占用检查、物品与灵兽版本校验、事务写入和资源刷新。物品扣除与灵兽更新同时提交；失败不消耗灵果。此道具不触发归元灵露的资质、成长、技能重抽或寿命恢复。
