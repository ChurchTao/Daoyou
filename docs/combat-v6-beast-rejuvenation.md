# 化生果

化生果是御灵集出售的固定灵果，仅最高层货架每批上架1颗，售价在170万至190万灵石之间。它在灵兽详情的「化生」入口使用，每次消耗1颗。物品可在储物袋或储藏室，确认时展示等级、属性点及保留内容。

物品格与预览名称使用天品颜色。

服用后，灵兽等级和修为归零，五项已分配属性点清零。宝宝和变异宝宝恢复50点待分配属性，假宝宝和纯野生为0点。个体ID、主人、名称、物种、身份、原始等级、变异、资质、成长、技能与格数、寿命、生成记录、携带编组和首发保持不变；只递增个体版本。已经是0级、0修为、未加点的灵兽不能消耗。

纯野生保留原始等级 `L0`。化生后重养至 `L0` 时，每级获得3点自由属性；之后每级获得5点。因此当前等级为 `L` 时，纯野生可分配总预算为 `5L - 2min(L,L0)`。例如原始30级的纯野生重新长到30级时仍有90点，不获得宝宝的50点，也不会额外亏损。其他身份沿用原点数预算。

服务端沿用背包物品操作的角色锁、战斗占用检查、物品与灵兽版本校验、事务写入和资源刷新。物品扣除与灵兽更新同时提交；失败不消耗灵果。此道具不触发归元灵露的资质、成长、技能重抽或寿命恢复。
