# combat-v6 Phase 6C：天衍圣地河洛九宫纵切

> 版本：`daoyou_rules_v4` / `daoyou_character_build_content_v4` / `character_build_v4`
>
> 本文是 combat-v6 天衍战斗内容的实现基线；旧《天衍圣地完整设计稿》只作为 battle-v5 历史设计和世界观参考。

## 1. 纵切边界

天衍圣地以五种普通 Debuff 法印、十种有向反应和 0～3 衍数构成战斗循环。法印没有施法者使用权，队友可以继续触发；收益和击倒归当前触发者。五行只属于天衍内容层，不扩展 `DamageKind`，也不接灵根、四技能栏、旧进度、Host、API 或持久化。

## 2. 六心法与共享技能

| 槽 | 心法 | 每级面板 |
|---:|---|---|
| 1 | 《河洛衍天总经》 | 法力+2 |
| 2 | 《三碧生化篇》 | 治疗+0.5 |
| 3 | 《九紫离明录》 | 法攻+0.5 |
| 4 | 《五中承天经》 | 法防+0.4 |
| 5 | 《七赤断法章》 | 封命中+0.4 |
| 6 | 《一白玄水诀》 | 速度+0.15 |

五门1级落印术为三碧生机、九紫流照、五中镇岳、七赤裁云、一白回澜。主心法20/40/60级依次解锁九宫布阵、河洛传印、三才护阵。两流派各由根基授予一门60级、消耗3衍数的终式；第三层只授予生生化阵或两种互斥版本的逆演天机。

五印使用不同ID和共同kind `tianyan.status.mark`，持续2个完整回合，可净化、倒地清除。同元素刷新；非生克覆盖；反应消费旧印后给存活目标挂新印。传印复制主目标当前印与剩余时间到另外两人，不刷新主目标、不触发反应。

## 3. 反应矩阵

| 旧印→新术 | 反应 | 结果 |
|---|---|---|
| 木→火 | 燎原 | 主伤+25%，追加0.25法攻固定伤害 |
| 火→土 | 熔岩 | 主伤+15%，3%maxHp固定DOT两回合 |
| 土→金 | 锻锋 | 主伤+15%，本击忽略20%法防 |
| 金→水 | 寒泉 | 主伤+15%，强减速两回合 |
| 水→木 | 滋荣 | 主伤+15%，治疗最低血友方 |
| 火→水 | 蒸发 | 有效冲击伤害50%追伤 |
| 水→土 | 泥沼 | 35%追伤，正常公式封行动一回合 |
| 土→木 | 崩根 | 40%追伤，法防快照降低20%两回合 |
| 木→金 | 断脉 | 35%追伤，正常公式封法一回合 |
| 金→火 | 熔金 | 40%追伤，物攻/法攻快照降低20%两回合 |

有效冲击伤害等于主打击吸盾量加实际气血损失，不含过量伤害。追伤为 `Fixed + HookDerived`，仍经过护盾，但不触发战意、吸血、功法或二次反应。多目标逐目标结算，同一行动常规最多获得1衍数。

## 4. 双流派

河图演生根基使宗门治疗与护盾各提高5%，七层方向依次覆盖单术强化、反应后续航、传印/布阵、生阵、低血保护、宗门总增益和河图终式的治疗/护盾/回蓝分化。

洛书制化根基使宗门主动直接法伤提高5%，七层方向依次覆盖火金单术、带印增伤/反应追伤/忽防、逆演或水术、DOT/驱散/减速、高血压制/法暴/冲克、总法伤/忽防/逆演和洛书终式的伤害/驱散/封法分化。

42节点稳定ID统一为 `tianyan.node.<hetu|luoshu>.<layer>.<slot>`；完整名称、数值与patch以 `src/shared/engine/combat-v6/content/tianyan.ts` 的确定性定义为准。

## 5. 结算与兼容

反应顺序固定为：锁定旧印、主伤、基础侧效、机制事件、反应追伤/状态、消费旧印、挂新印、增加衍数。主伤击倒时仍产生机制事件、友方侧效和衍数，但跳过敌方后续效果及新印。

`projectCultivatorMultiSectV4ToCombatV6` 是四宗门完整入口。Phase 1～6B 的注册表、投影入口和版本戳保持冻结，并显式拒绝天衍内容。
