# 天衍圣地：五行法印重做

本版在自身五行法印机制上纳入两轮平衡调整，提高生克收益、附带续航和经脉成长的回报，并修正少目标及单伤员场景的收益落空。两轮工程验证已完成，全境界 PvP/PvE 平衡仍待实战体验验收。保留五行生克，不恢复旧衍数、敌方落印、传印与流派终式循环。运行时真相源是 `packages/game-content/src/sects/data/tianyan-*.json`；组织旧进度定义和 battle-v5 文档不作为战斗规格。

## 核心规则

- 五行基础法术成功施放后，在自身留下对应法印。只有一个法印，不叠层、不消耗、不计时、不可驱散，倒地复起保留，战斗结束重置。
- 旧印生新术触发相生；新术克旧印触发相克。相同五行、其余组合正常施法并换印。
- 普攻、防御、道装技、玄元守一、澄灵诀与止戈保留法印。法力不足、封印等导致施法失败时不换印；技能合法施放但伤害未命中仍算施放成功。
- 换攻击目标不打断连招。多名天衍的法印独立，不能消费或复制别人的印。
- 伤害／基础附带效果／反应完成后，才更新法印；一次群攻只结算一组自身／友方收益。
- 相生相克不是两套互斥资源。两条流派均使用十种反应，也不要求依次遍历五行。

## 基础技能

L 表示所属心法等级。伤害沿用正式 V6 法术公式，下面的系数和 power 为传入公式的参数，不等于最终伤害百分比。人物法术先以有效法攻 A 的1.7倍减去法防、加上 power，再整体乘 coeff，随后结算修炼、波动与暴击等修正；高法防时沿用通用保底。恢复与护盾直接以有效法攻 A 计算，不使用1.7倍法攻；恢复经过通用施疗／受疗修正，不另行叠加治疗属性。

五行技能所属心法1级解锁；辅助技能主心法30级解锁。澄灵诀不能移除行动、物理、法术、复活封禁。护盾破坏的超额部分不会转化为额外气血伤害。

下一次物理／法术伤害行动的弱化持续整次多段／多目标行动；产生对应伤害（包括吸盾）后消耗。纯固伤、物法部分全未命中的混合行动、辅助和防御不消耗。几种同类弱化互相覆盖，不相乘。普通状态施加当回合不扣时长；持续恢复／伤害从当回合末起计次。

燎原只补偿反应新增的一席，不补普通三席的缺额；选择燎野时新增两席，最多补偿30%。补偿与其他同类增伤相加，仅作用于本次火法直接伤害，不放大余火。按本次出手选定的合法目标名单计算一次；人物和灵兽均占一席，隐身而不可选、倒地、逃离及板凳单位不占席。名单在伤害前固定，击杀前序目标不会增加后续目标的补偿。

选择余火后仍保留燎原新增攻击位，并给至多两名副目标附加余火；同时选择燎野时上限增至三名。每回合末损失2%最大气血，基础单跳上限0.8L＋0.2A，共2次，之后仍走通用DOT修正。副目标取本次冻结名单中主目标之后靠前的单位，不因未命中、死亡或免疫补位；主目标在场上的站位不影响名单顺序。只有一名敌人时不产生余火。

余火和滋荣沿用同kind后施覆盖、不叠层的规则；多个天衍也不能在同一目标上叠加同kind余火。持续伤害／恢复每次按施法者当前有效法攻计算，保留施放时技能等级。

## 流派与节点

全游戏经脉统一为七层：前六层每层三选一；第七层中间是唯一可选节点，两侧是自动成长奖励。下一层只能选与上一层相同列或相邻列的节点，第六层任一列均可连接第七层中间节点；沿用共用经脉连线 UI。未连通的可选节点不生效。两侧奖励在解锁第七层时自动获得，不参与选点和连线；末层可选节点可以是被动机制，无须设计成终结技能。

衍法天师根基：五行法术触发生克时，本次直接伤害提高12%。以覆盖人数、资源效率和附带续航分化。

执衡真君根基：木、土、金三种单体基础法术消耗降低10%；五行法术触发生克时，本次直接伤害提高6%。以破盾、驱散、削弱和短控制分化。

节点的伤害增减与其他同类 `damageBonus` 相加；法力折扣之间相乘后按引擎取整。恢复／护盾有各自显式倍率，不复制群攻人数。

## 节点主动与数值边界

- 借势：40法力、冷却3回合，需已有法印；单体法术 coeff 1.0、power L，自身获得 2L＋0.40A 护盾，再将旧印沿相生方向推进一位。不会触发五种基础法术的专属生克效果，也不会自动连续推进多次。
- 止戈：40法力、冷却3回合，单体法术 coeff 1.0、power 0.8L；下次物理／法术伤害行动削弱35%，2回合有效，不改变自身法印。使用独立状态，不提高镇岳等其他技能原有的25%弱化。
- 清泉／固本附带治疗均为0.8L＋0.15A；缄锋护盾为0.8L，持续2回合。
- 留隙与禁流同时选择时，禁流将稳定法术伤害削弱从25%提高至35%，仍持续2回合；该次土法的伤害代价仍保留。未选留隙时，禁流仍提高封印命中10%。
- 镇岳与镇世同时选择时，削弱仍为40%；镇岳转为山河倾覆法力消耗降低10%，替代原本增加20%的代价。
- 天人保留三种恢复／护盾收益，取消常驻伤害代价，补充燎原、淬锋本次法术伤害提高5%，让输出与辅助路线均能受益。
- 余火保留每跳2%气血上限、基础封顶0.8L＋0.2A及两跳；新恢复的攻击席只增加直接伤害，不再扩大原有DOT覆盖上限。普通余火在1／2／3／4／5个实际敌方目标时覆盖0／1／2／2／2名副目标；同时选择燎野时为0／1／2／3／3名。旧规则集下的受控伤害示例不作为正式 V6 公式的平衡证据。
- 余火与燎野可合法共存；余火和润物位于同一层，互斥；燎野和温泽、长春也位于同一层，互斥。润物与燎野可经第三层中列连通。分锋只在土印触发淬锋时增加金法目标。
- 润物的伤员指本次附带恢复前仍可选中、存活且有可恢复气血缺口的友方，包括自身、队友与灵兽；达到伤势限制后的恢复上限或拒绝气血恢复者不计。单人／多人档由本次恢复前锁定的伤员数确定一次，不能因先治满某个目标而让后一个目标改拿全额。最后一击结束战斗时仍结清附带凝露恢复。
- 滋荣将施加时的润物份额保留到后续各跳，不随其他友方受伤或治满改变，也不转移目标。单人全额变体与原滋荣使用相同kind，切换时刷新而不叠加；法攻、长春及天人的既有修正时序保持。
- 没有新增五行配装要求，也没有强制加敏、固定伤害专精、复活、全能治疗或另一套积攒资源。

## 两轮调整范围与待验收项

第一轮保留五行基础法术的 coeff、power、法力成本和基础人数，集中提高触发生克后的直伤、凝露／滋荣／烬垒，以及借势／止戈的行动回报。经脉取消指定的降伤、减人数和缩时惩罚；长春每跳恢复降低20%等未列入取消范围的取舍仍保留。

朱焰、锋芒、守拙、镇岳、清泉、敛芒、挫锐、留隙、禁流与镇世的原有取舍不变。澄明／明镜保留50%的法力加价，冷却回到基础2回合。借势不额外触发基础五行反应；止戈35%弱化不改写其他25%弱化状态。

第二轮实施四项：燎原新增目标缺席的15%／席直接伤害补偿、余火保留新增攻击席与原DOT强度但限制覆盖、润物单伤员全额与固定份额，以及蒸腾20%提高至30%。没有再改变基础五行技能的 coeff、power、耗蓝、封印命中或控制时长，也没有增加DOT叠层、主目标余火、死亡补位或治疗重选。

实现复用现有行动目标名单、数值事实与同类状态覆盖。核心仅补充冻结目标上下文和可恢复伤员筛选，没有增加持久字段或跨回合流程；恢复分摊先通过现有数值事实锁定，再执行互斥效果。终结出手只继续结清数值事实与直接恢复，不放宽结束战斗后附加新状态的限制。

验证分开记录机制正确性和实战平衡：

1. 机制回归采用正式 V6 规则集与法术公式，核对生克触发、完整恢复跳数、节点取舍、借势推进、止戈独立弱化和自动估值；不再用忽略 coeff 的旧公式证明反应收益。
2. 静态检查核对三份内容配置、说明和编译结果，运行聚焦领域测试及适用的 lint、typecheck／build；具体通过结果以本轮实际执行记录为准。
3. 后续体验按境界、同培养成本、1／3／5目标以及 PvP／PvE 分组，比较完整出手周期的伤害、有效治疗／吸收、控制成功后的有效行动、法力消耗与战斗回合数，并区分手动与自动战斗。重点观察火水线是否过强、复杂轮转是否得到足够补偿，以及执衡削弱是否挤压专业封辅定位。

## 自动战斗与验证

自动战斗读取自身精确法印，识别当前技能的反应增伤、减防、破盾、治疗与控制；最低血线恢复按实际选人模式估算。它仍是单步估值，不声称具备跨回合连招搜索。被动连锁不递归推演。

默认策略在自身气血低于40%时，优先使用金印下的衍法水法或水印下的执衡木法恢复，缺少对应法印时按当次收益估分。自身气血至少40%时，如果低于40%的非灵兽队友是当前可恢复的首选目标，且法力足够连施金、水两诀，两流派会优先铺金接凝露。其余场合沿用既有轮转。当前自动策略版本为 `combat_auto_rules_v10`，既有冻结场次沿用版本兼容处理。

山河／镇岳／止戈／镇世、留隙／禁流、森罗缚／盘根、裂土／蚀基与熔锋／钝兵复用 V6 同类状态优先级。较强减益存续期间拒绝同类较弱效果，等强效果按剩余时长比较。神通抽屉从主控指令选项读取当前法印、反应效果与换印预览，目标和条件以实际出手时的战局为准。

本地练功房实测，衍法对25%气血的负伤同伴先铺金，再触发凝露恢复32点。渡劫圆满、心法180级的临时构筑中，长春对负伤同伴恢复171点三次，缄锋产生144点烬垒并被陪练一击耗尽。挫锐样本采用同一构筑连续施放金印下的天锋一线，目标出手前气血为5444／6000、5125／6000和4789／6000时，伤害分别为319、336和299点。这组单场样本包含伤害浮动，仅用于核对节点在正常回合中的表现。

回归覆盖：五行25种组合、施法成功边界、跨目标保印、倒地复起、恢复一次／两次时序、盾伤溢出、整次出手削弱、38个可选节点连通与实际效果差异、4项自动奖励的层数门槛、镇岳／镇世与留隙／禁流组合、物法与固伤混合消耗边界、余火完整周期收益、自动战斗快照纯度。后续数值校准应观察短战回合数、长战法力、群攻总量、辅助收益占比与封控覆盖，不以配置编译通过代替平衡验收。
