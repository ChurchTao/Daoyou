# 灵兽等级与修为养成

## 展示与归元

灵兽直接显示数字等级，移除独立境界别名；物种携带要求仍使用主人境界。玩家文案统一为“修为”，已有存储字段 `exp` 和内部经验接口名称保留，不迁移存量个体。

归元为0级、0修为，已分配和待分配点数归零。五项基础属性均为10；气血、攻击等战斗面板依照资质与成长投影，并非全部为10。初始领取伙伴仍为10级。

## 升级预算

当前等级L升下一级需要 `100 + 20 × L + floor(L² / 2)` 修为，0→180级累计1,304,070。每级仍获得5点自由分配属性。等级不能超过主人且最高180级，达到上限时溢出修为清零；本次不增加上限储存机制。

野外战斗暂不发放灵兽修为。副本保留现有胜利结算条件及收益公式。

## 丹药与灵果

新增 `beast_cultivation` 药性／用途，产出 `gain_beast_cultivation` 效果。品质基础值采用已确认规划区间的中值：

| 品质 | 规划区间 | 丹药基础值 | 灵果修为 |
| --- | ---: | ---: | ---: |
| 凡品 | 550～625 | 587.5 | 470 |
| 灵品 | 1,100～1,250 | 1,175 | 940 |
| 玄品 | 2,200～2,500 | 2,350 | 1,880 |
| 真品 | 4,400～5,000 | 4,700 | 3,760 |
| 地品 | 8,750～10,000 | 9,375 | 7,500 |
| 天品 | 17,500～20,000 | 18,750 | 15,000 |
| 仙品 | 35,000～40,000 | 37,500 | 30,000 |
| 神品 | 70,000～80,000 | 75,000 | 60,000 |

丹药沿用 `resolveAlchemyEffects`：品质基础值 × 效果槽位倍率 × 丹方契合倍率 × 品相倍率，最后向下取整。品相倍率仍为下品0.9、中品1、上品1.1、完美1.3；契合倍率沿用0.85～1.15范围。区间不是增幅后的上限，不重新随机，也不在喂养或预览时重复乘算。

神品标准契合主效果丹药的下品／中品／上品／完美收益分别为67,500／75,000／82,500／97,500修为。按0级、主人180级、没有其他来源计算，中品17颗未满、18颗达到180级；完美14颗达到180级。

灵果按品质基础值80%向下取整，不使用丹药品相。灵种 `beast-nurturing` 用途对应灵兽修为果，沿用现有灵田成型概率、品质与产量规则。

新药性只作用于灵兽。炼丹以灵兽修为为主药性时形成单一灵兽药效；人物丹药路线排除该药性，避免同一消耗品混用人物与灵兽目标。不新增灵兽丹毒或服用额度，人物用药入口拒绝灵兽修为消耗品。

## 喂养与数据边界

灵兽页使用已有物品选择抽屉选择丹药或灵果，支持1～99颗，确认前显示实际增加修为、前后等级和最后一颗的溢出损失。达到当前上限禁止喂养；数量超过升至上限所需整颗数时拒绝，避免额外消耗。背包预览显示已存储的最终效果，操作入口转至灵兽页。

使用既有库存动作事务和角色锁，同时校验库存位置、数量、物品修订号、灵兽归属与修订号、战斗／结算占用。物品扣减和灵兽更新同事务提交，背包通过资源事件刷新。失败不扣物品。已有丹药、灵果和灵兽不会重抽或自动转换用途。
