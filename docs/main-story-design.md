# 主线剧情与剧情系统重设计（草案）

状态：设计草案第三稿（2026-11-10），未实现。本文覆盖三件事：主线故事大纲、剧情引擎改造、演出界面重构。现行实现的事实以代码为准；标注「待核对」的条目尚未对照代码或数值验证。

## 1. 现状评估

### 1.1 引擎

| 现状 | 位置 | 对扩展的影响 |
| --- | --- | --- |

存储按「轨道 + 章节编号」读取进度，多章节多半不需要改表（待核对 `storyRepository`）。

### 1.2 演出界面

- 一次只显示一句，点一下整句替换，读起来像翻幻灯片而不是读一页书。
- 人物小像只有 44×56，放在名字左边，存在感很低；现行八段演出都没有给角色配小像，也没有场景图，「眼前」只是一行说明文字。
- 选项是全宽卡片按钮（`InkChoiceButton` 的 `card` 布局），观感接近表单。
- 回看是另开一个面板，和正文割裂。

### 1.3 文案

- 人物在讲解功能（「储物袋也理一理」「先看生灵有几只」），没有自己想要的东西。
- 没有冲突、风险和悬念；第一次可能的战斗在第 19 幕。
- 没有贯穿的问题，故事在「回来交差」后结束。

## 2. 设计原则

1. 明线自足，暗线藏在水面下。玩家日常沉浸在传统修仙故事里，不需要去猜谜（第 3.1 节）。
2. 先定谜底，再倒推线索；线索藏在类型惯例里。
3. 每卷末尾揭开一层，揭示时把当初的原句摆回玩家面前。
4. 剧情制造需要，玩法是解决需要的手段。教学放在教学层，人物不讲解界面。
5. 境界即卷。现有 8 个破境任务是每卷的高潮。
6. 主线全部手写，不交给模型生成。
7. 主线不依赖玩家所选宗门也能成立；宗门只改变视角和部分台词。

## 3. 故事圣经：《万界》（暂名，第三稿）

前两稿的问题：第一稿谜底与玩家无关；第二稿开场就把谜题摆在玩家面前，逼着玩家时刻去猜。第三稿保留第二稿的真相，改变讲法：表面是一部传统的穿越修仙故事，谜底藏在水面之下，只在每卷末尾揭开一层。

### 3.1 讲法：明线与暗线

- **明线**是玩家日常沉浸的故事：穿越、入山、受欺、历练、结交、争锋、开府、远游。每卷有自己的对手、冲突和爽点，没有暗线也能独立成立。
- **暗线**是世界的真相。平时不提问，不制造悬疑，玩家不需要知道有谜。
- **线索藏在类型惯例里**。主角学得快、新手村的老人对你格外好、秘境每次不同、各宗风格迥异、修仙要斩断尘缘：这些是玩家默认接受的修仙套路，不会多想。揭示的时候，套路被重新解释，于是恍然。
- **揭示在卷末**。一卷的明线高潮结束之后，揭开一层，并把当初那几句话原样摆回玩家面前。随后回到平静的日常，再开下一卷。

写作约束：

1. 每处暗线细节在当时必须有一个说得通的寻常解释（套路、性格、巧合）。
2. 旁白和人物不替玩家起疑，不写「似乎哪里不对」「你总觉得奇怪」。
3. 一卷之内暗线细节不超过六处，每处一两句话。
4. 一次只揭一层。揭示之后不立刻抛出下一个问题。
5. 穿越者身份在日常里提供的是乐趣和乡愁（用人间的见识办事、对此界习俗的不适应、想家），不是悬疑。

### 3.2 真相（作者视角，不直接告诉玩家）

**关于你**

- 你从人间来。来之前的最后一夜许过一个愿，即创建角色时写下的心念。
- 你是魂穿：醒来时在别人的身体里。创建角色时生成的姓名与身世是这具身体的来历，你并不记得，只从别人口中听到（已定，2026-11-10）。
- 修行的代价是记忆。每过一个大境界，你忘掉一件人间的事。修仙界管这叫「斩尘缘」「道心通明」。
- 你不是第一次来。此前你已走到尽头七次，每次都发现自己忘光了，于是轮回重来。你住的那座「没主的旧洞府」，前头的主人就是你。
- 许伯是本地人，他送走过你七次。他从不说谎，只是不说全。

**关于外来人**

- 像你这样的人此界称「天外客」，成批而来。这一回来得最多，其他玩家就是同批的同乡，这是「道友」的本义。
- 天外客根骨异于常人，命格可以改写，死后带着记忆轮回。各宗心照不宣地争相收留。

**关于这一界**

- 此界的历史只有三千年厚，「上古遗迹」造出来时就是废墟。此界由人间的念想凝成。
- 八宗的传承互不相容，因为他们是八个已经塌掉的界的遗民。
- 秘境每次不同，因为那是此界尚未凝实的地方。蜃楼幻境映出的是已被抹掉的事。

**关于万界**

- 没有人惦记的界会消失，连本地人都不记得它存在过。这叫「忘」。
- 天外客的人间记忆是撑住一界的柱子。你忘得越多，此界越凝实；你回去，就是抽走一根柱子。
- 万界正在一盏盏地灭。人间那头出了什么事，留作全篇之后的悬念。

**立场**

- 守界人：知情的本地人，善意地帮天外客忘得快一些，好让他们留下。
- 归乡会：想不计代价打开飞升台回家的天外客。

### 4.1 本稿对系统的额外要求

- 序章在创建角色之前就要能播放演出；心念原文需要保存并可在卷九引用，引用前过文字过滤（是否已保存待核对）。
- 演出需要「回照」指令：揭示时把此前某几幕的原句重新摆出来。这是「恍然」的主要制作手段。
- 剧情标记要支持「写进手记的那几句话」这类多选一的内容，并在卷二按标记改写。
- 卷五需要舆图节点可按剧情进度对单个角色隐藏。

## 5. 引擎改造

### 5.1 结构：卷、章、幕

- 目录支持多章，章带 `requires`（前置章节与条件）和所属卷。主线不再写死章节编号。
- 章与章之间允许等待：显示「下一章：筑基后开启」，而不是空白。
- `encounter` 轨道启用为支线：人物线、八宗残篇、各宗专属段落。

### 5.2 通用条件，取代封闭事实表

用一组可组合的条件替换 10 个硬编码事实：境界不低于、已入宗、持有某物、某类事件累计次数、剧情标记是否存在。事件来源沿用现有的领域事件投影（`StoryDomainEventProjector`），信号到条件的映射改为数据表。新增条件只加数据和一个判定函数。

### 5.3 剧情记忆

- 选项可写入标记；后续演出的 `when` 可读取标记、宗门、境界。
- 演出完成时提交所选路径，服务端按剧本校验路径是否合法后保存。标记只影响文字和支线入口；奖励与数值仍由服务端固定配置决定。

### 5.4 新的幕类型

| 类型 | 用途 | 复用 |
| --- | --- | --- |
| 剧情战 | 指定对手的固定战斗，可设为必胜 | 破境试炼的对手配置方式与战斗入口 |
| 目标 | 多个目标或计数目标（完成三次事务） | 5.2 的条件 |
| 等待 | 章间门槛提示 | 5.2 的条件 |

### 5.5 演出指令扩充

- `stage`：谁在场。界面据此摆放小像。
- `aside`：玩家的心里话，排版区别于对白。
- `letter`：信件、残卷、铜牌铭文，以纸中纸的样式展示，可在见闻里重读。
- 问询式选项：同一组问题可以逐个问完，问过的变淡，最后一项离开。
- 不做表情差分：现有小像每类只有一张。

### 5.6 功能开放

幕上声明 `unlocks`，导航按已开放集合显示入口。已完成 `arrival` 的老角色迁移时全部开放。后端接口的权限不因此改变，开放只是界面层的引导。

### 5.7 当前目标与任务中心

- 当前主线目标在所有游戏场景常驻一行，低存在感，点开可前往。
- 任务中心合并三类：主线、破境、支线。
- 已读演出可以在见闻或修仙日志里重看（已有 `story-preview` 场景可复用）。

### 5.8 教学层

- 教学步骤增加「做一步」：等真实操作完成再前进，而不是点「知道了」。
- 与主线无关的界面说明改为首次进入时的一次性提示，不占主线幕数。

### 5.9 写作成本

剧本目前是手写 JSON。卷数增加后建议提供纯文本剧本格式，编译为现有 JSON 并沿用现有校验。放在第三期，先用 JSON 写完第一卷再定格式。

## 6. 演出界面重构

目标：读起来像一页纸，而不是一张张幻灯片。正文是唯一焦点。

1. 连续成页。同一场景的文字在一页上逐段落下，读过的段落变淡留在页上；换场景才翻页。向上滚动就是回看，取消独立的回看面板。
2. 小像入页。现有墨像是 320×320 的半身小像，不适合做大立绘站位。改为书页插图的用法：人物第一次开口时，小像以约 72–96px 落在段首页边，名字作题签；同一人连续说话不重复出像。玩家的话用玩家自己的墨像，靠另一侧排。宽屏在页边常驻在场人物。
3. 旁白与对白靠排版区分。旁白缩进、色淡；对白用「」。去掉「旁白」标签。
4. 选项是纸上的字。选项紧接正文，作为几行缩进的文字出现，行首一个朱砂点；按下时一道墨线划过；选定后那一行变成玩家说出的话并入正文，其余淡去。没有边框和卡片底。行高保证不小于 44px 的触控高度，键盘数字键保留。
5. 推进提示收敛。首次显示「点一下，继续」，之后只在段尾留一个小标记。
6. 物件展示。信件、残卷、铜牌用纸中纸呈现。
7. 收尾。一幕结束时的主操作仍用 `InkButton`，与全游戏一致。
8. 减弱动效的系统设置继续生效。

## 7. 文案规范（补充 `game-copy-guidelines.md`）

- 每句对白背后要有说话人想要的东西。
- 人物不解释界面和规则。
- 一段不超过四十字，一场戏不超过九十秒。
- 用具体的物件和动作代替形容。
- 按钮、目标提示等系统文字保持直白。

开场对照：

> 现行：「先别急着下山。在洞里转一圈，歇脚、存东西的地方都认一认，回来就不用四处找了。」
>
> 改写：老人把药篓放下，探了探你的鼻息。「这个时节水凉，怎么又有人躺在这儿。」他叹了口气，「能走吗？能走就跟我回去，喝口热的。」
