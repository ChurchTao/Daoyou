# 主线章节与演出的接入

世界观和卷纲见[创作底稿](./main-story-outline.md)，玩家可体验到的文本以[演出目录](../packages/game-content/src/performance/catalog.ts)为准。

- 创角保存时将新角色指向 `OPENING_STORY_CHAPTER`。每章在[剧情目录](../packages/game-content/src/story/catalog.ts)注册，以 `next` 衔接；持久化的章、幕编号用于续读。新章内容进入目录时一起验证演出结局、入口和引用。
- 演出幕负责台词与选择；战斗幕核对真实战果，练习幕接收对应教程确认。各幕在完成时按赠礼编号结算，角色行锁与初始伙伴领取记录保护重试。场景开放沿用各幕声明的 `unlocks`。
- 逐幕稿里的直接引语录成 `line`，在 `cast` 登记说话人，主角用 `player`。夹在台词里的动作按发生顺序写进 `narration`；心里直接冒出来的一句可用 `aside`。角色转述别人的原话，仍由当下讲述的人演。
- 玩家选过的话会自动回显一次。动作选项用全角括号，选项后的角色回话写在对应的 `then` 里。战果专属段落拆开后，每句台词和动作都要带同一 `when`。验收时分别走过各选项和战果，检查说话人、动作顺序和汇合处。
- 现行开篇依次是《捎个口信》《三次花开》《过了那道弯》《自己报的名字》。第四章从酒楼问路到选宗、记名、初选流派，接早课后的晚饭，随后在山中小住。停在第四章旧根基或差事幕的角色从晚饭续读。根基和宗门差事等后续剧情有了缘由再引出。
- 存有旧版主线记录的角色从新版第一幕另记进度，保留既有角色资产，重读期间游戏入口开放。旧章不再参加当前主线推进。更早期的 `arrival` 配置用于历史规则兼容。
