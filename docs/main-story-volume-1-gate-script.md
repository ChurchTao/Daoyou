# 第四章　自己报的名字

卷一第四章，接[《过了那道弯》](./main-story-volume-1-bend-script.md)。

### 一　借一句话

咪咪先听见，蹲在门槛上，两只耳朵齐齐朝着坡下。

**竹管里的声音**　爹，我这儿都好。

是个姑娘的声音。你探头往坡下看，一条石阶空荡荡的。等你穿好鞋，那姑娘又说了一遍，连说到「好」字前吸的那口气都和方才一样。

采药人正在门外紧筐绳。

**采药人**　前儿我下山就听她说这句。还没寄出去啊。

转过石墙才看见人。一个穿青布衣裳的姑娘蹲在泉边，手里捏着一截竹管，正在跟自己生气。她把竹管在水里一浸，再举到唇边。咪咪偏在这时叫了一声。

姑娘把竹管往掌心一磕。这回她没张嘴，声音是从竹管里传出来的。

**竹管里的声音**　爹，我这儿都好。

话音刚落，竹管里又响了一声猫叫。姑娘低头看着咪咪。

**青衣姑娘**　你家的？

**你**　昨天才算我家的。要重来么？

她把湿漉漉的竹管在衣襟上擦干，小心塞进一个布套。

**青衣姑娘**　就这遍吧。我爹上回嫌我每次都只说平安。这回听见猫叫，够他问上半天的。

姑娘把布套揣好。采药人背起药筐，临走又蹲下来，挠了挠咪咪的下巴。

**采药人**　昨晚它肯给你腾地方么？

**你**　我半夜醒了一回。它睡在正中间，我就剩个被角。

采药人笑了。咪咪还仰着脸等他挠，他又挠了两下，这才起身往岔路上去。

**青衣姑娘**　我得赶去集上。今日盐船回上渡，错过这趟，我爹还得再等半个月。

**你**　回上渡？我也想捎封信。我跟你走。

### 二　有人往家走

你跟着姑娘穿过鱼行。临水一座酒楼刚卸下门板，窗里有人把长竹篙往外递。姑娘扶了一把，从竹篙底下钻进去，把布套交给了窗下吃面的汉子。

**青衣姑娘**　给我爹的。他要问怎么还有猫叫，你叫他下回自己来听。

**盐船伙计**　好，给我吧。还有谁要捎东西？等我吃完这口就开船。

**你**　上渡撑船的周叔，你认得么？

**盐船伙计**　老周啊，认得。去写罢，我把汤喝完。

柜上有给客人包茶的纸。小二匀你一张，让你拿他记账的笔写。你趴在桌沿，先写周叔，托他把这纸捎回家。

*（写那座山的背面。） / （写咪咪。），两段择一。*

> 那座山我绕过去啦，背面果真是平的。还瞧见有人在上头晒被子。婆婆要是不信，你念给她听。

> 我在路上得了一只猫，叫咪咪。昨晚它睡中间，我睡被角。等我回家，得给它单找条被子。

你折了纸，又摊开，在底下挤了一行小字。等拜了师，我再写信，你们就知道往哪儿回了。盐船伙计已经站起来，一手扶着斗笠，腾出一只手接你的信。

**青衣姑娘**　我得回了。你几时带着猫上来，我再借它叫一声。

姑娘走后，你也叫了碗面。三枚铜钱搁在桌上，咪咪拨掉一枚，你弯腰找了半天。

**酒楼小二**　钱搁这儿就成。你这包袱沉，放凳上吧。还走远路么？

**你**　我想找个地方拜师。你在这儿见的人多，知道往哪边走么？

小二掀开灶头的帘子，叫里头的伙计替他招呼一会儿客人。你低头吃面，咪咪已经蹲到了空凳上。

### 三　跑堂的耳朵

小二搬了张矮凳，在你桌边坐下。他手里夹着几张纸，最上头一张折了角，写着哪一日有船。

**小二**　你先吃。这些是客人留下的路帖，去各家山门怎么搭车、怎么坐船，上头都写着。你想打听哪一家？我给你找。

少年自己拣一家问。小二说完，路帖仍在桌上，少年可以再问别家，也可以挑这一家的路去走。[八家的酒楼闲话](./main-story-volume-1-sect-visits.md)。

### 四　照帖问路

去处由玩家定。少年和咪咪照路帖上路。抵达时遇见的人会指给他去名册前的路。接引人问他想知道什么，少年从方才的见闻问起，弄明白这家宗门教什么、一路所见和门里有什么关系。听完可以当场拜入，也可以回酒楼再问别家。

往晋京去，白鹿书院的门敞着。松树下有人背书背到一半，见你来了，慌忙拿袖子盖住膝上的书。去别家也各有一幕，见[各宗山门演出稿](../packages/game-content/src/performance/mountain-gate-arrivals.ts)。

往元武国去，可在布庄搭车。到半山前恰逢桥断，少年跟着[渡人的剑修和卖豆腐的老梁](../packages/game-content/src/performance/data/mountain-high-water.json)过河。

### 五　回信有地方收了

掌籍的人等你把气喘匀才蘸墨。

**掌籍弟子**　名字？

**你**　{name}。

他说得写清来处。你把河弯的名字报出来，添了一句，上渡下船，走过染坊，面棚漏雨的那张桌子你从小就坐。

掌籍的提着笔，等了片刻。

**掌籍弟子**　写到上渡，成么？这一格就这么大。

掌籍的在册子上写好「上渡」，把册子转过来给你看。你认得自己的名字。桌角压着几封家信，你想起自己托盐船捎走的那张纸。

**你**　我答应家里，拜了师就告诉他们往哪儿回信。我能抄个地址么？

**掌籍弟子**　能啊。照这封信上的地址抄，再写上你自己的名字。以后有人捎信来，我就知道该给谁了。

掌籍的抽出一封信，拿手指给你看信封上写地名的那一行。你讨了张纸，一字一字抄下来。

**掌籍弟子**　早课还没散。你去找{path_teacher}，就说我给你记过名了。

你把抄好的地址收进怀里，往院里去。前排坐得满满的，有人瞧见你在门边张望，往旁边挪了半张凳子。

**你**　先生，听说门里有两种练法。我要怎么挑？

教习用交手的例子讲两种练法。各宗台词见[初习流派演出稿](../packages/game-content/src/performance/sect-first-path.ts)。

**你**　我要是先学一路，过些日子想换呢？

**教习**　回来找我就能换，不收灵石。学过的心法两路都能用。以后你给哪一路练的经脉，就给那一路留着，换回来还能接着练。你先挑一路，待会儿跟着练一遍。

玩家在对话里选一路，接当天的练习和晚饭。

### 六　筷子

早课上，教习走到你跟前，伸手拨了拨你攥着木杆的手指。你松开些，一转身又攥紧了。到傍晚，院子里都没什么人了，你还在试。

**同门**　开饭了。你再不来，锅巴都叫人刮光了。

喊你的是早课上给你让座的人。你把木杆靠在廊柱上，跟着进了饭堂。他碗里扣着一大片锅巴，掰了一角给你。

晚饭有一碟炒黄豆。你平日很会夹这个，今日第一颗掉进碗，第二颗掉到桌上。第三颗眼看夹住了，对座伸筷子把碟往你这头推了推。

**同门**　手摊开看看。

你右手虎口磨红了一片。对座那位翻开手掌给你看，他那儿有块硬茧。

**你**　教习叫我松手，可一松，那杆子就要滑出去。

**同门**　廊下那根木杆？我明早要去器坊，你带着它一块儿来吧。那儿有个老师傅，请他看看你是怎么握的。

回住处时，咪咪已经占了半张床。你把白天抄的地址摊开，借灯又认了一遍。明日写信回去，还有件新鲜事能讲。早晨才报的名字，方才去打饭，已经有人隔着半个饭堂喊你了。

*第四章完。续第五章《借炉的人》。*
