# 旧法宝焕新（临时）

玩家入口 `/game/artifact-migration`，洞府“洞府内”快捷区固定显示“旧法宝焕新”入口，不依赖可兑换资产预查询；没有待兑换资产时由页面展示空状态。直接读取 `creation_products.product_type = artifact`，不复制来源、不新增 SQL 或迁移状态，不使用 `app_settings`。功法、神通和材料不参与本工具。

## 固定兑换规则

每件有效旧法宝兑换 1 件普通成品道装。六个部位自选，法兵必须选已有器形，非武器不接受器形。旧品质和旧部位不影响道装生成。道装复用现有生成器，`baseQuality = 0`，材料择优增益为 0；不继承旧词条、旧强化或旧创作者，不自动装备，不消耗材料、灵石或灵气。

每件旧神品法宝另赠 500,000 灵石，与道装及评分图纸叠加，不再赠送小聚灵符。品质以锁定的原记录为准，非神品不获得此项补偿。灵石与物品发放、原记录删除同事务提交；若灵石余额无法完整容纳 50 万（现行上限 10 亿），整笔回滚并提示先使用部分灵石，不能截断奖励。奖励仅适用于仍持有的未兑换来源。

境界读取 `productModel.metadata.anchorRealm`：炼气、筑基、金丹、元婴保持；化神及以上统一化神；缺失、非法值及非对象 metadata 回退金丹。忽略小阶段，不根据兑换时角色境界或旧品质推断。对应道装档位 10／30／50／70／90，穿戴门槛仍使用新版各境界初期规则。图纸与成品使用同一归一化境界。

| 单件评分 | 额外图纸 |
| --- | ---: |
| 1～1999 | 0 |
| 2000～2999 | 1 |
| 3000～3499 | 2 |
| 3500～3999 | 3 |
| ≥4000 | 4 |

每张图纸的部位独立等概率抽取，允许重复并堆叠。评分为零、负数或非法数值时保留来源待核对；境界异常本身不阻止兑换。图纸后续使用普通炼器规则。

## 事务及上线

不需要初始化或导出：完成旧版清账并正常升级后即可使用，须保留 `creation_products` 原表。后端以会话中的当前角色为准，复用角色 Redis 锁、SQL 角色锁及占用校验；事务内以归属、类型和 ID 锁定原法宝，重新核算补偿，生成道装和图纸，发放至背包（不足进入仓库），删除原记录并提交资源变更。

所有奖励一次领完；失败回滚，原记录保留。成功后原记录不存在，重复请求不发奖。不保存抽取历史或请求结果；断线后核对原清单及背包／仓库。客户端不接受指定境界、评分、图纸数量或随机种子。
