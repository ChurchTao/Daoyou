# 百草志新谱 · 32 种灵植

八阶各四种。基础产物来自成株及繁茂路线，特化产物来自结实或凝珍。药效百分比表示一份同品灵果药效预算的分配。实际数据以 [目录配置](../packages/game-content/src/spirit-field/data/garden.json) 为准。

玉髓芝、紫猴花、天灵果沿用《凡人修仙传》的筑基三药关系。霓裳草、九曲灵参、金雷竹、悟道古茶树、麒麟神药和九妙不死药保留原名与代表性形态。品阶、成长和收成采用万界道友的规则。
