# 主线剧情创作底稿

本稿记录作者已经选定的故事方向，供后续讨论、卷纲和剧本共同引用。最近更新于 2026-11-18。

## 长篇与首版范围（已定）

整部主线从本土普通少年初次求道起，贯穿炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫九个大境界，写到玩家亲历飞升。卷数与后续分卷境界留给人物经历和游戏进度共同决定。首版制作范围为前三卷，交付目标是三卷都能从头玩到尾，后续版本再续写。下方卷纲表中的一行只记录一卷的走向与已定结果；当前已录入卷一前三章。卷一后续及卷二、卷三仍在设计中。

篇幅要花在玩家想亲自经历的事情上。卷二写师父来观战，卷一就要写出一段只有他见过主角怎样练、也只有他明白这场比试意味着什么的日子。卷三写魔修从泉底得手，玩家得先和他赶路、见他分念探路、亲手撒过红砂。按主角当时能见、能听、能做的事写正文。修炼、差事和出游应当让人再见面时已有变化；连续点对白、重复交差或等待破境都不能凭空生出这些经历。

卷一已展开为[《山外有山》分章细纲（讨论稿）](./main-story-volume-1-rework.md)，逐章记录从故乡到筑基下山的因果与教程位置。

卷一开篇已定：少年在遇见散修前就向往河弯外的天地。「三次花开」让他下决心离家求仙。[第一、二章逐幕试读稿](./main-story-volume-1-opening-script.md)记录本轮演出写法。

## 世界与两世的因果（已定）

玩家先过修士的日子。求长生、拜师、交友、斗法、争机缘，本身就值得走一趟。让玩家陪同辈一起听一位天才的传说，等他们有了自己的经历和判断，再让旧事走到眼前。每卷眼下这件事要有自己的结果，一次胜负、一段交情都值得占据卷末。

1. **人界、魔界与飞升。** 两界相隔遥远，只有少数古关相通。大多数人终生无缘见到对岸。人界已有传承多代的魔道师门，修习魔道的人也可以一生都没去过魔界。两界生灵都有飞升之路，修士飞升须能将毕生修成的形神收归一身。
2. **魔界高位者的选择。** 他年轻时怕死，为续命将神魂分寄魔界地脉。多年以后，这门保命之法也困住了他。他要把一缕神魂寄进一个根基未定、天资足以问鼎的少年，随其成长，在最后破境时夺身飞升。他看中了第一世主角的天资。少年后来修得的本领、结下的交情，都是他自己的。
3. **百年前的败局。** 第一世的主角距至高境界只差一步，本想再修些年。侵蚀已深，再拖下去会危及身边的人，他才决定提前冲关，逼对方现身，与伙伴共同一搏。主角遭反噬，第一世身死道消。百余年后，故人尚在，往事已成传说。
4. **旧友的托付。** 冲关前，主角已与伙伴分出部分魂魄与记忆，用天材地宝重塑肉身。他请故友让孩子自己长大，把将来是否修仙、如何生活交给第二世。旧友暗中相助，隐去身世。过早知情只会加重少年负担，也会使他暴露于那些推演出他尚存一线生机、觊觎其机缘的正道高层面前。
5. **第二世与终局。** 玩家从人界普通少年的身份开始，有自己的故乡和童年，对前世记忆混乱。一路成长后，他发现自己正是少年时仰望的天才，取回记忆，与两世好友共同击败魔界高位者。他本可以安稳过日子，最终选择亲自跨过古关，为两世的恩怨讨一个交代。恩怨了结以后，他自己挑选飞升的日子。玩家陪他迈出最后一步，亲眼看见上界。

## 贯穿主线的三段交情（已定）

**前世并肩的挚友，今生做了长辈和师长。** 他暗中看顾主角，也有值得少年真心求教的本事。两人要在今生重新建立一段真实的师徒情。到故事后段，主角才怀疑并认出他的旧身份。师长的名字、师承和手艺仍可选定。

**世家少主，今生结识的生死兄弟。** 少年时，他是世家里出了名的废柴。他只钻研一门功法，数十年如一日地练一招剑，付出别人不愿付的代价，最终成为化神之下第一人。同境相争，一剑足矣。他也会反过来影响主角怎样修行、怎样看待成败。

> “这世上天才很多，但大多数都是垃圾。”在他看来，很多人“努力配不上天赋”。强者要有一颗「强者之心」：宁折不弯，遇事不退。失败就是失败，任何理由，都是懦夫拒绝承认自己失败的借口。“只要想做的事，就一定会做到”，也要为自己的选择承担全部后果。

写他时要给对手应得的胜利。他会记得谁堂堂正正破过他的一剑，也肯当众承认自己当年输了。他的志向足以支撑几十年修行，无需靠旁人为他洗清误解来驱动。

**人界魔修，今生结识的同道。** 他和主角所修道途不同，理念相契，有独立的师承、愿望和判断。他可以与主角全力争同一份机缘，也会在终局凭自己的本领助主角一臂之力。卷三这场胜利属于他。

## 卷三：魔修为何争、如何赢（已定）

魔修用分念探路，收功时总有半息说不清：手已经端起茶碗，指尖却还留着远处石壁的湿凉。究竟是探出的那一念归来晚了，还是念已归位、旧触感迟迟未散？这两种情形练法相反，两条路他都花了几年。石泉灵物能让人亲眼看见运功时灵力走过的路径。他千里赴约，就是要看清自己收念的那个瞬间，决定往后几十年的功夫下在哪里。

入境时，魔修请主角在浅泉撒一把红砂。浮叶已随水面上涌，侧孔里仍有红砂吐出。魔修惯于分念查看岔路两头，因此记住了水面与底流换向相差的半息。

末场只有一枚随水翻涌的灵物，谁先握住就归谁。主角判断上涌的位置，抢占水面；少主选中石唇最薄处，等水下有光便出剑，想将它截在半途。魔修提前收回探念，潜入石下，将手伸到侧孔外，赌灵物会像红砂一样多随底流走半息。身在石下，他看不见水面，押错便来不及再争。少主一剑开石时，主角看见魔修的手已经握住灵物。入境时玩家亲眼见过的潮相，至此兑现。

### 卷三收尾：渡口暂别（已定）

魔修当卷用掉机缘，亲眼看见神念早已归位，迟迟未散的是指尖的旧触感。他终于知道今后要练什么。少主用碎石复看水路，认下这一败。主角仍惦记自己想看清的那半招，也肯在饭桌上跟朋友说起落败时的不甘。

渡口这顿饭由赢家请。饭后，魔修闭眼分念去碰湿石阶，玩家从温茶和凉酒两只杯子中选一只，递给收功的朋友。他头一次还是答错；少主调换杯子，主角添茶，再试一回。伙计来问明早的船票要买到哪里，三个人报了三个地名。翌日各自登程，暂别修行。若采用旧舆图支线，把线索放在归途，渡口是本卷最后一幕。

### 后续素材：山中守关（候选单元，卷次待定）

主角去找盛会上胜过自己的同辈，想再过一次招。此人正闭生死关，托他守关的姐姐要下山办事。主角答应替她守一个月，在山中租住，认识靠替闭关人送饭、递信和照看洞府为生的人。一封来自家中的急信送到，主角须查清闭关者究竟留下了怎样的嘱托，再决定能否惊动他。这桩守关的事先留作独行阶段的一段经历，待后续卷有完整的明线时再决定取舍。
