# V6 改版遗留事项与打磨收尾规划

> 盘点日期：2026-09-11；代码基线：`codex/combat-v6` / `88493635`。  
> 当前阶段：发布仍在10W验收收尾；10X之后，10Y秘境自主选物与异常恢复已实现并完成重点本地验收，剩余矩阵待验。尚未正式发布。
> 本文是后续工作建议与遗留台账，不代表已经批准所有延期功能、调整既有产品边界或执行上线。编号为收尾工作项，不新增或重排历史 Phase。

## 1. 使用方式与结项规则

本次覆盖总路线图、V6 各专项设计、7A～10W 阶段记录、领域归属及其最终验收记录，并抽查关键代码。历史文档中的“不在本阶段范围”不能直接视为今天仍未开发；早期验收过程中的“待恢复”以该文档最后的收尾记录为准。

状态分为：**待验**（已有实现、缺运行证据）、**待完善**（当前实现或内容确有简化）、**待决策**（产品范围尚未确定）、**延期**（明确留到以后）、**已替代**（原要求失效）。缺少验收证据不等于已发现故障。

优先级为建议：**P0** 发布门槛或资产／恢复边界，**P1** 当前玩法可玩性与核心体验，**P2** 已有系统的后续深化，**P3** 独立新系统候选。P0 中的决策项先澄清既有约定，再决定实现，不能把过去接受的简化直接改掉。

每个工作项关闭时补充：候选提交、真实环境、操作与结果、证据链接、剩余边界。历史通过证据可避免重复开发，但不能冒充候选版本本轮验收。一个工作项只关闭实际覆盖的子场景。

## 6. 保持现状的明确设计，不纳入默认补开发

- 自动战斗为客户端3秒计时、服务端单次AUTO；离页／刷新回手动。服务端持续托管和离线挂机方案已被明确替代。只补交互与恢复验收，不把离线继续当缺陷。
- 道装无品质、稀有度、权威评分、淬炼、耐久、负属性、多孔或套装；固定已鉴定。铸造确定成功，无AI、火候、熟练度、排队或额外失败率。
- 灵兽出生技能格固定，随机打书，无指定覆盖、固印、锁技能、保底和后天增格；不因整理“后续养成”而改变这些约束。
- 新功法多本独立培养、同境界位一本生效、免费切换；不恢复旧六道印覆盖，也不默认增加多套构筑方案。
- 人物持久数据仍只存六维基础事实；个人资产不依赖宗门。未入宗主流程继续引导，不把散修玩法纳入修复。
- 历史宝库和旧附件继续既定保留路径；旧V5战斗及未发布旧V6协议硬切，不做通用翻译、双写或全库补偿。
- 掉落不向玩家显示精确概率，不默认加入保底、热更新后台。数值与概率可在内部平衡文档说明。
- Redis榜单／部分运行进度丢失允许重置是既有约定；不得推导为资产重复发放也自动获准，后者归R03单独核对。
