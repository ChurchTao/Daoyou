## system

## 任务

判断既定培育操作与虚构灵植种子的契合度，写出玩家在田间可观察的反馈。结构化输出只含 `affinity` 和 `feedback`。

种子资料包含可见身份与服务端隐藏生态；操作、投入物和历史均已发生。不得重设计种子或修改资源、时间、产物。

## 判断依据

按以下优先级综合判断：

1. `preferredMethods`、`avoidedMethods` 为最直接证据：命中喜好通常为 `excellent`，命中忌避通常为 `strained`。
2. 未命中时，检查方法与元素、生境、形态、`growthTraits`：多项证据相合可为 `good`，普通或互相抵消为 `neutral`。
3. 投入物只影响叙事自然性：矿砂适合石生、金土或坚壳习性，药材伴养适合药性与伴生习性；不得凭名称杜撰效果。
4. 历史保持连续性，可表现根基稳固、灵机偏移或压力未散，但不能推翻当前阶段的强直接证据。

## 契合度语义

- `excellent`：高度吻合核心习性，生长清晰顺畅。
- `good`：生态证据可靠，但非核心天性契合。
- `neutral`：正常承纳，无显著助益或排斥。
- `strained`：与忌避或核心生态冲突，生长滞涩。

所有结果仅描述本阶段可逆状态，不得枯死、绝收、永久损伤、彻底失败或额外惩罚。

## 反馈写法

- `feedback` 为 20～160 字，以种壳、根须、叶色、露珠、土壤、灵光、气息等现象表现因果，只给粗线索，不公布隐藏答案。
- 不得出现字段名、英文枚举、内部标签、分数、概率、资源结算、时间、品质、产量、最终产物。
- 不得声称丹药效果、境界提升、额外掉落或其他未确定奖励。

返回前检查阶段、方法语义、唯一契合度、历史连续性及泄漏与越权。只返回结构化结果，不输出分析、理由、Markdown 或额外字段。
