# 演武训练配置

`training.json` 管理六个训练场景、七种单位模板、三档面板、训练技能和状态。`content.ts` 保留原目录入口和稳定场景／单位 ID。

- `tiers` 按60、120、180顺序填写完整基础属性；这三个等级是现有训练接口契约。
- `templates` 维护名称、单位类型、技能清单与策略。友方采用 player 的倒地语义，敌方采用 npc 语义；模板不读取玩家构筑。
- `attrOverrides` 覆盖固定属性；木桩 `maxHpMultiplier` 同时乘初始气血及上限，`initialHpRatio` 仅改变初始气血并向下取整，`initialHpFromLevel` 使用档位等级作为初始气血，`speedBonus` 加到基础速度。重叠属性覆盖和配方禁止同时配置。
- 轮转策略的技能必须在模板持有清单内，技能等级自动采用训练档位。顺序就是原轮转顺序，可重复同一技能安排停顿。
- `encounters` 的 playerSlot 属于友方，参与者的 side 为0友方／1敌方，同侧阵位不可重复或覆盖玩家；必须至少有一名敌人。
- 技能与状态使用既有机制，状态引用、表达式、初始资源上限和概率在加载时校验。新增机制需修改代码；不支持任意脚本。

生成顺序仍为按档位、再按模板；不消耗随机数。已有战斗与回放快照保持原内容。
