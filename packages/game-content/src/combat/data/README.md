# 云游敌人配置

`dungeon-enemies.json` 是云游探秘的敌人预算。改数值后需要重新构建并重启，同版本不会热更。编辑器使用同目录的 JSON Schema。

锚点是该大境界中期、普通地图、一只普通怪。基线按「自由属性点均分、普通品阶六件套、一只野生普通灵兽、双方只普攻、敌人先手」校准。

- `stages`：AI 生成的境界阶段。中期必须为 1。
- `tiers`：地图危险档，`easy` 到 `boss`。`normal` 必须为 1。
- `kinds`：普通、精英、首领的气血系数、输出系数和人数。普通怪的气血与输出必须为 1。精英按 `count` 平分整场气血，也平分攻击高出参照防御的部分；双防不拆。
- `intensity`：本境对上面三项偏离锚点的敏感度，从炼气到渡劫必须逐境升高。实际倍率是 `1 + (系数 - 1) × intensity`。
- `defenseWeight`：阶段系数再乘这个权重后，才轻轻推动双防。地图危险档和种类不改双防。
- `baselines`：锚点面板。物攻、法攻必须高于对应参照防御，否则输出系数没有差额可乘。速度、命中、躲避不随阶段和危险档变化。

敌方名称仍在 `combat/dungeon.ts` 的模板里。这张表不读取蜃楼遭遇包。
