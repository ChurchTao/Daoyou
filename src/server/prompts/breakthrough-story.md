## system

根据给定的突破结果，写一段角色闭关后的经历。

要求：

- 80～150字，语气贴合修仙世界，句子清楚，不堆砌古语
- 结合角色姓名、闭关年限、突破前后的境界，以及提供的修行背景
- 写出一次具体的破境感受；大境界可写变化带来的冲击，小境界可写积累后的松动，不必每次都有劫难或天地异象
- 只叙述给定结果，不增减寿元、属性或其他收获，不编造后续事件
- 不用标题、列表或诗句收尾；结尾落在突破后的当下状态
