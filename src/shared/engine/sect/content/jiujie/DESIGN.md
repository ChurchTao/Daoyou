# 九劫天宫设计稿

> 本稿记录九劫天宫首版生产规格。目标不是继续增加独立规则，而是把“行为触发型雷罚”压缩成现有宗门体系可以承载的：一套共通资源、一套共通技能底板、两条在同一底板上改变触发来源与兑现方式的道途。TypeScript 定义与专项测试是战斗行为的最终依据。

## 1. 宗门身份

- 正式名称：九劫天宫
- 简称：天宫
- 稳定内容 ID：`jiujie`
- 属性主题：雷
- 宗门气质：正统、肃穆、冷峻的天道审判道统
- 道途一：劫眼临身
- 道途二：天谴加身
- 共通战斗资源：劫数
- 共通核心状态：劫雷、劫债
- 核心战斗形态：不可驱散的行为型 DOT 与延迟清算

天宫不是传统的雷法爆发宗门。它以雷记录行为，以劫雷惩罚行动，以劫债等待清算。目标不是因为时间流逝而受伤，而是因为在身负天罚时继续施法、攻击或进行其他主动行为而触发雷罚。

核心循环：

```text
施加劫雷 → 目标主动行动 → 劫雷触发 → 获得劫数 / 增加劫债 → 消耗劫数清算
```

两条道途不拥有两套互不相干的资源和技能，而是共享同一循环：

- 劫眼临身：更多通过自身承伤获得劫数，再把承受的灾厄归还。
- 天谴加身：更多通过敌人行动触发劫雷获得劫数，再把目标的劫债提前兑现。

## 2. 背景设定

天地初开，九重天门悬于雷海之上。天劫并非单纯的突破试炼，而是天地对修士行为留下的回应：夺取机缘、逆转生死、强行续命和逃避代价，都会在天道中留下记录。

上古修士曾建立九劫天宫，试图整理这些记录。他们不自称天道，也不判断一个人是否“善”或“恶”，只记录：

- 谁引来了劫；
- 谁承受了劫；
- 谁试图逃避劫；
- 谁在劫临身时仍然选择出手。

因此，天宫的雷法更接近一套严苛的天道律令，而不是情绪化的惩罚。

天宫山门最高处有九座封闭天门。门中无人知道第九门后是什么，只知道历代宫主继任时都必须接受“九门问劫”。通过者可以执掌劫簿；失败者会化为雷池边的黑金石碑，继续记录后来者的脚步。

### 宗门教义

> 雷不因怒而落，劫不因弱而来。凡有所行，皆有天听；凡有所取，皆有归处。

### 门人誓言

> 我不求无劫，只求劫有所归。

### 叙事边界

第一版不确定开山祖师的姓名、年代和最终真相。宗门背景只承担三个功能：

1. 解释天宫为何记录行为；
2. 解释劫雷为何不可被普通驱散；
3. 为后续九重天门、宫主试炼和宗门剧情留下空间。

## 3. 共通战斗设计

### 3.1 宗门基础被动：《天威裁决》

九劫天宫的 `foundationPassiveId` 对应内部被动《天威裁决》。它是所有天宫弟子加入宗门后即获得的共通能力，不属于任何道途，也不占主动技能槽。

基础效果：

> **天宫弟子受到敌方主动法术或负面技能时，有 20% 的几率免疫整个技能。**

这里的“敌方主动法术或负面技能”指敌方施放的、带法术通道或带负面技能标签的主动技能。触发后，整个技能在施法前被拦截，伤害、治疗、控制、Buff 与技能费用效果均不执行；己方增益、自身施法和普通攻击都不触发该被动。它不改变劫雷 Buff 自身的不可驱散规则。

这个被动表达的是天宫弟子的根本气质：正统天道护持下，外来邪法、诅咒与控制未必能够落在身上。它不解释劫雷怎么施加、怎么触发或怎么清除，也不参与劫数生成。

两条道途只能在此基础上改变后续收益：劫眼临身增加承灾与反制，天谴加身增加施罚与清算；不得替换或重复注册《天威裁决》。

### 3.2 共通资源：劫数

两条道途共用唯一战斗资源：**劫数**。

| 项目 | 设计 |
| --- | --- |
| 资源名称 | 劫数 |
| 资源性质 | 战斗内临时资源 |
| 固定上限 | 3 |
| 主要用途 | 强化或启动共通清算技能 |
| 获取方式 | 劫雷触发、承受直接伤害、部分节点奖励 |
| 消耗方式 | 共通清算技能和部分防御技能 |
| 两条道途差异 | 只改变获取倾向与消耗后的附加效果，不改变资源 ID |

劫数不是怒气、法力或第二条伤害条。它表示“天宫弟子当前手中握有多少可以调用的劫威”。

共通规则：

- 劫数不能超过上限。
- 溢出的劫数不转化为伤害，除非具体节点明确规定。
- 劫数不跨战斗保存。
- 劫数不直接造成回合伤害。
- 不为两条道途额外建立“应劫值”和“主罪值”两条独立资源。

道途差异：

- 劫眼临身：自身受到直接伤害时，更稳定地获得劫数。
- 天谴加身：敌方身负劫雷并主动行动时，更稳定地获得劫数。
- 两条道途都可以通过共通技能消耗劫数。
- 劫眼临身的节点倾向“消耗后承灾反击”，天谴加身的节点倾向“消耗后加速目标清算”。

### 3.3 共通状态：劫雷

劫雷是天宫最核心的持续状态。

劫雷实现为单层、不可普通驱散的负面 Buff，而不是新的通用伤害类别。

基础规则：

- 劫雷由天宫技能施加。
- 劫雷不可被普通驱散、净化或移除效果清除。
- 劫雷持续若干回合，具体持续时间由技能和心法成长里程碑提供。
- 被标记目标进入一次主动行动时，劫雷触发一次。
- 一次主动行动最多结算一次劫雷。多目标神通即使产生多个 `SkillCastEvent`，也由 `source_action` 预算合并为一次结算。
- 目标使用主动神通时，触发造成雷属性持续伤害，并增加一层劫债或推进现有劫债。
- 目标使用普通攻击时，仍触发一次基础劫雷伤害，但不增加劫债、不记录主罪；普通攻击因此是承受基础天罚、避免进一步加重罪责的 fallback。
- 劫雷造成的伤害不再次触发劫雷。
- 被动效果、DOT 结算、反应伤害、状态自然过期不视为主动行动。
- 劫雷自然结束时直接移除，不生成余劫或其他替代状态。

“不可驱散”是劫雷的规则身份，不是驱散失败后额外反伤。第一版不设计“驱散反噬”，避免把反制交互扩展成第三套机制。

### 3.4 共通状态：劫债

劫债是劫雷触发后留下的可见计数。

基础规则：

- 劫雷因目标主动神通而有效触发时增加劫债；普通攻击触发的基础天罚不增加劫债。
- 劫债上限固定为 3 层，不允许无限叠层。
- 达到清算阈值时，不自动引入复杂控制，只为清算技能提供更高兑现价值。
- 共通终式可以消耗目标劫债进行一次天罚清算。
- 清算后劫债归零。
- 劫债不是劫雷的替代品：劫雷负责“目标行动时触发”，劫债负责“多次触发后的兑现”。
- 天谴道途另有最多 2 层的隐藏“重犯”记录。重犯只表达重复主罪的附加清算，不替代劫债。

### 3.5 反制边界

为了保留对手决策，天宫不是“挂上就必死”。

对手可以：

- 暂停使用高价值主动技能；
- 使用普通攻击承受基础劫雷，但避免继续增加劫债和主罪记录；
- 先击杀天宫弟子；
- 在劫债尚未达到阈值时调整战斗节奏；
- 通过防御、闪避或免伤降低劫雷本次实际收益。

对手不能：

- 用普通驱散移除劫雷；
- 通过清除一般 Buff 直接消除劫债；
- 用 DOT 结算触发劫雷；
- 让天宫因自身被动连锁产生无限劫雷。

## 4. 共通技能底板

两条道途共享以下基础神通。流派节点只改变这些技能的触发来源、目标范围、资源收益或清算偏向，不重新创建一套完全不同的技能列表。

| 技能 | 类型 | 职能 | 共通底板 |
| --- | --- | --- | --- |
| 《惊雷指》 | 普通攻击 | fallback | 造成基础雷属性直接伤害；不施加、延长或推进劫雷，不获得劫数 |
| 《天听引雷》 | 主动 | 生成 | 对目标造成雷伤并施加或刷新劫雷 |
| 《承天受劫》 | 主动 | 防御 | 短暂降低受到的直接伤害；劫眼道途额外记录承劫量 |
| 《劫簿落印》 | 主动 | 标记 | 目标已有劫雷时增加1层劫债并刷新劫雷；否则只补上劫雷；不直接清算 |
| 《雷狱问行》 | 主动 | 维持 | 延长劫雷或推进劫债；在目标已经行动过的情况下价值更高 |
| 《借劫回身》 | 主动 | 资源 | 消耗 1 点劫数，获得短暂护盾 |
| 《因果回响》 | 主动 | 追击 | 造成基础雷伤，并根据目标当前劫债追加伤害 |
| 《九霄清算》 | 主动 | 终式 | 消耗劫数，对带有劫雷或劫债的目标造成一次雷属性清算 |
| 《天威裁决》 | 被动 | 宗门基础 | 受到敌方主动法术或负面技能时，20% 几率免疫整个技能 |

### 4.1 《惊雷指》

宗门普通攻击，只承担所有主动技能均不可用时的 fallback 职责。

基础行为：

1. 对单体造成基础雷属性直接伤害；
2. 不施加劫雷；
3. 不延长已有劫雷；
4. 不增加劫债；
5. 不获得劫数；
6. 两条道途都不把它强化为主要循环技能。

《惊雷指》保留雷属性，只用于维持宗门表现一致性。它的伤害预算应接近其他宗门默认攻击，不能因为“雷属性”而获得额外机制价值。

### 4.2 《天听引雷》

宗门默认生成技能。

基础行为：

1. 对单体造成低到中等雷属性伤害；
2. 对目标施加不可驱散劫雷；
3. 若目标已经有劫雷，则刷新同名状态持续时间。

天谴节点可令重复引雷记债，或在新劫雷建立后留下“一次待立案”内部标记；该标记只服务初罪立案，不是新的战斗资源。

### 4.3 《承天受劫》

共通防御技能。

基础行为：

- 施法者获得短暂直接伤害减免；
- 劫眼道途期间受到的直接伤害被记录为“本次承劫量”；天谴道途不建立承劫记录；
- 不产生无敌，不清除已有劫雷；
- 结束后本次承劫量只作为后续技能的动态标量来源，不自动造成反伤。

流派变体：劫眼临身可以记录护盾吸收、建立照见关系并把承劫量转为伤害、治疗或护盾；天谴加身只使用该技能的基础直接伤害减免。

### 4.4 《劫簿落印》

共通标记技能。

基础行为：

- 目标无劫雷时施加劫雷；
- 目标已有劫雷时先增加1层劫债，再刷新劫雷；
- 劫债仍受3层上限限制，不直接造成伤害或获得劫数；
- 不创建一套可无限叠加的罪名状态。

天谴加身通过劫雷运行时记录目标最近一次主动技能类型，作为唯一“主罪”字段；《劫簿落印》本身负责施加或刷新劫雷，并在已有劫雷时推进一次劫债。

### 4.5 《雷狱问行》

共通维持技能。

基础行为：

- 对带劫雷目标造成一次较弱雷伤；
- 延长劫雷剩余时间；
- 推进一层劫债。

道途节点可以提高伤害系数，天谴的主罪和重犯仍由目标自己的主动行动推进。

### 4.6 《借劫回身》

共通资源技能。

基础行为：

- 消耗 1 点劫数；
- 获得相当于自身最大气血15%的短暂护盾；
- 不附带伤害或控制，避免一个技能包办全部职能。

劫眼节点可以让护盾破裂成为一次性的治疗与引雷触发器；触发由通用破盾事件承载。

### 4.7 《因果回响》

共通追击技能。

基础行为：

- 造成一次相当于0.45倍法攻的基础雷属性追击伤害；
- 根据目标当前劫债层数追加伤害；
- 每层劫债追加相当于0.10倍法攻的雷伤；
- 不消耗全部劫数，避免它与终式争夺唯一的清算位置；
- 目标没有劫雷或劫债时仍可使用，但只造成基础追击伤害。

道途节点可以让《因果回响》读取承劫量或在满劫债时催审，但不保存完整行为历史。

### 4.8 《九霄清算》

共通终式。

基础行为：

- 消耗 2 至 3 点劫数；
- 目标必须带有劫雷或劫债；
- 造成一次高额雷属性清算；
- 根据目标劫债数量提高伤害；
- 清算后按技能规则减少劫债，不直接清除不可驱散劫雷。

流派变体：

- 劫眼临身：伤害额外参考本场记录的承劫量，表达“将所受之劫归还”。
- 天谴加身：伤害额外参考目标重复主罪行为次数，表达“重罪加刑”。

## 5. 劫眼临身

### 道途定位

劫眼临身不是独立的反伤宗门，而是共通天宫底板的承灾偏向：

> 以身为劫眼，主动承受来力；把承受的灾厄转成劫数，再用共通清算归还。

它共享劫数、劫雷、劫债和全部共通技能。它不额外添加独立的“应劫资源”。

### 道途专属状态

道途有两个玩家可见状态：**劫眼**与**照见**。照见持续4次宿主行动、不可普通驱散、死亡移除，不计入普通减益数量。

- 劫眼是短时标记，不是永久形态。
- 劫眼期间，直接伤害记录为承劫量。
- 每次重新施展《承天受劫》都会重置本次开眼预算；第一次直接攻击劫眼的敌人被照见，并按节点施加劫雷或劫债。
- 劫眼结束后，已记录承劫量保留至下一次《九霄清算》兑现。
- 劫眼不能强制敌人攻击自己，避免变成传统嘲讽坦克。

### 六层节点主题

1. **第一层**：开门迎劫、承灾留名、雷光护心——开眼护盾、照见分流与首次受击收益。
2. **第二层**：血甲同书、问劫寻隙、借劫续门——护盾承伤入簿、追究照见者与状态续门。
3. **第三层**：不退天门、劫威反震、静候雷来——低血守门、直接受击反震与空回合收益。
4. **第四层**：众劫归一、雷狱追身、劫甲回生——承劫追击、问行追身与破盾回生。
5. **第五层**：真劫入簿、劫尽身还、清算留门——真实伤害、治疗以及三劫清算后重开。
6. **终极层**：九门归劫、身为天门、劫后再开——满额伤害、承劫护盾或循环重启。

承劫释放顺序固定为非消费治疗、非消费护盾、最终伤害并消费。真劫入簿单独释放45%真实伤害，与九门归劫组合为60%；九门归劫单独释放100%魔法伤害。身为天门额外释放35%魔法伤害和60%护盾；与真劫入簿同时选择时保留45%真实伤害。清算留门与劫后再开组合时只保留一组较长状态。

### 劫眼流派战术

- **引敌入劫**：优先施加《劫簿落印》，再用《承天受劫》承接攻击。
- **闭目归劫**：在敌方爆发前使用防御，等待承劫量进入《九霄清算》。
- **先守后刑**：低血量时不追求继续加雷，先用《借劫回身》保命，再清算。

### 劫眼流派弱点

- 对不攻击自己的目标，劫数获取偏慢。
- 承劫量需要真实承受伤害，不是免费伤害记忆。
- 《九霄清算》前若被击败，积累的承劫量不会自动转为全额反击。
- 不拥有稳定嘲讽、永久减伤或传统反伤循环。

## 6. 天谴加身

### 道途定位

天谴加身不是另一套“罪名技能”，而是共通天宫底板的施罚偏向：

> 先用《劫簿落印》记录目标，再利用目标重复主动行为推进劫债，最后用《九霄清算》兑现。

它共享劫数、劫雷、劫债和全部共通技能。它不额外添加“主罪资源”；主罪只是劫簿上的一个有限记录字段。

### 道途专属记录

道途使用玩家可见的**主罪**与**重犯**记录；二者均受保护、死亡移除且不计入普通减益数量。

- 主罪记录目标最近一次被天宫有效观察到的主动技能类别。
- 主罪不保存全部行为历史，只保存当前最值得惩罚的一类行为。
- 目标重复主罪行为时，劫雷触发额外推进劫债。
- 主罪优先级固定为控制、治疗或治疗混合、伤害、纯增益；一次行动只记录一种。
- 目标改变行为类型时，新主罪按节点规则替换旧主罪；定罪成册可以阻止一次替换，易罪不赦只在真实替换时加债。
- 目标死亡或清算后，按技能规则清除或重置重犯与劫债记录。

### 六层节点主题

1. **第一层**：天听记名、问行取证、初罪立案——重复引雷记债、主动取证与新案奖励。
2. **第二层**：伤罪加刑、援罪断供、禁罪反照——三类主罪各自拥有普通可驱散的即时处罚。
3. **第三层**：易罪不赦、定罪成册、庶行有录——变罪加债、锁罪以及有限记录普通攻击。
4. **第四层**：重法催审、疾书追罪、三问成案——满债催审、冷却联动与按当前主罪强制结算。
5. **第五层**：再犯从重、清册留案、两避成罪——额外劫雷、保留主罪与连续普攻反制。
6. **终极层**：三债终审、九罪同科、天谴不绝——固定两劫满额清算、分类判词与循环重挂。

普通攻击默认只触发基础雷罚；庶行有录每回合最多延长一次，两避成罪只统计劫雷期间同一目标连续两次普通攻击。任意非普通主动技能、劫雷移除或清算都会清空该连续计数。

### 天谴流派战术

- **先记后罚**：先用《劫簿落印》确定目标，再用《天听引雷》建立劫雷。
- **诱其再犯**：目标重复主罪后，用《雷狱问行》推进劫债。
- **重罪清算**：保留劫数，等目标重复行为达到阈值后施放《九霄清算》。

### 天谴流派弱点

- 目标改变行为类型后，重复主罪收益下降。
- 对低频行动、普通攻击和纯被动构筑，劫债推进较慢。
- 天谴加身不能凭空强迫目标行动，也不因目标静止而造成高额伤害。
- 目标优先击杀天宫弟子，新的劫雷来源会立即停止。

## 7. 六本心法与基础数值加成

六本心法全部使用现有 `growthProfile` 和 `panelModifier` 体系。心法的面板收益必须落在已有 `AttributeType` 上，不新增“劫雷伤害”“劫债效率”之类无法归入基础战斗面板的专属属性。

每本心法仍然拥有：

- 一组伤害、治疗、护盾、状态效果成长；
- 除主心法外各有一项符合自身设定的基础面板加成；
- 至少一门基础神通的来源。

| 心法 | 成长曲线 | 面板基础加成 | 设定理由 |
| --- | --- | --- | --- |
| 《九劫天书》 | balanced | 无 | 雷法以神识引动天威，主心法成长直接作用于关联神通 |
| 《劫眼观世》 | early | `MAX_HP`，ADD | 以身为劫眼，必须具备承受第一轮灾厄的肉身 |
| 《天谴录》 | balanced | `MAGIC_ATK`，ADD，满级15% | 天听落罪最终仍以雷法威能兑现，不把宗门主轴放在控制命中 |
| 《雷狱镇魂》 | late | `MAGIC_PENETRATION`，FIXED | 雷狱穿透护持与灵力屏障，强化雷法对法防目标的有效性 |
| 《因果问罪》 | balanced | `MAX_MP`，ADD | 记录因果、维持劫雷和执行清算都需要稳定的法力储备 |
| 《渡劫归真》 | early | `MAGIC_DEF`，ADD | 渡劫不是只会降雷，也要求门人拥有在天罚后继续站立的法身 |

说明：

- 以上均为面板基础数值加成，不把宗门专属机制伪装成属性。
- 《九劫天书》不提供面板属性加成，只提供主心法关联神通和标准心法成长。
- 《天谴录》的 `MAGIC_ATK ADD` 使用现有面板修改器，满级上限为15%。
- 满级上限固定为当前 TypeScript 定义中的数值，不叠加额外专属面板属性。
- 不使用 `STRENGTH`、物理攻击或暴击作为天宫主轴，避免雷法与近战爆发混淆。
- `MAX_HP`、`MAX_MP`、`MAGIC_ATK`、`MAGIC_DEF`、`MAGIC_PENETRATION` 都是现有属性，不扩展 battle-v5 属性枚举。

## 8. 基础神通与解锁底板

基础定义固定以下能力集合，两条道途共同使用：

| 能力 | 类型 | 角色 | 来源 |
| --- | --- | --- | --- |
| 《惊雷指》 | default | fallback | 《九劫天书》1级 |
| 《天听引雷》 | active | generator | 《九劫天书》1级 |
| 《劫簿落印》 | active | generator | 《天谴录》1级 |
| 《承天受劫》 | active | defensive | 《劫眼观世》1级 |
| 《雷狱问行》 | active | combo | 《雷狱镇魂》1级 |
| 《借劫回身》 | active | defensive / utility | 《渡劫归真》1级 |
| 《因果回响》 | active | utility | 《因果问罪》5级 |
| 《九霄清算》 | active | finisher | 《九劫天书》10级 |
| 《天威裁决》 | passive | defensive | always，内部能力及 `foundationPassiveId` |

四槽装配只从这套共通能力中选择。道途节点不额外创造一套平行主动技能，而是通过编译期修改同名能力的 effect plan 和事实描述。

初始装配：

- 《天听引雷》
- 《劫簿落印》
- 其余槽位为空

这样玩家先体验“施雷—等待行动—触发”的核心循环，再逐步解锁防御和清算。

《惊雷指》作为 default 能力独立于四个主动槽存在，不计入初始主动装配，也不参与“施雷—触发—清算”循环。

## 9. 编译和 battle-v5 边界

### 内容编译期负责

- 将共通技能底板编译为完整的 `AbilityConfig`；
- 节点插件通过语义特性启用监听器、状态、效果计划与技能事实，不按节点 ID 集中分派；
- 为同一技能生成流派变体的展示事实；
- 保证四槽主动技能不可重复，并且只能装配已解锁能力。

### battle-v5 只负责

- 行动事件、技能费用、冷却、Buff 生命周期；
- 标签触发、计数器、伤害、延迟伤害、资源修改；
- 既有的不可驱散 Buff 行为；
- 统一伤害管道和效果预算。

### 本版扩展边界

- 只在通用事件词表增加可复用的 `SHIELD_BREAK`，不增加 `jiujie` 专属事件；
- 不增加九种劫数枚举；
- 不增加所有技能类别的永久历史记录；
- 不增加静止强制伤害；
- 不增加并行主罪；任一时刻只保留一个主罪，分类处罚和判词是普通可驱散状态；
- 不在通用层根据宗门 ID 分派逻辑。

“成功进入主动行动阶段”固定以现有 `SkillCastEvent` 判定，并通过 `source_action` 监听预算锁定同一动作最多触发一次。DOT、被动、反伤、延迟伤害和状态自然结算不会发布该事件，因此不触发劫雷；不可驱散状态也不会被普通清除效果移除。

## 11. 视觉和文案基准

### 视觉

- 主色：深夜蓝、青白雷光、暗紫、炭黑、克制旧金。
- 建筑：悬浮残宫、断裂天柱、黑金宫墙、雷链、半毁天门。
- 劫眼临身：暗紫、焦黑、圆形祭坛、巨眼雷纹。
- 天谴加身：冷白、黑金、雷简、垂直天罚光柱。
- 整体：庄严、秩序化、具有天道官署感，不表现为邪异雷魔。

### 文案

技能描述按以下顺序书写：

1. 先说明天宫弟子做了什么；
2. 再说明目标身上的劫雷或劫债如何变化；
3. 最后说明消耗、清算或流派节点带来的差异。

避免：

- “目标所有行为均受惩罚”这类绝对描述；
- 把劫雷写成普通毒、灼烧或流血；
- 把劫眼写成永久嘲讽或无条件反伤；
- 把天谴写成完整的罪名数据库；
- 用宗门专属名词替代实际战斗效果。

## 12. 第一版交付边界

第一阶段实现范围：

1. `jiujie` 宗门生产注册内容。
2. 六本心法、面板基础数值加成、基础神通。

8. 共享引擎测试、宗门内容测试、能力行为矩阵测试。

本版实施规格已经固定：资源 ID 为 `sect.jiujie.calamity`，行动判定使用 `SkillCastEvent`，劫雷和劫债使用现有 `protected` 驱散策略，主罪只记录伤害、治疗/增益、控制三类。普攻通过通用 `GameplayTags.ABILITY.KIND.BASIC` 与主动神通区分。

节点具体效果由“基础参数 + 两组语义特性”的 `JiujieBuildSettings` 和两个流派私有 Build Facade 编译，不在 battle-v5 中增加 `jiujie` 分支。36个稳定节点 ID、既有技能 ID、资源 ID 与参悟存档保持兼容；节点可以改变规则与循环，但不创建第二套技能或资源。
