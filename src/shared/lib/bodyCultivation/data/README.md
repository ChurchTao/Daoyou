# 炼体成长与战斗收益

`body-cultivation.json` 是五轨标签、七个肉身位阶、进度需求和战斗收益的权威来源。编辑器使用同目录 JSON Schema，运行时严格校验；发布需要重新构建／启动。

- tracks 中四轨各映射一种修炼属性，perLevel 为每级收益；气血轨使用 hpRatioPerLevel 与 healLevelsPerPoint。气血增益仍以裸身面板为基数，最后向下取整；治疗仍按等级除以步长后向下取整。
- realms 保持现有七位阶身份和顺序。总等级门槛、修为境界与单轨上限可编辑；门槛必须能在前一位阶五轨上限内达到。解锁说明自动读取上限，避免重复填写数字。
- 战斗投影最高等级读取最后位阶的 softTrackCap，存储归一化不截断已有等级；调整上限会影响已有角色的当前战斗收益，历史战斗快照不重新编译。
- progress.base + progress.perLevel × 当前等级是下一等级所需进度，计算前保持原有非负整数化。milestoneInterval 只控制摘要中的下一里程碑显示，不新增里程碑奖励。
- 丹药执行器与轨道注册表继续通过原阈值入口读取配置。当前肉身进阶只校验总等级与修为境界，没有额外资源费用，本包没有新增扣费。
- 界面摘要仍展示存储等级对应的下一等级收益；超出战斗上限时，战斗投影按上限夹取并给出原诊断。此次保留原语义，不改写历史等级。
- 五轨和位阶的 ID 是现有持久状态结构的一部分，增加轨道、位阶或效果类型仍需代码扩展；formatVersion／contentRevision 不替代 condition 版本。
